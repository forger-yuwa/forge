## Gate A — 自由流の再構成 (**整合診断**。独立検証ではない)

> **訂正 (2026-09-20, codex result M3)**: 当初「$q$ と $Re'$ が独立実測なので過決定の検証になる」
> と書いたが、**原典 p.9 は自由流条件を燃焼器の温度・圧力から ref.5 / ref.7 の物性・較正で
> 還元したと明記している**。$q$ も $Re'$ も同じ還元の産物なので独立ではない。
> ここで示せるのは「**私の気体モデルと膨張計算が原典の還元と整合する**」ことまで。
> $P_{t,t}/P_{t,c}$=0.287 も $M$=7 を仮定して逆算した**暫定的な再構成値**であり、
> 「燃焼器から試験部への全圧損失が原因」という機構の断定はしない (系列別の $Re$ 差も最大 29.6 %)。

$P_{t,c}$ をそのまま等エントロピー膨張させると台帳と合わない。$M$ を自由にして
$q$ と $Re'$ から別々に解くと **9.2 と 10.5** になり (公称 7.0)、互いにも 16 % 食い違う。
8-ft HTST は燃焼駆動の blowdown なので、**燃焼器から試験部までの全圧損失**を見ていないのが原因。

そこで **$M$=7 を固定し $q$ から試験部全圧 $P_{t,t}$ を解き、$Re'$ を予測して実測と比べた**
(未知 1・条件 2 の過決定)。

```
Pt_t/Pt_c : 0.248 - 0.311 (中央 0.287), ばらつき 22 %   ← Pt_c は 4.2-17.3 MPa と 4 倍振れている
Re 予測/実測 : 0.957 - 1.296 (中央 1.061)   最悪 run 4 (1.296)
GATE A VERDICT: PASS
```

$P_{t,c}$ を 4 倍振っても回復率が一定なのは固定ノズルの挙動として筋が通る。回復率は $q$ だけで
決めており $Re'$ は別経路の検算だが、**両者とも同じ還元から来ているので独立ではない**。
言えるのは台帳・気体モデル・$M$=7 が互いに整合している、というところまで。自由流は $T_\infty$ 180–195 K、
$p_\infty$ 0.26–1.0 kPa、$U_\infty$ 1930–2130 m/s、$T_{aw}$ ($r$=0.89) 1530–1740 K。
ツール `tools/conditions.py` → `derived.json`。

## Gate B — 分母 $q_{FP}$ の独立検算 (**PASS**)

Eckert 参照温度法 (層流 Blasius / 乱流 1/5 乗則) で $q_{FP}$ を独立に組み、Table III の
絶対値と比べた。**合格条件は「1.0 に合うこと」ではなく、本文が明記する偏りを再現すること**:

> 層流 — 理論が実測より約 10 % 高い / 乱流 — 理論が実測より約 30 % 高い

```
層流 理論/実測 : 0.980 - 1.133 (中央 1.072)   ← 本文 1.10
乱流 理論/実測 : 1.194 - 1.549 (中央 1.335)   ← 本文 1.30
GATE B VERDICT: PASS
```

**中央値が本文の値と 3 % 以内で一致**した。Gate A の自由流 ($M$=7 + 回復率 0.287)、
燃焼ガス物性、$q_{FP}$ の転記が一貫していることの強い裏づけになる。

> **迎角を落とすと合わない**。乱流 run の多くは $\alpha$=7.2–7.6° で、自由流条件のまま
> 計算すると理論/実測が **0.50–0.65** に落ちる ($\alpha\approx0.2°$ の run 8/14 だけ 1.21)。
> パネルは平板なので**斜め衝撃波の背後**が縁条件になる (局所 $\gamma(T_\infty)$、$\beta$ =
> 8.3° @ $\alpha$ 0.2° → 14.1° @ $\alpha$ 7.6°)。これを入れて上表になる。

ツール `tools/flatplate.py` → `gateB.json`。

### $\delta^*$ との比較 (**実測ではなく別コードの計算値**)

> **訂正 (2026-09-20, codex result M3)**: Table II の $\delta^*$ の出典 ref.6 は
> **`Computer Program for the Design and Analysis of Hypersonic Inlets`**
> (Maslowe & Benson, Lockheed, NASA CR-77749) — **計算プログラム**である。
> 「別の測定量による独立検算」ではなく、**別コードの計算値との比較**。

| 位置 | $\delta^*$ forge [cm] | $\delta^*$ 実測 | 比 | $\delta^*/\delta_{99}$ |
| --- | --- | --- | --- | --- |
| I | 0.870 | 1.13 | **0.770** | 0.537 |
| II | 1.343 | 1.62 | **0.829** | 0.520 |

**$q$ が 20 % 高く $\delta^*$ が 20 % 薄いのは符号が整合している** (薄い BL は熱流束が高い)。

と考えられる。$\delta^*/\delta_{99}$ = 0.52–0.54 は $M$ 7 冷却壁として妥当。

## T4-G0 (成立ゲート) — 答えが出た: **2D 断面は取れない**

Fig 4 / Fig 5 を読んだ結果、**前向き壁の熱電対は縦すきま中心線から高々 6 mm 以内**に
収まっている (横方向オフセットが 0.152–0.305 cm 刻み)。$W$ が 0.10–0.41 cm なので、
**計測点はすべて縦すきま幅の数倍以内**、つまり深さ分布は**縦すきま流の衝突域で測られている**。
衝突から離れた「素の横すきま」断面は存在しない。

含意は 2 つ。

1. **T4 の深さ分布は横すきまの上界**である。case/49 (環状深キャビティ、縦すきまの供給なし) に
   そのまま当てると**過大評価**になる。
2. **素直に比べるなら 3 次元計算が要る** — 縦すきま × 横すきまの交差部をそのまま解く。
   幾何は完全に文書化されている ($L$=15.24 cm, $W$, $\theta$, タイル厚 6.35 cm, エッジ半径 0.25 cm)、
   流入はフェンスで一様 2 次元、分母は計算可能。**validation として筋は通る**が計算量は大きい。

**踏んだ罠 (記録)**

- **`gen_mesh_gap.py` (B1–B6) は使えない**。谷を鉛直線で 3 列に割る方式は、円弧の下端で壁も
  格子線も鉛直になり第一層が潰れる。2D 既定で skew 0.992 / 712 セル超過 = `gap2d_w018.h5` と同一。
- **VOUT (谷の上) を transfinite で張ると悪化する**。底辺が $s_{u1}/s_{d1}$ で 90° 折れるため
  第一層が楔になり skew 0.98。対辺点数を合わせても直らない。**非構造+recombine に任せる**のが正解で、
  2D の `gap2d_v4` が三角形 24 枚を含んでいるのはこの理由 (欠陥ではない)。
- **谷の天面 (`tV`) の点数を対辺に合わせて細かくすると、非構造メッシャが薄い三角形を量産する**。
  対辺一致 (`--n-vtop 0`) だと scale 1.0 で prism 14,768 枚の **85 % が skew>0.9**、全体 0.285 %。
  `n_core` 相当まで粗くする (既定 `--n-vtop -1`) と prism は 3,124 枚に減り**不良ゼロ**、
  全体 0.027 % になった。plan #50 が `gap4` の「対辺点数不一致」を欠陥と書いたが、
  **谷に関してはそれが正しい設定**である (#50 の訂正はこの行)。
- **トレンチ (縦すきま断面) は 1 ブロックにする**。上面と円弧の接点 $v_{u0}$ を**辺の途中**に置き、
  角は 90° の所だけにする。2 ブロックに割って接点を角にすると内角 180° で skew 0.98、
  深さ方向全域 (2.9 % のセル) が汚れた。
- **透過的に見える「もう 1 つの谷」も構造化しない**。腕 B の上流横すきま (`VOUTb`) は
  主すきまの谷と同じ形なので、同じ扱い (非構造+recombine、天面は `n_core` 相当) にする。
- **`setTransfiniteSurface` を同じ面に 2 回呼ぶと後の呼び出しが角を上書きする**。
  既定の角 (境界点すべて) で呼び直すと `Surface N is transfinite but has 6 corners` で落ちる。
- **変換器は節点番号が密であることを要求する**。gmsh は幾何点のぶん番号に穴を空けるので
  `renumberNodes()` が要る (`Error: unknown gmsh format. Nodes numbers` で落ちる)。
- **transfinite 面に `setSmoothing` を掛けてはいけない**。skew は下がるが median-dual が閉じず
  変換が `bcond無` で落ちる。
