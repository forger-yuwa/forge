# case/56 — TP-1187 すきま加熱 (乱流, M≈7) = **T4 乱流一次検証**

**T4**。[A78] NASA TP-1187 (Avery 1978) を乱流の一次検証に立てる。
2026-09-20 に **T2 (TN D-8233) を探索に降格**し、その差し替えとして新設した。

計画: [`plans/active/case-hypersonic-gap-heating-validation.md`](../../plans/active/case-hypersonic-gap-heating-validation.md) §3.1 / §5.1 #22

## なぜ差し替えたか

| | TN D-8233 (旧 T2) | **TP-1187 (T4)** |
| --- | --- | --- |
| 分母 $q_{FP}$ の素性 | 3 次元化したトンネル壁 BL の実測相関 | **同一パネルホルダ上の 2D 平板較正パネルの冷壁実測** |
| CFD で分母を作れるか | **作れない** (角干渉・圧縮領域・局所壁圧が要る) | **作れる** (分子分母とも冷壁 $q$、同一模型・同一手法) |
| 流れ場 | 正方ノズル角干渉 + 圧縮領域 | 空力フェンスで**一様 2 次元**、鋭利前縁 + BL トリップ |
| $\delta^*/W$ | 46–56 | **4.7–9.0** |
| 理論とのずれ | **未記載** (実測で最大 2 倍) | **本文が明記**: 層流 理論が 10 % 高、乱流 約 30 % 高 |

分母の定義は $q/q_{FP}$ (**冷壁 $q$ 比。駆動温度差で割らない**)。

## T4-G0 (成立ゲート) — 先に片付ける必要がある

**すきまが流れ方向 (longitudinal)** で、計測壁は**縦すきま流が横すきまと交差して衝突する**面である。
case/49 (横すきま、流れは開口を横切る) と対応づけるには、**衝突域から離れた位置の熱電対**を
選んで「横すきまとしての深さ減衰」を取り出せるかを先に確かめないといけない。
これは旧 T2-G0 と同じ性質の仮定だが、**基準流れが本物の 2 次元平板である**ぶん筋が良い。

→ 先決は **熱電対番号と座標の対応 (Fig 4 / Fig 5) の digitize**。
