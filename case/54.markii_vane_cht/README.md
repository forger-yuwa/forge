内部条件の逆算 (`ref/run42_internal_bc.json`) の残差床は **RMS 7.78 K** ($T_c$ 280→350 K で 7.84→7.59 K
とほとんど動かない = C3X と同じ縮退)。

**読み方**: **正圧面は $h$ が +0.8 %、壁温が −0.2 K / RMS 12.0 K** で、同定の残差床 7.8 K に近い。
連成そのものは効いている。外れるのは**負圧面前縁の層流域**で、実測は強い順圧力勾配で
$s/S\approx0.25$ まで層流を保ち $h/h_0$ が 0.22 まで落ちるのに、遷移モデルを持たない低 Re SST は
前縁から乱流になって $h/h_0$ を 1.0 まで上げる (+74.8 %)。その入熱が固体に伝わって壁温が +42.8 K になる。
C3X (亜音速出口) の同じ領域が +40.5 % / +21.4 K だったのに対し **Mark II では倍近い** —
超音速負圧面のほうが層流区間が長く、遷移モデルの欠如がそのまま効く。

→ **V5 の合否は「連成が正しいか」と「乱流モデルが遷移を持つか」を分けて述べる**。
前者は正圧面 (両翼) と C3X 遷移後で確認できた。後者は plan §5.1 #29。

### `run_0001` が収束しなかった理由 (2026-09-20)

`outlet_statPress` は**面ごと**に $M\ge1$ なら全量外挿・$M<1$ なら背圧アンカーへ切り替える
(SU2 `BC_Outlet` と同型で、それ自体は正しい)。ところが長い下流ブロックでは後縁衝撃と膨張波が
周期境界で反射を繰り返し、出口面が **M 0.87–1.67 のまだら**になる。すると面ごとに閉包が
毎ステップ入れ替わり、超音速側 (P≈72 kPa) と亜音速側 (背圧 169.9 kPa) で **2.4 倍の圧力段差**が
境界に立つ。スナップショット間の $|\Delta P|$ は出口ブロックで rms 40 kPa・最大 97 kPa、
上流ブロックでは rms 3.8 Pa しかない — **振動源は出口境界**である。

対策は下流を短くして、出口面を一様に超音速側へ寄せること。物理的な後縁シェディングと
区別するため、短縮後も `check_quasisteady` の VERDICT を見る。

### メッシュ変換時の落とし穴 (2026-09-20 に恒久対策済み)

周期境界の対応付け (`mesh.cpp: setPeriodicPartner`) は**平行移動した面重心の最近傍**を取るだけで、
距離を検査していなかった。ピッチを m でなく cm 換算で書いて `dy` が 100 倍小さかったとき、
変換も計算もエラーを出さずに**「完走したが M=1264・P=1 Pa」**の場を返した。
現在は対応後の残差距離 (> 0.25 × 最小面寸法で停止) と 1 対 1 性を検査し、正常時も
`[setPeriodicPartner] physID 3 <-> 4: 214 faces, max residual 2.98e-08 m (face size 0.0228 m)`
のように出す。
