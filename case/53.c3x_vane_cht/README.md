## 実験データの定義と自己検査 (`ref/run108_surface.csv`)

報告 p.125 (付録 A の前書き) より:

- **温度は 811 K (1460 °R) で正規化**、**熱伝達係数は $h_0$ = 1135 W/m²K (200 Btu/hr/ft²/°F) で正規化**。
- $h$ は**ガス全温 $T_g$ 基準** (p.21: 有限要素の入力は「実測外表面温度・冷却孔の熱伝達係数・2D 断面形状・
  材料熱伝導率・**ガス流の全温**・各孔の平均冷却剤温度」)。よって $q = h\,(T_g - T_w)$。
- run 108 に当てると: $T_w$ = 513–612 K、$h$ = 327–895 W/m²K、$q$ = 87–206 kW/m²。

**自己検査**: 転記した $T_w$ の単純平均は 562.4 K で、報告の $T_w/T_g$ = 0.73 ($T_{T1}$=786 K → 573.8 K) に対し
**0.716 (−1.9 %)**。平均の定義 (弧長重み・対象点の範囲) の差と考えられる。**転記ミスではない**ことの根拠として、
全 75 点が単調性・範囲の検査を通り、分布形も物理的 (前縁で $h$ 最大、負圧面で遷移して上昇) である。

### それでも段 (b) は「逆算」のままである (理由)

公開されているのは**冷却剤温度と流量**で、**孔の熱伝達係数 $h_c$ そのものではない**。
報告は「孔径・実測流量・冷却剤温度から Nusselt 数を計算し $C_r$ を掛ける」としか書かず、
**どの相関かを書いていない**。Dittus–Boelter $Nu=0.023Re^{0.8}Pr^{0.4}$ に $C_r$ を掛けると
$h_c$ = 1489–2892 W/m²K (C3X) になるが、**これを固体に課すと外表面温度が実測より 30 K 冷たくなる**
(RMS 62 K、全体倍率 1 個で合わせても RMS 60 K = **分布が違う**)。

さらに**冷却孔の位置は公開されていない** (図 6/7 の (U,V) 系から剛体変換を最適化して決めた、下記)。
したがって内部側には**推定が 2 つ** (孔位置・相関) 入り、$h_c$ の同定はその誤差を吸収する。
実際、同定値と相関値の比は C3X で **0.14–4.0** とばらつく (Mark II は 0.44–1.70 でまし)。
感度解析では $\partial T_w/\partial\ln h_c$ の最小特異値が **65 K** で条件数 36 — 逆問題自体は
解けている。**ばらつきは条件数のせいではなく、モデル (孔位置) の誤差**である。

→ **V5 の扱いを次のように分ける** (2026-09-20 改訂):
- **段 (a) 実測 $T_w$ → $h$** が forge の検証の本体。内部条件を一切使わないので clean。
- **段 (c) 連成壁温**は、内部条件が推定を含むぶん **forge の検証としては弱い**。
  連成機構 (固定点に到達するか・界面熱量が保存するか) の実証と感度解析として扱い、
  実測との一致度を forge の精度として宣伝しない。
- **$T_c$ は公開値 (孔ごと) を使う** (`--Tc-published`)。これで旧稿の「$T_c$ と $h_c$ の縮退」は
  帯の項目から外れる ($T_c$ はデータであって自由度ではない)。残差床は C3X 9.98 K / Mark II 7.70 K。

## 固体メッシュと内部条件の逆算 (V5 段 (b) 相当、**CFD 不要**)

- **固体メッシュ**: `tools/gen_solid_mesh.py` → `mesh/solid_c3x.npz`
  (4127 節点 / 7712 三角形、外周 **240 節点** を弧長等間隔に配置 = 流体メッシュと 1 対 1 で合わせるため、
  冷却孔は各 32 辺の物理曲線)。外周弧長 31.98 cm (表 IV の SS+PS = 31.505 cm に対し +1.5 %。
  復元した前縁/後縁円弧の分)。
- **内部条件の逆算**: `tools/infer_internal_bc.py` → `ref/run108_internal_bc.{json,png}`。
  外表面に $q = h\,(T_g-T_w)$ (実測) を Neumann で課し、孔ごとの $h_c$ を最小二乗で同定する。

**結果 (run 108, $T_c$=300 K, $k_s$=17.2 W/mK)**:

| 量 | 値 |
| --- | --- |
| 同定した $h_c$ | **313 … 4207 W/m²K** (平均 1744)。前方の $\phi$6.3 mm 孔で 300–500、後縁側の小径孔で 2900–4200 |
| 外表面温度の残差 | **RMS 10.7 K / 最大 35.4 K** (実測 $T_w$ の幅 513–612 K) |
| 熱収支 | 外表面入熱 41.4 kW/m = 孔からの排熱 (機械精度で一致) |

**この逆算で分かったこと (V5 の設計に効く)**:

1. **$h_c$ と $T_c$ は縮退する** — データが拘束するのは概ね $h_c\,(T_w-T_c)$ の積。
   $T_c$ を 280→350 K と振っても RMS は 10.65→10.83 K とほぼ動かず、$h_c$ の平均だけが 1595→2662 と動く。
   $T_c \gtrsim 400$ K では一部の $h_c$ が 1e5 W/m²K へ走る (局所壁温が $T_c$ に近づくため) ので**非物理**。
   → **$T_c$=300 K を代表に採り、280–350 K の幅を帯に積む**。
2. **残差床 10.7 K は弧長原点の取り方に鈍感** (原点を ±0.5 cm 動かして RMS 10.5–10.7 K)。
   つまり**マッピングの曖昧さが原因ではなく、10 孔 Robin + 2D 伝導というモデルの限界**。
   → **V5 段 (c) の CHT 予測を「実測と一致」と言えるのは、この 10 K 級の床より内側に入ったときだけ**ではなく、
   逆に**床より小さい差を主張してはいけない**。帯の下限としてこの値を登録する。
3. **後縁側 35/240 節点はデータ範囲外** ($s/S>0.87$)。外挿した熱流束を課すと固体温度が 950 K まで跳ねる
   (図の破線)。**後縁の固体温度は検証対象外**と明示する。

~~$h_c$ の妥当性: $\phi$6.3 mm 孔で Dittus–Boelter 相当は $Re_D\sim3\times10^4$~~ →
**誤り (2026-09-20)**。公開された流量から $Re_D$ は **2.2×10⁵** (7 倍大きい)。この $Re$ で
Dittus–Boelter は ~2000 W/m²K になり、同定値 (218–4706) の**前方 7 孔は 3–9 倍小さい**。
「整合する」という旧稿の主張は、間違った $Re$ 見積りに基づいていた。上節の扱いに従う。

### V5 段 (a) の結果 — 実測 $T_w$ を課した $h$ (`run_0003_smoothgeom`, 2026-09-20)

$h = q_w/(T_g-T_w)$、$T_g$ = 入口全温 786 K、$h_0$=1135 W/m²K。$q_w$ は界面診断
`iface_q_compact` ($k_{\rm eff}(T_1-T_w)/d_1$)。比較はデータ範囲 $s/S\le0.87$ の 402 節点。

> **報告する熱流束の定義を変更した (2026-09-21、ユーザ指示)**: 以後の $h$ は**保存形
> `iface_q_eff`** (壁半 CV に実際に入った粘性エネルギー流束 ÷ 面積) を一次に取る。plan
> [`boundary-conjugate-heat-transfer`](../../plans/active/boundary-conjugate-heat-transfer.md) §4.3 の
> 正本であり、実測 $h$ も金属の熱収支から出ているのでこちらが対応する量。`compare_h.py --flux`
> の既定、`cht_loop.py --flux` の既定とも `q_eff` に変更済み。**本節以前の表は
> `iface_q_compact` の値**で、C3X では保存形の方がバイアスで約 2.2 pt 大きい。
> **SU2 と比べるときだけは `iface_q_compact` 同士**にすること — SU2 の `Heat_Flux` は等温境界で
> $k(T_{here}-T_{wall})/d_{ij}$ (`CFVMFlowSolverBase.inl:2638`) と同一構成で、保存形の出力を持たない。

| 領域 | 節点数 | バイアス | RMS |
| --- | ---: | ---: | ---: |
| 正圧面 (全域) | 164 | **+10.6 %** | 21.7 % |
| 負圧面 **層流域** $s/S<0.25$ | 109 | **+40.5 %** | 53.9 % |
| 負圧面 **遷移後** $0.25\le s/S\le0.87$ | 129 | **+4.0 %** | 11.0 % |
| 全体 | 402 | +16.6 % | 31.9 % |

**読み方**: 負圧面の遷移後は **+4 %** で一致する。外れるのは**負圧面前縁の層流域**で、
forge は前縁から乱流になり、実測が $s/S\approx0.17$ まで $h/h_0$ を 0.42 まで下げてから遷移するのを
再現しない。**低 Re SST に遷移モデル ($\gamma$–$Re_\theta$ 等) が無いため**で、C3X で広く報告されている
挙動と同じ。CHT (段 (c)) の壁温予測にはこの層流域の過大評価がそのまま効くので、**V5 の帯に
「遷移モデル無し」の項目として積む**。
$q_w$ の定義差は小さい (compact 基準で 2 次片側 +3.1 %、再構成勾配 −0.05 %)。
ソルバ出力 `qwall` は `iface_q_recon` と**同値で符号が逆** (ガス側正)。

収束: `check_convergence.py` は `NOT CONVERGED (stalled/plateau)` (前 run の収束場から
cross-mesh restart したので低下幅が 1.2–2.1 dec しか無い)。**報告量の側で判定**すると
`check_quasisteady.py --series-csv wall_series.csv` が **`q_total: STEADY` (drift 0.1 %)**、
壁 $h$ 分布の step 30000→60000 の変化は **rms 1.45 % / 最大 7.6 %**、場の残る変化は前縁付近で
$|\Delta\rho|/\sigma_\rho \le 0.08$。**「残差はプラトー、報告量は定常」**として扱う。


### 負圧面後縁の壁圧 — 背圧の定義誤りと SU2 対照 (2026-09-20, plan #44)

後半 ($s/S>0.45$) の壁圧が $P_s/P_{T1}$ で実測より **$-0.026$ 低く**、後縁へ向かって拡大していた。
**同一メッシュ・同一 BC の SU2 8.5 も同じだけ低い** (下表、差 0.0002) ので**ソルバ起因ではない**。

真因は背圧の定義。報告の $M_2=0.90$ は翼列の標準定義である**入口全圧からの理想出口マッハ**
($P_{s,\rm exit}=188{,}908$ Pa) だが、`setup_run.py` は「出口面の**局所** $P_t$ から計算した $M_2$」が
0.901 になるまで追い込んでいた ($185{,}064$ Pa = 理想 $M_2$ **0.919**)。
**翼列損失 1.9 % を二重に引いて**背圧が 2.1 % 低かった。

| $s/S>0.45$ の bias (Ps/Pt) | forge 185.1 kPa | SU2 185.1 kPa | forge 188.9 kPa |
| --- | ---: | ---: | ---: |
| 負圧面 | $-0.0257$ | $-0.0259$ | **$-0.0125$** |
| 負圧面 rms | 0.0349 | — | **0.0232** |
| 正圧面 | $-0.0261$ | $-0.0263$ | $-0.0232$ |
| 負圧面 前半 ($s/S<0.45$) | $-0.0129$ | $-0.0131$ | $-0.0094$ |

訂正後も**後縁へ向かって残る欠損**があり (正圧面 $-0.0232$ / 負圧面 $-0.0125$)、これも両コードで同一。

**消した候補 (2026-09-20)**:

1. **翼型の digitise — 無罪**。報告 Table III の座標そのものから測った喉は $o/\text{pitch}=0.2881$ (出口角 **73.26°**)、
   メッシュ実測は 0.2871 (73.32°)、計算された気流角は 73.04°。三者が一致する。
   平滑化翼の表点からの最大ずれ 0.0104 cm は報告の外形不確かさ ±0.008 cm と同等。
2. **周期出口ブロックの角度 — 効かない**。`gen_fluid_mesh.py` の `exit_angle` 72.38° (表 IV 設計値) は
   報告座標が与える 73.26° と **0.88° (喉幅で 5.4 %)** 食い違っているが、
   `run_0026_exitangle_7326` の A/B で**壁圧の bias/rms は 4 桁まで同一**、出口気流角も 73.07 → 73.06°。
   流れが自分で出口角を決めるので、ブロックの向きは境界条件として効いていない。

3. **$s/S$ 定義のずれ — 説明にならない**。測点の abscissa に一律シフトを当てて rms を最小化すると、
   **負圧面は最適シフトが $-0.006$ しかなく効果も僅か** (rms 0.0261 → 0.0248)。
   正圧面は $-0.042$ で rms が半減する (0.0268 → 0.0139) が、**符号が淀み点仮説と逆**
   (計算の淀み点は幾何 LE から正圧面側へ $+0.021$ なので、報告が淀み点起点なら $+0.021$ が要る)。
   急勾配曲線への当てはめの産物とみなす。

**残る候補 (未検証)**: 2D 仮定 (端壁 BL による AVDR≠1 — forge に流管収縮を与える手段が無く、
報告も AVDR を載せていない)、鈍後縁のベース圧。**現時点では未帰属**。
ただし両コードで同一なので **forge の欠陥ではない**。plan §5.1 #44(c)。
根拠 run: `case/53.c3x_vane_cht/run_0009_uniformTw/`, `run_0025_pb_idealM2/`, `su2_run108/`。

#### 決定的事実 — 強制側では壁半割面の流束が解に入らない (`run_0040_wallflux0`)

強制のまま**壁半割面の熱流束だけを 0** にしても、場は run-to-run ノイズ床の **0.70–0.85 倍**しか変わらない。

**まるごと捨てられている** (診断 `ifaceFw`/`qwall` にしか出ない)。

したがって**強制側の市松は壁 BC の流束離散化からは原理的に生じ得ない**。
ただし**壁温ピン自体は内部勾配に効く**ので「壁 BC 全体が無関係」とまでは言えない
(反例: cell はゼロ化対象外、`Qw_Wall` の W–I 置換は内部点側に残る。codex 2026-09-20)。

### 正体: 「温度の市松」は $P$ と $\rho$ の打ち消し残り (2026-09-20 深夜、codex 指摘)

codex の「理想気体では $\delta T/T \approx \delta P/P - \delta\rho/\rho$ なので、$P,\rho$ が小さくても
$T$ が小さい保証はない」という指摘を検算したところ、**log の Nyquist 射影で恒等式が厳密に成立**した (残差 0.0000)。

| --- | ---: | ---: | ---: | ---: | ---: |

**$P$ と $\rho$ の 2 節点成分は両コードでほぼ同じ大きさ** (0.021–0.027 %)。違うのは**打ち消し精度**だけ:

- **SU2**: $\delta P/P$ と $\delta\rho/\rho$ が **0.5 % 以内で一致** → 2 節点モードが**等温**で $T$ に出ない。
- **forge**: **6 %** (平滑) 〜 **15 %** (粗) ずれ、その差がそのまま $T$ の交番になる。

比 $(\delta P/P)/(\delta\rho/\rho)$ は forge **1.062**、SU2 **1.000**
(等温なら 1.000、等エントロピーなら $\gamma=1.4$)。
**forge の 2 節点モードは等温から 6 % だけエントロピー側にずれている**、というのが正体。

**したがって「エネルギー方程式のバグ」ではない** — エネルギー方程式は EOS と厳密に整合している。
問題は**ソルバがどの性質のモードを許すか**であり、$\mu_t$・壁閉包・応力形・熱伝導補正を
いくら直しても $T$ が動かなかったのはこのためである。

#### 真因: **再構成する原始変数の選び方**が違う

[`CEulerVariable.cpp:38-41`](../../.external/su2-src/SU2_CFD/src/variables/CEulerVariable.cpp) —
理想気体・低マッハ補正なし・ROE (本ケース) では

```cpp
if (ideal_gas && !low_mach && (Upwind == ROE || Upwind == MSW)) {
    // Based on CRoeBase (numerics_simd).
    return ndim + 2;      // 2D なら 4
}
```

原始変数の並びは `[T, u, v, P, rho, h, c]` (`LowMachPrimitiveCorrection` の添字 `nDim+1`=P, `nDim+2`=rho, `nDim+4`=c から確認)。
したがって **SU2 が MUSCL 再構成するのは `T, u, v, P` の 4 つだけで、$\rho$ は再構成せず EOS から導出**する。

| | 再構成する量 | 導出する量 |
| --- | --- | --- |
| **SU2** | $T$, $u$, $v$, $P$ | **$\rho = P/(RT)$** |
| **forge** | $\rho$, $u$, $v$, $w$, $P$ ([`convectiveFlux_slau_d.inc.cuh:167-181`](../../solver_density_cuda/cuda_forge/convection/convectiveFlux_slau_d.inc.cuh)) | **$T = P/(\rho R)$** |

**これで全部説明がつく**:
- SU2 は $T$ を**直接再構成**するので面の $T$ は滑らか。不整合は $\rho$ に行き、$\rho$ が $P$ を正確に追う (実測 −0.0211 vs −0.0210)。
- forge は $T$ が**独立な 2 つの再構成の差**なので、両者の不一致をそのまま浴びる。
- $\mu_t$・壁閉包・応力形・熱伝導補正・スキーム・精度をどういじっても $T$ が動かなかったのは、
  どれも**再構成する変数の選び方**に触っていないから。

さらに SU2 には `ComputeConsistentExtrapolation` (「再構成量を**熱力学的に整合するよう**再計算する」) と
`LowMachPrimitiveCorrection` があり、理想気体ではどちらも飛ばされる。
**再構成変数の選び方だけで整合が取れているため**であり、SU2 がこの問題を設計として認識していることが分かる。

#### 候補 (c) 「分子輸送が SU2 と違う」は照合して棄却 (2026-09-21)

`gasProperties_d.cu:58-66`) で、`thermCondMethod: 1` が $k=\mu c_p/\mathrm{Pr}$、`prandtlLam: 0.72` /

#### 真の経路は乱流熱伝導 (2026-09-21)

`run_0085_prt1e6_long` で**乱流熱伝導だけを実質 OFF** (`turbulentPrandtl: 1.0e6`) にすると、
比が **1.027 → 0.986**、$A_T$ が **−0.00051 → +0.00013 %** (SU2 は +0.0001 %) になる。
$T$ の交番は乱流熱流束 $-(\mu_t/\mathrm{Pr}_t)c_p\nabla T$ が**減衰させているのではなく駆動している**。
機構は $\nabla\cdot q$ の交番成分 $\propto \nabla(\mu_t/\mathrm{Pr}_t)\cdot\nabla T$ で、壁法線温度勾配が
$4.5\times10^6$ K/m と巨大なので、$\mu_t$ のわずかな交番が大きな交番熱源になる。
ただしこれは物理を壊す診断で生産には使えない (判定も `DRIFTING`)。

#### 候補 (b) 「SLAU にエントロピー波散逸が無い」は**誤り** (codex 2026-09-21)

当方は「SLAU の質量束散逸は $\Delta P$ 比例項しか持たない」と読んだが、**見落としだった**。
一定速度・一定圧力の密度摂動 (接触波) では `convectiveFlux_slau_d.inc.cuh:531-534` で
$\widehat{|V_n|}_p=\widehat{|V_n|}_m=|u_n|$ となり、`:562` は厳密に

$$\dot m/S_f = \tfrac{u_n}{2}(\rho_L+\rho_R) - \tfrac{|u_n|}{2}\Delta\rho$$

で、第 2 項がまさに接触波散逸である。`:422-423` の完全気体エンタルピーと `:593-597` の風上輸送を
合わせると、散逸は接触波方向 $r_s=(1,u_x,u_y,u_z,|u|^2/2)$ に対して
$-\frac{S_f}{2}|u_n|\Delta\rho\,r_s$ となり、質量だけでなく運動量・エネルギーまで整合している。
forge の Roe も同じ成分を持ち ($-\frac{S_f}{2}|u_n|(\Delta\rho-\Delta P/c^2) r_s$)、
**純粋な接触波では両者の減衰率は同じ** $\lambda_s=|u_n|$。

**指標の解釈も訂正**: 接触波成分の射影は $A_\rho - A_P/\gamma$ であって $A_T=A_P-A_\rho$ ではない。
**$R=1$ は「等温」であって「エントロピー波成分ゼロ」ではない**。$R=1.027$ は $A_T = 0.027 A_\rho$ の意味で、
「温度交番が 2.7 %」ではない。

#### 現行の候補: 接触波散逸の**速度下限**が SLAU に無い

Roe は `convectiveFlux_roe_d.inc.cuh:342-344` で $\lambda_j\leftarrow\max\{\lambda_j,\epsilon(|U_a|+c_a)\}$ を
**接触波を含む全固有値**に適用する。SLAU の `mdot` にはこの下限が無い。
**近壁では面法線速度 $u_n$ がほぼ 0 なので、SLAU の接触波散逸 $|u_n|\Delta\rho$ が消える** —
これが交番の近壁局在と整合する。

検証は `space.slauContactFloor`$=\epsilon$ (既定 0.0 = ビット不変) として、**下限の不足分だけ**を
接触波方向に足す実装で行う (ROE への切替は交絡するので使わない):

$$\alpha_s=\Delta\rho-\Delta P/\bar c^2,\quad
\delta\lambda_s=\max\{0,\epsilon(|\bar u_n|+\bar c)-|\bar u_n|\},\quad
\delta F=-\tfrac{S_f}{2}\delta\lambda_s\alpha_s\,(1,\bar u_x,\bar u_y,\bar u_z,|\bar u|^2/2)$$

**ROE への単純切替は使えない**: `run_0087_roe_recon0_long` は `rms_roe` が 1.26e3 → 3.87e4 と

#### 生産ケースでは、リップルの 6/7 は境界条件 (2026-09-21)

上の 0.021 % は**一様壁**の値である。生産ケース (実測 $T_w$ を 480 節点へ折れ線内挿して課す) は同じ
平滑メッシュでも **0.125 %** で 6 倍大きい。同一メッシュ・同一設定で**壁 BC だけ**を一様 574 K に
替えた `run_0095_prod_uniTw` は **0.019 %** に落ちる。

| run | 壁 BC | 課した $T_w$ の 2 節点交番 | 壁熱流束の 2 節点成分 |
| --- | --- | ---: | ---: |

| `run_0094_prod_reconT` | 実測 $T_w$ + `reconT: 1` | 0.053 K | 0.131 % |

| `run_0088_cf0` | 一様 566 K | 0.000 K | 0.021 % |
| SU2 (`su2_smooth`) | 一様 566 K | 0.000 K | **0.011 %** |

**生産で見えているリップルの 6/7 は、68 点の熱電対を 480 節点へ直線で内挿した境界条件**が
$h=q/(T_g-T_w)$ を通って戻ってきたものであり、ソルバ由来は 0.019–0.021 %。
**だから生産ケースでは `reconT: 1` を足してもリップルは改善しない** (0.125 → 0.131 %) —
効くのは小さい方の項だからである。$T_w$ の無制約スプライン化は既に不採用 (測点を通る spline でも
現行折れ線と最大 7.62 K / 11.47 K 差 = 測定 ±1 K 超)。

**生産レシピの結論 (2026-09-21)**: **平滑メッシュ (`--curv-smooth 400`) + `reconT: 1` (専用 $\psi_T$)、
接触波下限は使わない**。`reconT: 1` は生産のリップルを変えないが、一様壁で測れるソルバ固有の
2 節点モードを 1.039 → 1.027 に下げ、**h の結論を 0.1 % も動かさない**
(`compare_h.py`: `run_0065` / `run_0093` / `run_0094` の領域別 bias が PS +9.8 % / SS 層流 +39.9 % /
SS 遷移後 +4.7 % / 全体 +16.3–16.4 % で一致)。

SU2 自身は平滑メッシュで**悪化**している (0.994 → 1.009) 一方、forge は 1.178 → 1.027 と大きく改善した。
また**平滑メッシュでは forge の $\mu_t$ の交番は SU2 の 1/7** なので、
「forge の $\mu_t$ が余計に交番している」という筋は同一メッシュでは成り立たない
(粗メッシュでの 6 倍差はメッシュ強制への感度差だった)。


### 副産物 1: forge の Harten エントロピー補正が次元不整合 (未修正)

[`convectiveFlux_roe_d.inc.cuh`](../../solver_density_cuda/cuda_forge/convection/convectiveFlux_roe_d.inc.cuh) の有効経路:

```cpp
eta_vl = 0.1*(abs(Ua)/ca + 1.0);   // |Ua|/ca は無次元 -> eta_vl も無次元 (0.1-0.2)
if (lam[1] < eta_vl) ...            // lam は m/s (Ua, ca とも m/s)
```

すぐ下にコメントアウトされた `h_fix = 0.05*(abs(Ua)+ca)` が本来の Harten 形。
この case ($c\approx530$ m/s) では本来 ~53 m/s のところ実効 ~0.1。SU2 の床 $0.001(|U_a|+c_a)\approx0.53$ m/s。
**市松の原因ではない**ことは上の掃引で分かったが、**次元不整合そのものは欠陥**なので別途起票する。
opt-in の `space.roeEntropyFixCoeff` (既定 0 = ビット不変) を SU2 同形で追加済み。

### 副産物 2: `solverConfig.hpp` 変更後の差分ビルドで ROE が step 3 NaN

`roeEntropyFixCoeff` をメンバに足した直後、**係数 0 でも** ROE が step 3 で NaN になった。
bisect で「committed 状態では完走」を確認し、**クリーンビルドで解消**。
既知の罠 ([[stale-build-struct-layout-trap]]) を踏んだもので、エントロピー床のロジックは無罪。
**`solverConfig.hpp` を触ったら差分ビルドを信用しない。**

### ROE の TP / 凝縮対応 (ユーザ指摘 2026-09-20)

`thermalMethod == 2` の分岐はあるが、**固有値・固有ベクトルは CPG の $\gamma$ で組んでいる**
(`ca_L = sqrt(gamma P/ro)`, `roe_L = P/(gamma-1) + rho v^2/2`)。実効 $\gamma$ や
$\partial p/\partial\rho|_e$ を使う厳密な TP Roe にはなっていない。
凝縮も `condModel` で物性を切り替えるだけで、二相 frozen 音速は入っていない。
**本件 (C3X) は `thermalMethod: 0` なので影響しないが、将来課題。**

| --- | --- |

| 2 次 + `venkatK` 0.01 | step 271 |
| 2 次 + `limiterScaled: 0` (旧経路) | step 291 |

### `run_0001` が収束しなかった理由 (2026-09-20)

`inlet_uniformVelocity` は「速度 3 成分 + config エントロピー $P_s/\rho^\gamma$」を課して $R^+$ を内点から
取る**正しく posed な**亜音速入口だが、**全温を固定しない**。内部静圧が config アンカー (313.6 kPa) でなく
252 kPa に落ち着いた結果、入口 $T_t$ が 786 → **738 K** (−48 K) になった。$h$ は $T_g$ 基準なので
この時点で比較に使えない。あわせて入口ブロックが定常に落ち着かず (低マッハ域の大規模モード)、
残差が 1e−3 台で停滞した。**全圧入口に替えたら同じメッシュ・同じ CFL で残差が 3 桁下がり**、
$P_t$・$T_t$ が全面で指定値どおりになった。

その `inlet_Pressure_dir` は step 214 で入口節点が NaN 化して使えなかったが、真因は BC カーネルの
欠陥 2 件で 2026-09-20 に修正した ([`methods/boundary.md`](../../methods/boundary.md) 「例: 全圧固定流入」):
(1) $P_c>P_t$ で境界マッハの根号内が負、(2) 方向ベクトルを保持する `bvar` を毎 step 次元付き速度で
上書きするため $M\to0$ で長さ 0 → 0/0。
なお `cfl_pseudo` は 0.5 で安定、**2.0 は 8000 step で残差が 3 桁上がる**ので使わない。

### 壁熱流束の節点間振動は**形状**だった (2026-09-20)

`run_0002` では壁 $q$ が隣り合う節点で 52 ↔ 302 kW/m² と振れた。node の壁市松
([[node-wall-entropy-checkerboard]]) を疑ったが、`iface_align`=1.0000・`iface_d1`=2.00 µm 一定で
幾何は健全、第一内点の $|U|$ が 38 → 68 → 13 → 1.4 m/s と飛ぶ位置が**輪郭の角と一致**した
(折れ角と $|q-\mathrm{smooth}(q)|$ の相関 0.57)。

原因は 2 つ。(i) 座標表が 78 点 / 周長 32 cm しかなく、負圧面前縁の高曲率域で 1 弦 6 mm が 20° 曲がる。
(ii) 復元した前縁/後縁円弧の**中心を「頂点から $x$ 方向に $R$」**と置いていたが、取付角 60° の翼では
鼻が $x$ を向いていないので中心が 0.06 cm ずれ、区間端の表点が円から 0.05 cm 外れ、そこに円弧を
繋いで**半径方向の段差 = 折れ角 60°** ができた。

対策は [`tools/smooth_profile.py`](tools/smooth_profile.py): 円弧は **$R$ 固定の最小二乗で中心を決め**
許容 0.003 cm で区間を伸ばし端点を円上へ射影 → 全周に**周期平滑化スプライン** (重み = 報告の
座標不確かさ ±0.008 cm、$s=0.05m$)。4 ゲート (残した表点からのずれ / 折れ角 / $R_{LE}$・$R_{TE}$ /
自己交差) を**落ちたら書き出さない**。結果: 折れ角 60° → **3.8°** (0.1 mm 刻み)、表点からのずれ
rms 0.0016 cm、$R_{LE}$ 1.179 (報告 1.168)・$R_{TE}$ 0.188 cm (報告 0.173)。
