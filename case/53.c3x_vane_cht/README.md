  点が 1 つでも欠けたら**書き出さずに落ちる**。

### 報告自身の不整合 (2 件、いずれも記録して回避)

1. **表 VIII / IX の SI 圧力列が psia 列と 51.7 倍ずれている** (例: C3X 4411 は "6177 (46.34 psia)" だが
   46.34 psia = 319.5 kPa)。**psia 側を正**とする (文献が引用する ~3.2 atm と一致する)。
2. **C3X 表 III の点 29 は inch 値が誤植**: "0.4115 cm (0.0162 in)" だが 0.0162 in = 0.0411 cm。
   前後の点間隔 (~0.6 cm) から **cm 値 0.4115 が幾何的に正しい** (0.0411 だと点 30 と 0.047 cm しか離れない)。

## 実験データの定義と自己検査 (`ref/run108_surface.csv`)

報告 p.125 (付録 A の前書き) より:

- **温度は 811 K (1460 °R) で正規化**、**熱伝達係数は $h_0$ = 1135 W/m²K (200 Btu/hr/ft²/°F) で正規化**。
- $h$ は**ガス全温 $T_g$ 基準** (p.21: 有限要素の入力は「実測外表面温度・冷却孔の熱伝達係数・2D 断面形状・
  材料熱伝導率・**ガス流の全温**・各孔の平均冷却剤温度」)。よって $q = h\,(T_g - T_w)$。
- run 108 に当てると: $T_w$ = 513–612 K、$h$ = 327–895 W/m²K、$q$ = 87–206 kW/m²。

**自己検査**: 転記した $T_w$ の単純平均は 562.4 K で、報告の $T_w/T_g$ = 0.73 ($T_{T1}$=786 K → 573.8 K) に対し
**0.716 (−1.9 %)**。平均の定義 (弧長重み・対象点の範囲) の差と考えられる。**転記ミスではない**ことの根拠として、
全 75 点が単調性・範囲の検査を通り、分布形も物理的 (前縁で $h$ 最大、負圧面で遷移して上昇) である。

## 公開されていない入力 (V5 の設計に効く)

**冷却孔ごとの冷却剤温度・流量は報告に無い**。報告は方法だけを書いている
(p.21「孔径・実測流量・冷却剤温度から Nusselt 数を計算し、助走区間補正 $C_r$ を掛ける」)。
付録 A の run 別データにも冷却剤の欄は無い (弧長 / 軸距離 / 正規化温度 / 正規化 $h$ と圧力分布のみ)。

→ **V5 の段 (b) は「公開された内部条件で固体を解く」ことができない**。代わりに
**公開量 (実測 $T_w$ と報告の $h$) から内部条件を逆算する**形にする:
外周に $q = h(T_g-T_w)$ を課して固体を解き、孔ごとの $(h_c, T_c)$ を最小二乗で同定する。
**その同定の不確かさを V5 の帯に別項目として積む** (推定した内部条件を「公開値」と偽らない)。
