# 52. M5 乱流すきま (case/49 条件の 2 次元等価) — T3

計画: [`plans/active/case-hypersonic-gap-heating-validation.md`](../../plans/active/case-hypersonic-gap-heating-validation.md) の **T3**。
層流の一次検証は [`case/50`](../50.deep_cavity_wieting_m7/README.md)、乱流の厳密検証 (TN D-8233) は [`case/51`](../51.gap_turbulent_thd8233/)。

**問い**: **乱流**で、深いすきま内部の熱伝達は平板基準に対してどうなるか。
case/49 (M5 環状すきま 幅 2.5 mm × 深さ 50 mm、$D/W$=20、平板断熱 × すきま 500 K 等温) の
**2 次元等価**を、case/50 で検証済みの数値経路で回す。

## なぜ T2 (TN D-8233) より先か

答えるのが case/49 の本題であり、数値経路は case/50 で検証済みなので**未知は乱流モデルだけ**に絞れる。
T2 は流入がトンネル壁 BL ($\delta^*$ = すきま幅の 46–56 倍) で再構成が重い。
**T3 が文献の帯から外れたときに限り T2 を立てる**。

## 条件 (case/49 `derived.json` をそのまま)

M5 / ISA 20 km: $T_\infty$ 216.65 K, $P_\infty$ 5474.72 Pa, $U_\infty$ 1475.21 m/s, $Re/m$ 9.134e6。
TP 乾燥空気 4 種 (N2/O2/AR/CO2)、低 Re SST ($k_\infty$ 81.6, $\omega_\infty$ 50531 = TI 0.5 %, $\mu_t/\mu$ 10)。
平板**断熱**、すきま壁 **500 K 等温**。

## 分母の作り方 (plan §4.4a (iii))

平板が断熱だと $q_{fp}=0$ で **$q$ 比が定義できない**ので、**500 K 等温平板の smooth run** を別に回して分母にする
(TN D-8233 と同じ構成)。駆動温度差 $(T_{aw}-T_w)$ が分子分母で共通なので **$h$ 比 = $q$ 比**。

## 開口位置の決め方 (実測)

smooth 断熱 run で $\delta_{99} \propto x^{0.649}$ (2.119 mm @ $x$=100 mm) と実測し、
case/49 の目標 $\delta_{99}$ = 5 mm (= 2W) になる **$x$ = 350 mm** に開口を置いた ($\delta_{99}$≈4.8 mm = 1.9 W)。
断熱壁温は 1114 K (case/49 の TP 推定 $T_{aw}$ 1126.3 K と **1.1 %**)。

## 起動レシピ (実測)

M5 乱流は case/48 (M4.19) より厳しい。**2 次段 cfl 2 は前縁 $x$≈7.5 mm で発散** (`run_0001`)。
通ったのは 層流暖機 cfl 0.2 → SST soft 0.2 → mid 0.5 → 2 次ランプ 0.3/0.6/1.0 → 本段 **cfl 1.2** + relax 0.7、
IC の壁近傍ランプ幅 400 µm。

## 判定 (文献の帯)

- **TP-1187**: 乱流はすきま深さの **60 %** で $0.1\,q_{FP}$ (層流は 30 %)
- **TN D-7939**: $z/W>4$ で非攪乱面値の **2 % 未満**
- **CR-141925**: $h/h_{ref}\approx0.366\,(z/W)^{-0.96}$ (層流 in-line gap。乱流横すきまには別式なので**帯として**使う)
