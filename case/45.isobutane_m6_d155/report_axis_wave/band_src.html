Euler との差から排除厚さを測る方法と、「帯」がずれて壁がへこんだ仕組み

使ったデータ: NS case/45.isobutane_m6_d155/run_0022_ns_ib_pass0/res_24000.h5 (積分法の壁) と Euler run_0001_euler_shortest_dry/res_12000.h5 (同じ設計壁)。主に x = 21.0 rt の 1 断面で説明する。NS は残差が横ばいで止まった状態 (check_convergence: NOT CONVERGED、プラトー)、Euler は収束 (PASS)。計算条件の全体は 前のレポート の §1。

一言でいうと: 境界層で「流れが足りない分」を測るときに、比べる相手 (Euler) を少しだけ補正する。その補正量を壁のすぐ外の狭い区間 (=「帯」) で測っている。x ≈ 20 から先では帯が境界層の縁に引っかかり、補正が狂って排除厚さを 1〜2 % 小さく測っていた。それが壁の小さなへこみになり、軸の山の元になっていた。

1測りたいもの: 境界層で足りなくなった流れ

ノズルの 1 断面を、軸 (r = 0) から壁まで切って、単位面積あたりの流量 ρu を並べたのが下の図。黒が Euler (粘性なし)、赤が NS (粘性あり)。

  • 壁から離れたところ (コア) では、赤と黒はほとんど重なる。
  • 壁の近く (y が δin の約 2.5 倍より内側) では、赤が黒より小さい。これが境界層。薄い赤で塗った面積が「足りない流量」。
  • この足りない流量を、「壁を何 mm 外に広げれば取り戻せるか」に直したのが排除厚さ δr。設計では、非粘性の壁にこの δr を足して実際の壁にする。
  • 正しく足せていれば、測った δr は足した δin と同じになる (比が 1)。これを「固定点」と呼んでいる。

2Euler をそのまま引かない理由

「赤と黒の差を足し合わせればいい」と思えるが、そうしていない。NS と Euler はコアでも完全には一致しないからである。下の図 2 の左は、比 ρuNS / ρuEuler を断面全体で描いたもの。

  • (a) を見ると、コアでも比は 1 ではなく 0.995〜0.999 である。上流の小さな波や、軸付近の値のずれのため。
  • この 0.1〜0.5 % のずれを無視して断面全体で差を取ると、コアのずれまで「境界層で足りない分」に数えてしまう。断面積の大部分はコアなので、δr は数 % 以上狂う。
  • そこで、壁のすぐ外の狭い区間だけで比を測り、「境界層がなければ壁際でも NS はこの比で Euler からずれているはず」と考える。その区間が帯。

3帯で比を測って、壁まで延ばす

図 2 (b) の手順:

  1. 帯の中 (色の区間) で、比を壁からの距離 y の 1 次式 (直線) で近似する。
  2. その直線を、帯の下端から壁 (y = 0) まで延ばす (点線)。これが「境界層がなかったときの比」の見積もり。
  3. Euler の ρu にこの比を掛けたものを基準にする。NS と基準の差の面積が「足りない流量」で、そこから δr を出す (図 3)。

図 2 (b) の緑 (帯 A) は境界層の完全に外にある。比は帯の中で 0.999 で平らなので、延長した点線もまっすぐ 0.999 のまま壁まで下りる。基準は「Euler × 0.999」。

橙 (帯 B) は下端が y = 2.34 δin で、境界層の縁 (y ≈ 2.3〜2.7 δin、比が 1 から急に落ち始めるところ) にかかっている。帯の中に「落ち始め」が入るので、直線が大きく傾き、壁まで延ばすと比は 0.98 まで下がる。基準が実際より 2 % 低くなる。

5帯の位置は断面ごとに自動で決めていた

帯の位置は人が決めず、断面ごとに次のルールで自動で決めていた。

  1. まず壁から 1.5 δin の位置に帯を置く (細いノズル上流では 0.02 rw のほうが大きければそちら)。
  2. 「帯の中で比が 1 % 以上変わる」「帯の中にも足りない流量が 1 割以上残る」など、まだ境界層の中にいる兆候があれば、帯を 1.25 倍外へずらしてやり直す。
  3. 兆候が消えたところで止める。
  • x ≈ 12〜19 では 3 回ずらして 2.93 δin (帯 A の位置) で止まっていた (x
  • x < 19 では 3 回ずらして 2.93 δin (帯 A の位置) で止まっていた。
    • lt; 12 は 0.02 rw の下限が効いてもう少し外)。
  • x ≈ 19.5 から先は 2 回目で止まってしまい、2.34 δin (帯 B の位置) になった。1.25 倍刻みなので、帯は一段で 20 % 壁側に跳ぶ。
  • 帯 B は境界層の縁に少しかかるが、「比が 1 % 以上変わる」という判定には引っかからない程度だった。ところが δr には 1〜2 % 効く。判定のしきい値が、効いてくる誤差に比べて粗かった。
  • 結果として、自動選択の δr (青) は x ≈ 19.5 で急に 2 % 落ち、x ≈ 28 までかけて戻る。帯を外に固定した値 (緑) は、x = 10〜35 で 0.998〜1.002 に収まって平らである。

6それが壁のへこみになり、軸の山になる

帯が x≈19.5 で壁側に跳ぶ→δr を 1〜2 % 小さく測る→平滑化して、壁が x≈17〜29 で 0.001 rt へこむ→へこみの入口 (x≈18〜21) で圧縮波、出口 (x≈22〜30) で膨張波→特性線に乗って軸へ→軸 x≈57 で M が下がり、x≈69 で上がる

へこみの深さは δr の 1 % 程度 (約 0.1 mm) しかないが、M6 の軸対称ノズルでは、壁から出た弱い波が軸に集まって強まる。壁 x≈18 発の特性線は軸 x≈57.5 に、壁 x≈24 発は軸 x≈68 に着くので、軸の谷と山の位置と合う (前のレポートの Figure 7〜8)。積分法の壁 (run_0022) にはこのへこみが無く、軸にも山が無い。

まだ確かめていないこと: 帯を外に固定した抽出で壁を作り直し、NS を回して軸の山が消えることは、まだ見ていない。ここまでは既存の場を測り直した結果である。帯の決め方の直し方 (下限を設ける、x 方向に急に跳ばないようにする) も未決定で、plan の残作業表 (§5.1 #7) に入れてある。
