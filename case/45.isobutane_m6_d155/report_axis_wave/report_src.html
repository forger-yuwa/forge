M6 ノズル試験部の軸 M の山 — 排除厚さ・壁の作り方・場の応答

対象: イソブタン燃焼ガス M6 ノズル (出口径 1.55 m)。積分法壁 (pass 0) → Euler 差分抽出壁 (pass 1, 2) → 最終壁 の 4 枚の壁と、その NS 解。 計画: plans/active/verification-m6-axis-wave-mesh-su2.md

目的: 試験部の軸上 x≈69 rt に出る M の山 (最終形で +0.23 %pt) が、排除厚さ δr の求め方・壁の作り方とどう結びついているかを、各段階の δr・壁の 2 階微分・軸 M・場のコンタで並べて示す。

結論: 山は Euler にも積分法の壁 (run_0022) にも無く、壁を Euler 差分の抽出値に替えた時点で現れる。2 枚の壁の δr の差は x=8〜80 rt で 2 % 以内しかないが、その差が作る擾乱は壁 x≈15〜25 から C− 特性線に沿って軸へ集まり、軸の x≈57 に谷、x≈69 に山を作る。壁の 2 階微分の細かいガタつきは、山の出ない積分法壁のほうがむしろ大きく、山の有無を説明しない。

最大の限界: NS の 4 run はどれも check_convergence が NOT CONVERGED (残差プラトー) である。山の高さはスナップショット間で 0.004 %pt 以内しか動かないが、反復誤差の影響幅は未測定。また「どの区間の δ 差が効いているか」は特性線の幾何と差分場から読んだもので、区間を限った A/B はまだ回していない。

2. 排除厚さの求め方と壁の作り方

壁は「非粘性設計壁 rinv(x) に半径方向の排除厚 δr(x) を足す」ことで作る。δr の出所が 2 通りある: 1 発目は境界層積分法、2 回目以降は前回の NS 場と Euler 参照の差から測る。

2.1 積分法 (CONTUR 型運動量積分) — pass 0 の壁

実装: design/forge_design/feedback/deltastar_integral.py。Sivells CONTUR (AEDC-TR-78-63 §5) の軸対称 von Kármán 運動量積分を、入口から出口まで 1 本の常微分方程式として前進積分する。

dθ/dx + θ [ (2 − M² + H) / (M (1 + (γ−1)/2·M²)) · dM/dx + (1/r_w) dr_w/dx ] = (C_f / 2) · sec φ_w (CONTUR Eq. 61)
  1. 縁条件は設計壁から決め打ち: 縁マッハ数 Me(x) は、スロート上流は A/A* の亜音速枝、下流は逆 MOC が出した設計壁上の M。Te, pe, ρe, ue は semi-perfect ガスの等エントロピー関係から。境界層が主流に与える影響 (相互作用) は入っていない。
  2. 速度・温度分布を仮定: u/ue = (z/δ)1/N、温度は Crocco 型の 2 次式、断熱壁 Tw = Taw = Te(1 + Pr1/3(γ−1)/2·M²)。N は Reδ の関数で、CONTUR Fig. 10 を折れ線テーブルにしたもの。
  3. θ から δ を根探索: 各ステーションで、横曲率の重み (1 − z cos φ/rw) 込みの θ・δ* を 16 点 Gauss 積分し、与えられた θ に合う δ を Brent 法で解く。H = δ*/θ が決まる。
  4. 摩擦: Spalding–Chi 型の圧縮性変換 (Fc, FRδ = μe/μw) と Cfi = 0.0773 / [(log Reθi + 4.561)(log Reθi − 0.546)]。
  5. 入口の θ0: 入口直管長 (0.0386 m) を仮想発達長とする乱流平板 θ0 = 0.036 xv Rex−0.2 = 0.119 mm。
  6. 出力: 壁法線方向の δ*n(x) を 1500 点で出し、半径方向に直して δr = δ*n / cos θw。スロートで 0.0011 rt、出口で 0.70 rt。

run_0022 の時点ではこの出力を平滑化せずに壁へ渡していた。現行コードは同じ 5 次 P-spline (§2.2 の 5) を通す。

2.2 Euler 差分からの抽出 (帯局所参照) — pass 1 以降の壁

実装: design/forge_design/metrics/deltastar.py::band_local_deficit と feedback/deltastar_loop.py。考え方は「NS 場の質量流束 ρUx が、同じ設計の非粘性解 (固定した Euler run) に比べて壁近くでどれだけ足りないか」を断面ごとに測り、その不足を運ぶのに要る半径方向の厚さを δr とする。

  1. 断面の対応づけ: 同じ x の断面で、NS 側を ηNS = r / (rw,NS − δin)、Euler 側を ηE = r / rinv と正規化して重ねる。δin はその NS run の壁に足してあった δr。固定点では NS のコアは設計壁の非粘性流に一致するはずなので、「足した分を引いた壁」で揃える (物理壁で正規化すると、M6 では 1.5〜7 % 半径を引き伸ばしてしまい、膨張部で 10〜20 % の偽欠損が出る)。
  2. 参照プロファイル qref を作る: 境界層のすぐ外の帯 y ∈ [yb, 1.5 yb] (y は壁からの距離) で比 qNS/qE を y の 1 次式で最小二乗フィットし、壁側 y < yb へ延長した比を Euler の q に掛けたものを qref とする。yb は max(1.5 δin, 0.02 rw) から始め、帯の中で比が 1 % 以上変わる・帯の比がコア比より 5 % 低い・帯の中に欠損が 10 % 以上残る、のどれかなら 1.25 倍ずつ広げる (最大 14 回)。
  3. 欠損と等価半径:
D = 2π ∫_{y<y_b} (q_ref − q_NS) r dr (q = ρ U_x) 2π ∫_{r_eff}^{r_w} q_ref r dr = D → δ_r = r_w − r_eff
  1. ゲート: D < 0・根なし・NaN は「hard」で前回値を保持。帯フィットの RMS > 0.5 %、帯幅を 3 倍/6 倍にしたときの感度 > 5 %、帯内残留欠損 > 10 % は「soft」(使うが記録)。
  2. 平滑化: 断面ごとの生値 (1250 点、ノイズ 4〜8 %) を平滑化する。旧 (run_0023 の壁): 3 次平滑化スプライン。新 (run_0025 以降): 5 次 B-spline + 係数の 3 階差分ペナルティ (P-spline)。ノットは ξ = √(x − x0 + 4) で等間隔 (物理で約 2 rt 間隔、スロート側が密)、λ = 1。壁が x ≥ 0.5 で単調でなくなれば λ を 10 倍ずつ上げる (run_0025 → 最終壁では λ = 100 まで上がった)。
  3. 緩和: δnext = (1 − ω) δin + ω δextracted、本系列は ω = 1。

2.3 δr から実際の壁へ

実装: design/forge_design/geometry/wall_axismach.py::PhysicalNozzleWall (offset = radial)。以下のとおり、平滑化は δr の段階だけで、壁そのものは補間スプライン (点を必ず通る) で作る。δr に残ったガタつきは壁の 2 階微分にそのまま乗る。

  1. 設計壁 (逆 MOC の 334 点を通るクランプ 5 次 B-spline) を、入口から xF まで 3000 点で評価する。
  2. 各点に δr(x) を足す。δr は CSV (1250 点) から線形補間で取る。
  3. 足した点列から真の幾何スロート (r′ = 0 の点) を微小 λ の平滑化スプラインで探し、スロート曲率は 1 パラメータの最小二乗で推定する。
  4. 下流: スロート (r′ = 0, r″ = κt でクランプ) から出口まで、全点を通る補間 5 次 B-spline。上流: 入口直管からスロートまで 5 次 Hermite で作り直す。
  5. メッシュ生成 (meshing/mesh2d.py) はこのスプラインを 1250 個の x 断面で評価し、半径方向に 97 点を等比で並べる。

本ページの壁は、この経路を各 run の入力から再実行して作り直し、保存されている wall_physical.csv と 4 本とも最大 1.2×10−15 m で一致することを確認した上で微分している (Figure 3)。

3.4 場のコンタ

  • 擾乱の通り道: Figure 7 の pass 1 では、壁 x≈20〜22 (r≈5.7) から出た負の帯が C− 特性線に沿って下り、軸の x≈55〜62 に届く。その後ろに正の帯が続き、軸の x≈65〜75 で強まる。帯は軸に近づくほど濃くなる。Figure 8 の差でも、同じ経路の波と、軸上の +/−/+ の交互パターン (x≈50〜55 / 60〜66 / 70〜77) が見える。
  • 平滑化した壁でも同じ経路: pass 2 と最終壁 (Figure 7 の 2・3 段目) では、壁際の起点ははっきりしないが、同じ特性線の束 (壁 x≈15〜25 発) に沿って弱い帯が軸の x≈55〜75 に届く。最終壁では帯が弱い。

4. 特定できたこと / できなかったこと

特定できたこと (観測)

  • Euler と積分法の壁では、試験部の軸 M に x 方向の山は無い (b70 0.007 %pt 以下)。
  • 抽出壁 3 枚すべてで、x≈57 の谷と x≈69 の山が出る。山の高さは時間的に落ち着いている (変動 ≤ 0.004 %pt)。
  • 積分法と抽出値の δr の差は x = 8〜80 で 1〜2 % 程度にすぎない。
  • その差による擾乱は、壁 x≈15〜25 から C− 特性線に沿って軸へ集まり、軸に近いほど強い。
  • 壁の 2 階微分の高周波のガタつきは、山の出ない積分法壁が最も大きく、山の大きさとは対応しない。
  • 軸側の半径方向格子を 6 倍細かくしても、山の 88 % が残る (別途の A/B: run_0041_ns_axgap0125)。

特定できていないこと

  • δr の差のうち、どの区間 (x≈15〜25 か、スロート直後 x<6 か) が効いているか。区間だけを入れ替えた A/B は未実施。
  • 軸への集束が物理なのか、軸の扱いで増幅された数値なのか。r/rw = 0.1 の波形が 3 枚の抽出壁でほぼ同じで、軸上の値だけ違う点は、軸ノードの寄与を疑わせるが、切り分けていない。
  • 最終壁で軸の山が 0.35 → 0.23 に減った理由。平滑化 (λ=1 → 100)、もう 1 回の抽出、rt の 0.1 % 変更、が同時に変わっている。
  • NS の残差プラトーが山に与える影響の幅。
