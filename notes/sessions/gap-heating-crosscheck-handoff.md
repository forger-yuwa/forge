### 1.2 G3 は PASS、G9 は達成可能性に疑義

- **G3 (圧力比)**: `case/50/tools/g3_pressure.py` で 4 幅すべて照合。$p_c/p_m$ = 0.979 / 0.959 /
  0.950 / 0.944 で全点 1.0 ± 0.1 の内側。**分母問題の影響を受けない検証点**。
- **G9 (残差)**: T1 の残差プラトーは停滞でなく**有界振動** (§4.7-4)。全保存量が 3 桁一致で同期
  (1.513 / 1.513 / 1.511 / 1.516)、トレンド −0.07 dec/100k step で末尾は +0.10 (上昇)、振幅 1.5 桁。
  **step 数では達成できない**。基準の組み替えか定式化変更かは #46。

  > **訂正 (2026-09-22)**: §4.7-4 と直前セッションの報告にある「丸め床の 90–490 倍上」は
  > `rms_ro / \langle\rho\rangle` を eps で割ったもので、**次元が合っていない**。
  > `rms_ro` は密度でなく「CV を出入りする質量流束の和」[kg/s] なので密度で割っても無次元にならない。
  > CHT 側が同じ誤りを codex result-2 M4 で指摘されて撤回済み (commit `5e9b0533`)。
  > 正しくは `case/57.transition_flat_plate/tools/rounding_floor.py` の形
  > — 節点ごとに $e_i = \varepsilon_{32}\sum_f(|\rho_f u_f\cdot S_f| + p_f|S_f|/c_f)$ を作り
  > level 2 出力の `res_ro` と比べる (第 2 項は SLAU の圧力差散逸。絶対圧の引き算なので
  > pRef ゲージが無いと壁近傍で支配的)。**`case/56` では未測定**。#46 を進めるならまずこれを回す
  > (`output.level: 2` の run が要る)。

### 1.5 forge の深部は「未収束」でなく「float32 で分解できていない」(#28)

`case/56/tools/gap_series.py` (新規) で `run_0005` の 16 枚を `check_quasisteady.py` に通すと
`OVERALL: NOT ALL STEADY`。DRIFTING している量を分解能と突き合わせると:

| z/W | 実測 $q_w$ [W/m²] | 温度差 1 ULP 何個分 | |
| --- | --- | --- | --- |
| 1.39 | 2144 | 740 | 分解できている |
| 2.83 | 112.3 | 1158 | 分解できている |
| 4.22 | 1.558 | 16.1 | 分解できている |
| 8.44 | 0.061 | **0.6** | **1 ULP 未満** |
| 14.11 | 0.054 | **0.6** | **1 ULP 未満** |

第 1 層 8 µm・$\lambda$=0.0255 なら温度差 1 ULP (3.05e-5 K) だけで $q_w$ = 0.097 W/m²。
深部速度も 2.665e-4 m/s に対し eps × $U_\infty$ = 2.432e-4 m/s (**比 1.10**)。
→ **z/W ≤ 4.22 は収束済み、z/W ≥ 8.4 は「検出限界以下」**と書く。「静穏な物理解」とは書かない。

### 1.6 SU2 クロスチェックは CFL でつまずいていた (§4.7-5)

`run_0007_xcheck_su2` の 200k 反復は **`AVG_CFL` が下限 0.30 に張り付いて**いた。SU2 は残差が
増えた反復で `CFL *= factor_down`、減った反復で `*= factor_up` するので、既定 `(0.5, 1.2)` は
**積 0.60 < 1** → 残差が振動する限り CFL は必ず下限へ落ちる (§4.7-4 の有界振動がまさにその条件)。
`(0.95, 1.05)` (積 0.9975) でも 1000 反復で 0.29 倍になり保持できない。→ **`CFL_ADAPT= NO` + 固定 CFL**。

速度実測 (同一メッシュ 65,194 節点、他プロセスなし):

| | ms/反復 | 実効 CFL | CFL/秒 |
| --- | --- | --- | --- |
| forge (RTX 3060) | 4.36 | 1.5 | 344 |
| SU2 (i5-12400F × 6 スレッド) | 59.4 | 0.30 | 5.1 |

1 反復あたり 13.6 倍、**擬似時間の進み方で 68 倍**。SU2 12 スレッドは 113.7 ms で 6 より遅い
(6 物理コア)。→ **クロスチェックは反復数でなく Σ CFL を揃える**。

## 3. この作業特有の罠 (全部踏んだ)

### 3.1 `case/56` の 2D すきまメッシュは 2 種類あり、混同されている

plan #50 は「`gap2d_w018.h5` が skew 0.992 / `VERDICT: FAIL`、tri 24 枚、
`run_0003/0004/0005/0009/0011` は参考以上に使わない」と書いているが、**実測すると 2 つの
別メッシュの話が混ざっている**:

| メッシュ | 節点 | 三角形 | skew | 判定 |
| --- | --- | --- | --- | --- |
| `gap2d_v4` (run_0003/0004/0005/0009/0011 と SU2 `gap2d_v4.su2` が使用) | 65,194 | **24 枚** | max 0.951 / >0.9 が **4 セル** | **SOFT-PASS** |
| `gap2d_w018` | 71,811 | **0 枚** | max 0.992 / >0.9 が **712 セル** | **FAIL** |

「tri 24 枚」は v4 の特徴、「skew 0.992 / FAIL」は w018 の特徴。
→ **上記 run は `gap2d_v4` = SOFT-PASS の上に乗っている**。#50 の「使わない」を機械的に
適用すると 1.5M step と SU2 280k 反復を捨てることになるので、**次のセッションで #50 の
記述を実測に合わせて直す** (どちらの run がどちらのメッシュかを明記する)。
forge/SU2 は同一 gmsh モデル由来なので、tri 24 枚は**両者に等しく入る** = 比較には効きにくい。

### 3.2 `physProp.visc` は剛性の見積りにしか入らない (#51)

`cuda_forge/setDT_d.cu:82` の局所 dt と block-DPLUR の粘性対角は**設定定数 `cfg.visc`** を読むが、
粘性流束は `vis_lam[ic]` (Sutherland $\mu(T)$) を読む。冷たい自由流で $\mu_\infty$ を入れると
近壁の粘性剛性を 5–7 倍過小評価し、**細かい $\Delta x$ の列だけ**実効 Fourier 数が 0.5 を超えて発散する。

→ **直前セッションの forge CFL 上限測定 (`_fgcfl_{3,6,10}` はすべて発散、CFL 2.0 は完走) を
再解釈する必要がある**。発散位置は**すきまではなく下流側の板の境界層** (x = 58〜62 mm、
領域 −60〜+90 mm) で、これは #51 の症状と一致する。`case/56` の config の `visc` を
実効 $\mu$ に合わせれば CFL 上限が上がる可能性が高い。**未検証**。

### 3.3 実行中のシェルスクリプトを編集しない

bash はスクリプトを**バイト位置で逐次読む**。長時間 run の最中に `run_case.sh` へ行を挿入すると
forge 終了後の再開位置がずれる。**1 日に 2 回踏んだ**: 1 回目は完走した 800k step の run が
**もう一度始まり** `residual_history.csv` が上書きされた (`run_0009` は 0–522k しか残っていない)。
2 回目は `line 59: syntax error` で止まり **VERDICT と残差図が作られなかった**。
症状は毎回違う。編集は `pgrep -x forge` が空のときに行う。

### 3.4 壁熱流束は forge の壁出力から取る

場から幾何的に片側差分を取ると、襟が床付近で傾いていて同一 $y$ の内側ノードが無く壁点を拾えない。
**`res_gap_6_<step>.h5` の `qwall`** を使う (`gap_eval.py` / `gap_series.py` はそうしてある)。
直前セッションはこの罠を**一度直した後にもう一度踏んだ**。

### 3.5 SU2 の後処理で板上面を拾わない

`su2_gap_eval.py` は以前 `c[:,1] < 1e-9` で壁を選んでおり、**下流側の板上面 161 点**
(y=0, x=3.4〜60 mm, $q$ が 5.6e5 W/m² まである) が「すきま壁」に混ざって深さ 0 に潰れていた。
修正済み (`< -1e-9`)。

### 3.6 少数点のフィットを「一致」と呼ばない

必ず **隣接点の増分比**と **1 点除外の係数**を出す。どちらかが崩れたら「事後回帰」と書き、
検証精度として引用しない (§4.4c で 12 % を撤回した経緯)。
