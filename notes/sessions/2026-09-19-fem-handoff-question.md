# 質問: 非定常熱構造 FEM に渡すべき「ガス温度」と「熱伝達率」は何か

これは plan レビューではなく**技術的な相談**。案件は `case/49.plate_annular_cavity_m5`
(plan: `plans/active/case-plate-annular-cavity-m5.md` の §4.7.1 / §4.7.2 / §4.7.3)。
判断の根拠になる CFD 実測は下に全部貼ってある。**私の推奨とユーザ案の両方を批判的に検討してほしい。**
根拠のない一般論ではなく、下の数値に即して答えること。数値に誤り・見落としがあれば指摘してほしい。

## 1. 物理設定

極超音速平板 (M9, ISA 20 km: T_inf 216.65 K, P_inf 5475 Pa, U_inf 2655 m/s) の上に、
環状の深いキャビティ (外径 50 mm, 深さ 25 mm, すきま片側 3 mm) がある。平板に円柱が
はまっていて、その周囲のリング状すきまがキャビティ。すきまの上端 (開口) が平板面 (z=0)、
底が z=-25 mm。偏心ケースは上流 5 mm / 下流 1 mm。

ソルバは forge (node 中心 median-dual, 圧縮性 RANS, Menter SST low-Re, 半完全ガス TP)。
定常 RANS を壁温 20 / 500 / 1000 degC の等温壁で 3 本ずつ回した (同心・偏心 計 6 本)。
全 run がゲート合格 (NaN 無し / 残差 / 派生量 STEADY / 質量・エネルギー収支 2 % 以内)。

半完全ガスでの値: 主流総温 Tt = 3000.0 K、回復温度 (断熱壁温) Taw = 2883.4 K
(回復係数 0.8963)。**完全ガス (CPG) だと Taw = 3362 K となり 479 K 過大**なので使えない。

## 2. 最終目的

この構造を**非定常熱構造 FEM** で解きたい。FEM には対流境界条件として
`q'' = h * (T_gas - T_wall(t))` を与える。T_wall は FEM が解く未知数で、過渡の間に
20 degC 付近から上昇していく。**安全側 (入熱を過小評価しない) に倒したい。**

## 3. 基準温度 4 定義の比較 (同心, 面積平均)

同じ壁面熱流束 q'' を、割る温度差 (基準温度) だけ変えて h を出したもの。

- (A) すきま中央面の局所 T0: 壁点ごとに、すきま中央面上の同じ (θ, 深さ) の総温を引く。
      h_eff = Σq·w / Σ(ΔT·w) (総入熱を再現する係数)

- (C) 主流総温 Tt = 3000 K (スカラー)
- (D) 断熱壁温 Taw = 2883.4 K (スカラー)

## 5. その他の実測

- すきま内のガス: 体積 5.54 cm3 (半割), 静圧 5778 Pa, 密度 0.0483 kg/m3,
  質量 0.268 mg, 開口流入 1.364e-4 kg/s -> **入れ替わり時間 2.0 ms**。
- 開口リップ (90 度の鋭角) は幾何的特異点で、q'' は格子細分で h^-0.5 で発散する
  (実測 290 -> 355 -> 419 kW/m2)。総入熱 Q(eps) = 44.4 - A*sqrt(eps) で有限だが、
  ピーク q'' は格子収束しない。リップ帯 (|z| < 1 mm) の入熱は全体の 37-56 %。
- 壁解像: 冷壁 (20 degC) で y1+ > 1 の面積が外筒内壁の 32.5 %、最大 3.88。
  500 degC で最大 1.39、1000 degC で 0.80。冷壁の値ほど不確かさが大きい。
- 偏心 (上流 5 mm / 下流 1 mm) だと 500 degC 以上で底面入熱がほぼ消える
  (h_aw: 1.185 -> 0.0317 -> 0.00338 W/m2K)、侵入深さ 25 -> 9.25 -> 6.38 mm。
- 計算は等温壁 (壁温一様) で回している。実機の壁温は非一様。

## 6. 私 (Claude) の推奨

1. **T_gas は (D) Taw = 2883.4 K の定数**。理由は精度でなく BC として閉じるから。
   (A)/(B) の基準温度は壁温に従属する (キャビティ平均 T は 456 -> 866 -> 1327 K) ので、
   冷壁時の値 456 K を固定して渡すと壁が 773 K を超えた時点で `T_gas < T_wall` となり
   FEM が「冷却」と解いてしまう。符号を間違える。
2. **h は単一値でなく深さ分布 h_aw(z) を、3 壁温の包絡 (各深さの最大値) で**渡す。
   深部は冷壁ほど高く、開口近傍は熱壁ほど高いので、冷壁校正だけだとリップ近傍で
   最大 -31 % の過小評価になる。
3. **リップ帯はピーク q'' でなく帯積分 Q を面積で割って均す** (格子依存の局所溶融を避ける)。
4. ガス入れ替わりが 2 ms なので定常 RANS の h を過渡 FEM に渡すのは準定常として正当。
5. margin をかけるなら、到達温度側は T_gas を Tt = 3000 K にする (+117 K)、
   昇温速度側は h に明示係数 (x1.5 程度) をかける、と**別々の物理量に別々に**かける。

## 7. ユーザの案 (これも評価してほしい)

「**h は (A) すきま中央面の全温基準の値を使い、FEM に渡すガス温度は Taw にする**。
ダブルで安全側になるのでは?」

私の回答は「h と ΔT は同じ q'' を分け合う逆数の関係なので安全率は重ならない。
q''_予測 = h_A * (Taw - Tw) = q''_実際 * (Taw - Tw)/(T0_mid - Tw) となり、実測の倍率は
外筒内壁で 13.0 / 16.6 / 20.8 倍 (20/500/1000 degC)、底面で 11.2 / 18.3 / 37.3 倍。
壁温が上がるほど倍率が膨らむ。最終到達温度は T_gas が決めるので変わらず、昇温が
13-37 倍速くなるだけで、設計判断に使えない」というもの。
