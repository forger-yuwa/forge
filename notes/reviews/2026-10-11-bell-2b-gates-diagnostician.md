## 要旨

- **前提の訂正**: run_0003 の CV 残差 −5.2e-7 は閉じた値ではなく、壁会計 (単調増加) と出口面会計 (単調減少) が交差した瞬間の値。閉じ代の床は両会計の漸近値の差 ≈ 5e-5。単一スナップショットの |cv| は推力系の STEADY と組まないと交差点で偽合格する。
- **残差プラトーの正体 (確度高)**: (a) ω 残差の高周波ジッタ (末尾 40 % で 2 桁の幅、平均 10 step 間隔、運動量と無相関、y1+ 5.7 → 1.6 で不変)、(b) 遅い単調トランジェント 2 か所 (出口側壁の断熱壁回復温度への熱的発達、収縮部の μt)。推力には 1e-4 以下でしか効かない。追加の run は不要。
- **ゲートの組み替え**: (i) 残差は記録、FAIL は DIVERGED と有意な末尾上昇のみ、NOT CONVERGED は併記 (SERN §4.39 と同型)。(ii) STEADY の列を壁会計・出口面会計・η・η_wall (drift・osc 1.5e-4) と ṁ (1e-3) にし、cv_residual は列から外す。単調列は漸近値 (最終比) も 1.5e-4 以内 (実効の単調許容は 7.5e-5)。(iv) 最終 |cv| ≤ 1e-4 を収束判定に (1e-3 の精度ゲートを吸収)。窓のため本段の出力間隔を本段長の 1/20 以下に。
- **(C) y1+ と AR**: 壁法線の近壁層 + AR ≤ 5000。現行格子は AR > 700 のセルが 1493 個でスキュー中央値 0.27・最大 0.417 → 例外の条件に当たらない (実装者の判断は正しい)。y1+ ≤ 1 にはスロート第一セル約 0.6 µm・収縮部約 2 µm。条件: 入口面・出口面は平面のまま (出口の数ステーションで半径線へ戻す)、AR > 1000 の全セルがスキュー ≤ 0.1 を自前で検査し README に「AR 緩和 (≤5000)」、float32 の ulp は許容。ni ≥ 2000・y1+ の緩和は採らない。
- **(D)**: η は出口面会計を主、壁会計を照合。台帳には両方と cv を残す。
- **(E)**: 推力・η 1.5e-4、ṁ 1e-3。
- **(F) pRef**: 置かない (燃焼室 1e7 Pa に合わせると出口で相対誤差が約 700 倍)。**別件**: 近軸の hoop 閉性の修正 (`axisSegmentRWeight`、commit 0b4dff4e) がこの作業ツリーに無い → 別項目で A/B (今回の変更に混ぜない)。
- **(G)**: CPG の CV 残差 3〜5e-3 は `outlet_statPress` の亜音速分岐と節点 P の不一致で説明できる。記録のみ。確認は出口列で M_n < 1 の節点 P を Ps に置き換えて再積分 (run 不要)。
- **次の試験 (事前登録)**: run_0003 を同一メッシュ・同一設定で +24000 継続 (`run_0005_tp_cv_continue2`)。**A**: |η_exit(48000) − 0.979183| ≤ 1.5e-4 かつ継続区間の全スナップショットで |cv| ≤ 1e-4 → ゲートを §4.1 に書き driver の定数を変える。**B**: いずれか外れる → 壁会計の内訳 (摩擦か入口面か) を分けてから次の 1 変更を諮る。
