結論: **案 (a) を採用候補に絞り、まず既存の区間再構成を x・y 両成分へ拡張した CPU の幾何 A/B を行う。**

第 1 仮説: FP64 で残る静止場の偽半径力の主因は、折れた双対面の集約と半径重み付けの順序が交換できないことである。 確度: **高。ただし実 run の数値は今回未追認。**
  
  根拠: `gmshReader.hpp:1514`～`:1527` と `variables.cpp:753`～`:757` に、ブリーフどおりの演算順序を確認した。`dual_segment_closure.py:83`、`:123`、`:140` は区間ごとの y 成分を集計するため、この仮説の検査になっている。一方、**r 重み付き x 成分の検査は実装されていない**。
  
  反証条件: 同じ接続・境界所有・向きで再構成した W_f に対して、Σ±W_f − (0, A_planar) が FP64 の丸め規模まで下がらない、または現行幾何との差が観測された欠損を説明しない場合。「集約誤差だけで説明できる」は棄却する。

第 2・第 3 仮説: 追加しない。B0 の密度残差床や軸 Mach の誤差原因まで、この仮説で説明できたとは扱わない。

判別 A/B: **変えるのは面メトリックの定義だけ。時間積分は 0 step、CPU で同じメッシュを 1 回ずつ評価する。**

- **A:** 現行の r̄_f ΣS_k。
- **B:** 区間ごとの Σr_kS_k。接続・向き・境界所有・A_planar は共通とし、内部面だけでなく境界半割面も含める。
- **事前登録する判定:** 各 CV の E_x = |Σ±W_x|/A_planar、E_y = |Σ±W_y−A_planar|/A_planar を測る。j=2〜8 は両成分とも最大 1e−10 以下を暫定合格値とし、全域では打ち消し条件を考慮して、各成分の閉性欠損が `100 ε64 × (A_planar + Σ|W成分|)` 以下かも確認する。
- 同じメトリックから、一定圧力の運動量残差と、一定軸方向速度 U の質量残差 `−ρU Σ±W_x` を評価する。これは**幾何演算子の試験**であり、ノズル壁 BC を満たす流れの試験ではない。
  
  → **B だけが合格し、差が旧欠損を説明するなら**、集約誤差説を支持し、面積・向きの別不整合が主要因という候補を外す。  
  → **B にも丸め規模を超える欠損が残るなら**、集約誤差だけという仮説を棄却し、境界所有・面の向き・面積の対応を再点検する。

案 (a) の実装時に守る範囲は次のとおり。

- **保存:** 内部面で一つの数値流束を両 CV に逆符号で配れば、内部交換の保存は維持できる。ただし、軸や壁の状態拘束を含む全体収支まで保証するものではない。
- **方向・面積:** W_f は一般に旧面ベクトルと平行ではない。`ss=‖W_f‖` にすると法線・数値散逸・CFL・陰解法係数も変わる。`setDT_d.cu:64`、`:76` がこの依存を持つ。
- **再構成:** `pcx/pcy`、`gr0/gr1`、planar 勾配用幾何は今回の比較では固定する。一定状態の幾何積分が正確でも、非一様状態や非線形数値流束の区間積分が正確になるとは限らない。
- **ライン・壁:** 接続を固定してもライン係数は変わる。曲がった境界の半割面も集約されるため、壁法線との整合確認が必要である。壁側でも `sx/ss` が使われる（`viscousFlux_d.cu:885`）。
- **適用範囲:** 新データセットの存在だけで有効化せず、まず true 2D・node・`isAxisymmetric=1`・`axisymMethod=0` に限定する。平面・3D・cell 経路の旧幾何を上書きしない。`axisRFloor>0` と軸面のゼロ除算回避も別途整合させる（`variables.cpp:744`）。

やらない方がよいこと: **`hoopAreaFromClosure` の既定化と面メトリック変更を同時に行うこと、`sx/sy` だけ替えて `ss` を残すこと、格子変更を混ぜること。** 静止場の成功だけで精度改善・B0 の床解消を宣言することも避ける。

呼び出し側の前提への異議: 「(a) が根本」は**一定流束の幾何閉性について採用**する。「流束全体の精度が上がる」は要再検証である。(b) の残存近似が軸 Mach に何 % 効くかは、提示された欠損率から算出できない。**生産精度の判断には測定が必要**だが、次の一手は長時間 run ではなく上記の幾何検査とする。
