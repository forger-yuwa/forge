## こちらが出した仮説 (誤りだった)

SLAU の質量束 (`convectiveFlux_slau_d.inc.cuh:562`) は散逸が $\Delta P$ 比例項しか無く、
エントロピー波 $(\Delta\rho-\Delta P/c^2)$ を減衰させる項が無い。Roe にはある。だから
$\delta P/P$ と $\delta\rho/\rho$ が 2.7 % ずれて残るのではないか。

## codex の結論 (原文要約)

> **「SLAU にエントロピー波散逸がない」という仮説は誤りです。** `mdot` の密度を掛けた速度分離項に、
> その散逸が既にあります。推奨する A/B は、**SLAU の再構成を維持して、接触波散逸にだけ速度下限を加える試験**です。

1. **SLAU にも接触波散逸がある**。一定速度・一定圧力の密度摂動では `slau:531-534` で $g=0$、
   $\widehat{|V_n|}_p=\widehat{|V_n|}_m=|u_n|$ となり、`slau:562` は厳密に
   $\dot m/S_f = \frac{u_n}{2}(\rho_L+\rho_R) - \frac{|u_n|}{2}\Delta\rho$。
   **見落としていたのは第 2 項**。さらに `slau:422-423` の完全気体エンタルピーと `slau:593-597` の風上輸送を
   合わせると、散逸は接触波方向 $r_s=(1,u_x,u_y,u_z,|u|^2/2)^T$ に対して
   $F^{\rm SLAU}_{{\rm diss},s} = -\frac{S_f}{2}|u_n|\Delta\rho\,r_s$ で、質量だけでなく運動量・エネルギーまで整合している。
2. **forge の Roe にも接触波成分はある** (`roe:262-271,286` 左右固有ベクトル、`roe:290-294` 中央 3 固有値 $|U_a|$、
   `roe:372,383,394` $R|\Lambda|L\Delta Q$、`roe:401-405` 減算) で
   $F^{\rm Roe}_{{\rm diss},s} = -\frac{S_f}{2}|u_n|(\Delta\rho-\Delta P/c^2) r_s$。
   **純粋な接触波では SLAU と同じ**。Nyquist モードの減衰率は両方式とも $\lambda_s=|u_n|$ で
   $da/dt = -2\lambda_s a/h$。**SLAU だけが減衰できない、とは言えない**。
3. **指標の解釈の訂正**: 接触波成分の射影は $A_\rho - A_P/\gamma$ であり、$A_T=A_P-A_\rho$ とは別物。
   **$R=1$ は等温であってエントロピー波成分ゼロではない。** $R=1.027$ は $A_T=0.027A_\rho$ の意味であって
   「温度交番が 2.7 %」ではない。
4. **代替仮説 (推奨)**: Roe は `roe:342-344` で $\lambda_j \leftarrow \max\{\lambda_j, \epsilon(|U_a|+c_a)\}$ を
   **接触波を含む全固有値**に適用する (従来の Harten 補正も `roe:316-319,331-334`)。SLAU の `mdot` には
   **この接触波速度下限が無い**。したがって
   > **近壁の小さな面法線速度で、接触波散逸の下限がないことが、温度交番の定常的な残留に寄与する。**
   ただし**比較対象の SU2 run に実際にどの下限が設定されていたかは未確認**。
5. **推奨 A/B (1 つ)**: ROE に切り替えず、両群で `reconT=1` + 専用 $\psi_T$ を維持し、
   B 群だけ `slau:597` 直後・残差加算前に**下限の不足分のみ**を足す:
   $\alpha_s=(\rho_R-\rho_L)-(P_R-P_L)/\bar c^2$、$\delta\lambda_s=\max\{0,\,0.001(|\bar u_n|+\bar c)-|\bar u_n|\}$、
   $\delta F = -\frac{S_f}{2}\delta\lambda_s\alpha_s(1,\bar u_x,\bar u_y,\bar u_z,|\bar u|^2/2)$。
   `massflux[ip]` にも質量分を反映する。**`mdot` だけ変えて既存の $h_{\rm upwind}$ を掛ける方法は不可**
   (追加エネルギーが接触波方向にならない)。$0.001$ は固定した試験値で、SU2 の設定再現ではない。
   判定は同じ初期場から 16000 step、1000 step ごとの同じ符号つき射影、`ratio` の末尾 `STEADY` を前提に平均 $R$。
   **支持する結果**: B の $R$ が再現幅を超えて 1.027 から 0.995 側へ動き、$|A_T|$ も減る。
   **支持しない結果**: $R$ が再現幅内で不変、または離れる。$R$ だけ改善して $|A_T|$ が減らなければ採らない。
   $A_\rho$ がほぼ 0 になると比が不安定なので、元の 3 振幅を併記すること。

## 当方の採否

| 指摘 | 採否 |
| --- | --- |
| 仮説 1「SLAU に接触波散逸が無い」は誤り | **採用 (撤回)**。`slau:562` の $-\frac{|u_n|}{2}\Delta\rho$ を見落としていた。README / plan の該当記述を訂正する |
| 指標の解釈 ($R=1$ は等温、エントロピー波成分ゼロではない) | **採用**。以後「比 $R$ = 等温からのずれ」と書き、接触波成分は $A_\rho-A_P/\gamma$ で別に測る |
| 代替仮説 (接触波散逸の**速度下限**の欠如) | **採用**。近壁は $u_n\to0$ なので SLAU の接触波散逸が消える、という機構は本件の近壁局在と整合する |
| 推奨 A/B (下限の不足分だけを接触波方向に足す) | **採用・実装**。`space.slauContactFloor` (既定 0.0 = ビット不変) として実装し、$\epsilon=0.001$ で A/B する |
| 「SU2 run の実際の下限値は未確認」 | **採用 (留保)**。本 A/B は SU2 の再現でなく**因果試験**として扱う |
