# diagnostician 諮問記録: ③ベル (M) を NS で評価するときの δ* の扱い (#7) (2026-10-12)

- 上位: diagnostician (Fable)。ブリーフ: [`briefs/2026-10-12-bell-m-deltastar-route.md`](briefs/2026-10-12-bell-m-deltastar-route.md)
- 対象: plan [`tooling-nozzle-bell-two-mode`](../../plans/active/tooling-nozzle-bell-two-mode.md) §4.4「δ* と物理寸法」・§5.1 #7・#8・§6 V3

## 結論 (原文要約)

生産の作り方は (C) — (M) の非粘性壁をそのまま物理壁として (D) と同じ NS recipe で評価。δ* の効きは (B) (NS からの一発補正) を L100 で 1 回回して測り、U_k の δ* 項にする。(A) (TP の積分法 + k_f の較正) は棚上げ。測った効きが 5e-4 を超えたら (B) を生産に昇格。根拠: (M) は停留輪郭なので δ* を補正しない損失は δ* の 2 次 (≈ |c₂|δ*² ≈ 1e-4 η)、有効 ε・スロート流量の 1 次項は (D) と共通モード。①風洞の積分法は δ* を 3〜12 倍過大にした。非粘性壁の ε は (C) では物理 ε と同じ、(B) では ε_inv = (√ε − δ*_e/r_t)²。スロートは補正しない (共通モード)。安い一手: ピン版 L100 の非粘性壁を (D) の recipe で NS 1 本 (η_M0) — どの道でも無駄にならない。ユーザの判断が要る点: (A) の棚上げと (C)、昇格の線 5e-4、スロート δ* を両モードとも補正しない。

## ユーザの決定 (2026-10-12)

主セッションが「補正で狙いに近づくのは壁圧・壁沿いのマッハ数・出口の分布 (1 次)、推力 (停留で 2 次)・有効出口面積 (物理 ε で固定)・摩擦損失は補正で変わらない」と説明したうえで:
- **δ* 補正は (M) の設計者の選択肢にする** (補正する / しない)。
- **補正の方法は、δ* の理論式を NS の計算結果で較正する形** (plan の (A) の向き — 積分法 + k_f の較正 — で、較正の元を NS の結果にする)。Fable の推奨 (C を生産・A を棚上げ) は「補正しない」側の既定としては採るが、(A) の棚上げは採らない。

## 当方の採否

| 項目 | 採否 | 理由 |
| --- | --- | --- |
| (C) 補正なしの評価 (V3 の (M) の既定) | **採用** | ユーザ決定で「補正しない」も選択肢として残る |
| (A) の棚上げ | **不採用** | ユーザ決定: 補正の方法は理論式 + NS 較正 |
| (B) の一発補正を生産の昇格先に | **不採用 (保留)** | 補正の方法はユーザ決定の理論式 + NS 較正。(B) は較正の検証手段として使える |
| 次の一手: η_M0 (非粘性壁の NS、L100) | **採用** | 補正なしの評価値で、較正の元データ (NS の δ*) にもなる |
| ε_inv の置き方・スロートを補正しない | **較正の設計の諮問で再確認** | 理論式 + 較正の形で、出口半径の合わせ方とスロートの扱いを決め直す |
