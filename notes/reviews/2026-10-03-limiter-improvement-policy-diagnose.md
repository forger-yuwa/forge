結論: **既定を維持し、許容逸脱量から定めた領域一定 ε̂=2×10⁻⁶ を opt-in で現行式と比較することを、次の一手として推奨する。**

第 1 仮説: **局所 h によって極小化した ε̂ を適度に大きくすると、精度を損なわず入口近傍の制限付き再構成の変動を抑え、残差床を改善できる。** 確度: **中**  
  根拠: `solver_density_cuda/cuda_forge/limiter_d.cu:375–396` と `limiterFunctions_d.cuh:43–46` は、その介入が作用する経路を確認できる。plan §5.1 #4r・#5a は小さい ε̂ と ψ の大振幅変動を記録している。ただし AWS の生データは手元に存在せず、数値は独立再検証できていない。  
  反証条件: 実効 ε̂ の変更を確認したうえで、十分な反復後も固定エッジの再構成変動と入口残差が改善しない、または改善に必要な緩和が下記の精度ゲートに違反する。この場合、**提案した許容誤差内の定数 ε̂ による改善策**を棄却する。ε 一般や丸めの関与まで除外しない。

第 2 仮説: **勾配射影・制限面の切替と陰解法更新の結合が支配し、許容できる ε̂ の変更だけでは床が下がらない。** 未確認。CFL 半減の結果は、この結合全般を除外していない。

判別 A/B: **同じ状態から、ε̂² の定義だけを変える。**

- 対照: 現行の ε̂²=(0.05 h_i/L_ref)³。
- 変更側: 領域一定 ε̂²=4×10⁻¹²。
- 共通条件: `case/16.nozzle_wys/run_0524_floor_dry_L1/res_48000.h5` の同一メッシュ index コピー、plan §4.2 の参照 4 値、CFL・BC・再構成・組成輸送を固定。同一ビルドで両腕を実行する。
- 長さ: 最初の **2000 step は有限性・精度・介入の動作確認**。失敗なら打ち切る。通過した場合は同じ比較を **48000 step** まで継続し、下降中なら延長する。2000 step の値を床とは呼ばない。
- 見る量: 入口集合 S の絶対残差ノルム、全 `rms_*`、固定エッジの ψ_iδ_m,ij の変動、全期間の近傍逸脱、壁圧・壁温。開始・終了に毎 step の 100 step 窓を置く。

**今回新たに提案する合格条件**は、末尾 10%・20% の両窓で入口残差と全域 `rms_ro` が対照の **1/2 以下**、固定エッジの再構成変動ノルムも **1/2 以下**、他の活動している残差列は **10% 超悪化しない**こと。これは改善策を選ぶ工学的基準であり、原因確定の閾値ではない。

→ **A: 改善条件と精度ゲートをともに満たす**なら、定数 ε̂ を採用候補として標準ケースへ進める。  
→ **B: 定常化した比較で改善条件を満たさない、または精度ゲートに違反する**なら、この定数 ε̂ 案は不採用とする。下降継続・標本不足は判定保留。

具体形・精度ゲート:

1. **ℓ と K を独立に調整しない。** (a) の形なら ℓ=1 に固定し、ε̂=2×10⁻⁶ は K≈1.5874×10⁻⁴ に相当する。既存 `venkatK` の意味を黙って変えず、新経路では ε̂ を直接指定する方が明瞭である。これは**試験値**であり、新しい生産既定値ではない。

   この選択には解析的根拠がある。同符号の増分の絶対値を d=|δ̂_m|、p=|δ̂±| とすると、現行式の制限後の逸脱は、厳密算術で

   **max(ψd−p, 0) ≤ ε̂/(2√2)**

   と抑えられる。提案値では上限が約 **7.1×10⁻⁷ q_ref** となり、既存診断の絶対床 10⁻⁶ q_ref より小さい。浮動小数点での実測確認は別途必要だが、0.011 を借りるより明確な根拠になる。

2. **case/16 の精度:** NaN/Inf・非物理再構成は 0。壁圧差 ≤0.1%、壁温差 ≤0.1 K。準定常性の判定窓内変動も、この比較許容差より十分小さくする。`check_convergence.py` と `check_quasisteady.py` の VERDICT・判定区間を添え、残差床が下がっただけなら「改善した未収束」と報告する。

3. **既定化前の精度:** Sod の 100/200/400 格子、同一 CFL・同一物理時刻で、ρ・P・u の L1 誤差を現行対照比 **1.01 以下**、観測次数の低下を **0.05 以下**とする案を事前登録する。根拠となる既存試験は `convection-node-wall-reconstruction.md:1040–1065`。近傍逸脱は全期間で測り、現行で 0 の変数に新規逸脱を許さず、既存逸脱の率・最大量も悪化させない。**診断許容幅を広げて通してはいけない。**

   加えて `procedures/verification/README.md:9–29` の node 標準ケース 05/09/36/44/46 と冷却壁 48 を対象とする。局所 h を外すため、Sod の流れ方向細分だけでなく、**滑らかな極値を含む問題の格子細分**も必要。これらが揃うまでは既定化しない。

4. **Wang 型:** 具体形は ε̂_q=K′(q_max−q_min)_global/q_ref。SU2 ソースの `CLimiterDetails.hpp:381–398` でも全域 reduction と二乗を確認できる。ただし一様な成分ではレンジが 0 となり、非零の平滑化幅を保証しない。外れ値や離れた強い衝撃にも左右されるため、今回の初手には選ばない。K′=0.05 の流用も不可。[SU2 公式説明](https://su2code.github.io/docs_v7/Slope-Limiters-and-Shock-Resolution/)

やらない方がよいこと: **ε と凍結の同時導入、SU2 の 0.011 の移植、入口だけの 1 次化、残差低下だけでの既定変更。** ε が不合格だったことだけを理由に、凍結へ自動的に進むこともしない。

凍結を後日導入すると判断した場合は、**再構成失敗点の再計算を許す FUN3D 型**を推奨する。ただし公式記述は「選択された点」での再計算であり、面だけの処理と同義ではない。forge では共有される節点 ψ、組成再構成、周期 group の整合が必要になる。凍結配列・有効状態・参照値を restart に保存し、メッシュ・BC・離散化変更時の解除も設計する。凍結後の残差収束は、元の動的リミッタ作用素の収束とは分けて評価する。[FUN3D 公式マニュアル](https://fun3d.larc.nasa.gov/papers/Website_June2014_Chapter06_Analysis.pdf)

呼び出し側の前提への異議: **ε が小さいという観測と、それが ψ の 0/1 振動・残差床の原因だという解釈が混在している。** また、細分で ε̂ が縮むことは、滑らかな極値で平滑化効果が消えることを意味しない。滑らかな極値では増分が O(h²)、現行 ε̂ は O(h³ᐟ²) なので、むしろ ε̂ が相対的に支配し得る。優先順「ε → 凍結」は支持するが、凍結は予約された次工程ではない。
