## codex の回答 (原文)

**現時点では真因を断定できません。** ①温度の単純な float32 丸めでは説明不足、②典型的な低マッハ圧力市松とは整合しにくい、③壁の熱的拘束は未検証の有力候補です。ただし、**SU2 型に替えれば 1/20 になるという根拠はありません。**

探索は 8 コマンド、ファイル変更・計算投入なしです。

**1. float32：単純な温度量子化は小さすぎる。ただし残差・更新の精度問題は残る**

`run_0009_uniformTw/res_wall_5_60000.h5` の保存値から得た全壁の中央値は次のとおりです。

| 量 | 値 |
|---|---:|
| 第一内部点までの距離 | 2.0002 µm |
| 有効熱伝導率 | 0.0405376 W/(m K) |
| 600 K 付近の float32 の 1 ULP | 0.0000610 K |
| 1 ULP に相当する \(k_\mathrm{eff}\Delta T/d_1\) | **1.237 W/m²** |

観測された **0.083 K は約 1360 ULP**。温度差 5–9 K に対する量子化誤差は約 \(10^{-5}\) の相対量であり、0.92% の熱流束変動を直接説明できません。小さい距離は信号と丸め誤差をともに増幅するため、**「2 µm だから温度丸めが約1%になる」わけではありません。**

一方、精度が効きうる箇所はあります。

- [viscousFlux_d.cu:107](/home/sano/work/forge/solver_density_cuda/cuda_forge/viscousFlux_d.cu:107)：float 座標同士の差から距離・非直交補正係数を計算。続く **228–229 行**で直接差分と非直交補正を加算するため、項同士が大きく相殺する場合は有効桁が減ります。
- [calcGradient_d.cu:770](/home/sano/work/forge/solver_density_cuda/cuda_forge/calcGradient_d.cu:770)：LSQ の近傍差分×係数を float で積算。伸長格子の係数と相殺が増幅要因になりえます。
- [SLAU 実装:561](/home/sano/work/forge/solver_density_cuda/cuda_forge/convection/convectiveFlux_slau_d.inc.cuh:561)：エンタルピー移流を組み、float の `atomicAdd` で残差へ積算。[粘性側:281](/home/sano/work/forge/solver_density_cuda/cuda_forge/viscousFlux_d.cu:281)も仕事・伝導を同じ残差へ加えます。**大きな面流束の差として小さい残差を求める段階**が主要な候補です。
- [timeIntegration_d.cu:1084](/home/sano/work/forge/solver_density_cuda/cuda_forge/timeIntegration_d.cu:1084)：陰解法補正を float に書き戻します。線形解法の誤差や、保存量更新時の微小補正の消失も、温度そのものの ULP とは別問題です。

保存場には面別残差・更新補正がないため、**これらが 0.083 K を生んだとは数値で立証できません**。過去の幾何桁落ち事例も、今回の帰属を直接証明しません。

**2. 低マッハ前処理：backstep の成功をそのまま適用できない**

[SLAU 実装:516](/home/sano/work/forge/solver_density_cuda/cuda_forge/convection/convectiveFlux_slau_d.inc.cuh:516)では、`lowMachPrecond=1/2` が質量流束中の圧力差項 `−χ ΔP/c` を変更します。`=2` は陰解法側の前処理も伴います。

[backstep の既存比較](/home/sano/work/forge/plans/accepted/time_integration-lowmach-preconditioning.md:256)では、圧力 odd-even が `=0` の 38.2 Pa、LHS だけ変更する `=3` の 43.5 Pa に対し、`=2` は 5.6 Pa。これは圧力市松に対する裏付けです。

今回の **T・速度が同期し、P は相関 −0.04** という既知結果は、その機構を主因とする説明を支持しません。厳密には相関だけで間接的な圧力作用まで否定できませんが、**「壁で M→0、したがって前処理不足が原因」とは判定できません**。また `=2` は空間残差も変えるため、効いても単なる収束加速とは限りません。

**3. 壁 T ピン：離散問題は確かに違うが、ピン自体が欠陥とは言えない**

現行コードの順序は、

`保存量更新 → no-slip → T/roe/P ピン → EOS・物性・壁乱流条件 → 勾配・流束 → 壁残差ゼロ化`

です。[main.cpp:1348](/home/sano/work/forge/solver_density_cuda/main.cpp:1348)

さらに [nodeWallDirichlet_d.cu:63](/home/sano/work/forge/solver_density_cuda/cuda_forge/nodeWallDirichlet_d.cu:63) の状態ピンと残差ゼロ化に加え、[timeIntegration_d.cu:1025](/home/sano/work/forge/solver_density_cuda/cuda_forge/timeIntegration_d.cu:1025)で壁エネルギー行を単位行化します。つまり壁エネルギー自由度を拘束しています。

**残差ゼロ化だけを根拠に、内部点の熱拡散が欠落しているとは言えません。** 内部点側には壁との直接温度差による伝導が残ります。強い Dirichlet 条件として成立する構成で、[純伝導の既存検証](/home/sano/work/forge/methods/boundary.md:174)もあります。

ただし SU2 の自由な壁状態は、第一内部点との交換・局所勾配を変えます。これは十分に検証価値のある違いです。しかし対流・内部熱拡散も SU2 と異なるので、**現在のコード間比較から20倍差を壁拘束へ帰属できません。**

なお現行 `main.cpp` にはピンを EOS より前へ移した修正があります。**現行順序が既存 run の実行バイナリにも入っていたかは今回確定していません。** 順序の不具合と、強い温度拘束そのものは区別が必要です。

**既知の node 壁エントロピー市松と同じか**

**症状は近いものの、同一原因とは断定できません。**

[該当 plan §2.8](/home/sano/work/forge/plans/active/boundary-node-nozzle-wall-outlet-stability.md:160)は、memory の「未解決」から更新されています。旧事例は断熱壁の壁節点で、断熱熱漏れ修正による大幅改善、その後の現行構成での実質解消が記録されています。ただし後者は幾何修正と壁間隔変更が交絡し、帰属未確定です。

今回は等温ピンされた壁の**第一内部点**です。旧事例の laminar 再現は「SST が必要条件ではなかった」ことを示しますが、今回まで同じ基底欠陥とする証拠にはなりません。

**次の A/B は一つ：forge 内で熱的壁拘束だけを SU2 型へ変更する**

同一の `res_60000.h5` から、新規ディレクトリに複製した A/B を開始します。精度・メッシュ・SLAU・SST・CFL・リミッタ・前処理は固定し、同じソース版を使います。

- **A：現行の強い等温拘束。**
- **B：壁温状態ピン、壁エネルギー残差ゼロ化、陰解法のエネルギー行拘束を一組として解除し、指定温度 566 K と第一内部点から求めた SU2 型の壁熱流束を、壁エネルギー式へ整合する符号・面積・線形化で与える。** 運動量の no-slip と SST の壁条件は維持する。

**`nodeWallDirichlet: 0` だけでは不可**です。運動量条件まで変わります。また現行の node 壁流束は [viscousFlux_d.cu:529](/home/sano/work/forge/solver_density_cuda/cuda_forge/viscousFlux_d.cu:529)で壁勾配を使うため、ピンを外すだけでも SU2 型にはなりません。

評価量は既存と同じ区間・同じ定義の **第一内部点 T と q の交番振幅**。壁温の変動による見かけの相殺を避けるため、T 側も必須です。

| 結果 | 確定できること |
|---|---|
| A が再現し、B で T と q がともに約1/20へ低下 | **熱的壁閉包の変更だけで差を除去できる**。ただしピン・壁流束・線形化のどれが効いたかまでは分離できない |
| A/B がともに同程度で落ち着く | **SU2 型壁閉包への変更だけでは20倍差を説明・解消できない**。float32 や内部離散化のどちらかが確定するわけではない |
| A 自体が低下する／片側が未収束・発散 | 元の振幅の持続性や実装版・反復過渡が交絡し、帰属不能 |
