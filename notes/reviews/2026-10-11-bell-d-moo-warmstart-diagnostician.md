# diagnostician 諮問記録: ③ベル (D) の MOO — warm start の発散と第一セル厚の余裕 (2026-10-11)

- 上位: diagnostician (Fable、このセッションはユーザ指示で Fable)。ブリーフ: [`briefs/2026-10-11-bell-d-moo-warmstart.md`](briefs/2026-10-11-bell-d-moo-warmstart.md)
- 対象: plan [`tooling-nozzle-bell-two-mode`](../../plans/active/tooling-nozzle-bell-two-mode.md) §4.1・§5.1 #8a。エスカレーション条件 4 (手順の変更とキャンペーンの回し直しの前)

## 依頼内容

(D) の MOO (`case/68.bell_two_mode/run_0010_moo_d`、AWS B) で、warm start (最近傍の cross-mesh 補間) の doe_001 が本段で発散した (出口の壁の角から逆流が育ち step 41558 で NaN)。同じ形を冷間の段階起動で回した A/B (`run_0011_tp_d_doe001_cold`) は全ゲート PASS (η_exit 0.970260)。warm start の doe_002 は壁解像で FAIL (y1+ 最大 1.096、1 超え 7.3 %)。下流の第一セル厚を ×0.7 にした格子は AR 最大 3770 で不変。主セッションの案: (1) TP は全点冷間、(2) 下流の第一セル厚 ×0.7、(3) 新しいディレクトリで最初から回し直す。

## 結論 (原文要約)

**案 1 と案 3 は採用。案 2 (×0.7) は doe_002 には足りるが範囲全体の根拠が無いので、キャンペーン投入前に最も圧縮の強い成立点 1 点を ×0.7 の格子・冷間で回して y1+ を測る。**

1. **全点冷間 (確度 高)**: A/B は 1 変数。冷間の段階起動は 4/4 PASS (run_0008・0009・doe_000・run_0011)。`driver.py:410-421` の `_warm_for` は PASS が 1 つあれば必ず最近傍 PASS の場を返すので、run_0010 では doe_000 以外の全点が warm だった (2/2 で問題)。機構は `interp_field.py:212-216` の仕様からの推論: 生座標の cKDTree の最近傍で、新しい壁が旧い壁より外にある帯 (θ_max 32° > 24°、最大 ≈ 1 r_t) に旧い壁節点の値が入る → 本段の `outflow` に亜音速の層が接して逆流が育つ。**soft・mid は warm start の保険にならない** (本段開始時点で出口の角の帯が Ux 最大 1568 m/s のまま)。TP で warm start を残す理由は無い (段の長さは同じ、CPG の docstring の不始動の偽アトラクタは warm start の害)。冷間に揃えると評価が評価順に依存しなくなる。
2. **冷間の別の失敗 (確度 中)**: 冷間の実績は θ_max 24〜32°・θ_e 10〜17°・L 16〜18 で、範囲の角は未試行。キャンペーン中に見るもの: fail_class の dv 空間の分布、RETRYABLE の失敗段 (soft/mid なら IC、本段なら 2 次/SST)、**同じ fail_class が 3 連続で停止、DOE の RETRYABLE + SUSPECT が 20 % を超えたら停止して諮る**、PASS < 4 の例外、infill が同じ失敗領域を繰り返し提案していないか、ω のプラトー (#3f の観察)。
3. **×0.7 で足りるか (確度 中)**: y1+ は第一セル厚に線形なので doe_002 は 0.77 になるが、doe_002 の最大位置 (x 13.0 r_t、θ_e 2.63° の再圧縮域) より厳しい角 (θ_max 45°・θ_e 2°・L 短) では超え得る (他の 4 本 0.82〜0.85 から doe_002 1.10 へ 30 % 跳んだ)。格子で余裕を取る代償はほぼ無い (AR 最大はスロート側)。**判別 A/B**: 最も圧縮の強い成立点を `wall_first_frac 1.75e-5` で冷間 1 本。**A**: y1+ 最大 ≤ 0.9 かつ超過 0 % → ×0.7 で本番。**B**: それ以外 → 1.25e-5 (×0.5) で同じ点をもう 1 本 → PASS なら ×0.5 で本番。この 1 本は「角で冷間が起動するか」も答える (本段で発散したら recipe を諮ってから)。ゲート (許容 2 %、目標 1) は変えない。
4. **RETRYABLE の扱い (確度 中)**: 自動再投入はしない、サロゲートにも入れない (現行どおり)。run_dir と最後の res を残し、DOE の後にまとめて見る。集中していれば recipe 変更を諮ってから手動で再評価し、同じ台帳に `retry_` タグで足す。
- **新キャンペーンでの記録**: 同じ seed・bounds なら LHS の x は同じなので、新キャンペーンの doe_000・doe_001 と run_0010/doe_000・run_0011 の η_exit の差を第一セル厚の格子感度として記録する (期待 |Δη| ≲ 1e-4)。
- **やらない**: warm start の補間を正規化座標に直す、壁解像ゲートを緩める、soft/mid の延長や cfl の変更を「保険」として同時に入れる、run_0010 の台帳に新しい点を混ぜる、×0.7 を測らずに 60 点を投入する。
- **異議**: 機構の細部 (帯の値の由来) は推論として書く。「soft・mid は下がった」を段階起動が効いた根拠にしない。y1+ 0.77 の見込みは doe_002 だけ。doe_002 の η_exit 0.965720 は warm 経路の値なので比較の基準にしない。
