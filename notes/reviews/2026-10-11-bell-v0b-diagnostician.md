## 要旨

1. **V0 は締める**: θ_max 違反 2 点の除外 → 57.1 %、n161 不一致 2 点を通過に → 18/29、出口直前の弱い不受理 2 点を通過に → 69.0 %、marginal 1 点を不受理に → 53.6 %。どれでも中間。事前登録の処置 (S1 と (D) の MOO を並行) は変わらない。V0-c は族の定義が変わったための記録の更新 (新しい判断ではない)。
2. **(D) の最小の直し方 (#3d)**: 成立条件 (ii) を「r'' ≥ −tol on [0, x_m] かつ r'' ≤ tol on [x_m, L]」に置き換える (`_sign_changes` が |r''| ≤ 1e-10·max を飛ばすので x_m で r'' が 0 に接して符号を変えない壁が通っていた)。`v0b_sliver_check.csv` の細い成立区間 10 点は全部この接触型で本物の窓ではない。残り 29 点は新条件でも成立。併せて成立区間の端を走査点の間で二分法で詰める (x_m の 0.025 刻みの量子化を消す)。J 最小の規則は変えない。
3. **ゲートが帯内の x_m に敏感なのは主に物理**: (D) の min-jerk 壁は圧縮波の合体を出口近傍まで引き延ばし、x_m を動かすと合体点が x = L をまたぐ (弱い不受理群の開始 x/L 0.87〜0.97)。二値のゲートが x = L で崖になる。判定側の副次の問題: n 依存は弱い合体の検出感度、**C⁺ 族の間隔比の指標は初期線側の前線を基準にするアーチファクトで使えない** (`moc_forward.py:854-870`)。MOO の制約は二値でなく連続の余裕 (C⁻ 間隔比の最小 [x ≤ L] ≥ 0.2、C⁺ は n 321・161 の両方で反転 0) にし、C⁺ 指標の正規化を MOO の前に直す。
4. **書き方**: 言ってよいのは「V0-b = 中間 (再割当てで 54〜69 %)」「40° 全不受理は一致、他 2 パターンは不一致 (合体点が出口面の前後)」「θ_max 25°・θ_e 10° の (D) は L80・L90 で通過、同じ格子点の TOP は全 L で不受理」。言わないのは「(D) は内部衝撃波が無い」「(D) が TOP より良い」「Rao の台地を含む」(Phase 2 の台地の L が未確認)。
5. **次の一手**: #3d を実装して V0-c を回す。**V0-c の事前登録**: A = 分類が中間のまま、かつ n161 不一致 ≤ 2 → V0 を閉じ、(D) の MOO の準備と S1 を並行、④の基部は (D) 先行。B = 分類が変わる・有効条件が破れる・既存 29 点のうち合否が 4 点以上反転 → 再諮問。
