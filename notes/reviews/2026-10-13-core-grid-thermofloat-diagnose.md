第 1 仮説: **`thermoFloat: 1` 内の float 量子化・近似評価が、この微小補正に対する非比例応答の主要部分を作っている。** 確度: 中

根拠:

- **組成の丸めは double 研磨では直らない。** `dependentVariables_d.cu:95`〜`:103` は、ρY/ρ と正規化を float で行い、その結果を double の `Y` に戻す。保存量から計算した組成がほぼ一定でも、ρ が変われば計算途中の丸めによって `Y` が段差状に変わり得る。double Newton は、その丸められた組成に対する温度を解く。
- 凝縮なし・床が非活性なら P = ρR(Y)T（同 `:201`）。したがって組成の丸めは **R と T の双方**を通じて P に入る。「T を double で研磨するから P も滑らか」は成立しない。ブリーフの T 約 2e−6 K の誤差を説明する規模かは、まだ未確認。
- `thermo_d.cuh:728` は float の初期研磨点を作り、`:750` は有限の更新量を基準に研磨を終了する。滑らかな物性・非クランプ条件なら Newton 後の温度誤差は通常二次に小さくなるが、**ゼロにはならず、今回の差分に十分小さい保証もない**。
- さらに cp は最終温度ではなく研磨点で評価され、h は一次 Taylor で組まれる（`dependentVariables_d.cu:173`、`:182`）。γ と音速には明示的な float 演算が残る（`:186`、`:225`）。**FP64 の状態格納でもこの経路は残る。** これらは T・P の誤差が小さくても残差応答に影響し得る。

反証条件: 入力・評価時点・射影をそろえた有資格の比較で、`thermoFloat: 0` にしても両腕の ‖N‖ が旧経路の 90 % 以上残るなら、**この切り替えで除去できる誤差が主因という仮説**を退ける。

第 2 仮説: 熱物性経路以外の分岐・有限振幅の非線形性が主因。確度: 低〜中、未確認。μt の小さな変化と節点速度の符号反転数だけでは、面再構成後の風上切り替えやリミッタを除外できない。

判別 A/B: **変更は `physProp.thermoFloat` の 1 → 0 のみ。新規評価は 5 本、各 1 step。**

資格は次を事前登録する。

- 同じバイナリ・物性・メッシュ・環境変数を使い、実効設定が `physProp.thermoFloat: 0` になったことを確認する。読み取り階層は `solverConfig.cpp:1093`〜`:1095`。
- 9 保存量の入力一致と、半補正が全成分について Q0 + δ★/2 になっていることを確認する。温度初期推定の与え方も対応する旧評価とそろえる。
- `res_1` の残差は更新前、保存量は更新後として扱う。出力保存量から今回の入力状態を逆算しない。
- 圧力射影・c²・体積重み・領域は旧判定器の値に固定する（`cg_pg_hist_judge.py:22`〜`:26`）。非有限、床・クランプの作動、差分信号に対する丸め誤差を確認する。
- Q0 の共用は、評価対象の更新前残差が Γ に依存しないことを条件とする。

各経路 m について、同じ射影後に

`N_m = R_m(Q½) − ½R_m(Q1) − ½R_m(Q0)`

`ℓ_m = ‖N_m‖ / ‖½[R_m(Q1) − R_m(Q0)]‖`

を求める。主判定は縮流部 x/r_t ∈ [−8, −2]、GI・GB の双方で行う。

- **A:** `ℓ₀ ≤ 0.05` かつ `‖N₀‖ ≤ 0.1‖N₁‖` → この状態・補正方向で、熱物性評価経路の切り替えが非比例成分の大半を除去したと判断する。
- **B:** `‖N₀‖ ≥ 0.9‖N₁‖` → この切り替えで除去できる誤差が主因という説を退ける。
- 中間、腕で割れる、信号不足、資格不足 → 判定不能。

T・P の比例誤差 `≤ 1e−3` は**補助診断**として残す。残差だけ改善する場合は γ・音速などの寄与が残るため、T・P の合否を経路全体の判定と同一視しない。可能なら同じ評価から `Rmix`・cp・γ・音速の比例誤差も併記する。

やらない方がよいこと: 成功直後に `thermoFloat` の既定値を変更する、Newton だけを修正する、B0・point の停滞原因が確定したと報告すること。A で言えるのは**固定状態の有限差分評価への寄与**までであり、長時間のプラトーを支配していること、Γ の設計が正しいこと、収束改善は未証明。§4.90 の再試験は可能だが、補正を新経路で求め直し、SST を含む資格を改めて満たす必要がある。

呼び出し側の前提への異議: 「組成が一様」は float 経路内部の組成まで一定である証拠ではない。また、判定器の `wall_interior` は x/r_t ∈ [−2, 0] で、主判定の縮流部とは異なる（`cg_pg_hist_judge.py:22`〜`:23`）。ブリーフの T・P の表がどちらの領域かを明示し、残差の主判定領域でも同じ統計を出すこと。履歴差については §4.93 の ‖D/2‖/‖N_old‖ ≈ 1.5e−5 という記録から、今回の主因候補には戻さない。
