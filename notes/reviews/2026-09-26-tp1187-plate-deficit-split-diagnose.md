結論: **(a) を採用し、同一バイナリ・同一実効設定の 2D 平板で、壁法線の節点分布だけを変える A/B を行う。**

第 1 仮説: **粗い壁法線分布が、入口移送やすきまがなくても平板の `qwall` を低下させる。** 確度: **中**
  
  根拠: 2D は単一の等比分布（[gen_mesh.py:61](/home/sano/work/forge/case/56.gap_tp1187/gen_mesh.py:61)）、3D は近壁部と外側で別々に分布を決め、外側の第一間隔は円弧分割にも依存する（[gen_mesh_gap3d.py:306](/home/sano/work/forge/case/56.gap_tp1187/gen_mesh_gap3d.py:306)）。**第一層 8 µm が同じでも、境界層全体の離散化は揃っていない。** ただし、これだけでは熱流束への影響の符号・大きさは証明できない。`3D/2D = 0.9108` は [plan #60:919](/home/sano/work/forge/plans/active/case-hypersonic-gap-heating-validation.md:919) の記録値であり、今回は読み取り制限により実測を再検証していない。

  反証条件: 下記 A/B が判定可能な状態まで達したとき、粗／細の比 R ≥ 0.95 なら、**「壁法線の粗さ単独で 5 % 超の平板不足を生む」という仮説を退ける**。3D 固有の離散化や入口移送との相互作用まで否定したことにはしない。

第 2 仮説: **H2：移送された入口分布と受け側の離散方程式の不整合による再発達。** 確度: **中・影響未確認**。抽出コードは `Uy`・`k`・`omega` を渡している（[extract_inlet_table.py:38](/home/sano/work/forge/case/56.gap_tp1187/tools/extract_inlet_table.py:38)）ため、「乱流量を渡していない」という説明は支持されない。実際の入口 CSV と適用後の値は未確認。

第 3 仮説: **H3：上流横すきまの影響。** 確度: **低・未確認**。ブリーフの上流側不足は優先度を下げる材料だが、閉塞比較がなく、除外済みとは扱わない。

判別 A/B: **変更点は壁法線の節点座標列だけ。**

- **細側**：既存 2D 平板の格子。**粗側**：3D の平板入口列と同じ高さ配列を採用する。第一間隔だけ合わせたり、`--r-y` 一つで近似したりしない。
- 2D の流れ方向格子、トリップ位置、一様流入口 BC、壁温、物性、SST は固定する。**一様流 BC と、一様場からの初期化は別**。既存場を初期推定として使い、細側は同一メッシュ restart、粗側は cross-mesh restart とする。
- **上端高さは既存 2D のまま保持する。** 生成器の既定値は 2D が 0.35 m、3D が 0.08 m（[gen_mesh.py:85](/home/sano/work/forge/case/56.gap_tp1187/gen_mesh.py:85)、[gen_mesh_gap3d.py:530](/home/sano/work/forge/case/56.gap_tp1187/gen_mesh_gap3d.py:530)）。3D の高さ配列の上に外側層を延長する。全長平板の上端まで 0.08 m に下げると、境界位置の変更が交絡する。
- 両側を同一バイナリ・CUDA blocksize・明示した `limiter` 設定・`qAccumulatorFP64` 設定で実行する。**古い細側の保存結果を、そのまま唯一の対照にしない。**
- 長さはまず **20,000 step、2,000 step ごと保存**。これは判定終了の保証ではない。`check_convergence.py` の適切な同一設定区間での `PASS` と、比較する `qwall` 系列の `check_quasisteady.py` による `STEADY` が揃うまで延長する。未達なら判別不能として残す。
- 評価位置は前回比較の 29 断面に対応する **x₂ᴅ ≈ 1.780–1.860 m**。両側の `VALUE/qwall` から **R = meanⱼ(q粗(xⱼ)/q細(xⱼ))** を求め、断面別の比も併記する。**許容差は 5 % に固定。**

→ **A：R < 0.95** なら、入口移送・すきまを必要とせず不足が出るため、H1 を採用する。H2/H3 を「不足発生の必須原因」から外せるが、3D への寄与は残る。  
→ **B：R ≥ 0.95** なら、上記の限定した H1 を退け、入口移送を次の優先候補にする。**H2 の確定ではない。**

やらない方がよいこと: **(c) の片側差分を決定実験にしない。** 第一内部点が同じなら、その差分は同じ値になり得る一方、ソルバを再実行した際の温度・乱流場の変化を検査できない。また、この A/B より先に高価な 3D 細分化や L30 再投入へ進まない。

呼び出し側の前提への異議:

- **Major — 「同じモデル・設定」の確認が不足している。** [3D solverConfig.yaml:19](/home/sano/work/forge/case/56.gap_tp1187/run_0065_L15_v2/solverConfig.yaml:19) は `qAccumulatorFP64: 1`、同ファイル24行は `limiterRoRef/PRef/ARef` を明示するが、[2D solverConfig.yaml:19](/home/sano/work/forge/case/56.gap_tp1187/run_0002_fp_t8_long/solverConfig.yaml:19) では省略されている。省略時の実効値・実行バイナリが不明なので、差の原因とは断定できない。**対案：今回の両腕で実効値とバイナリを固定する。**
- **Major — 時間変動 <0.05 % を収束・準定常の認定に使えない。** plan #60 の記録では両既存 run は `NOT CONVERGED (stalled/plateau)`。記録された `ALL STEADY` は TC 観測量の系列であり、今回の平板比較系列の VERDICT ではない。**対案：平板比較量そのものに判定ツールを適用する。**
- **Major — 平板の格子感度を TC90–95 の補正倍率へ転用しない。** 今回提案する A/B には、3D の取り込み・衝突域が存在しない。根拠となる `0.9108` も plan #60 の平板比較値に限られる。**対案：結果を平板の機構判別に限定し、衝突域への波及は未確認と明記する。**

不足情報: **3D 格子の実生成引数と完全な入口高さ配列、両既存 run の実行バイナリ・実効設定、平板比較系列の VERDICT と再現可能な抽出スクリプト。** 今回は `res_*.h5` を読まず、判定ツールも実行していないため、数値結果の独立認証はしていない。
