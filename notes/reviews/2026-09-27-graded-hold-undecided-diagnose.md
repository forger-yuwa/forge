結論: **B のみ同一設定で +20000 step 継続する追加検証を事前登録し、新規 run で累積 30000–40000 step を再判定する。**

第 1 仮説: `qerr_cj` の判定未了は減衰中の過渡によるもので、追加20000 stepで現行基準を満たす。確度: **中**。  
  根拠: `case/62.conjugate_disk/run_0017_hold_B_conduct/static_hold_series.csv` のツール判定窓は厳密には **10100–20000**。この100点で増分比の中央値は **0.94635 / 100 step**。誤差は単調増加するが増分は減衰している。幾何減衰を仮定した外挿値は約 **0.00565276 %**であり、これは予測であって合格根拠ではない。  
  同 run の `CONVERGENCE_VERDICT.txt:2`–`9` は **`PASS (converged)` / `OVERALL: ALL PASS`**。今回再実行した準定常判定は **`qerr_cj: DRIFTING` / `OVERALL: NOT ALL STEADY`**。残差合格と静止保持合格は分ける。  
  反証条件: 累積30000–40000の固定窓で `qerr_cj` が `STEADY` にならなければ、「追加20000で十分」は棄却する。ただし、それだけで不安定性や slip 起因を確定しない。

第 2・第 3 仮説: 追加しない。今回の資料では、元の H1/H3 の順位を変える証拠がない。

判別 A/B: **変えるのは反復長だけ**。A＝既存Bの20000 stepまで、B＝同じ状態から累積40000まで。元の一様ICのAは延長しない。  
  → **延長側で全条件を満たすなら**、今回の未了は待ち時間不足だったとの仮説を支持し、純伝導IC限定の再登録へ進む。  
  → **延長側でも未達なら**、今回の延長で解消する仮説を棄却して停止する。閾値超過なら静止保持失敗、閾値内でも非定常なら判別未了を維持する。

  既存6系列の `--tail 0.5 --drift 0.001 --osc 0.001` は維持する。準定常ツールには**継続区間だけ**を渡す。累積系列全体に `--tail 0.5` を掛けると別の窓になる。残差は、同一設定であることを確認した旧区間＋継続区間を累積stepで連結して通常判定し、継続区間単独に再度数桁の低下を要求しない。

やらない方がよいこと: 誤差が許容の約1/90だから合格扱いすること、合格するまで窓や延長長を動かすこと、静止保持合格前にCHTを始めること。

呼び出し側の前提への異議: **「全壁節点の熱流束の準定常性を確認済み」は受け入れない**。確認済みなのは最大誤差の系列である。また、今回の相対 drift **0.553 %** は誤差自身に対する値で、熱流束誤差の包絡値の変化に換算すると **3.76e-5 W/m² / tail**。小さいという観測は正しいが、登録済みの不合格を覆す理由にはならない。

不足情報: 各壁節点の符号付き熱流束系列とそのVERDICT、再開元保存量の実際のdtype・再開直後の連続性。`--keep-src-dtype` だけでは元出力の精度は保証できない。元の一様ICのAについては今回の閲覧範囲では独立再検証していない。
