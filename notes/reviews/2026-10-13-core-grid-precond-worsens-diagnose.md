結論: **`lowMachPrecond: 3` の Γ を保ち、`dt_local` の拡大だけを有効／無効にする A/B を行う。**

第 1 仮説: 前処理に伴う局所刻みの拡大が、近壁の反復を増幅側へ変えている。確度: **中**。
  根拠: `setDT_d.cu:274` は既存の `dt_local` 全体を拡大する。平均流の時間対角は `timeIntegration_d.cu:1354`、SST の時間対角も `update_d.cu:397` でこの刻みを読む。一方、平均流の対流ブロックは物理の Jacobian のまま (`timeIntegration_d.cu:1374`)。したがって、音響速度の変更だけで安定性を保証できない。
  観測との対応: `case/45.isobutane_m6_d155/run_0689_pp_p3/` は縮流部の ρ 残差が 676 → 1296、`run_0690_pp_p2/` も 630 → 1170 と後半に増加した。対照 `run_0688_pp_c/` は 73 → 49。両前処理腕に共通する Γ と刻みのうち、まず刻みを分離する。
  反証条件: 拡大を外したことを同一状態で確認しても、対照と同程度の持続的増加が残るなら、**「拡大を外せば今回の増加が解消する」という仮説を退ける**。

第 2 仮説: β < 1 における境界拘束と Γ の組合せが、近壁の補正を悪化させている。確度: **低、未確認**。`timeIntegration_d.cu:1440`・`:1464` は拘束行と `gvec` を対応して処理しており、コード上の明白な行処理漏れは見つからない。ただし β = 1 ではランク1項そのものが消えるため、その回帰試験は β < 1 の検証にならない。

第 3 仮説: 今回は独立候補として追加しない。β の空間変化の寄与は未確認で、現状では第 1・第 2 仮説から分離する証拠がない。

判別 A/B:

- **変更する一点**: `setDTlocal_precond_scale_d` の倍率を通常どおり適用する腕 S+ と、倍率を 1 に固定する腕 S0。これは**新設する診断用スイッチの提案**で、既存の YAML キーではない。`lowMachPrecond: 3`・`precondEps: 0.15` と Γ の計算は両腕で維持する。
- **構成・長さ**: 同じ診断バイナリ、`run_0608_cg_gref_cont_k1/res_60000.h5` の同一保存量から、新規 run を各 20,000 step。point・`cfl_pseudo: 1`・`implicitRelax: 0.7`・`nStepInner: 5` を固定する。既存 P3 は再現確認に使い、直接の対照は同じバイナリの S+ とする。
- **資格**: 初回更新前の同一状態で、右辺が一致し、S0 の刻みが拡大前の刻みに一致し、S+/S0 がコードの期待倍率になることを確認する。SST・化学種など、同じ `dt_local` を読む経路にも変更が届くことを記録する。
- **見る量**: 縮流部 x/r_t ∈ [−8, −2] に加え、今回の悪化場所である x/r_t ∈ [−2, 0]・壁から 0〜10 節点目を固定して、全保存量の体積重み付き RMS を時系列で取る。1,000 step ごとに記録し、W1 = 10k〜14k、W2 = 16k〜20k の非重複窓で d = q̄(W2)/q̄(W1) を求める。
- **結果 A**: S+ が増加を再現し、両領域の ρ・ρE で S0 の d ≤ 0.8、かつ両窓の傾きが負 → 刻みの拡大への依存を支持する。他の保存量・領域への悪化移動があれば、改善とは判定しない。**Γ の正しさ、流れと SST のどちらが原因か、旧 CFL 上限との同一機構までは言えない。**
- **結果 B**: S+ が増加を再現し、S0 でも両領域の ρ・ρE が d ≥ 1.1、かつ d_S0/d_S+ ≥ 0.8 → 拡大の除去で解消する仮説を退け、第 2 仮説を優先候補にする。ただし境界実装の不具合を確定したとは言わない。
- 中間・成分間の不一致・対照の再現失敗は判定不能。閾値は診断用の事前登録値で、収束基準ではない。両腕の `check_convergence.py` の VERDICT を添える。

やらない方がよいこと:

- **[Major] `=0`・`cfl_pseudo ≈ 6.5` を「刻みをそろえた対照」と呼ぶこと。** 倍率は局所状態に依存し、ブリーフでも壁で 6.67、内部で 3.2〜5.0。単一 CFL では局所刻みを一致させられず、Γ も異なる。対案は上の倍率だけの A/B。
- **[Major] `precondEps` を先に変えて原因を判定すること。** 刻みだけでなく β と Γ も変わる (`setDT_d.cu:268`、`timeIntegration_d.cu:1466`)。対案は ε を固定すること。

呼び出し側の前提への異議:

- **[Major] 「6.7 × 0.7 ≈ 4.7 だから旧上限 6〜8 に近い」は根拠不足。** 4.7 は引用した上限より低く、旧試験は格子・バイナリ・発散場所が異なる。README `:320`〜`:323` の結果は候補を考える材料であり、今回の安定限界ではない。対案は現在の構成で拡大の因果効果を測ること。
- **[Major] 「粘性の説は外れた」は範囲を狭める必要がある。** 示されたのは壁法線方向の推定比の中央値であり、局所最大・全接続面・熱伝導・実際の反復作用は確認していない。実装の刻みは面 CFL の最大値を使う (`setDT_d.cu:191`)。また、粘性込みの刻み全体を拡大する処理は、音響部分だけを縮めて刻みを再計算する処理と同じではない。対案は「調べた帯の中央値では、拡大前の音響項が優勢だった」と限定すること。
- **[Minor] 約 25 倍は RMS の倍率ではない。** ブリーフの全域量は ΣV(R/V)²。同じ体積なら RMS 比は約 √25 = 5 倍。対案は二乗和と RMS を区別して表記すること。

不足情報: 現行状態で刻みと Γ を分離した比較、および β < 1 の壁ブロックの実測がない。既存３腕の **`VERDICT: NOT CONVERGED` は plan §4.83・§4.85 の記載を引用**したもので、禁止された生データの再読・判定再実行はしていない。ファイル変更・計算起動なし。**plan 未反映**であり、本提案の登録は依頼どおり呼び出し側が行う。
