結論: **最終 δ に対する Nδ の直接評価を共通の計測処理に加え、`run_0632` の Q₀・Q₁ を固定して、右辺の再構成次数だけを変える A/B を一つ行う。**

第 1 仮説: **二次再構成を含む右辺と、一次 FVS を使う左辺の応答差が、島の ρ・ρE の減衰不足の主要部分を担う。** 確度: **低**  
　根拠: 左辺は自節点状態を使う閉形式 FVS で組み立てられる（[`timeIntegration_d.cu:893`](/home/sano/work/forge-coregrid/solver_density_cuda/cuda_forge/timeIntegration_d.cu:893)）。`case/45.isobutane_m6_d155/run_0632_cg_resp_cap50/` では、暫定の不足 d_lhs−d_act が ρ **0.0812**、ρE **0.1864**。ただし、再構成への帰属は未確認であり、これを最初に試す理由は変更を一つに限定できるためである。  
　反証条件: 計測資格を満たした固定状態の比較で、一次化による応答差が e の大きさ・減衰を妨げる射影の双方に対して小さいこと。

第 2 仮説: **一次化しても残る、SLAU と FVS の流束応答の違い。** 確度: 低。低マッハ・圧力速度結合への帰属は未確認。

第 3 仮説: **平均流に依存する粘性・熱伝導係数や、その結合の左辺での近似。** 確度: 低。SST 保存量の凍結は μt 固定ではなく、この経路は除外されていない（依頼ファイル内 plan §4.39）。

判別 A/B: **`space.convMethod` だけを現行の二次から `0` に変える。**

- 入力は両腕とも `case/45.isobutane_m6_d155/run_0632_cg_resp_cap50/` の同じ Q₀・Q₁。δ = Q₁−Q₀、左辺、上限、SLAU、リミッタ設定、物性・境界条件を固定する。**一次化した右辺から新しい δ を作らない**。`convMethod: 0` が一次、`limiter: 0` はリミッタなしであり、操作を混同しない（[`solver-settings.md:9`](/home/sano/work/forge-coregrid/procedures/solver-settings.md:9)、設定階層は `solverConfig.cpp:637`）。
- 各次数について Q₀・Q₁ から **各 1 外反復、計 4 回の残差評価**を行う。読むのは更新前の残差。元の次数で既存の R₀・R₁ を再現できることを先に確認する。
- 共通の計測処理として、**Q₀ で係数を固定したまま、全てのライン外近傍の δ を使って bδ = b₀−Nδ を直接評価**する。これから Aδ と真の g を作る。旧近似との差は、島の各成分について主判定と同じノルムで測る。新しい計測資格は事前登録し、例えば真の ‖g‖/‖Aδ‖ ≤ 0.01、残差再現誤差も信号の 1 % 以下とする。資格不足なら項別の結論を出さない。
- 有限補正への応答を ΔR₂、ΔR₁ とし、e₂ = ΔR₂+Aδ、e₁ = ΔR₁+Aδ を比較する。特に **C_rec = ΔR₂−ΔR₁ = e₂−e₁** は Aδ が相殺されるため、再構成変更の寄与を直接測れる。各状態で粘性・源項が両腕で変わっていないことも確認する。

　→ **結果 A**: 島の ρ・ρE の両方で、一次化後の ‖e₁‖と |⟨e₁,R₀⟩| が二次の半分以下。再構成変更が不整合の主要部分を除くことを支持する。一次化によって定常方程式も変わるので、これだけで一次化を対策として採用しない。  
　→ **結果 B**: 両成分で ‖C_rec‖ ≤ 0.1‖e₂‖、かつ |⟨C_rec,R₀⟩| ≤ 0.1|⟨e₂,R₀⟩|。**この補正方向では再構成変更の寄与は小さく、第 1 仮説を退ける**。第 2・第 3 仮説のどちらかが確定するわけではない。中間・成分不一致は判定不能。

　dx 依存への接続として、同じ評価で C_rec を**ライン外の流れ方向の面とライン面の寄与に分ける**。流れ方向の寄与が大きければ接続の手掛かりになる。ただし、面積/V の係数が大きくなるだけでは dx 依存の説明にならない。隣接補正の相殺も含めた作用が必要であり、別々に発達した Gref と Grefc の値だけから機構を確定しない。

やらない方がよいこと: **K = 90 に増やすだけで添字の不整合を解決した扱いにすること、旧 q5 を事後的に緩めて M-r を A に書き換えること、流束変更・μt 固定・低マッハ補正を同時に試すこと。** Rhie–Chow 型補正やエントロピー安定化の追加を支持する証拠も、今回の結果にはまだない。

呼び出し側の前提への異議: **M-r の正式結果は「判定不能 (資格不足: rcap50:q5, rcap1:q5)」を維持する。** 応答差の数値は探索的な証拠として使えるが、「q5 以外は独立に検証済み」「Nδ の誤差は島で 1e−6 未満」は受け入れない。また ΔR_X は有限補正への応答であり、振幅依存を確認するまでは厳密な J_Xδ と呼ばない。
