## 依頼内容

r パラメータの DE に直した生成器で L_k 5 本を回した結果、事前登録の判定は A (70〜100 % に主枝の根、60 % は根なし)。T3〜T6 の前に 4 点を問うた: (1) 主枝の受理規則を θ_E ≤ θ_B から det_D > 0 に替えるか (θ_E ≤ θ_B は θ_B ≥ 40.8° の偽枝を通す)、(2) C2 の判定量 g̃ が kernel のパラメータ c にほとんど依らず括れない (L 100 % で c·R_t² 0 / −0.35 に −0.0690 / −0.0677) のは何が原因か、(3) T3 の 1e-4 (n 161 で 1.2e-4) をどう判定するか、(4) 計算の進め方 (C2 の走査で L_k 1 本 約 5 時間)。

## 結論 (原文要約)

**C2 の走査 (T5、約 20 時間) は回さない。linear 族には C2 の根が存在しないので、§4.4 の「外 κ_B: C2」を撤回し、(M) は円弧 kernel・B で C1 (曲率の跳び Δκ_B を記録) に改める。受理規則は det_D > 0 にして T6 (円弧、L100・L70 × n 241/321) へ進む。**

1. **受理規則 (確度 高)**: det の恒等式 (`rao_axisym.py:561`) から D で dθ/dr = −a/(r·det)、関係域で a > 0 なので **det_D > 0 ⟺ DE が D で流れを軸向きに曲げ始める (dθ/dσ < 0)**。これが「古典の枝の延長」の物理的な定義。θ_E ≤ θ_B は幾何の経験則で θ_B ≥ 40.8° で破れる → **det_D > 0 を受理条件に、θ_E ≤ θ_B と de < 0 は記録**。両方を受理条件にするのは冗長。det_D > 0 の候補が θ_E > θ_B を破ったら方針の穴として諮る。2 つの族は det_D = 0 (D での r の折り返し) の両腕で、そこで de = dθ/dσ|_DE,D は ∓∞ に跳ぶ (L70・θ_B 36.09°: 主枝 de −0.125、偽枝 det −0.005 で de +8.8)。**g̃ も det_D = 0 を跨ぐと −∞ → +∞ に跳ぶので、外側で g̃ の符号変化を brentq すると折り返しに収束して偽の C2 根を返す** — det_D > 0 を g̃ の前に置く。L60 の根なしは規則の産物ではない (主枝は θ_B 37.6° で det_D → 0⁺ に終わり x_E 最小 15.18)。κ_B を下げると根は折り返しへ寄る (L70: det_D 0.100 [c 0] → 0.08 [−0.35] → 0.02 [−0.7]) ので linear 族でも救えない。R_t 1 に結びつく可能性 (チャートは R_t 0.382) は §8-1 の R_t 0.4 感度 (CFD ピンの後) に記録。
2. **C2 (確度 高)**: (a) 族の取り方・(b) g̃ の実装・(c) 走査範囲のどれでもなく、**根が存在しない**。部品試験 (L100・n 161、θ_B を振って x_E = L の中の根を挟んだ値): c·R_t² 0 → g̃ −0.0690 (κ_B 1.00)、−0.35 → −0.067 (0.80)、−0.6 → −0.067 (0.59)、−0.8 → −0.063 (0.39)、≤ −0.95 は族の θ_max = 1/(2|c|R_t) < 30° で中の根なし。L70: c 0 → −0.169、−0.35 → ≈ −0.19、−0.7 → ≈ −0.3 (符号変化なし)。**理由 (物理)**: kernel 側の D を通る C⁺ は膨張扇で θ が増え続ける (+0.04 = 波項 0.125 − 軸対称項 0.085) のに、DE は D で θ を減らす (det > 0 なら必ず dθ/dr < 0)。BD は 6.7 r_t あり、κ_B の影響は D までにほぼ失われる (Δκ_B 0.6 で kernel 側 Δ0.006)。DE の横断微分は D の状態だけで決まるので、kernel の終端曲率は C2 の自由度にならない。「膨張 kernel + Rao 制御面」に固有の曲率不連続 (文献は未照合)。確かめたこと: g̃ の定義と実装 (de の差分 −0.029187 vs 解析 −0.029189、kernel 側は延長壁を実際の BE 壁にしても +0.0378)、Goursat 壁の B 直後の解像 (κ_W(B⁺) は当てはめ点数 3/4/6/10 で 0.072〜0.074、+0.07 は実在で Δκ_B = −0.93 は (M) の性質)、`kernel_field` は θ の極大で s を切るので κ_B < 0 は探索できない (傾向からも届かない)。`solve_kappaB` の添字の欠陥は C2 の撤回で不要になる (linear を残すなら c は記録用の明示パラメータにして根は取らない)。
3. **T3 (確度 中)**: T6 の系列で判定。合格線は生産の n (321) で ≤ 1e-4 かつ n 161/241/321 で単調減少・次数 ≥ 1。n 161 の −1.25e-4 は記録 (PASS と書かない)。旧版の 161 → 321 は次数 1.66 相当。閉合 |W_m − E| も同じ扱い。
4. **計算**: C2 の走査はやらない。T6 を円弧で L100 と L70 (成立域の両端) × n 241/321 の 4 設計 (n 321 は 1 本 1〜1.5 時間)。T3 は同じ run で判定。T4・T1a′ は T6 の後。
- **次の一手**: 部品試験を L70・L100 で再現 (約 3 分)。**A**: 主枝 (det_D > 0) の x_E = L 根で |g̃| ≥ 0.03 かつ c ∈ [−0.8, 0] で符号変化なし → §4.4・§6 の改訂を確定して T6 へ。**B**: 主枝上で g̃ が符号を変える → C2 根を残し、その L_k だけ `solve_kappaB` (det_D > 0 を g̃ の前に入れてから)。
- **やらない**: C_SCAN を広げる・細かくする、g̃ の符号変化を枝を混ぜて brentq する、θ_E ≤ θ_B と det_D > 0 を両方受理条件にする、n 161 の 1.2e-4 を「ほぼ合格」と書く、L60 の根なしを規則のせいにする。
- **異議**: 前回の自分 (S1 導出の「外 κ_B: C2 で閉じる」) は誤り — κ_B は D での横断微分を制御できない。撤回の 1 行を S1 の記録と前回の諮問記録に追記する。

## ユーザの決定 (2026-10-11)

主セッションが「C2 を目標のまま、解が無ければ (M) は古典どおり円弧 (C1) でよいことにする。両方作れたら推力の差を記録」と提案し、ユーザが了承 (「いいぞ」)。推力用ノズルは Rao・TOP とも C1 (曲率の跳びあり) が標準、という説明のうえで。(D) 直接モードは B-spline のまま C2。
