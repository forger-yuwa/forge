## 本文 (要点の転記)

### 1. 現行判定の本質的な弱点
(a) y_b が ×1.25 の離散値で断面ごとに独立に決まる (`metrics/deltastar.py:212`, 再帰 L242–277) → 段付き y_b(x) がそのまま δ_r の段差 (1 段内側 −1.6 %、外側 ≤0.25 %)。
(b) 止めるしきい値 slope_max=0.01 が目標精度 (局所 0.3 %) と無関係。x≈20 の切替後 band_slope は +0.0075〜0.0100 でしきい値ぎりぎり。band_deficit_share は線形フィットが BL 形状を吸収して ±0.000 で効かない。
(c) band_smooth_x は離散値の移動中央値なので段差の位置が動くだけ。
切替点の実測: run_0022 x=5.15 (3.91→4.82) +4.4 %、x=19.70 (2.93→2.34) −1.6 %、x≈88〜93 で 2.34↔1.88 トグル ±1.0 %。run_0023/0025/0038 も x≈5.2 で +3.3〜4.4 %、x≈20 で −1.0〜−1.7 %。

### 2. 候補比較 (要約)
A 現行 adaptive 却下 / B plateau 梯子: raw は位相に頑健 (plateau vs plateau_phase の raw 差 max 0.25 %, p95 0.11 %) だが離散 k で却下 / C band_smooth_x 却下 / D k 固定 3.66: x<10 で縁が 4.6〜7.7 δ_in → 単独不可 / **E 縁アンカー・x 平滑帯 推薦** / F NS 単独の縁検出 (entropy / p_t の 1 % 回復): E の検出器が T6 を落としたときの代替 / G 内側 30 % コア α 却下 / H CONTUR 形 × 低次補正: 平滑化段の保険 / I 全断面積分 却下。

### 推薦 E
1. 密な梯子 y_j = y_0 g^j, g = 1.25^(1/4), y_0 = max(1.2 δ_in, 0.016 r_w), y_j ≤ 0.5 r_w で δ_j = δ_r(y_b=y_j) (既存 band_local_deficit を測定器に使う)。
2. 縁の連続推定 y*: R(y) = δ_r(1.25y)/δ_r(y) − 1 を補間し |R| < ε (0.3 %) を初めて満たす y (線形補間の交点)。無ければ NaN (hard にしない)。
3. x 平滑化: κ = ln(y*/y_ref), y_ref = max(δ_in, 0.0133 r_w)。|Δx| ≤ 3 r_t 移動中央値 (NaN 無視) → 3 次 P-spline (ノット 6 r_t) で κ̃(x)。NaN は y_b 側をスプラインで埋める。
4. y_b(x) = c y_ref exp κ̃(x), c = 1.25 に帯を固定して現行どおり測る。
5. 感度: c = 1.0 / 1.56 (soft)。hard は NaN / no_root のみ。
6. extract_and_merge: 単調性ガードで λ が smooth_lam×10 を超えたらその pass を失敗にする (λ=1000 で黙って通さない)。
c=1.25 の根拠: 1 段内側 −1.6 %、1 段外側 ≤0.25 %、2 段外側 ≤0.1 %。

### 3. オフライン検証 (CFD 前)
場: F1 run_0022 (Euler run_0001)、F2 run_0038 (Euler run_0037)、F3 run_0042 res_12000 (新)、F3′ 同 res_8000 / res_11000。
量 ρ = δ_r,raw/δ_in、x∈[3,93]。ρ′ = ρ − P-spline(ノット 10 r_t, λ=1)。段差 S(x) = median(ρ′,(x,x+2]) − median(ρ′,[x−2,x))。
T1 段差: max|S| ≤ 0.3 % (x≥8), ≤ 0.6 % (3≤x<8)。対照 adaptive は x≈20 で 1.4〜1.5 %、x≈5 で 2〜4 %。
T2 パラメータ感度: c∈{1.0,1.25,1.56}, ε∈{0.2,0.3,0.5} %, 窓∈{2,3,5} r_t で |Δ − median Δ| ≤ 0.3 % 全点、|median Δ| ≤ 1 %。
T3 梯子位相 y_0×g^½: max|Δ| ≤ 0.1 %。
T4 スナップショット F3 vs F3′: max|Δ| ≤ 0.2 % (adaptive も同様に測り場の変動と区別)。
T5 壁: extract_and_merge で 3 場とも λ_used = 1、c=1.0 と 1.56 の δ_next 差の高域成分 (ノット 20 r_t を引く) ≤ 3e-4 r_t。
T6 合成: べき乗則 BL + コア波 1 % を x 列 100 断面に拡張、δ99/δ* を 8→2 に滑らかに変えて縁が格子を横切る → 隣接跳び ≤ 0.1 %、max|S| ≤ 0.2 %、バイアス ±3 % 以内。
どれか落ちたら E 不採用 → F に替えて T6 から。CFD A/B (B0 adaptive / B1 E) はオフライン合格後に 1 回、§6 の事前登録のまま。

### 6. 呼び出し側の前提への異議
1. 「プラトー案は梯子依存で不採用」は帰属が誤り: raw は位相に頑健。δ_next 2.2 % は位相版の no_plateau 43 断面 (x=74〜94) → 重み 0 → 末端無拘束 → 壁非単調 → λ 1000 の結果 = 平滑化段の設計の欠陥。
2. x≈5.2 の段差 (+3.5〜4.4 %) が 4 場すべてにある → 合格範囲を x∈[3,93] に。
3. 「adaptive の跳び 9.4 %」は定義依存 (診断者集計 6.1 %、x=6.95)。指標を S/Δ に統一。
4. 1e-3 r_t のへこみで ±0.3 %pt → 目標 ±0.05 % には 10 r_t スケールで 0.2 % δ の滑らかさが要る。T5 の 3e-4 r_t を壁レベルで必ず確認。
