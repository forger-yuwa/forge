**結論:** V6′ 総合は **判定不能**とし、次は `df20_i200` を同じ設定で **294,000 step 延長**して、未釣合いの減衰と静定後の感度を判定する。

**第1仮説:** 比較 run の差の主因は連成過渡の残存である。**確度：中**。

根拠：評価器の保存処理を除いて再計算し、基準 run の(a)〜(f) `PASS` を再現した。節点ログから `check_quasisteady.classify_series` でも再判定した。共通帯は **−19.779487〜−4.166299 mm、211節点**で固定した。

準定常は各系列の末尾半分、`drift=osc=0.001`。G-if は末尾80更新で、`interval=50` は step **96000〜99950**、`interval=200` は **84000〜99800**。③温度更新と④全域固体内部残差は全 run で許容内だった。

**重要な補正:** `20/200` の局所非静定点は共通帯の外にある。共通帯では準定常判定が通るが、G-if と(e)は通らない。これは「ゆっくり動くため準定常判定を通る」と「釣り合っている」が別である実例である。

`20/50` と `5/200` の類似した減衰は緩和遅れを支持する。一方、`20/200` の共通帯上端の物理残差は75k時点 **−5.378 W/m²**、99.8k時点 **−5.490 W/m²**であり、この区間では減っていない。したがって「全条件で基準へ単調に収束中」とまでは言えない。

反証条件：比較側が局所 `ALL STEADY`、帯内 G-if `PASS`、(e)≤0.1%を満たした後も、共通帯の基準との差が温度または熱流束で **0.5%を超えて残る**こと。この場合、「差は過渡だけ」という説明を棄却する。

**第2仮説:** 未静定な帯外の流体・界面応答が、更新間隔に依存する帯内の持続的な差を作っている。確度：低、未確認。固体の固定点式だけでは除外できない。第3仮説は置かない。

**判別 A/B:** 計算長だけを **100k → 累積394k step** に変える。対象は `20/200`、追加294k step。既存 run を複製した新しい run で、同時刻の流体場・壁温・`conjugate_state_5.h5` を一緒に引き継ぐ。固体状態だけの再開は避ける。[再開仕様](/home/sano/work/forge-cht/methods/boundary.md:497)

比較帯は上記211節点に固定し、延長部分の末尾半分を準定常判定区間、最後の80更新を G-if 判定区間として事前に明記する。

- **A：** 局所 `ALL STEADY`、帯内 G-if `PASS`、(e)≤0.1%、基準との差が温度・熱流束とも≤0.5% → **登録許容の範囲で緩和遅れ説を支持**。
- **B：** 同じ静定・釣合い条件を満たすが、基準との差が0.5%超 → **過渡だけという仮説を棄却**。
- **294k延長しても静定・釣合い条件を満たさない場合は判別未完。** 有限時間の未収束を固定点依存の証拠に変えてはいけない。現在の情報から、294kで必ず二択に決着するとは保証できない。

この一手がAでも、残る `20/50`・`5/200` の局所静定が未確認のままなら、2×2全体はまだ閉じない。

**やらない方がよいこと:** 最終スナップショットの感度 `PASS` を総合 `PASS` に読み替えること、帯を深部へ縮めること、`Df_scale` を変えて得た合格を元の `20/200` の合格として扱うこと。

**呼び出し側の前提への異議:** (e)=0.5050%は符号付きの固体–流体不釣合いとして再現できた。「未解消の不釣合い」という読みは採用するが、その原因を緩和遅れと確定はしない。また、帯の選定条件は伝導漸近に近い範囲を定義するもので、lipからの影響が厳密にゼロである証明ではない。
