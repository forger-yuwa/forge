第 1 仮説: **G2 の主因は、float の組成正規化誤差を `1−X_i` が増幅すること。補数形で除去できる。** 確度: 高  
  根拠: `thermo_d.cuh:569–576`。格納済み X について、現行分子と補数形分子の差は、実数演算なら `1−ΣX`。これを小さい `Σ_{j≠i}X_j` で割るため相対誤差が増幅する。二成分では混合平均 D は、本来、組成によらず D₁₂ になる。

  ファイルを変更せず行った **NumPy float32 の合成検算**では、固定 D₁₂ に対して次を得た。これは G2 実測の再現ではなく、演算機構の確認である。

  | 他成分モル分率 | 現行形の相対誤差 | 補数形の相対誤差 |
  |---|---:|---:|
  | 1e-4 | 1.660e-4 | 0 |
  | 1e-6 | 1.328e-2 | 0 |
  | 1e-8 | 1.000 | 0 |

  三成分・異なる固定 Dᵢⱼ の576評価でも、最大相対誤差は現行形 1.000、補数形 1.659e-7。**float32 自体の不可避な精度限界ではない。**

  反証条件: 実際の FAIL 点と同じ X・T・P・種データを使い、分子だけ補数形に変えても独立参照との誤差が 1e-5 を超える場合、「分子の評価だけが原因」という仮説を棄却する。

第 2・第 3 仮説: 未確認の候補を増やす根拠はない。

判別 A/B: **A＝現行分子 `1−X[i]`、B＝補数形 `Σ_{j≠i}X[j]`**。独立した CUDA 係数ハーネスで同じ入力を各1回評価する。CFD は0 step、分母・二元係数・ガード・コンパイル条件は固定する。

- 対象は既存 G2 状態、二成分の微量成分 1e-2～1e-8、異なる Dᵢⱼ を持つ三成分、純成分端点。
- **A が FAIL・B が PASS なら第1仮説を支持**。B も FAIL なら補数形だけで解決する仮説を棄却し、許容は変更しない。A も PASS なら元の FAIL を再現できていない。
- **合格条件**: 既存 G2 全点で独立 double 参照との相対誤差 ≤1e-5、NaN/Inf・非正値0件。二成分の非純成分点では両種 D が D₁₂ と相対 ≤1e-5。三成分も同じ許容。`n==1` の0、および `denom<1e-30` の自己拡散へのフォールバックは維持する（`thermo_d.cuh:568,575`）。純成分端点に二成分極限との連続性は要求しない。

やらない方がよいこと: 誤差が `ε₃₂/(1−X_i)` に沿うことだけで許容を緩めること、凝縮時だけ補数形へ切り替えること、短い CFD run の近さで影響なしと判断すること。

呼び出し側の前提への異議: **「支配種だから ∇Y が小さい」は未確認**。局所組成だけでは面を挟む勾配を保証できず、コードは両側の Y の差を使う（`speciesTransport_d.cu:296`）。対案は係数そのものの精度で合否を決めること。また「変わるのは X_i→1 の点だけ」も厳密には誤りで、ΣX の丸め誤差があれば他の組成でもビットは変わり得る。

不足情報: 最大誤差点の実際の float X・T・P・D・独立参照値が未提示。2.93e-4 はブリーフ記載値として扱い、実測の再確認はしていない。**plan 未反映**。呼び出し側が §5.1 #3・#5 と §6 に、補数形採用とビット一致契約の適用範囲を反映する必要がある。
