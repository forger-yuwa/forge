結論: **走行中の F1 を既定の判定まで完了させ、L1 の投入はその結果を待つ。** L1 は有用な加速試験にはなるが、現在の判定案では低マッハの硬さを真因として特定できない。

第 1 仮説: 境界層内の SST 更新と平均流の連成が、B0 の遅いモードの維持に寄与している。確度: **中**

- 根拠: `plans/active/tooling-nozzle-core-grid.md:746` では、上限 50→1 によって残差集中域の `dt_local` は中央値で **0.977 倍**にしか変わらない一方、残差は **1/25〜1/160**になっている。したがって「その場所の音速制限によって局所の擬似刻みが小さい」だけでは、この改善を説明できない。
- コード上、SST の更新分母にも `V/dt_local` が入る（`solver_density_cuda/cuda_forge/update_d.cu:403`）。壁側の刻み変更が SST 更新を通じて離れた残差集中域へ作用する可能性は残る。ただし、その伝達機構は未確認。
- 反証条件: F1 で凍結が実効的に成立し、両評価窓で縮流部の ρ・ρE 残差がともに対照の **2/3 以上**、残差の集中割合も対照と同程度なら、「SST の内部更新を止めれば停滞が大幅に緩和する」を退ける。熱拡散や乱流場の影響一般まで否定するものではない。

第 2 仮説: 低マッハの音響・移流時間尺度の差が、point の減衰の遅さに寄与する。確度: **中、寄与率は未確認**。M = 0.02〜0.08 は整合するが、低マッハであること自体は律速の証拠ではない。

第 3 仮説: 平均流のライン外結合と有限回の内部反復が、温度境界層の遅いモードを十分に減衰させていない。確度: **中、未確認**。局所粗化の成功は整合するが、粗化は演算子・刻み・壁側の結合も変えているため、節点数だけには帰属できない。

判別 A/B: **新しい試験を足さず、登録済み F1 の比較を完結させる。**

- 対照: `case/45.isobutane_m6_d155/run_0619_cg_gref_b0_ctl/` の 0〜20k。
- 凍結側: `case/45.isobutane_m6_d155/run_0626_cg_gref_freeze/`。同一起点・B0・上限 50 のまま、変更は `FORGE_FREEZE_TURB=1`。20k 固定、延長しない。
- 判定窓は 10k〜15k・15k〜20k。まず内部の ρk・ρω の凍結を確認し、μt と `dt_local` の変化も記録する。
- **A**: 両窓で登録済みの全域平均流・化学種残差と縮流部の ρ・ρE がすべて凍結/対照 ≤ 1/3 → SST 更新への強い依存を支持。ただし「μt の遅れが原因」とは確定しない。
- **B**: 両窓で縮流部の ρ・ρE がともに ≥ 2/3、縮流部の残差寄与率の比が 0.5〜2 → 第 1 仮説の上記予測を退け、平均流側の反復を優先する。
- 中間・成分間の不一致・凍結不成立は判定不能。根拠は同 plan §4.38 の既存登録。

やらない方がよいこと: **L1 の成功を、そのままラインへの前処理実装の根拠にしない。** `lowMachPrecond: 1/2` への置き換え、ε の引き下げ、CFL・内部反復数の同時変更も、この切り分けには加えない。

呼び出し側の前提への異議:

1. **［Major／却下］「L1 で ≤ 1/3 なら低マッハの硬さが律速、≥ 2/3 なら退ける」は因果判定として強すぎる。**  
   `setDT_d.cu:268`〜273 は Γ の変更に加えて `dt_local` を拡大し、その同じ刻みを SST が読む（`update_d.cu:403`〜404）。実装式から計算すると、ε = 0.15、M = 0.02〜0.08 で拡大係数は約 **5.51〜6.35 倍**になる。L1 は平均流と SST の更新バランスも変える。  
   **対案:** 成功時は「この point 構成で、モード 3 が20k以内の平均流残差を改善した」、不成功時は「この設定・予算では所定の改善が得られなかった」に限定する。低マッハの寄与一般は、どちらでも確定・排除できない。

2. **［Major／却下］「エントロピー・渦の伝わる速度そのものが速くなる」という説明は修正が必要。**  
   現行仕様では前処理後も対応する固有値は Uₙ のまま（`methods/time_integration/theory.md:205`）。また Γ_c = I + αgrᵀ、rᵀ = ∂p/∂Q なので、Δp = 0 の純粋な成分には Γ_c は恒等作用する（`lowMachPrecond_d.cuh:54`〜56）。  
   **対案:** 「音響側の時間尺度を調整し、拡大した擬似刻みで非音響成分の反復を進められる可能性」と説明する。粘性・熱伝導・SST を含む今回のモードへの効果は実測事項である。

3. **［Major／却下］「前処理なしと答えがビット一致」は保証できない。**  
   モード 3 が SLAU の散逸を変更しないことは確認できる（`convection/convectiveFlux_slau_d.inc.cuh:579`〜584）。しかし、反復経路と丸めが変わるため、これは最終状態のビット一致の保証ではない。参照 point 自体も、提示された記録では通算 0〜200k の **`VERDICT: NOT CONVERGED (プラトー)`** である（plan `:663`）。  
   **対案:** 「同じ状態に対する RHS と定常方程式を保つ」と記載し、有限反復での到達状態の一致とは分ける。

4. **［Major／要再検証］新しい L1 側だけの領域残差では、縮流部モードの改善を対照比較できない。**  
   ブリーフによれば `run_0611` の0〜20kには全域残差しかない。B0 での残差集中が、point に切り替えた後も続くとは限らない。  
   **対案:** 既存対照を使う L1 は全域残差の加速試験と位置付け、領域残差は補助観測にする。ラインへの実装判断には、縮流部の同一指標を両側で比較できる証拠と、平均流・SST 全体の減衰確認が必要。
