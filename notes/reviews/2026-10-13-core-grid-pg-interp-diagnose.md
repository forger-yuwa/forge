結論: §4.91 の「判定不能」を維持し、**同じ全補正後状態を「継続中」と「再起動直後」で評価する A/B**を先に行う。振幅回帰やリミッタ変更にはまだ進まない。

第 1 仮説: 線形性の不合格には、残差評価の履歴の違いが主要な成分として混入している。確度: 中。
  根拠: `case/45.isobutane_m6_d155/cg_pg_judge.py:36`〜43 では、基準・半補正の残差を `res_1`、全補正の残差を `res_2` から取得している。`plans/active/tooling-nozzle-core-grid.md:1290` にも評価条件の不一致が明記されている。一方、これが誤差の主因であるという直接測定はまだない。
  反証条件: 同じ全補正後状態で測った履歴差の寄与が、既存の比例しない成分 N の 10 % 以下であること。

第 2 仮説: 評価履歴をそろえても、局所的な非線形性・分岐切り替え、または残差評価の数値誤差が残る。確度: 低。壁際への集中は候補の位置を示すが、リミッタ・μt・境界処理のどれかは未確認。

第 3 仮説: 実際の反復悪化には、Γ と sweep 内緩和による実効左辺が、圧力残差を減らしにくい補正を作る機構が関与する。確度: 低〜中。§4.90 の仮説として残すが、今回の資格不足の測定では確定しない。

判別 A/B: **変更点は全補正後状態の残差を評価する履歴だけ**とする。

- A は既存の継続中評価。GI は `case/45.isobutane_m6_d155/run_0698_pg_gi800/res_2.h5`、GB は `case/45.isobutane_m6_d155/run_0701_pg_gb800/res_2.h5` の残差。
- B は各 run の `res_1.h5` の状態を、同一メッシュの新しい run に `restart_field.py` で移し、**各 1 step、計 2 本だけ**実行して得る `res_1` の残差。同じバイナリ・設定・環境変数を保ち、9 保存量の転送をビット一致で確認する。δ を再計算せず、倍率も変えない。
- SST の微小変化も含め、A が評価した状態を移す。ここで SST を Q0 に戻すと、評価履歴と状態変更が混ざる。
- 圧力への射影係数・体積重み・集計領域は既存判定と固定する。以下の R は、その固定射影後の残差ベクトルとする。

履歴差を D = R_B − R_A とすると、評価条件をそろえた比例誤差は **N_new = N_old − D/2**。大きさだけでなく、このベクトル差を測る。

→ **履歴差で説明できる結果**: 両腕で、評価条件をそろえた線形性誤差が登録基準 0.05 以下になる。第 1 仮説を支持し、「今回の不合格が離散残差の非滑らかさを示す」という解釈を退ける。ただし SST の資格不足は別途残る。

→ **履歴差では説明できない結果**: 両腕で ‖D/2‖ ≤ 0.1‖N_old‖。第 1 仮説を主因として退け、第 2 仮説を優先する。

中間値・腕ごとの不一致は判定不能とする。これらの閾値は新しい診断基準として、実行前に登録する。

やらない方がよいこと: s = 2, 4, … の回帰を先に増やすこと、壁際を除いて合格にすること、リミッタや μt の処理を先に変更すること。前者は評価履歴の差と有限振幅の応答を混ぜ、後二者は今回説明すべき成分そのものを変える。

呼び出し側の前提への異議:

- **Major — 「微小補正なのに比例しないので、残差が滑らかでない」は要再検証。** 根拠は `plans/active/tooling-nozzle-core-grid.md:1290`。max|δ|/max|Q0| は局所相対変化を保証せず、評価履歴も違う。また「立ち上げ直後どうしの差にも N が含まれる」は、現状の定義では証明されていない。N は全補正の継続中評価を含む三点の組合せであり、半補正と基準の差だけから非比例成分を分離できない。対案は上記の同一状態 A/B。
- **Major — 「GB の低減は GI の約 1/10」を機構の証拠にするのは却下。** 判定 JSON の縮流部では L_GI = 0.00210714、L_GB = 0.000224345、比は約 0.106。ただし線形性誤差は GI 0.71254、GB 1.69144 で、`qualification.linear_response = false`。対案は「現在の混在した評価手順で得た参考値」と明記し、Γ が低減を約 1/10 にしたとは結論しない。
- **Major — 「5 sweep で十分に解けている」は範囲を限定する。** `cg_pg_judge.py:54`〜58 の Cauchy 判定と u₅ は ρ・ρE が対象で、‖Hδ − b‖を測っていない。JSON の縮流部 u₅ は GI 0.003168、GB 9.11e−6。対案は「この二成分の補正は、5 sweep と 800 sweep で近い」と記す。全成分の線形系の解き残しや、外反復の収束まで除外しない。
- **Major — SST の資格を事後的に緩めて合格にするのは却下。** `cg_pg_judge.py:40`・48 は保存量の厳密な不変を要求し、JSON でも `setup_switch_half_freeze = false`。全域最大値で正規化した微小差だけでは、壁際の残差への影響を上限評価できない。対案は旧判定を維持し、新試験では転送一致と実行中の保存量変化を分けて記録する。

ユーザの問いに現時点で答えるなら、**測定した ρ・ρE の補正には、GB の 5 sweep が大きく解き残している兆候はない**。Γ と緩和が作る実効左辺によって外反復の低減が弱まる仮説は残るが、その残差応答を測る手順に評価履歴の混在があり、「なぜ悪くするか」はまだ特定できていない。
