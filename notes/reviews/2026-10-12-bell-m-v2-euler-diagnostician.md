# diagnostician 諮問記録: ③ベル (M) の V2 (Euler と MOC の推力の整合) (2026-10-12)

- 上位: diagnostician (Fable、このセッションはユーザ指示で Fable)。ブリーフ: [`briefs/2026-10-12-bell-m-v2-euler.md`](briefs/2026-10-12-bell-m-v2-euler.md)
- 対象: plan [`tooling-nozzle-bell-two-mode`](../../plans/active/tooling-nozzle-bell-two-mode.md) §6 V2・§5.1 #6・#8。エスカレーション条件 3・7

## 依頼内容

Hall 初期線の (M) 壁 (L100・L70) を Euler で回した `run_0015`・`run_0016` (AWS B、全ゲート PASS) で、推力が MOC の値より +0.287 %・+0.288 % 大きく、登録の線 0.2 % の外だった。差はほぼ全部がスロートの流量 (Euler ṁ/ṁ_1D 0.99263 vs Hall 線 0.989706、+0.295 %) で、流量あたりの推力の差は −8.6e-5・−7.3e-5。問い: 判定と記録、CFD ピン版での V2 の事前登録、Hall の流量の誤差の V3 への効き、この Euler 場を凍結源に使ってよいか。

## 結論 (原文要約)

**V2 (Hall 版) は登録の線で FAIL と記録し内訳を併記、線は変えない。合否が立つのは CFD ピン版の V2 — run_0015 (L100) を凍結源に W3 → V2 を回し直す。事前登録は「推力 0.2 % (主)、ṁ 2e-4、F/ṁ 5e-4 (内訳)」。**

1. **判定と記録 (確度 高)**: F/ṁ を合格条件に差し替えない (条件の後出し)。記録の文: 「V2 (Hall 版壁): F_Euler/F_MOC − 1 = +0.287 % (L100)・+0.288 % (L70) → 線 0.2 % の外で FAIL。内訳: ṁ_Euler/ṁ_Hall − 1 = +0.295 %、(F/ṁ)_Euler/(F/ṁ)_MOC − 1 = −8.6e-5 / −7.3e-5。原因は初期線 (Hall、R_t 1) の流量で、§4.4 の『CFD ピン既定・Hall は検算』の検算として機能した。合否が立つのはピン版の V2」。R_t 1 の Hall の級数は適合式と 1.1e-2 rad 合わないので流量も信用できず、Kliegel–Levine 型の Cd (γ ≈ 1.2・R 1 で ≈ 0.993) に近いのは Euler 側。「MOC の膨張が 0.3 % ずれている」とは書かない。
2. **ピン版 V2 の事前登録 (確度 中〜高)**: (主) |F_Euler/F_MOC − 1| ≤ 0.2 %。(内訳 1) |ṁ_MOC(ピン線)/ṁ_Euler − 1| ≤ 2e-4。(内訳 2) |(F/ṁ)_Euler/(F/ṁ)_MOC − 1| ≤ 5e-4。**A** 主が通る → V2 PASS。**B** 主が外れ内訳 1 は通る → 膨張部の不一致として再諮問。**C** 内訳 1 が外れる → ピンの写像か凍結源の照合の問題 (#6 の照合に戻る、膨張部を疑わない)。
3. **V3 への効き (確度 高)**: V3 の η は (D)・(M) とも NS で測るので、Hall の流量誤差は (M) の壁の形を通してだけ入る。W3 で Hall 版とピン版の差 (θ_B・θ_E・θ_max・壁 x 3.4〜5.3・F_cs) を記録し、Δθ_B・Δθ_E ≤ 0.1°・壁 Δr ≤ 1e-3 r_t なら V3 の U_k に入れない。V3 の前に要ること: (i) ピン版 V2 PASS、(ii) **#7 の扱い (δ* 補正済みの物理壁で NS 評価するか、非粘性壁のまま NS で評価して δ* の効きを U_k で持つか) を plan に書く** (未決なら諮問)。(M) の NS 評価は (D) と同じ格子族・recipe (第一セル 1.25e-5・冷間・本段 60000)。
4. **凍結源 (確度 中〜高)**: run_0015 を凍結源に、run_0016 から取った線との差を照合の記録に (スロート特性線の依存域は x_B より上流なので両者は一致するはず)。凍結の前に (a) `check_source_matches` PASS、(b) ṁ の末尾 10 スナップショット (15000〜30000) の相対ドリフト ≤ 1e-5、(c) 格子確認 1 本 = run_0015 を ni 1801・nj 181 (×1.5) で回し、ピン線の m*/ṁ_1D の差 ≤ 1e-4 かつ線上の θ の最大差 ≤ 1e-4 rad なら現格子を凍結源に、外れたら細格子を凍結源にする。
- **次の一手**: 照合・ṁ ドリフト・格子確認を先に、run_0015 を凍結源に W3 の L100 1 本。ピン線の m*/ṁ_1D が 0.99263 と 2e-4 以内 → ピン版 V2 へ、外れる → ピンの写像を先に直す。
- **異議**: 呼び出し側 — 流量あたりの推力の一致を V2 の合否に使わない。Hall 版の V2 が外れることは #3b から予見できたので、登録時に「Hall 版は記録・ピン版が合否」と書くべきだった (今回直す)。
