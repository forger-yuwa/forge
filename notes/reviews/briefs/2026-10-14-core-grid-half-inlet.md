## 1. 前提 (観測事実)

- Gref (4719 × 160、75.5 万節点) の B0 は縮流部で停滞する。停滞帯は x/r_t −6〜−3.25・壁から 60〜100 節点目 (温度境界層の縁)、M 0.02〜0.08。入口 (x/r_t ≈ −12.5) の主流 M は 0.012〜0.023。縮流部だけ流れ方向を粗くした Grefc では停滞が 1/30〜1/60 (§4.37)。
- 低マッハの処理 (`lowMachPrecond` 1・2・3) は、どれもこのケースの縮流部の反復を良くしなかった (§4.81・§4.83・§4.85)。既定の `thermoFloat: 1` は FP64 でも残差になめらかでない誤差を乗せ (§4.95)、B0 の止まる先を 0.3〜0.4 % 動かす示唆がある (§4.97、判定不能)。同じ入力でも B0 の止まる先は 0.1 % 揺れる (§4.97)。
- 形状: `geometry.r_inlet: 6.485` r_t (物理 0.5 m、収縮比 42.1)、`L_U: 12.0`、`L_pipe: 0.5`、`R: 2.0`。縮流部は 5 次 Hermite `UpstreamThroatPoly` (x ∈ [−L_U, 0]、(r_U, 0, 0) → (1, 0, 1/R))。単調 ⇔ μ = L_U²/(R Δr) ≤ 20。今の μ = 13.1。
- 半径を半分 (r_U = 3.2425、収縮比 10.5) にすると、L_U = 12 のままでは μ = 32.1 で非単調。単調にするには L_U ≤ √(20·2·2.2425) = 9.47。
- 設計の連鎖は `initial_line: cfd` (凍結源 `run_0062`) で、凍結源の縮流部の形 (r_U・L_U・L_pipe・Hermite) を照合する (`cfd_initial_line.py`)。YAML の `r_inlet` を変えるだけでは設計の段で止まるか、スロートより下流の壁まで作り直しになる。
- 格子は `core_grid_mesh.py` が物理壁 (`wall_repr.json` → `load_wall_file`) を `mesh2d.generate_axisym_mesh` に渡して作る。

## 2. 私の案 (縛られなくてよい)

- 形: スロートより下流 (x ≥ 0) の物理壁は今と同じ。縮流部を r_U = 3.2425・L_U = 9.0 (μ = 20.07 → 9.0 では 20.07 なので L_U = 8.9 で μ ≈ 17.7、要確認) の Hermite に替え、入口の x 位置 (−12.5) を保つため配管を L_pipe = 3.6 に伸ばす。壁の物体を差し替えてメッシャに渡す。
- 格子: Gref と同じ mesh ブロック (nj 160・axis_cap_frac・x 方向の密度の表) で作る。
- 初期値: `run_0608` res_60000 (Gref の B0 の停滞の場) から `interp_field.py` (別格子)。縮流部の流速は面積比で 4 倍になるはずなので、移送直後は大きな過渡がある。
- run: B0 で 6 万 step (または段階起動から)。対照は Gref の B0 (`run_0619` など)。
- 見るもの: 縮流部の残差の減り方 (§4.37 と同じ指標)、`check_convergence`、量の準定常。形が違うので量の値は比べない。

## 3. 判断してほしいこと

推奨を 1 つに絞り、事前の読み方つきで:
1. 形状の変え方 (L_U・配管の扱い、下流の壁を保つか)。
