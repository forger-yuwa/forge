## 草案

1. mesh2d: 新キー (例 `axis_cap_frac: c`) — 各断面で第 1 セル fr_i から比 q_i の等比、間隔が c に達したら軸まで一様、総数 nj − 1 を固定し q_i を二分法で解く (Σ min(fr_i q^j, c) = 1)。実現可能条件 fr + (n−1)c ≥ 1 を検査。Euler と NS は `mesh_params()` で同じキーを読む。
   試算 (fr 1.3e-5): nj 129・c 0.04 → q 1.071、一様区間 10 セル; nj 193・c 0.02 → q 1.046、28 セル; nj 257・c 0.0133 → q 1.033、45 セル (隣接比の最大 ≤ 1.07)。
2. 系列: A1 = nj 129・c 0.04、A2 = nj 193・c 0.02、A3 = nj 257・c 0.0133 (軸側間隔 1/2・1/1.5)。ni 2000・壁側の第 1 セル (1.3e-5・スロート 4.5e-6)・ブレンドは生産格子のまま。メッシュ品質 `--ar-max 5000`。
3. 対象: 最終壁 (run_0117: k_f 1.054129・r_t 76.6539 mm、Md_moc_offset +3.770e-4) の NS (IC run_0117 を interp_field → 段階起動 → cfl 1・60000 step) と設計壁の Euler (IC run_0114 を interp_field → soft → cfl 2・12000 + 延長)。
4. 量: η=0・0.05・0.1 の Mach 波・オーバーシュート・傾き、出口コア M、δ_E/δ_C (NS)。準定常は `check_quasisteady --series-csv` (量ごとの閾値は #11a〜g と同じ考え方で事前登録)。
5. 判定案: A2→A3 の差が η=0.1 の波・オーバーシュートで ≤ 0.005 %pt、出口コア M ≤ 1e-4 → A3 (または A2) を「格子収束した評価格子」とし、最終設計の波・オーバーシュートを A3 の値で再判定 (閾値は不変)。差が大きい → 諮問。
