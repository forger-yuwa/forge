## 2. 期待値と出典 (V4 の今の事前登録、plan §6 の V4)

- float の新しい経路で case/45 の B0 の構成を `run_0183` の res_100000 から、2 出力連続の水準 (|欠損| ≤ 0.1 kg/s かつ θ_r(40/70/94) のドリフト ≤ 0.05 %/2 万 step) まで、2500 step ごと、最大 20 万 step。
- θ_r と Q_w を、両方の run の末尾 2 万 step (9 点以上) で比べる。分母は参照の窓の平均。
- **両方の窓のドリフトと振幅が閾値 (θ_r 0.05 %・Q_w 0.1 %) の 1/5 以下**で、平均の差に両方の時間変動の幅を足しても閾値以内。

- FP64 の参照は、B0 を同じ記録の形 (2500 step ごと) で回し直す。
- 記録: `dq_requested` と `Q_after − Q_before` の統計、壁の熱流束の分布の差、step 数。
