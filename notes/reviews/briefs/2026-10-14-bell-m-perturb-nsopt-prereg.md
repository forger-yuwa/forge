## 案 (主セッション、§5.1 #8c)
- 物理壁 = 補正済みの Rao 壁 + Σ_{k=1..4} a_k η_k(t)、t = (x − x_B)/(x_E − x_B)、η_k(t) = sin²(πt/2)·sin(kπt)
  (B で値・傾き 0 = 円弧との C1、E で値 0 = ε 保持、E の傾きは自由 = θ_E を固定しない — ユーザ指摘)。a_k ∈ [−0.03, +0.03] r_t (仮)。
- 単目的の経路 (§5.1 #8b と同じ停止・確認・回し直し)、LHS 12 + 出発点 a = 0、種 0 と 1、まず L100。
- 判定 (案): Δ = 最良 − 出発点。A: Δ > 3e-4 → 補正済み Rao は上限でない。B: Δ ≤ 1e-4 → この族の中では上限。その間は判定不能。
