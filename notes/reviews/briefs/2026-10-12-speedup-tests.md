## 1. 観測事実
- G0 (生産の格子 4719 × 121) の B0 (上限 50) は停滞し、上限 1 で回し続けると θ_r(40) が 1.22 % 動いてから停止規則に届く (§6.56、FP64 の停止値 θ_r 0.0771585 / 0.1140364 / 0.1268318、Q_w 9.2148 MW、通算 17.25 万 step)。B0 の停止値 (`run_0483`、14.5 万 step) は θ_r 0.078111 / 0.115199 / 0.128021、Q_w 9.2764 MW。
- 停滞の場所は縮流部の上流の境界層の縁 (x/r_t −8〜−5、M 0.004〜0.08)。上限 50 の反復はここで乱れを増幅、上限 1 では増幅しない (forge-25 の双子)。case/45 は SLAU・`lowMachPrecond 0`。
- `lowMachPrecond` は 0 / 1 (散逸だけ) / 2 (散逸 + 左辺) / 3 (左辺と擬似時間の刻みだけ、収束解は 0 と一致) (`solverConfig.cpp:470`、plan `time_integration-lowmach-preconditioning` §116)。≥ 2 は `lineImplicit`・`implicitThermalJacobian ≠ 0`・`lineViscCoupling 2` と併用不可 (`main.cpp:3480`、`solverConfig.cpp:1442・1456`)。`precondEps` 既定 0.15。case/23 では 2 で約 2.2 倍の正味の加速 (チャンバの振動も消えた)。case/45 では 2026-09-02 に 2 + SST で発散 (README の probes5/6、詳細未確認)。
- point (B0 の 4 キーを外す) の FP64 は、同じ Q32 の起点 (= `run_0483` の停止場) から 20k〜25k で θ_r −1.135 / −0.819 / −0.680 %、100k〜120k でも DRIFTING (§6.49・§6.50、`run_0713`・`run_0714`、残差の履歴は全 step、場は窓だけ保存)。
- 格子: G0 の AR 最大 4,573 (AR > 1,000 のセルは壁から 0〜17 層、スキュー ≤ 0.0019)。G0c (縮流部 x/r_t −8〜−2 を流れ方向に max(1, d/2)) の AR 最大 8,705、AR > 5,000 は 1,325 セルで x/r_t −7.79〜−2.23・壁から 0〜5 層、スキュー ≤ 0.0024。AGENTS の基準は AR ≤ 1,000、壁法線の直交した境界層のセルは ≤ 5,000 (2026-09-12 のユーザ決定、裏付けは isothermal plan §8-3 の A/B)。
- G0c の B0 の FP64 は Q32 の起点から 30,000 step で rms_ro 7.5e-7〜1.2e-6 (3.6〜3.8 桁低下)、θ_r は DRIFTING (§6.52)。forge-25 の Grefc (Gref の縮流部を同じく粗く、AR ≤ 10,000 を診断に限り許可) は B0 のまま、Gref を point で止めた値と θ_r −0.05 %・Q_w +0.04 %。

## 2. 試験の案
### P: 低マッハの前処理 (左辺だけ) で point の収束が速くなるか
- 腕: G0、Q32 の起点 (`_tr/q32_init.h5` = B0 の停止場)、point (B0 の 4 キーを外した §6.48 の設定)、FP64 (`~/forge-fgeom7-fp64`)。P0 = `lowMachPrecond 0`、P3 = `lowMachPrecond 3`・`precondEps 0.15`。各 1〜2 本、20,000 step・1,000 ごと。
- 見る量: rms_* の推移 (桁の下がり方)、θ_r(40/70/94)・Q_w の、上限 1 の FP64 の停止値への近づき方 (step ごとの残り)。答えは変わらない設定なので、同じ step での値の差は「進み方の差」。
- 判定案: 両窓 (例 10k〜15k・15k〜20k) で P3 の θ_r の残り (停止値との差の絶対値) が P0 の 0.5 倍以下なら「効く」、0.9 倍以上なら「効かない」。発散したら効かない側。
### G: G0c の格子で答えが変わらないか (AR の緩和の裏付け)
- 腕: G0c、B0 (上限 50)、FP64、G0c の Q32 の起点 (`_g0c/q32_init.h5`) または §6.52 の `run_0725` の res_30000 から再開、停止規則 (§6.11) まで、上限 20 万 step。
- 比べる相手: G0 の上限 1 の FP64 の停止値 (§6.56)。差が θ_r ≤ 0.1 %・Q_w ≤ 0.1 % (設計チェーンの許容) なら「G0c で答えは変わらない」→ ユーザの条件つきの受け入れに合う。あわせて壁の熱流束の分布・δ_loc・出口の量・停止までの step と時間を記録。
- 格子が違うので、差は離散化 (流れ方向の間隔・AR) の影響と、停止の違いの合計。
