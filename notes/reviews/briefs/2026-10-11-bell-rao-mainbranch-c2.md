- det_D (DE の陰関数の行列式、det = 2a·cot θ + c·tan(θ−μ)) の符号が DE の族を分ける: det_D > 0 では θ−μ が減り、θ_D > μ_D なら θ = μ を跨ぐ (主枝)。det_D < 0 では M と θ−μ がともに増え、θ_E 40〜45° (偽枝)。det_D は BD 上で符号を変え (θ_B 36° では η ≈ 52 と 77)、そこで E が跳ぶ。恒等式 det = −sin(θ+μ)(ν′ tan(θ−μ) − a)/(sin μ sin θ) から、det は θ+μ < 90° でも 0 になり得る。ただし実際に 0 になるのは D 自身がその上にある場合だけで、θ_B 12〜50° × η_D 36 点の DE 720 本はすべて流量に達した (4 条件の外の終わりは 0 件)。det_D ≈ 0 の D は別の積分 (擬似弧長) で r_E・θ_E が 4 桁一致。

## 3. 問い (推奨を 1 つずつ)

1. **主枝の判定規則**: 受理条件を θ_E ≤ θ_B から **det_D > 0** に替える (または両方) べきか。det_D > 0 の族が「古典の Rao の枝の延長」だと言える根拠があるか。
2. **C2 (T5)**: g̃ が c にほとんど依らないのは、(a) kernel の族 κ(s) = 1/R_t + (κ_B − 1/R_t)S(s/s_B) の取り方で C2 が届かない、(b) g̃ の定義・実装の問題、(c) 走査範囲の問題、のどれが疑わしいか。根が無かった場合の扱い (例: C2 を「κ_W(B⁺) − κ_B の最小化」に緩める、kernel の族を変える、円弧 kernel + B の後の当てはめで C2 を作る)。T5 を回す前に確かめる安い試験があれば 1 つ。
3. **T3 の 1e-4**: n 161 で 1.2e-4 を、T6 (n 161/241/321) の結果で判定すると決めてよいか (n とともに減って n 321 で 1e-4 を下回れば合格)。
4. **計算の進め方**: C2 の走査 (L_k 4 本 × c 10 点 × 約 30 分) と T6 をどの順・どこで回すか (例: L 100 % だけで C2 の根の有無を先に見る、c の走査を粗くする、AWS B の空きコアで並列)。
