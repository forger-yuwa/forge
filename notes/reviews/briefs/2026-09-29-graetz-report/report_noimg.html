軸対称 CHT の流れあり検証 — 管内層流の Graetz 問題

2026-09-29ブランチ feature/cht-axisym-graetz (ca81c8ea、main 未マージ)状態 報告 ユーザ決定による例外閉鎖

結論: 管内層流の Graetz 問題 (次節で説明) を使いました。登録した条件 (node・FP64・M 0.05・Re 1000・Pr 0.72) で、流れのある軸対称 CHT (管 + 固体殻、軸を含む) の対照差し引き局所 Nu は、評価窓 x⁺ 3e-3〜0.1 で古典 Graetz 解から 3 格子とも最大 0.82 % 以内でした (許容 2 %)。壁温を固体越しに決める共役計算と、壁温を直接与える非連成計算の差は 0.03 %、細かい格子ほど格子間の差は減りました。最大の限界: 流れの前提を確かめる登録検査 V-g1 の 2 項目が FAIL のままで、ユーザ決定により例外として閉じています。検証全体の合格ではありません。また、対照を差し引いた量の検証なので、絶対熱流束の精度は保証しません。

何を検証したか

Graetz 問題

円管の中を、速度分布がすでに放物線にそろった層流 (十分発達した流れ) が、一様な温度 Tin で流れてきます。ある位置 (x = 0) から先の管壁を一定温度 Tw に保つと、ガスは壁から温められ、温められた層が下流ほど厚くなります (Figure 1)。この問題を Graetz 問題と呼び、1883 年に Graetz が解析解 (固有関数の無限級数) を与えました。物性一定・軸方向の熱伝導なし・粘性発熱なしが前提です。

局所ヌセルト数 Nu の定義

壁のある位置 x で、壁からガスへの熱流束 qw、壁温 Tw、その断面の混合平均温度 Tb (流量で重み付けした平均温度) を使って

Nu(x) = qw D / ( k ( Tw − Tb ) )

と定義します。D は管の直径 (2 mm)、k はガスの熱伝導率です。熱伝達率 h = qw/(Tw − Tb) を無次元にしたもので、加熱開始点の直後は大きく (温められた層が薄いので熱がよく伝わる)、下流では一定値 3.657 に近づきます。混合平均温度は Tb = ∫ρ u T r dr / ∫ρ u r dr です。

横軸 x⁺

Graetz 解は、加熱開始点からの距離 x を x⁺ = x / (D Pe) で無次元にすると、流速や物性によらず 1 本の曲線 Nu(x⁺) になります。Pe = Re Pr (ペクレ数、今回 720) は、流れが熱を運ぶ強さと熱伝導の強さの比です。今回の加熱区間 172.8 mm は x⁺ = 0.12 にあたり、評価に使った窓 x⁺ = 0.003〜0.1 は壁から 4.3〜144 mm の範囲です。

ΔT と、対照 run を差し引く理由

ΔT = Tc − Tin は、固体殻の外面の温度と入口ガスの温度の差、つまり加熱の強さです。本番では ΔT = 10 K (Tc = 310 K、入口 300 K) を主に使い、ΔT = 5 K と ΔT = 0 も回しました。

forge は圧縮性のソルバなので、Graetz 解が無視している粘性による発熱と、圧力が下がることによる冷却が入ります。そのため、加熱していない ΔT = 0 の run でも、壁とガスの間にわずかな熱流束と温度差が生じます (Figure 4 の灰色の線)。この分は加熱と関係なく、どちらの run にも同じように入ります。そこで、同じ格子・同じ流れの ΔT = 0 の run (対照 run) の値を引き、加熱によって生じた分だけで Nu を作りました。

Nu = ( qw − qw,0 ) D / ( k [ ( Tw − Tb ) − ( Tw,0 − Tb,0 ) ] )　(添字 0 が対照 run)

この引き算は、温度の方程式が流れを固定すれば温度について線形であることを使っています。加熱 run と対照 run とで流れは少しだけ違う (加熱で密度が下がる) ので、厳密には打ち消し切れません。その残りは ΔT = 5 K と 10 K の比較 (V-g5、差 0.14 %) で見ています。

結果

差し引きの中身

Figure 4 は Nr = 32 の加熱 run と対照 run の生の値です。熱流束は対照 run の方が 1〜3 % の大きさで、向きが逆 (ガスから壁へ) です。壁温と混合平均温度の差は、下流の x⁺ = 0.1 で対照 run が 0.17 K あり、加熱 run の 2.1 K に対して 8 % になります。差し引かないと、下流ほど Nu が大きくずれます。

局所 Nu と古典 Graetz 解

差し引いた Nu を、古典 Graetz 解 (graetz_ref.py、forge と独立に解いたもの) と比べました。比べ方をそろえるため、基準の側も各壁節点が受け持つ区間で熱流束を平均しています。3 格子とも窓全体で誤差は負で、大きさは 1 % 以内に収まっています。

V-g1 ①: 圧力勾配が Poiseuille の式より大きい理由

V-g1 ②: 対照 run の x=0 断面の温度非一様

特定できたこと・できなかったこと

特定できた

  • 対照差し引き局所 Nu と古典 Graetz 解の差は、窓全体で 3 格子とも 0.82 % 以内。
  • 共役と非連成の等温壁の差は 0.03 %。固体の層数 (8 と 16) の差は 3e-7。
  • 圧力勾配のずれ (V-g1 ①) は、加熱による加速と壁せん断のずれで説明できる (収支は 0.005 % で閉じた)。
  • 強制形の等温壁は、細かいセルでは cfl_pseudo 5 だと起動直後に崩れる (2 で安定)。

特定できなかった

  • 対照 run の温度非一様 (V-g1 ②) の原因。散逸・圧力仕事の有無で温度幅が大きく変わることは補助計算で見えたが、不確かさが基準を超えた。
  • x⁺ 0.1 付近の −0.5〜−0.8 % の由来 (格子・有限 M・差し引きの非線形のどれか)。
  • 絶対熱流束の精度 (共通の加算誤差は差し引きで消えるため)。
  • 節点別の G-if と系列の再抽出 (中間場・界面ログを削除したため、保存済みの記録に依存する)。
