## 1. 観測事実

### V2c (斜め衝撃波、slip ランプ、上面 = A slip 低領域 / B farfield 低領域 / C slip 高領域)
- 旧形状 (ランプ 0.2–0.7 m → 水平、H 0.3、L 1.2): B vs C 最大 0.087 Δp (圧縮角 x 0.21)、角の値は A = B (6 桁一致)・C だけ違う。1 評価の作用素 A/B (`run_0092`/`0093`) は幾何・状態・面・残差とも同一 → 作用素差は棄却。C の最終場から A・B・C を継続 (`run_0094`–`0096`) すると角は 3 本とも C の値を保持、同一初期場での B vs C は全線 0.0210 Δp (出口端 1 節点)、除くと 0.0080。
- 絶対残差 A/B (`run_0097`/`0098`、射影なしで再集計): 圧縮角は 2 状態とも全 5 成分 ≤ 5.2e-7、**凸角 (ランプ終端 x 0.715、下面) で 4.6e-3 / 7.3e-3** の非零残差、場全体で約 2000 節点が閾値 1e-5 超。
- 形状 v2 (ランプを出口まで、折れは付け根 x 0.2 だけ、A/B H 0.5・L 1.8、C H 1.1): cfl 1 で A・B が step 691 / 640 に発散 (下流 x 1.5–1.7 の下面で P が衝撃後理論値を超えて増大、ρ 低下、閉塞ではない: 出口 M 1.7–2.2)。cfl 0.5 × 3000 (`run_0104`) は 2.5 桁でプラトー。cfl 0.5 × 12000 (`run_0105`–`0107`): A は step 10570 で発散、B・C は 2.3–2.5 桁でプラトー (C の rms_roUz rising)、壁圧の末尾 2000 step 変動幅 0.0024 / 0.0020 Δp (必要条件 < 0.001) → 判定不能。B vs C (step 12000) は全線 0.188 Δp (x 1.8)、圧縮角 0.0867 Δp。
- 解釈の現状 (前回諮問): 「初期場に依存した停滞状態」であり、定常解の非一意性や farfield 無関係は確定していない。

### V2d-2 (右端流出の音響反射、左端 = 内部と同じ高温の隔離配置、dual-time)
- dt 8.8e-7 (`run_0110`–`0121`): パルスなし対照 3 物性 × 短・長 PASS、窓付き反射 cpg 0.055 %・tp1 0.26 %・tp2 0.31 % PASS。時間精度: tp2 の dt/2 (`run_0122`) との差 1.13 % (基準 1 %) FAIL。
- dt 4.4e-7 (`run_0130`–`0141`): 全判定 PASS (反射 0.40/0.94/0.77 %)。dt 2.2e-7 (`run_0142`) との差 **2.18 %** (dt 細分で拡大)。
- パルス振幅 1e-3 P∞ = 2.2 Pa (P∞ 2851 Pa)。差 1.13 % = 約 0.025 Pa、2.18 % = 約 0.048 Pa。float32 の P (2851 Pa) の 1 ulp ≈ 2.4e-4 Pa。
- V2a (CPG 音響、P∞ 101325、dt 1.25e-6、nSub 20、cfl_pseudo 12) は dt/2 との差 0.58 % で PASS していた。
- 関連の既知事象: [moment-time-order-noise-and-front] (case/44 のモーメント時間次数の低下は float32 ノイズ床が原因だった)。

## 5. 仮説 (未確認)
- V2c-1: 凸角の残差停滞は node slip 凸角の既知/未知の欠陥で、farfield と無関係 (A slip でも同じ停滞が出ている)。
- V2c-2: 停滞はリミッタ係数の切り替え (species-transport セッションが case/16 で観測した既定 `limiterScaled 1` の残差の床と同型) による。
- V2d-2-1: dual-time の物理時間項 (U^{n+1} − U^n)/dt の float32 丸めが dt を小さくするほど効き、時間方向の誤差が dt で増える。
- V2d-2-2: 内部反復 nSub が dt に対して足りず、内部収束の打ち切り誤差が dt 細分で相対的に大きくなる。
- V2d-2-3: 振幅 2.2 Pa が小さすぎて float の床 (〜0.01–0.05 Pa) に近い。
