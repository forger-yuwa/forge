## 1. 観測事実

- 前回の判別 (b) で、同じ `qwall`・座標を揃えた比較 3D/2D = **0.9108** (3D x∈[−10,−2] cm、29 断面、0.8920–0.9223)。
  事前固定 5 % を超えたので「比較不整合だけ」は退けた。3D 6 枚・2D 6 枚で時間変動 < 0.05 %。
- **3D/2D の x 方向分布** (3D の x [cm]: 比): 入口直後 −16.9: 0.896 / −15.9: 0.870 / (上流の横すきま −15.67〜−15.0 で跳ね) /
  −12.4: 0.880 / −9.3: 0.894 / −5.6: 0.912 / −1.8: 0.923。**上流の横すきまより上流 (入口から 1.5 cm 以内) で既に 0.86–0.90**。
- **壁法線方向の格子**: 第一層は両者 8 µm。入口列の節点数は 3D **37** (うち y<2.6 cm = δ99 程度で 32) に対し 2D の抽出列 **137** (同 92)。
  3D: 0 / 8 / 17.8 / 30.0 / 44.9 / 63.2 / 85.8 / 113.7 µm、2D: 0 / 8 / 16.5 / 25.5 / 35.0 / 45.1 / 55.7 / 67.1 µm。
- 入口は 2D 平板 `run_0002_fp_t8_long` の x₀=1.707485 m 断面を `inletProfile` で与えている (3D の粗い列へ補間される)。

## 5. 仮説 (未確認)

- H1 **壁法線の離散化**: 3D の列は伸長率が大きく (第 2〜5 層で 2D より 10–30 % 粗く、δ99 内の点数は 1/3)、
  壁面温度勾配 (qwall) を低く出す。入口直後から比が 0.87–0.90 なのは、2D の分布を粗い列に補間して与えた瞬間に
  勾配が取れていないことと整合する。
- H2 **入口の受け渡し**: 補間・k/ω の写し方で近壁の乱流状態が入口で崩れ、再発達している (x 方向に 0.87→0.92 と回復する)。
- H3 **上流の横すきま**: x≈−15 cm の開口が境界層を乱す。ただし比は開口より上流で既に低いので主因ではなさそう。
- H1 と H2 は「入口で低く、下流で回復」という同じ形をするので、x 分布だけでは分けられない。

## 6. 聞きたいこと

**H1/H2/H3 を分ける判別を 1 つ選んでほしい**。候補:
(a) 2D 平板を 3D と**同じ壁法線の節点分布**で作り直して回す (2D なので安い。入口からの一様流の平板なら H2・H3 を含まない)、
(b) 3D の入口列の分布を 2D と同じ密度にした 3D 格子で回す (高い)、
(c) 後処理のみ: 2D の解を 3D の節点高さで標本化して片側差分で q を出す (離散化が勾配を落とす量の見積り。ただしソルバの qwall とは別物)、
(d) その他。
あわせて、**判別に使う許容差を事前に 1 つ決めてほしい** (例: (a) で 2D 粗格子が 2D 細格子より 5 % 以上低ければ H1 を採る)。
結果によって D1 の判定は変わらない (TC95 は分母をどう取っても実測下限 2.57 に届かない) ことは前回確認済み。
この判別は「3D run の熱輸送が格子で系統的に低い」なら衝突域 (TC90–95) にも効くかどうかを知るためのもの。
