- §6.29 (SST の更新の停止)・§6.33 (block の系の組み立ての double 化)・§6.35 (平均流の FP64 での累積) はどれも判別不能で、大幅な抑制は観測されなかった。
- §6.37 (case/48 平板 M4.19 一様・冷却壁に case/45 の陰解法の設定一式): **結果 B (再現せず)** (§6.39)。θ(0.3/0.6/0.9) の float − FP64 は両窓で |e| + E ≤ 9.2e-5 (基準 5e-4)、前提はすべて合格。
- **§6.38 (既存の出力の解析、記録)**: 各節点の「自分の step 0 からの変化」の float − FP64 (A の step 0 の値で割る):

## 2. 仮説 (呼び出し側、未検証)
- **H1**: 入口〜収縮部のほぼ淀んだ低マッハ域で、float の ρE (≈ p/(γ−1) ≈ 1.4e6 J/m³。TP では生成エンタルピーの分も入る) の刻みが、圧力に換算して 0.03〜0.07 Pa 程度になり、M 0.0005〜0.007 の流れの動圧 (0.1〜10 Pa 程度) に対して粗い。そのため流れ (特に冷却壁の温度境界層) が丸めに左右され、その差が下流の境界層へ運ばれる。換算は代表値の見積もりで、場の値では確かめていない。
- **H2**: この領域は小さな乱れを増幅しやすい (float 同士でも差が育つ)。float では丸めが乱れの源になる。H1 と H2 は両立する。
- 平均流を FP64 で積んでも残差は float に丸めた ρE から作るので効かない (§6.35) こと、case/48 では再現しないことは、H1 と矛盾しない。

## 3. 次の試験の案 (未検証)
- **短い run で入口〜収縮部を見る**: 差は step 1,000 で既に入口〜収縮部に出ているので、各 2,000 step (500 ごとに出力) で足りる見込み。case/45 の全格子でも 1 本数分。
- 腕 (どれも §6.26 と同じ入力 `_tr/q32_init.h5`・設定):
  - R0 = FP64 × 3 (再実行の差の基準)
  - R1 = FP64 + **ρE だけ** step 末尾で float32 に丸める × 3 (§5.1 #19 の診断に、丸める量を選ぶ環境変数を足す)
  - R2 = FP64 + ρ と ρu だけ丸める × 3
  - R3 = float × 3 (既存の傾向の再確認)
- 指標: x/r_t < −2 の節点で、各腕の R0 の平均からの |ΔU|/U・|ΔT|/T の分布 (割合・中央値) と、腕の中の再実行の差。step 1,000・2,000。
- 読み方の案: R1 が R3 と同じ規模に離れ、R2 が R0 と同じなら「ρE の量子化が入口の差の十分条件」。R2 も離れるなら量子化一般。R1・R2 とも R0 なら H1 は退く。

## 4. 直し方の候補 (原因の確定の後、未検証)
- ρE を基準値からの差 (ρE − ρE_ref) で持つ / エネルギーや圧力だけを double で持つ / 計算領域の入口を淀みの少ない位置へ移す / 低マッハ前処理 (離散化の補正なので H1 なら効かない見込み)。
