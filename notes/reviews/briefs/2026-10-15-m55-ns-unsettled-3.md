## 観測事実

- 事前に固定した判定は **複合要因**: 両経路の差 |P0_A − P0_B| は最大 1.03e−4 Pt (全時点 ≤ 1e−6 にならない)、B (保存量から作り直した状態) でも超過は消えない (49,862〜79,964 点)、A − B で説明できるのは超過量の 0.11〜0.65 % だけ。最大の超過は B でも A とほぼ同じ (差 ≤ 1.4e−5)。超過の大部分は保存量の状態にある。
- A − B の差の大きさ (T ±0.036 K、P 相対 ±1.5e−4、h0 ±43 J/kg) は、出力の原始量・h0 が陰解法の更新の前の状態で、保存量が更新の後 (`main.cpp` の `advanceImplicitSteady` で `writeStepOutputs` が次の step の `dependentVariables` の前) という 1 step のずれと矛盾しない (コードを読んだだけ、計測していない)。
- 超過の位置: 入口の列・壁の行は 0 点。壁からの距離 27〜91 点 (nj 92 で j 0〜64)、x −1〜8 m、軸の行は 183k で 64〜150 点 (100k〜160k は 1,947〜3,803 点)、残りは内部。183k の x の分布は [−1, 0) に 16,642 点、[0, 1) に 23,056 点。
- 超過の点の集合 S (183k の 50,441 点) では **h0 が入口より低い**: 平均の h0 − h0_in は −55 J/kg (100k) → −2,152 J/kg (183k) に単調に減り、同じ区間で平均の ΔP0/Pt は −5.1e−5 → +1.46e−4 に増えた。内部の代表点 (i 2778・j 36・x 0.298 m) では ΔP0/Pt −1.22e−3 → +2.36e−3、h0 − h0_in −29 → −4,618 J/kg。
- 同じ場の μt/μ (res_183000、j は軸 0 → 壁 91): 例 i 300 で j10/36/60/85 = 8.2/10.0/41.6/0.0、i 2778 で 1.9/27.4/96.7/0.0、i 4700 (出口付近) で 0.1/753/35.9/0.0。径方向の格子は `axis_cap_frac 0.03` (壁側の約 62 層が近壁の等比、軸側は一様)。
- 時系列 (`check_quasisteady --series-csv`、S を固定): S の ΔP0 の平均・最大、h0 の平均は DRIFTING (h0 の平均の drift 18.8 %/tail)。最大の超過は 100k の +0.616 % → 170k の +0.223 % → 183k の +0.236 %。
- 入口の列の 9 点で静温も Tt を最大 2.62 K 超える (保存量から作った状態でも)。
- 停止規則の系列 (前のブリーフ): 質量の収支 r が時定数 約 6 万 step で減少、θ_r は単調に増加。収束は NOT CONVERGED (still converging)、準定常は DRIFTING。

## 呼び出し側の仮説

- H1: 全圧の超過は冷却壁による熱の除去 (h0 の不足) に伴う物理的な効果 (Rayleigh 流れで熱を除くと全圧が上がる: dP0/P0 ≈ −(γM²/2)·dT0/T0) で、S は外側の境界層 (μt/μ が 10〜750 の領域) にある。超過も h0 の不足も時間とともに動いているのは、熱的な境界層の発達という遅い過渡で、質量の収支・θ_r の遅いドリフトと同じ原因。ソルバの欠陥を示すものではない。
- H2 (除外していない): 数値の散逸・`thermoFloat 1`・軸の扱いによる偽のエントロピーの減少。
- 入口の列の静温の超過 (最大 2.6 K) は入口の BC の扱い (別の問題)。
