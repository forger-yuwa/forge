## 3. 私の案 (縛られなくてよい)

- 同じ 3 つの状態を `physProp.thermoFloat: 0` (double だけの Newton) で 1 step ずつ評価し直す: Q0 (1 本、R(Q0) は腕によらない)、GI と GB の Q0 + δ★/2 (`run_0702`/`run_0703` の書き込んだ入力 h5 を流用) と Q0 + δ★ (`run_0698`/`run_0701` の res_1 を restart) の計 5 本。他は §4.92 の B の run と同じ。
- 判定: `thermoFloat: 0` で縮流部の圧力残差の線形性の誤差が両腕で ≤ 0.05 になり、T・P の比例の誤差も 1e−3 以下になる → 比例しない応答の主因はハイブリッドの温度反転。依然として両腕で ≥ 0.5 → 主因ではない。
- 結果が前者なら、§4.90 の測定 (Γ の補正の残差の応答) を `thermoFloat: 0` でやり直せる。
