## 観測事実 (実装担当の測定、commit 2d280bb1。g1 と g3 は x station が同じ、z = 0 の中間線)
- 実装: `mesh_sern3d.py` の `_te_wake_midline()`。x ∈ (L_cowl, L_cowl+L_b) を 3 次 Hermite `y = y_te + L_b·(m0·t(1−t)² + m1·t²(2−t))`、m0 = 下側壁面 (cowl_out) の最後の上流の辺の傾き (−4.4072°)、m1 = tan θ_b (−40.2355°)。終端で旧中間線の位置と勾配に一致。既定 0 で旧格子とビット一致 (試験 `design/tests/run_sern_te_wake_tests.py` 64 項目)。
- 位置と勾配の両方を戻す Hermite は、L_b によらず途中で旧中間線より急になる (最急 ≈ (4m1 − m0)/3 ≈ −47.8°)。
- L_b ごとの値:

## 問い
1. L_b と曲線の選び方。(a) Hermite で L_b = 1.0 H (最大の折れ 5.08° = A の他所の最大と同程度)、(b) 0.5 H、(c) 別の曲線 (各 station の折れを均等に配る曲線。位置と勾配を戻すなら総回転は約 51° なので、最大の折れの下限 ≈ 51°/station 数)。
2. 格子の確認の許容差の事前登録 (数値で): 最初の下流の辺の角度 (下側の層で m0 から何度以内)、後縁の折れ、復帰区間の最大の折れ (例: A の後縁以外の最大 5.00° + 1° 以下)、品質 (`check_mesh_quality` の VERDICT が A と同等以上、skew 最大の増分、ヤコビアン最小の下限)。
3. 中間線を噴流の境界 (θ_b) から最大 0.11 H 離すと、噴流のせん断層を解像する細かい層がせん断層から外れる。これは A/B の因子 (後縁の折れ) と交絡するか。交絡するなら判定 (§6.0 の結果 A/B) の読み方をどう変えるか、または交絡しない作り方 (例: 変形を後縁近傍の数 station に限り、位置の差を下流で遠方へ逃がす) があるか。
4. stage_key へのメッシャのオプションの登録を生産前に回してよいか (今回の A/B は別 run なので不要、という整理で足りるか)。
