## 目的 (使い道)

軸対称 M6 風洞ノズル (case/45) の設計チェーンで、非粘性設計壁 r_inv(x) に半径方向排除厚 δ_r(x) を足して物理壁にする。
δ_r は「前回の NS 場」と「設計壁の Euler 場 (固定)」から断面ごとに測り、次の壁に使う (固定点反復、ω=1)。
**要求**: 試験部の軸 M を Euler (≈設計) から ±0.05 % 程度に保つこと。実績では δ_r に x 方向 1〜2 % の局所的な誤差 (幅 ~10 r_t) があると、
壁の微小なへこみ → 圧縮/膨張波 → 軸に集束して軸 M に ±0.2〜0.35 %pt の谷と山が出る。**局所的に滑らかで、x 方向に段差や跳びを作らないこと**が最重要で、
全体の 1〜2 % の一様なバイアスは許容 (出口径で後補正する)。

## 観測事実

- 現行の抽出 (`band_local_deficit`): x 一定の断面で q = ρU_x。NS 側を r/(r_w,NS − δ_in)、Euler 側を r/r_inv で対応 (δ_in = その run の壁に足した δ_r)。
  壁から y ∈ [y_b, 1.5 y_b] の「帯」で比 q_NS/q_E を y の 1 次式でフィット → 壁まで延長 → q_ref = 比 × q_E。
  欠損 D = 2π∫_{y<y_b}(q_ref − q_NS) r dr、2π∫_{r_eff}^{r_w} q_ref r dr = D から δ_r = r_w − r_eff。
  y_b は max(1.5 δ_in, 0.02 r_w) から 1.25 倍刻みで、帯内比の変化 >1 %・帯内残留欠損 >10 %・帯の比がコア比の 0.95 未満 のどれかなら広げる (最大 14 回)。
  その後 5 次 P-spline (ノット ~2 r_t、3 階差分ペナルティ λ=1、単調性ガードで λ ×10) で平滑化。
- 実データ (case/45 `run_0022_ns_ib_pass0`、x = 21 r_t、δ_in = 0.1136 r_t、r_w = 6.01 r_t、境界層の外縁は y ≈ 2.5 δ_in):
  NS/Euler = 0.367 (y=0.5 δ_in), 0.508 (1.0), 0.851 (2.0), 0.976 (2.3), 0.997 (2.5), 1.000 (2.7), 0.999 (3〜40)。コアは 0.995〜0.999 で一定ではない (軸近くで 0.995)。
  断面全体で Euler − NS を積分すると δ ≈ 0.1148 (帯 A 0.1135 より 1.1 % 大)。
- 帯の切替の害: x≈20 で y_b が 2.93→2.34 δ_in に切り替わる。帯 B は境界層の縁 (0.976→0.997 の行) を含むので直線が傾き、壁で比 0.98 → δ_r −1.8 %。
  3 回の抽出 (run_0022/0023/0025 の場) すべてで同じ場所に出て、壁が x≈17〜29 で 1e-3 r_t へこみ、軸 M に谷 (x≈57) と山 (x≈69) が出た。
  積分法 (CONTUR) の壁 run_0022 には山が無い。差分場 ΔM・∂p/∂x で壁 x≈15〜25 から C− で軸へ届く帯を確認 (ユーザ判断: 軸の数値振動ではなく壁起源)。
- 帯を固定すると (run_0022 の場): y_b = 2.93/3.66/4.58 δ_in で x=14〜30 の δ_r/δ_in = 0.999 ± 0.001 で平ら。2.34 δ_in 固定は x=14〜19 で 0.875〜0.973。
- 新バイナリ (`bc1c84d1`, 9/20 に limiterScaled 既定 0→1 を含む) の run_0042 (同じ壁) では δ_r/δ_in = 1.04〜1.06 (旧バイナリの run_0038 は 0.993〜1.002)。原因未確定。
  この場では adaptive の切替点が x≈35 に移り、x≈38〜45 で −1.3 %。
- 修正案「プラトー」(帯を 1.5·1.25^k δ_in の梯子で外へ並べ、連続 2 段の変化 <0.3 % の最初で止める) を実装 (既定 off、既定経路はビット一致)。
  run_0042 の場で隣接断面の跳び 0.42 % (adaptive 9.4 %)。**しかし梯子の始点を ×√1.25 ずらすと δ_next が最大 2.2 % (x=7.4) 変わり、x=74〜95 で 56 断面がプラトー無し**
  → 梯子依存で不採用 (codex 諮問 `notes/reviews/2026-10-04-m6-band-plateau-fix-diagnose.md` の反証条件 0.5 % を満たさず)。tol 0.15 % にすると未検出 136 断面。
  外側の帯 (≥7 δ_in) は x≥60 でコアの波を拾い ±1〜2 % 揺れる。
- 計算の状態: NS run はすべて `check_convergence` NOT CONVERGED (残差プラトー)、軸の山は時間的に STEADY (変動 ≤0.004 %pt)。
  メッシュは 1250 × 97 (壁側等比、第 1 セル 4.5e-5 r_w、境界層の外縁付近の節点間隔は δ_in の 0.1〜0.2 倍程度)。

## 仮説

- H1: 現行の帯選択は、離散刻み (×1.25) と固定しきい値 (比の変化 1 %) が組み合わさっているため、境界層の縁にかかった帯を通してしまい、x 方向に段差を作る。根本的に頑健でない。
- H2: 境界層の外縁を直接 (例えば比 q_NS/q_E や全エンタルピー・全圧・渦度の回復で) 検出して、その外縁の一定倍に帯を置けば、連続で頑健になる。
- H3: 帯 (局所参照) という発想自体をやめ、別の定義 (例: コア整合を軸近傍を除いた広い範囲で取る、外縁検出した δ99 までの積分、質量流量だけを合わせて形は積分法に任せる) の方がよい。
