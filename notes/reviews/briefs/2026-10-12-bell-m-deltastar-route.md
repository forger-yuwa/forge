## 2. 観測事実

- (M) の非粘性壁 (ピン版 L100) の Euler: η 0.99036。(D) の NS の Pareto は L 21.69 で 0.98083 → 粘性の損失はおよそ 1 % の桁 (摩擦と境界層による有効面積比の減少)。(M) の非粘性壁をそのまま NS で回すと、境界層の排除で有効 ε が小さくなり、η は「物理 ε で設計した形」より低く出るはず (向きは確実、量は未測定)。
- plan の現行の #7 (§4.4): 積分法 (`feedback/deltastar_integral.py`、CONTUR 型の閉包、現状 CPG) を TP にする (μ(T)・d ln u_e/dx・回復温度をエンタルピーから)、k_f を較正用と検証用の形状に分けて受理、非粘性壁を法線にずらしたあと §4.2 の拘束付き当てはめ (`joint_fit_wall` を始点 r・r′・r″ と終点 r・r′ を任意に指定できるよう拡張) で物理壁を確定、射影の残差を記録。帰還ループは回さない。合格の線は #7 に列挙 (ビット一致・TP 微分 1e-4・検証形状の δ* 差を記録・拘束 1e-6・射影の残差の受理値は後で事前登録)。実装量は大きい (積分法の TP 化・当てはめの拡張・較正キャンペーン)。
- 既存の部品: `metrics/deltastar.py` (NS 場から δ* を抽出、SERN で使用)、`feedback/deltastar.py` (経験式、v1 の初期補正)、`feedback/deltastar_loop.py` (①風洞の δ* 帰還、CONTUR 初期壁 + 固定 Euler 基準・帯局所抽出 — 生産レシピ)。①風洞の経験: 物理壁のスロートの δ* は NS の実効値の 3〜12 倍過大に出た (積分法・経験式の過大評価)。
- NS 1 評価は GPU 単独で約 3 分 (共有で 10〜25 分)。

## 3. 選択肢 (主セッションの整理。これに縛られなくてよい)

- **(A) plan どおり**: TP の積分法 + k_f の較正・検証 + 拘束付き当てはめ → 物理壁 → NS で評価。設計時は NS 不要 (積分法だけ)、ただし較正キャンペーン (NS 数本) が一度きりの開発費。実装量 大。
- **(B) NS からの一発補正**: 各 L_k で (M) の非粘性壁 (inviscid ε を物理 ε より少し小さく仮置き、または同じ ε) を NS で 1 本 → `metrics/deltastar.py` で δ*(x) を抽出 → 法線にずらして拘束付き当てはめで物理壁 → NS でもう 1 本 (評価)。1 設計 = MOC + NS 2 本。積分法も k_f も要らない。当てはめの拡張は (A) と共通で要る。
- **(C) 補正なし**: 非粘性壁をそのまま物理壁として NS で評価し、δ* の効き (B を 1 つの L_k で回した差) を U_k の δ* 項に入れる。V3 は「(M) は δ* 補正なしの形」として比較。
- 設計時間の比較 (V3 の主項目) では、(A) は設計時の費用が最小で開発費が大きい、(B) は 1 設計あたり NS 2 本、(C) は NS 1 本だが形が劣る、という差になる。

## 4. 問い (推奨を 1 つずつ)

1. V3 に向けて (A)(B)(C) のどれを (M) の「生産の作り方」にするか。①風洞の δ* の教訓 (積分法の過大評価) と、③が断熱壁・真空・TP であることを踏まえて。
2. 選んだ道の最小の合格の線 (事前登録) と、V3 の U_k の δ* 項の作り方。
3. 「非粘性壁の ε」をどう置くか (物理 ε と同じにして当てはめで出口半径を合わせる / δ*_e を見込んで小さくする)。§4.2 の拘束 r(L)=r_t√ε は物理壁に課す。
4. 今すぐ回せる安い一手 (例: ピン版 L100 の非粘性壁を NS で 1 本回して δ* と η の差を見る) があれば。
