# 諮問ブリーフ: point では float と FP64 の差が B0 の約 1/50 — 解釈と次の手 (2026-10-11)

- 依頼者: 主セッション (エスカレーション条件 3・7・1・4)
- plan: `plans/active/architecture-float-state-double-geometry.md` (§5.1 #22、§6.26〜§6.27、§6.48〜§6.50)
- ユーザの目的: case/45 で double をやめたい (float のずれの原因を突き止める)。

## 0. 問い
1. §6.49・§6.50 と forge-25 の観察 (§5.1 #22) から、plan に書いてよい範囲。「float のずれは B0 の反復の性質と重なって出る」をどこまで言えるか。
2. 次に最も情報の多い試験 (下の案の優先と組み方)。

## 1. 観測事実
- §6.27: 共通の Q32 の起点から B0 (lineImplicit 1・lineDtDirectional 1・上限 50・ITJ 5・cfl 4・緩和 0.7) で 30,000 step: FP64 は θ_r ≤ 0.12 %、float は +0.9〜1.9 %。
- **§6.49 (段 1)**: 同じ起点から point (上の 4 キーを削除、ほか同じ) で FP64 ×2・float ×2: W1・W2 (20,000〜30,000) で θ_r の Δ が 0.001 ポイントまで一致 (−1.135 → −1.485 % など、両精度とも同じ向き・同じ量)。Q_w は 0.008〜0.012 ポイント違う。
- **§6.50 (段 2)**: 120,000 step。W3・W4 (100,000〜120,000) で max|ΔF − ΔD| + N = 0.026〜0.034 ポイント (0.1|D| = 0.143〜0.189)。θ_r は両精度とも W3 → W4 で +0.07 ポイント戻り中 (まだ動く、DRIFTING 0.1 %/窓)。`check_convergence` は 4 本とも CHECK FAILURES (残差は起点から 1.9 桁、rms_ro 3.7〜4.3e-7、worst は rms_roOmega)。事前登録の判定は判別不能 (付帯条件)。差は W1・W2 の 0.000 → W3 0.026〜0.029 → W4 0.032〜0.034 とわずかに増えている。
- §5.1 #22 (forge-25、別の格子 Gref 4719 × 160): B0 は point の収束値より θ_r +0.6 % の所で止まる。上限 50 → 1 で停滞が解け始める (ω の残差は増える)。上限・方向別 dt は setDT にしか入らず右辺を変えない。B0 の停滞は揺れでも床でもない遅いモード (lag-1 +0.9998)、残差の上位 0.1 % の節点は縮流部 x < −2 r_t の主流側。x を粗くした Grefx では B0 で 5 桁下がり point と 0.002 % で一致。
- float の調査の場の記録 (§6.38・§6.47): B0 で float と FP64 の差は縮流部で先に・最大に育つ。
- 効かなかった介入 (B0 のまま): SST の更新の停止、block の組み立ての double、qAccumulatorFP64、状態の step 末尾の量子化、pRef。

## 2. 呼び出し側の読み (未検証)
- float の大きなずれは B0 の反復の性質 (縮流部の遅いモードを減衰させない) と重なって出る。FP64 も B0 では本来の解から離れて止まっており (forge-25 の Gref では θ_r 0.6 %)、float の丸めの揺れはその遅いモードを押して別の所へ流す。point では遅いモードが減衰するので、float と FP64 は同じ解へ向かう。
- double をやめる道は、B0 の反復を直して遅いモードを減衰させることと重なる (FP64 の精度の改善にもなる)。

## 3. 次の手の案 (未検証)
- **案 C1 (上限 1)**: ラインは残して `lineDtDirectionalCap: 1` (forge-25 の A/B と同じ) で float ×2・FP64 ×2 を共通の Q32 の起点から 30,000 step。B0 との違いは上限の 1 点。float の大きなずれが消えるなら、方向別 dt の伸びが要る。
- **案 C2 (ラインだけ)**: `lineImplicit 1`・`lineDtDirectional 0`・ITJ 5。方向別 dt を外す。
- **案 L (point を延長)**: §6.50 の 4 本を 120,000 → 200,000 step へ延長し、収束・準定常の付帯条件を満たすか見る (判定の形は延長として事前登録)。
- 呼び出し側の好み: 案 C1 を先 (forge-25 の結果と直接つながり、B0 の 1 点だけを変える)。
