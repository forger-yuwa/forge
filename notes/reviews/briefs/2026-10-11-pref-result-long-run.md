## 0. 問い

## 1. 観測事実
- §6.27 (確定): 共通の Q32 の起点 `_tr/q32_init.h5` から 30,000 step。FP64 (A `run_0487`) は θ_r が ≤ 0.12 % しか動かず、float (B `run_0488`・B′ `run_0489`) は +0.9〜1.9 % 動く。D = (+1.892, +1.647, +1.431) % (θ_r の 3 断面 x/r_t 40・70・94)、Q_w +2.114 %。窓 W1 20〜25k・W2 25〜30k。B と B′ の差 N_B 0.07〜0.14 ポイント。
- §6.38: 差は指定の閾値で入口〜収縮部 (M 0.016〜0.08) が先に超え、後に下流でも超えた。
- §6.41・§6.43: 状態の step 末尾の量子化 (ρE だけ・9 保存量すべて) では入口〜収縮部の初期の温度差の主な成分は出ない (結果 B ×2)。
- **§6.45 (pRef、各 2,000 step、A で 1 本ずつ)**: 前段の関門は通過 (閉性 g の最大 2.6e-16、Cp − C の a の差 [−0.00037, +0.00036]、温度差 RMS ≤ 0.0054 K・最大 0.137 K)。e_Fp = +0.092 [+0.046, +0.138]、d = e_F − e_Fp = +0.821 [+0.494, +1.147] → L_d が 0.5 に 0.006 届かず判別不能。a: C 0.2164〜0.2166、Cp 0.2163〜0.2166、F 1.04〜1.23、Fp 0.294〜0.317。温度差 (step 2,000、x/r_t < −2): Fp は RMS 1.5〜1.6 K・最大 37〜41 K・|ΔT| > 1 K の節点 3.3〜3.6 %、差の最大の所の平均 −0.006 K。F は RMS 3.7〜4.5 K・最大 119〜134 K・5.4〜5.7 %・−0.91〜−1.04 K。
- `space.pRef` は SLAU の内部の面・境界の半割面・hoop ソースで圧力の項を (p̃ − pRef) で組む (p̃ は float の P から作る)。

## 2. 呼び出し側の読み (plan §6.45 に記録済み、判定ではない)
- 正式には判別不能。記録として、pRef の変更で射影 e は 0.91 → 0.09、温度差は RMS で約 6 割・最大で約 7 割減った。型と直交する差 (RMS 約 1.5 K) は残る。「残差の加算が真因」とは言わない。下流への効果は未測定。

## 3. 次の試験の案 (未検証)
- **長い試験**: 共通の Q32 の起点から 30,000 step・500 ごと (§6.26 と同じ)。腕: Ap = FP64 + pRef ×1、Bp = float + pRef ×2。A で 3 本同時 (メモリ 約 7.5 GB) か 1 本ずつ。比べる相手は §6.27 の A (FP64、pRef なし)・B・B′ (float、pRef なし)。
- 判定の案 (§6.26 と同じ Δ・窓・D):
  - 前提: Ap が A と同じ (|ΔAp − ΔA| ≤ 0.1|D| を 6 組すべて)。
  - 「抑制」: Bp・Bp′ がそれぞれ Ap から 0.1|D| 以内 (6 組すべて)。
  - 「抑制不十分」: Bp・Bp′ がそれぞれ Ap から D の向きへ 0.5|D| 以上 (6 組すべて)。
  - それ以外は判別不能。§6.33・§6.35 のような「再実行の差の 10 倍」の条件は使わない案 (再実行の差 N が 0.07〜0.47 と大きく、0.5|D| と同じ桁になって判定できなかったため)。代わりに 2 本とも条件を満たすことを要求する。
- 短い試験の再試行 (Fp・F を 5 本ずつに増やして d の判定をやり直す) は、長い試験で目的の量が見えるならやらない案。
- 所要: 3 本同時で 1〜1.5 時間 (§6.26 は B で 5 本共有で 1.5 時間)。
