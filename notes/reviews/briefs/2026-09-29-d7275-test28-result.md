## 1. 観測事実

- 入口は forge の燃焼ガスで解いた斜め衝撃波 (θ 9.8°) の背後の局所状態を平板に平行に (T 348.65 K、U 1923.95 m/s、p 8451 Pa、M 5.11)。Table III は p_l 8412 Pa (+0.5 %)・T_l 363.3 K (−4.0 %)。前縁の衝撃波は解いていない。
- run_0023 (y1 3 µm): 本段 PASS (4.0–4.6 dec) だが St の下流 8 点が DRIFTING (層流水準から上昇中)、壁解像 FAIL (>1 が 14.8 %)。
- run_0024 (同メッシュ +60k): St ALL STEADY、R28 = 1.380。run_0025 (y1 2 µm、interp_field): PASS・St ALL STEADY・壁解像は前縁 1 点のみ超過、**R28 = 1.411 [1.355, 1.491]**。3 → 2 µm で St +2.3 %。
- 試験 26 (同じ x 対応 = Table I 熱電対位置): R26 = 1.321 [1.275, 1.448]。R28/R26 = 1.068 (3 µm では 1.045)。
- Eckert (論文 p.14 の式、Table III の換算): 試験 28 で実験/Eckert 0.701、forge/Eckert 0.99 (Pr* 0.69) / 1.05 (forge 物性 Pr* 0.746)。試験 26 は 0.755 と 0.99 / 1.06。
- 試験 26 の y1+ は比較域 0.26–0.28 (y1 3 µm)、試験 28 の 2 µm は平均 0.60。試験 26 の収束はユーザ判断で条件付き (残差床は比較域外、比較量の変化 ≤ 5e-6)。

## 2. 期待値と出典

- 事前登録 (T4-0b-T28 decision): |mean(R28)/mean(R26) − 1| ≤ 0.10 → 『衝撃波の背後でも関係は変わらない』、> 0.10 → 差を報告し上位に諮る。読み取り ±0.4〜1 %、T_l −4 %、入口モデルは記録。
- G15 (plan §6): 試験 26・28 の B を位置 II 局所で一次、パネル平均は診断。前提ゲートは G14 と同じ。

## 5. 呼び出し側の見立て (未確認)

- 機械的な読みは『関係は変わらない』(1.068)。ただし R は 0 → 9.8° で 1.32 → 1.41 と上がっており、その 2.3 % 程度は格子 (y1+ の違い) で説明できるかもしれない (試験 26 の y1+ は 0.27 と小さい)。
- 実験/Eckert は 0.755 → 0.701 と下がり、forge/Eckert はほぼ一定。R の上昇の大半は実験側が Eckert からさらに下がったことに見える (原因ラベルは付けない)。

## 6. 聞きたいこと

1. 事前登録の読み『関係は変わらない』を確定してよいか。格子感度 (3 → 2 µm で +2.3 %、2 水準のみ) と試験 26 の y1+ の違いをどう書くべきか (試験 26 も 2 µm で回すべきか)。
2. 入口モデル (前縁衝撃波を解かない) と T_l の −4 % の差を、結論の制約としてどこまで書くべきか。
3. G15 (試験 26・28) を『条件付きで満たした』として T4-0 を締め、#60 (3D すきま) に戻ってよいか。戻る前にやるべきことがあれば 1 つ。
