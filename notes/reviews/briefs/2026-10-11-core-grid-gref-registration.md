## 2. 期待値と出典

- ユーザの目的 (§4.16): Gref を物差しにして、各格子の |G − Gref| (+ 揺れ・反復条件の感度・後処理の予算) を測る。設計の許容差に収まる最も安い格子を選ぶ。Gref は生産の候補ではなく、1 本だけ回す。
- 許容差 τ: ユーザ未確認。仮に §4.5 の値 (θ_r・δ・Q_w 1 %、出口の主流 M 0.02 %、軸・η 0.1 の M 0.02 %pt) を使う。
- ユーザの方針: 比較のためだけの run は増やさない (「増やしたケースなんてやる意味ないじゃん」)。終わりは別の未収束 run の値からの差でなく、その run 自身の変化で決める。
- 前回の登録 (§4.4・§4.5) の J0 は「水準に到達し、到達後 4 万 step の窓が STEADY・u ≤ τ/4」。G1・G1x は水準に入らず、この規則では判定できなかった。

## 3. 判断してほしいこと

推奨を 1 つに絞り、§4 の新しい節にそのまま書ける形で示してほしい。候補を下に挙げるが、縛られなくてよい。

- (a) **Gref のキー** (`mesh.axisSegmentRWeight`): コードの既定はキー 1 (hoop の修正)。ただし既定化の検証は未完了で、G0 ではキー 1 の方が揺れが大きい (規則では未支持)。候補: キー 1 の 1 本。既存の G0 (run_0485)・G1 (0603)・G1x (0605) のキー 1 と、通算 180k〜200k で並べられる。
- (b) **長さと停止の規則**: 候補: 水準で止めず、通算 20 万 step の固定長で回す。G1・G1x と同じ起点 (run_0183 の res_100000 から interp_field)・同じ長さにする。160k〜200k の 17 出力を残す。
- (c) **判定の式**: 候補: 各格子の窓 180k〜200k (9 出力) の平均で E = |G − Gref| を量ごとに出す。不確かさは窓の揺れから取る (定義は諮りたい。今の u = 最後の値からの最大のずれか、平均の標準誤差か)。p は §4.10 の後処理の予算。合格は E + U_G + U_ref + p ≤ τ。G0 の窓は run_0485 の 40k〜60k (通算 180k〜200k) を使う。140k の再開の跳ねと、restart_field と interp_field の起点の違いをどう扱うかも示してほしい。
- (d) **反復条件の感度 s** (§4.4 の point の継続 4 万 step) を Gref と各格子で要るか。要るなら、どの run に足すか (run を増やす費用と見合うか)。
