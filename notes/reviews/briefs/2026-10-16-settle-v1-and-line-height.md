## A. V1 の代替検査 (#1、commit 27249e14)

### 観測事実

#### 試験の条件 (implementer の報告)

- 試験ケース: case/71 `run_0009_euler` の写し。
  - Euler、2 化学種、node 軸対称、定常陰解法 SLAU、466,570 節点。
  - 初期場は `restart_field.py` で res_12000 から作った (ビット一致と報告)。
- ビルド: float、sm_86、RelWithDebInfo。
  - 変更前のバイナリは HEAD 57f395b8 のソースを書き出して別にビルドした。
- 一時 run の置き場所: `/tmp/claude-1000/-home-sano-work-forge/e254baf2-8857-4243-99d2-53804f553ad9/scratchpad/runs/`
  - リポジトリの外。codex の sandbox から読めない場合は、この報告の数値だけを証拠とする。

#### 変更前のバイナリの再現性

- 同じ入力で 2 回回すと、step 0 から出力が一致しない。
  - `res_0` 以外の全出力が違う (変更前どうしの比較)。
  - 実装者の仮説: node の atomicAdd による和の順序の違い。

#### 代わりに確かめたこと

**回し直しでも変わらない部分のビット一致**
- 一致したもの:
  - `res_0.h5`
  - 全 `.xmf`
  - 出力のファイル名の集合
  - 残差 600 行の形式
- 1 step の run の比較:
  - step 1 の出口・壁の h5 もビット一致した。
  - 違ったのは更新後の全場 `res_1` だけで、変更前どうしの比較と同じ。
- 最初の流束評価の面ごとの massflux (938,047 面、`FORGE_DUMP_MASSFLUX`) とその入力の状態:
  - 次の 4 つの間でビット一致した。
    - 変更前のバイナリ
    - 新しいバイナリでキー無し
    - 新しいバイナリで全キーあり
    - 最終のバイナリ

**600 step 後の差**
- 新しいバイナリと変更前のバイナリの差 (キーの有無どちらも):
  - RMS 相対 1e−6〜5e−5
  - 最大相対 1e−4〜2.7e−3
- この差は、変更前のバイナリどうしの差と同じ桁。
- ログの違いは、監視の行の worst residual の列名だけ。

**随時の書き出しの後**
- step 600 の場は、要求なしの run とビット一致しない。
- その差は、要求なしの run どうしの差と同じ桁。

#### 合格した挙動の検査

- (b) 出力の間隔
- (c) 節点の出力が全場と 15 時点でビット一致
- (d) 流量の CSV が、面ごとの値を独立に集計した結果とビット一致
- (e) 協調停止の成功と失敗の終了コード
- (g) 随時の書き出しが止めずに書け、失敗しても計算が続く

### 期待値と出典

- plan §6 V1 (f): 出力を有効にしても全場の値がビット同一。

## B. 試験部の線の高さ (card plan §6 V5c)

### 観測事実

- run_0010 res_86000 (`case/71.m55_combustion_wt/run_0010_ns_b0/`、手元)。
- 試験部 x 4.0〜7.95 m での d = 100 (M/5.5 − 1):

| 線 | 平均 | 最大偏差 | 片振幅 |
| --- | --- | --- | --- |
| 軸の節点 | −0.019 % | 0.073 % | 0.059 % |
| 第 1 層 (η 0.03、r 20〜23 mm) | −0.000 % | 0.062 % | 0.057 % |
| 第 2 層 (η 0.06) | +0.001 % | 0.062 % | 0.061 % |
| η 0.1 | −0.002 % | 0.094 % | 0.076 % |
| η 0.2 | −0.020 % | 0.289 % | 0.172 % |

- NS の格子は、軸付近の行が η 0.03 刻みで x によらず一定。
- Euler の参照 (`run_0009_euler` res_12000):
  - 軸の節点 +0.016 %、第 1 層 (η 0.019) +0.0145 %。
  - 軸と第 1 層の差は 0.0015 %。
  - NS では 0.019 %。
- ユーザの決定 (2026-10-16): 「r/r_w = 0.1 この値に意味なくて、軸から第一層めあたりの高さにしてはどうか」
- 主セッションの提案: 格子の行でなく η 0.03 の固定値にする。
  - 理由: 格子を変えると第 1 層の高さが動く。Euler の格子では η 0.019。
- 適用の範囲:
  - 次の run から使う。
  - run_0010 の判定は事前登録どおり η 0.1 のまま残し、η 0.03 の値を併記する。
  - 合否は η 0.1 と同じで、最大偏差 PASS・片振幅 FAIL。

### 問い B

1. η 0.03 の固定に穴はあるか。例えば:
   - 試験部の入口の近くで、η が小さい線ほど拡大部の波を拾わなくなる (判定が甘くなる) 側の偏りはないか。
   - 軸付近の格子の質の影響は受けないか。
2. 片振幅・最大偏差の許容 (0.05 %・0.1 %) を η 0.1 で決めた。そのまま η 0.03 に使ってよいか。
