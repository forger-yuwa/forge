## 2. 今回の探索 (登録外・判定に使わない、step 20000 の場から)

`cg_pp_where.py` → `_band_ab/core_grid/pp_where.json`、補足は手元の解析。

- **残差の場所**: 全域の Σ V (R/V)² (ρ) は C 1.66e4、`=3` 4.13e5、`=2` 4.15e5 (約 25 倍)。C では 86 % が x > 0 の壁際 (壁から 0〜10 節点目)。`=3`・`=2` では 52〜55 % が **x/r_t −2〜0 の壁際 (壁から 0〜10 節点目)**、33〜37 % が x > 0 の壁際。上位 0.1 % の節点は x/r_t ≈ −0.2 (−1.6〜1.7)・壁から 0〜2 節点目。ρE は x −2〜0 の壁から 10〜40 節点目 33 %・0〜10 節点目 26 %。停滞帯 (境界層の縁、壁から 60〜100 節点目) ではない。
- **細かい区間** (`=3`): x −2〜−1 の壁から 0〜20 節点目で残差は C の 3400〜7700 倍、x −0.5〜0 の 0〜6 節点目で 800〜2100 倍、x 1〜2 の壁際は 11〜19 倍。そこでの刻みの比 (`=3`/C) は壁で 6.67 (M → 0、β = ε²)、壁から 10〜20 節点目で 3.2〜5.0。μt/μ は壁から 0〜10 節点目で ≈ 0 (粘性底層)。
- **粘性で刻みが決まる説の検査**: 壁法線の面の粘性の項 2(visc + μt)/(ρΔn) と非粘性の項 |u| + c の比 r_v (`setDT_d.cu:83` と同じ形、visc は設定の定数 1.8e−5) の中央値は、x −2〜−1 で 0.03〜0.07、x −1〜0 で 0.06〜0.13、x 1〜2 で 0.12〜0.24 (壁から 0〜64 節点目)。刻みは非粘性の項で決まっており、前処理で 6.7 倍にしても粘性の CFL は 1 程度。この説は外れた。
- **場の差** (`=3` − C、step 20000): 壁際のスロート付近で δT は 1 K 前後 (最大 2.5 K)、δP/P は 1e−5〜1.7e−4、δρ/ρ は ≤ 2e−3、|δu|/c ≤ 3.5e−3。場はわずかしか違わないのに、残差が数十〜数千倍。
- 前処理の刻みの拡大 (`setDT_d.cu:255`〜`:276`) は dt_local (粘性の項を含むスペクトル半径から決めた刻み) に (|u|+c)/(½(1+β)|u| + c′) を掛ける。SST の更新もこの dt_local を読む (§4.38 の記録、`update_d.cu:403`)。

## 3. 私の見立て (未検証、潰した証拠ではない)

- 候補 1: 前処理は音波でない成分 (エントロピー・渦・乱流) から見ると、低マッハ域で擬似時間の刻みを約 6.7 倍にするのと同じ。point の cfl × relax の上限 (6〜8) に近い実効値 (6.7 × 0.7 ≈ 4.7) で、壁際の欠陥補正の反復が減衰しなくなる。SST も広がった刻みで更新される。
- 候補 2: 前処理のカーネルの壁の節点の行の扱い (ランク 1 項と拘束の行、TP の χ_eos) が、β が小さいときに標準の経路と違う振る舞いをする (M6 の移植の回帰 R2 は β = 1 で確かめた)。
- 候補 3: スロートで β が境界層を横切って ε² から 1 近くまで急に変わり、隣どうしの刻みと Γ が大きく違う。
