# 諮問ブリーフ: ④デュアルベルの子 plan の §4・§6

- 日付: 2026-10-11
- 依頼元: 主セッション (Opus)。AGENTS.md「モデル分担とエスカレーション」条件 1 (§4・§6 を新規に書く) と 3 (参照値・許容差の事前登録)
- 対象: `plans/active/tooling-nozzle-dual-bell.md`。親 `plans/active/tooling-nozzle-design-tool.md` §3 確定事項 14・15
- 段階: **実装も run もしていない**。§4・§6 の下書きの妥当性を問う

## 1. ユーザが決めたこと (覆さない)

- デュアルベルは高度で指定する: 低い設計高度 h1 (海面モード)、高い設計高度 h2 (高空モード)、**使えなくてよい高度帯** [h_a, h_b] (帯の中で遷移してよく、帯の中の性能は問わない)。遷移高度そのものは定義しない。
- **剥離・遷移の判定は公知の試験データ (経験式) を正とし、CFD は念のための検証**。CFD に合わせて係数を較正しない。
- TP 基準・断熱壁・C2 (変曲点の折れだけは例外)。剥離評価 (外部領域・TC1A 検証) は別セッションで、本 plan は使える前提で進める。
- ベースは③と同じ道具 (兄弟 plan `tooling-nozzle-bell-two-mode.md`) で h1 に合わせて設計する。

## 2. 観測事実と出典

- Stark のデュアルベル遷移式 NPR_tr = (1/M_e)(1 + (γ−1)/2 M_e²)^{γ/(γ−1)} (M_e = 等圧延長の壁面 Mach、延長を全長で使う場合。切り詰めると遷移 NPR は線形に上がる): 調査ノート §3 の表 ([SGWK12] 式 (1)、調査役が本文で確認 ✔、主セッションは未確認)。
- DLR P6.2 軸対称デュアルベル: R*=10 mm、ε_b 11.3、ε_e 27.1、L_b/R* 6.2、L_e/R* 8.3、α 9°、ベース TIC (設計 Mach 不記載)、CP 延長、N2・p_a 1 bar。NPR 30 で変曲部剥離、48 で剥離域の勾配が減り、51 で全流れ。延長部の剥離域圧力は p_a の 92 % (調査ノート §2.3.2 の [NGS07] 行、✔)。座標表は非公開。
- 外部流があると延長部の剥離域圧力が p_a の 75 % まで下がる ([SGWK12] ✔ 調査ノート §4.4)。Re が下がると遷移 NPR が上がる ([VSH13] △)。
- 経験式どうしのばらつきは大きい (調査ノート §3 末尾、NASA は Crocco–Probstein に 20 % の余裕を推奨)。

## 3. 問い

§4 の設計と §6 の判定基準に Critical / Major があるか判定し、GO / GO-with-changes / NO-GO を付けてほしい。指摘は最大 6 件、各指摘の推奨は 1 つ。特に次を見てほしい (縛られなくてよい):

- Q1 §4.3 のモード保証の定式化 (NPR(h_a) < NPR_tr^lo、NPR_tr^hi ≤ NPR(h_b)、ベースが h1 で剥がれない) は、遷移高度を定義せずに「帯の外のモード保証」を表すものとして正しいか。ヒステリシス (上げと下げの差) とスロットルの扱いに穴はないか。帯が狭すぎるときに形状を作る前に INFEASIBLE とする検査は成立するか。
- Q2 §4.2 で Stark の遷移式を TP に拡張する (p_c/p_ext を凍結 TP の等エントロピーで求め NPR_tr = (p_c/p_ext)/M_e) のは、試験データを正とする方針に照らして妥当か。係数の幅を P6.2 と平面モデルの試験値から決める手順で、幅の根拠が足りるか (データが 2 系統しかない)。
- Q3 §4.4 の延長部: ベース出口の流れをベースの壁に沿った前進 MOC で作り、変曲点の中心膨張扇を経て壁圧指定で延長を作る構成に穴はないか。特にベース出口の流れが一様でない (ベースが TOP 的な形なら内部衝撃波を含みうる) ときの扱い。
- Q4 §6 V2 (P6.2 の作り直しで ε_e を 2 % 以内) と V3 (経験式と試験の比較を合否でなく幅の入力にする) は、検証として循環していないか。
- Q5 §4.5 で MOO ループ内は経験式だけでモードを判定し、遷移の CFD は有望形状の検証に回す分担は妥当か。

## 4. 仮説 (未検証の見立て)

- CP 延長なら延長部の壁面 Mach が一様なので、Stark の式で遷移 NPR がほぼ決まり、MOO の制約として扱いやすい。
- 経験式の幅は ±5〜10 % 程度になると見ているが根拠はない。
