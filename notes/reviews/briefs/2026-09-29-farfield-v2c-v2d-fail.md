## 1. V2c 斜め衝撃波

### 観測事実
- 形状 (`setup_v2c.py`): 3D 薄板 (z 3 層 slip)。下面 = 平板 (x ≤ 0.2) + 10° ランプ (0.2–0.7) + 水平 (0.7–1.2)、すべて slip。M 2.5 CPG、入口 xmin farfield (超音速流入)、出口 xmax outflow。
  A = 上面 H 0.3 slip、B = H 0.3 farfield、C = H 0.8 slip (共通領域 0 ≤ j ≤ 60 の節点座標は A/B と同一式、上に 5 mm で 100 行)。
  リミッタ基準値は固定。定常 block-DPLUR cfl 1、6000 step。残差は 2.4–2.5 桁でプラトー (3 本とも)。
  *最初の形状 (ランプが出口まで) は A で流路閉塞して発散したので 0.7 m で止めた (run_0060–0062 は破棄)。*
- 判定 (`eval_v2c.py`、評価線 = 下面 x 0.2–1.2、z = 5 mm の 201 節点): Δp_shock (理論) = 87532 Pa。
  **B vs C の最大 0.0870 Δp (x 0.210)** → 基準 0.02 を超え FAIL。A vs C 2.61 Δp (x 1.07、反射衝撃波) で対照は OK。
- 評価線上の B−C (Δp 単位): x 0.200 −0.0036、**0.205 +0.0447、0.210 −0.0870**、0.220 +0.0069、0.25 −0.0083、0.30 −0.0039、0.4–0.6 ≤ 0.0008、0.7 +0.0011、0.8 +0.0024、0.9–1.15 ≤ 0.0003、**1.20 (出口端の節点) −0.0211**。角 (x < 0.23) と出口端 (x > 1.19) を除いた最大 0.048 Δp (位置は未確認、出口寄りと推定)。
- 角付近の値: **A と B が 6 桁まで同一** (x 0.210 で 229281 Pa)、C は 236899 Pa。時間的には step 1000 から 6000 まで 1 Pa 以内で一定 (非定常ではない)。
- 経路依存の否定: cfl 0.5 で B・C を回し直した (run_0066/0067) → 角の値は cfl 1 と 6 桁同一。
- 丸め・変換の否定: 同じ msh を変換し直した B (run_0068_v2c_B_rep) → 角は 229281 Pa で同一、評価線全体の差は最大 46.7 Pa (0.0005 Δp)。
- 共通領域全体の B−C 分布 (z = 5 mm): x ≤ 0.19 は全行 0.0000。x 0.21 は下面だけ 0.087。x 0.7・0.9 の**上面の境界節点 (y 0.3) で 0.10 Δp** (B 179.7 kPa vs C 188.7 kPa。C では内部の行)。x 1.1 で内部 (y 0.18) 0.061 Δp、x 1.2 で 0.063 (y 0.152)。
- 置換・HLL 退避 0、NaN 0。

### 期待値と出典
- plan §6 V2c: max|p_B − p_C| ≤ 0.02 Δp_shock、A ≥ 0.1 Δp。
- plan §4.2 と methods: 非反射は「法線方向の小振幅音波」に限定、斜入射の線形反射係数 (1−cosθ)/(1+cosθ)。
- 私の見積もり (未検証): 超音速で境界に平行な流れでは、定常の斜め波の p'/v'_n は ρU/√(M²−1) (M 2.09 の衝撃後で 1.139 ρc)。境界は Z = ρc で特性量を作るので、反射係数 (1.139−1)/(1.139+1) ≈ 6.5 %。内部で見た反射波 0.06 Δp と同程度。

### 仮説 (結論ではない)
- H1: 角 (x 0.205–0.21) の差は farfield と無関係 (A=B が同一)。高い格子 C で角の離散解が決定的に変わる何か (節点順序に依存する角節点の処理など) がある。上流 (x ≤ 0.19) は完全一致なので上流からの伝播ではない。
- H2: 角・出口端以外の差 (最大 0.048 Δp) は farfield が定常の斜め衝撃波を約 6 % 反射する実力値。§6 の 2 % 基準は、法線入射向けの設計に対して厳しすぎた (設計どおりの挙動) か、あるいは境界の欠陥か。
- H3: 出口端の節点 (0.021) は outflow 列の局所的な差。

### 問い
1. V2c を「FAIL (境界の実力 ≈ 6 % 反射)」として記録し、SERN (側面・上面は Mₙ ≈ 0 の接線流、プルーム境界の斜め衝撃・膨張が当たる) への影響を V3 で見る方針でよいか。それとも §4 の設計を見直すべきか (例: 超音速の接線流に対して Z を ρU/√(M²−1) にする等)。
2. 角の差 (H1) は評価から除外してよいか。除外するならどういう根拠・追加試験が要るか。

## 2. V2d-2 TP 音響のパルスなし対照

### 観測事実
- 形状 (`setup_v2d.py`): V2a と同じ薄板チャネル (Δx 5 mm、左右端 farfield)、dual-time (dt ≈ 8.8e-7、nSub 20)。内部 = 一様 T 600 K・Y_EXH 0.13 (tp2) / 600 K (tp1 単成分 AIR / cpg)、P 2851、u = 0.3 c_i。farfield の自由流 = 外気 (220 K、Y 0、u = 同じ 0.3 c_i、P 2851)。評価点 x 0.8。
- パルスなし (run_0072 cpg / 0077 tp1 / 0082 tp2): max|P − P∞| = **2.4e-4 Pa (cpg、PASS) / 1.636 Pa (tp1、FAIL) / 2.490 Pa (tp2、FAIL)**。基準 0.01 × 1e-3 P∞ = 0.0285 Pa。
- 長領域 3 m のパルスなし (run_0085、tp2) → **2.4888 Pa** (短 2.4895 とほぼ同じ)。擾乱は t 1.15e-3 まで 0、1.27e-3 に最大 (2.49 Pa)、以後 0.8→0.55 Pa。左端から音速で来た時刻 0.8/(c_i+u) ≈ 1.28e-3 s と一致。
- 左端の自由流を内部と同じ高温状態にした診断 (run_0086 tp2 / run_0087 tp1、右端の自由流は外気のまま) → **max|P − P∞| = 0.0000 Pa**。
- パルスありの反射 (短 vs 長の差) は 0.066 % (cpg) / 0.23 % (tp1) / 0.22 % (tp2) で PASS。V2d-1 接触波 (塊の流出) も 3 物性 PASS (P 1e-4 P∞ 以下、ΔT ≤ 0.025 K、ΔY 2.6e-6)。
- plan §6 V0p (事前の記録): TP の保存形混合で圧力 +0.654 % (境界と無関係の既存性質)。

### 期待値と出典
- plan §6 V2d-2: パルスなし対照で評価点の |P − P0| ≤ 0.01 × パルス振幅 (plan-4 M1 の意図: 内外の状態差だけで境界が擾乱を出さないこと)。

### 仮説
- H4: 擾乱は左端の流入境界で低温の外気が高温の内部に入り、接触面ができる瞬間に TP の保存形混合 (V0p) が出す圧力波。右端 (出ていく側) の境界は内外の状態差で擾乱を出していない (左端を高温にすると 0.0000)。
- ただし「流入口で接触面を作るときに圧力波を出す」ことを境界の欠陥とみなすかは判断が要る (他の入口条件でも同じことが起きるかは未確認)。

### 問い
3. V2d-2 の対照を「右端 (試験対象) の境界は擾乱 0」として合格扱いにし、左端流入の擾乱は V0p と同じ既存の内部離散化の性質として記録する、でよいか。追加で要る試験はあるか (例: 左端を既存の入口条件にした同じ配置で同じ擾乱が出ることの確認)。
