## 2. 試験の案 (未検証)
- 腕 (AWS B、4 本同時、B0 の設定・旧バイナリ・環境変数は §6.26 と同じ、格子だけ G0c): FP64 ×2・float ×2、各 30,000 step・500 ごと (step 1〜19,500 の場は消す)。
- 判定 (§6.48 の段 1 と同じ形、窓 W1 20,000〜25,000・W2 25,000〜30,000、Δ は各 run の step 0 から、D は §6.27 の値を尺度として使う、N は再実行の幅):
  - 結果 A (大差が残る): 両窓・3 断面で min sign(D)(ΔF − ΔD) − N ≥ 0.5|D|。
  - 結果 B (差が小さい): 両窓・3 断面で max|ΔF − ΔD| + N ≤ 0.1|D|。
  - それ以外は判別不能。
- 正規化の分母: G0c の FP64 の step 0 の θ_r (G0 の旧 A の値ではなく)。
- 解釈の範囲の案: B なら「縮流部を粗くした格子では、B0 のままこの期間の float と FP64 の差が小さい」。格子が原因・double が不要とは言わない。
