  B は点上ゲート不合格 (スロート直後の 2 点のみ)、それ以外 (単調・r″ の極値 5・始点/出口・物理壁のスロート κ 0.4944 で補間 0.4941 と同等) は良好。
- 物理壁の「非単調」は**試験の組み方の不備**: n 2400 では x_e が 95.227 (1200 では 95.104) に伸びるのに δ_r 表は x=95.10 までで、端の外で `delta_r_from_table` がクリップ →

- **スロート始点の MOC 点の不整合** (`wall_mode: cplus`、`start_line: throat_char`、`n_start` 41):
  最初の区間 (x 0 → 0.0258) の割線勾配と両端 θ の平均の差が **0.044°** で、n_axis 1200・2400・9600 で変わらない (2 区間目以降は 0.003〜0.005°、9600 で 0.0005〜0.0018°)。
  点 x=0.0258 で r − 1 = 1.98e-4、θ = 0.7906° → 局所曲率は位置から 2(r−1)/x² = **0.595**、角度から tanθ/x = **0.535**。ハード拘束の r″(0) = 1/R = **0.5** とどちらも合わない。
  補間壁の 0.050° も B の 0.028° も同じ場所。
- `PhysicalNozzleWall` は設計壁を 3000 点で標本化して δ_r を足し、真のスロート位置と曲率を**オフセット点群から推定し直し** (`_locate_throat`: κ は ±0.15 の 1 パラメータ LSQ)、
  下流をその κ でクランプした補間 5 次スプラインで作り直す (`wall_axismach.py:325-336`)。上流 Hermite もその κ に合わせる。つまり設計壁の r″(0)=1/R は物理壁には直接残らない。
- MOC 解像度で全長が変わる: `Lc_mode: explicit` で x_F は 1200 → 2400 で +0.123 r_t (9.4 mm)。

## 仮説 (当方)

H1. スロート直後の不整合は MOC の始点 (スロート特性線 `throat_characteristic(n=n_start)` と `cplus` 壁の最初の C⁺ 線) の離散化で決まり、n_axis では消えない。`n_start` を上げると縮む見込み (未測定)。
H2. 設計壁の始点の曲率拘束 r″(0)=1/R は MOC の始点データと 10〜20 % 食い違うので、全点で 0.005° を課すと、どの滑らかな曲線も満たせない。
H3. B (λ=1e-9) は x ≥ 0.08 では位置・角度とも十分に忠実で、滑らかさは補間の 2〜3 桁上。

## 問い

Q1. 事前登録の判定 (A 棄却、B 不合格) はこのまま記録する。そのうえで次の一手はどれか:
    (a) `n_start` を上げて始点の不整合が縮むかを測る (H1) → 縮めば同じゲートで B を再判定、
    (b) 始点の曲率拘束 r″(0)=1/R を外す (または MOC 始点データから決める) 版を加え、同じ全点ゲートで判定、
    (c) スロート直後の区間 (x < 数個目の点) を別ゲートにする (全点ゲートの緩和にあたるので、やるなら根拠と新しい閾値の事前登録が要る)。
    当方は (a) → (b) の順を考えている。(c) は結果を見てから合格条件を変えることになりかねないので避けたい。
Q2. 試験の不備 (δ_r 表の範囲 < n 2400 の x_e) の直し方: n 2400 の壁で C2 の CONTUR を回し直して δ 表を作る (正攻法、形状のみで CFD 不要) / 表の端を外挿する / x_e を揃える。
Q3. n_axis を変えると x_F (全長) が変わる件を、壁表現の A/B にどう扱うか (同じ n で比べるので A/B 自体は影響を受けない理解でよいか。生産の n を変えるのは別判断か)。
Q4. 点間の検査を A の暴走 (補間との差 6.8) を確実に拾う形で定義したい。「設計壁の補間との差 ≤ 閾値」と「r″ の局所極値の数」以外に入れるべきものはあるか。
