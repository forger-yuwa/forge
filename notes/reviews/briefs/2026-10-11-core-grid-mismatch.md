## 2. 私の読み (未確認)

- 停滞は「左辺が予測する小さな減少 (時間項と緩和で R₀ の 96 % が残る) を、左辺 Jacobian と実際の応答のずれ e がちょうど打ち消す」釣り合い。e は運動量 (特に ρv) で大きい。
- 懸念: 停滞した状態では実際の R がほとんど変わらないので、左辺が何かしら減少を予測すれば m ≈ 1 になるのは当然では、という自己循環。ただし A = J なら ρ_act = ρ_lhs のはずなので、e ≠ 0 自体は A ≠ J (または非線形) の証拠と見ている。
- e の出所の候補: (a) 右辺の 2 次の再構成・リミッタ (左辺は 1 次の FVS)、(b) SLAU の低マッハの散逸・圧力と速度の結合 (左辺は FVS で、音響の散逸が c の大きさ) — ユーザの「低マッハ補正」の見立てに対応、(c) 粘性の交差項・μt の Q 依存 (凍結しても μt は ρ・歪みで動く)、(d) 軸対称の源項。

## 3. 提案 (縛られなくてよい)

e を項別に切り分ける。M-r の Q₀ と Q₁ (= Q₀ + δ、`run_0632` の res_1) を固定し、**右辺の選択肢 X だけを変えた 1 外反復の run を Q₀ と Q₁ からそれぞれ回して R_X(Q₀)・R_X(Q₁) を取り** (各 10 秒)、J_X δ ≈ R_X(Q₁) − R_X(Q₀) を作る。A δ は M-r の書き出しの値をそのまま使う (同じ δ、同じ左辺)。e_X = J_X δ + A δ の島での大きさが、どの X で小さくなるかを見る。X の候補: 1 次の再構成 (リミッタ/MUSCL を切る)、SLAU の代わりに FVS 系や Roe の流束、粘性の交差項を切る、μt を凍結 (コード変更が要る)。
