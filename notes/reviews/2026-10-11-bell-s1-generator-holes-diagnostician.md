## 依頼内容

実装者 (#5) が、前回の諮問 ([S1 の導出](2026-10-11-bell-s1-rao-tp-derivation.md)) の構成手順 4「DE で |c| > 1 なら解なし」が成り立たないと指摘して止まった。c = Φ₂ cos μ/V は DE 上で cos(θ−μ) に恒等的に等しく、c = 1 は θ = μ で M が極値をとる点 (M をパラメータにした線の折り返し)。問いは 5 つ: (1) 規則の直し方と TIC 判定の数え方、(2) L_k 60 % 付近の別の枝、(3) T1a (Rao チャートの照合に要る R_t 0.382 で Hall の初期線が通らない)、(4) T6 (n 641 が Hall のガードで使えない)、(5) 実装上の選択。

## 結論 (原文要約)

**前回の構成手順 4「|c| > 1 は解なし」は誤りとして撤回し、DE を r (弧長) でたどって θ = μ を正則に通す修正を採用する。** TIC 判定は修正後の 5 本の結果で行う (旧規則の 4/5 根なしは数えない)。S1 の諮問 2 回はこれで消化したので、修正後に 2 本以上で根が括れなければ諮問なしで TIC へ切り替える。

1. **|c| 規則 (確度 高)**: θ = μ では dΦ₂ = 0 から dM = 0。dΦ₃ = 0 から dθ/dr = −tan θ/(2r)、C⁺ の適合式と dr/dσ = sin 2μ からは dθ/dr = −tan μ/(2r) で、θ = μ で一致する。したがって折り返しを越えても Φ₂・Φ₃ 一定の線は C⁺ の適合式を満たしたまま滑らかに続く。解なしの条件は θ ≤ 0・θ+μ ≥ 90°・M が表の外 (TP は M_max 16)・M_cap まで流量に達しない、の 4 つ。「dr ≤ 0」は C⁺ では θ+μ ≥ 90° と同値で、独立の規則ではない。**T2 と T1b は折り返しを跨ぐ D でも必ず回す** (積分の重み・`_cum`・`points` が変わるため)。`synth_bd` に θ_B > μ_B の組 (例: M_B 2.2・θ_B 32°) を足し、折り返し点で dθ/dr = −tan θ/(2r) を点検する。反証条件: 跨いだ先で T1b の残差が 1e-12 × 尺度を超える、または T2 が跨いだ D で 1e-5 に収束しない。
2. **60 % の別の枝 (確度 中、未確認)**: θ_B ≳ 37° で θ_E ≈ 40°・L 6.3〜7.2 の枝は、B の後で壁が外へ開いてから戻る形 (BE の平均壁角 ≈ 45° > θ_B)。受理条件に **θ_E ≤ θ_B** を足す。「θ_E ≤ 20°」は (D) の設計箱に揃える比較の箱としてだけ書き、物理の規則にしない。`solve_thetaB` の枝は添字 `br` でなく **η_D の連続性**で追う。60 % は θ_B 36〜46° を細かく走査して表を出し、主枝が届かなければ「(M) で作れない L_k」として 1 本と数える。
3. **T1a (確度 高)**: チャートの γ はどの資産にも無く、±1° の合否にはできない。T1a は**記録 (合否なし)** に格下げし、#6 (CFD ピン) の中で case/29 の R_t 0.382 の TOP 壁の Euler 1 本を凍結源に CPG γ {1.2, 1.3, 1.4} で回して、チャート値がその帯のどこにあるかを記録する。Hall のガードと R < 0.5 の警告は緩めない。代わりの必要条件として **T1a′: 同じ L_k・ε で前進 MOC ゲートを通った (D) 壁の MOC 推力 ≤ (M) の MOC 推力** を足す (破れたら停留点が最大でない証拠。偽枝も拾う)。
4. **T6 (確度 高)**: n {161, 241, 321} の 3 水準で単調性と Richardson 外挿を見る。加えて n 321 固定で dM を半分、m・q を倍にし、kernel 場の分解能と DE/Goursat の分解能を分ける (既定は dM = 1.28/n、m = q = n/2 で n に連動)。n 641 は CFD ピン (#6) の後に記録として足す。
5. **実装上の選択**: 問題なし (外側の根を c で取る、B の先の同じ曲線での延長、`cplus_closure`、Goursat の 8 % 延長、`Isentrope` の ν を `interior_vec` に渡す)。記録すべき点が 2 つ: 円弧 100 % で κ_W(B⁺) = +0.075 (C2 の根で消えることを T5 で確かめ、θ_max を L_k ごとに表に)、C2 の根が κ_B < 0 (kernel 内で変曲) に落ちたら明記する。
- **次の一手**: r パラメータの DE を実装し T1b/T2 を跨ぐ D で通す → 円弧 kernel・EXH・R_t 1・ε 50・n 161 で L_k 60〜100 % の 5 本 (根の有無・θ_B・θ_E・θ_max・推力 2 会計の差・候補の表)。**A**: 4 本以上で主枝の根が括れ T2 が跨ぐ D で 1e-5 → T3〜T5 (C2) へ。**B**: 2 本以上で根が括れない (枝の規則の後) → §8-4 の TIC へ、追加の諮問なし。
- **やらない**: Hall のガードを緩める、T1a のために今 R_t 0.382 の Euler run を立てる、θ_E ≤ 20° を物理の規則として書く、旧規則の 4/5 を TIC の根拠に数える、修正後の結果に「もう 1 回修正してから」の例外を足す。
- **異議**: 前回の自分 — 「|c| > 1 は解なし」と「折り返し (dr/dM ≤ 0) は解なし」は同根の誤り。呼び出し側 — 規則の誤りによる根なしは S1 の性質ではないので TIC の目安に「形式上該当」もしない (諮問回数の消化は受け入れる)。「θ_E ≈ 40° の枝が混ざるため未確認」のまま 60 % を根なしと数えない。
