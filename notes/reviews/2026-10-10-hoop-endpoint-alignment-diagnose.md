結論: **閾値を維持し、境界半割面の端点を内部面・面積と同じ M̃ にそろえる CPU・0 step の A/B を、互換性条件を訂正してから実施する。**

第 1 仮説: 全域 FAIL の主因は、境界半割面と内部区間が共有すべき中点を異なる演算で生成することによる閉性欠損である。確度: **高（機構）、説明率の実測は未確認**。  
  根拠: `gmshReader.hpp:1492`・`:1553` の中点と、`:1656` の半割ベクトルは有限精度で同じ端点を保証しない。高精度台本もこの違いを明示的にモデル化している（`dual_segment_closure_hp.py:237`・`:250`）。  
  反証条件: 同じ丸めた端点を共有する参照でも厳密な閉性欠損が残る、または端点整合後の binary64 計算で現行閾値を超える CV が残る場合。「端点整合だけで今回の FAIL を解消できる」という仮説を棄却する。

第 2・第 3 仮説: 現時点では追加しない。

判別 A/B: **変更するのは境界半割区間の端点定義だけ**。`case/45.isobutane_m6_d155/run_0252/nozzle.h5` の入力座標・内部区間・接続・境界所属・`A_planar` を固定し、両腕とも区間別 W を計算する。A は従来半割、B は共通の M̃ までの区間。CPU・0 step。  
→ **A が旧 FAIL を再現し、B が全域合格なら**端点不整合説を支持する。**B にも超過が残れば**端点だけで十分という仮説を棄却し、残差の内訳を再診断する。A が再現しなければ比較自体が無効。

合格条件は実施前に次を登録する。

- **全 CV・両成分で**欠損 ≤ `100·ε64·(A_planar + Σ|W成分|)`、超過数 **0**。j 2〜8 の最大 `E_x/E_y ≤ 1e-10` も維持する。旧 §4.4 の FAIL は書き換えない。
- B の半割ごとに、外向きに整向した `S = rot(M̃−N)` と、**同じ端点による** `r = (N_y+M̃_y)/2` を使う。ベクトルだけ替えて旧 `(3N_y+O_y)/4` を残さない。長さ・集約重心も整合させる（現行生成は `gmshReader.hpp:1659`・`:1672`）。
- 丸めた M̃・G̃ を固定した厳密参照で、`ΣS = 0`、`ΣW = (0, area_b)` を確認する。`area_b−A_planar` と binary64 の演算誤差は別に測る。**旧欠損から E1 を引くだけでは修正後の検証にならない。**
- §6.14 の FP64 ビット一致は**前変更の検証記録として保存**する。今回の変更許可は、既存データでは対象境界の `surfVect`・`surfArea`・`centCoords` に限定し、それ以外はビット一致を要求する。新設 `rSurfVect` は別枠とする。case/48・case/39 の不変条件と、float/FP64 変換器間の幾何一致は維持する。
- 差の上限は「`u·|M|` の桁」で済ませず、半割ごとの厳密な端点差から導く。集約面では寄与数と加算丸めを含め、W では **S の変化と r の変化の両方**を含める。

やらない方がよいこと: 閾値の緩和、`E1` 除去の推定値による合格宣言、新 HDF5 のキー 0 を旧 run の再現と呼ぶこと。今回の幾何検査から定常解の改善を主張すること。

呼び出し側の前提への異議: **「厳密参照 (a) が閉じる」ことは、現在の有限精度の構成まで整合している証拠ではない**。また、`rot(M̃−N)` の変更はソルバのキーで無効化できない共有幾何にも及ぶ。§4.6 の不活性経路のビット一致は、同じ HDF5 を読む新旧実装の比較として定義し直す必要がある。
