1. **Major — case/56の数値は再現できるが、「80万step完了・収束・深部上限」は成立していない。**

   [README:248](/home/sano/work/forge/case/56.gap_tp1187/README.md:248)は「+800k step回して決着」としています。しかし確認時の`case/56.gap_tp1187/run_0005_gap_t8_deep/`は残差が389,000 step、保存場は350,000 stepまでで、80万は設定値でした。

   300,000 stepの壁出力から、丸めた評価位置`z/W=1.39 / 2.83 / 4.22`で **0.0337929 / 0.00177113 / 0.0000245596**を再現しました。ただし判定は次のとおりです。

   | 対象 | 再判定 |
   | --- | --- |
   | 全保存量の残差 | `NOT CONVERGED (stalled/plateau)` |
   | 浅い3点、50k–350kの系列 | `STEADY` |
   | `z/W=8.44 / 14.11`の系列 | `DRIFTING` |

   準定常判定は`check_quasisteady.py`の`classify_series`を既定閾値で実行しました。`z/W=14.11`の300k値は**2.947×10⁻⁶**で、主張する`<2×10⁻⁶`を既に超えます。350k場の深さ5–10幅では最大`|T−300|=0.0043945 K`でした。壁温に近いことは確認できますが、これだけで丸め誤差と物理解を分離できず、「物理的な床」「追加反復では変わらない」とは言えません。

   **対案:** 実行中・評価step・残差未収束を明示し、浅部は「熱流束が準定常」と記載する。深部は絶対量の変動範囲として報告し、精度・格子・IC依存性による誤差評価なしに物理的上限を設定しない。

2. **Major — W70の薄板伝導は有力な候補だが、「1–2桁差の原因だった」という確定には至らない。**

   [skin_smear.py:46](/home/sano/work/forge/case/50.deep_cavity_wieting_m7/tools/skin_smear.py:46)の順方向拡散式と符号には、今回確認した範囲で明白な誤りはありません。しかし再実行すると、`run_0006_T1_wd0063_long`の0.8 sでは、`z/W=0.5`が**0.1806対実測0.4150**、`z/W=4`が**0.0239対0.0600**です。深さ4幅の時間感度は0.4–1.6 sで**0.0049–0.0468、約9.6倍**あり、「2倍程度」ではありません。

   独立系列`run_0008_T1_wd0211_long`の`z/W=0.5`では、生CFD **0.2232**が実測**0.2155**に近い一方、モデル適用後は0.8 sで**0.4001、約86%過大**です。この点だけ補正前を採用してモデルの裏付けとするのは不整合です。

   また、[原論文](/home/sano/work/forge/papers/gap_heating/Wieting_1970_NASA-TN-D-5908_deep_cavities_hypersonic.pdf)本文pp.6–7は、挿入時間0.8 s、中心線到達時の評価、20 Hz記録を説明しています。「最小二乗」は後壁の**空間分布**への曲線当てはめであり、[README:261](/home/sano/work/forge/case/50.deep_cavity_wieting_m7/README.md:261)の時間区間還元という説明は誤読です。一定熱源・後壁単独・両端断熱も、挿入中の熱履歴や床との接続を再現したものではありません。

   **対案:** 結論を「横方向伝導が差の一部を説明し得る」に戻す。計測時刻と熱履歴、薄板の接続条件を固定し、同じ観測モデルで全比較点・複数幅を評価する。

3. **Major — TP-1187のGate Aを支える「独立実測」の説明が原典と整合していない。**

   [README:50](/home/sano/work/forge/case/56.gap_tp1187/README.md:50)は`Re'`を独立実測、同105行は`δ*`を別の測定量としています。しかし[TP-1187](/home/sano/work/forge/papers/gap_heating/Avery_1978_NASA-TP-1187_gap_heating_laminar_turbulent.pdf)本文p.7では、自由流条件を燃焼器の温度・圧力とref.5/7の物性・較正から決めたと説明しています。`δ*`はref.6を引用し、その文献は境界層厚さの独立測定報告ではなく計算プログラムの報告です。

   したがって`q_dyn`と`Re'`の照合は入力の整合診断にはなりますが、独立測定による検証とは確認できません。`Pt,t/Pt,c=0.287`も、[conditions.py:59](/home/sano/work/forge/case/56.gap_tp1187/tools/conditions.py:59)で仮定した`M=7`と気体モデルから逆算した有効値です。「燃焼器から試験部までの全圧損失が原因」とする機構特定までは支えません。個別系列の`Re`差も最大29.6%あります。

   **対案:** 原典のref.5、6、7まで条件還元の出典を追い、測定値・計算値・補間値を台帳で区別する。0.287は暫定的な再構成値とし、損失原因の断定を外す。

4. **Major — Gate Bの「解析と近い」を「実験の分母を再現できた」に置き換えている。**

   `case/56.gap_tp1187/run_0002_fp_t8_long/`の保存場から**83.486 / 77.339 kW/m²**を再現し、両量の時系列は`STEADY`でした。一方、残差は`NOT CONVERGED`で、実験分母との差は依然**+18.8% / +21.9%**あります。[README:99](/home/sano/work/forge/case/56.gap_tp1187/README.md:99)の「分母はforgeで作れる」は、許容誤差なしには検証完了の根拠になりません。

   原論文の乱流分母は、先行研究ref.5の大型較正パネルデータを用いたものです。「理論が約30%高い」も同研究の理論との比較です。今回の参照温度法がその理論と同一であることを示さず、中央値1.335を再現成功とするのは弱い判断です。

   加えて[flatplate.py:115](/home/sano/work/forge/case/56.gap_tp1187/tools/flatplate.py:115)の合格範囲は層流`0.85–1.45`、乱流`0.95–1.75`で、表示する「1.10 / 1.30を±0.25」とも一致していません。

   **対案:** Gate Bは現状「解析との整合診断」に留める。実験分母との差を誤差予算に残し、原典の理論・較正と対応づけた系列別許容で判定する。一次比較は引き続き共通の文献分母を使う。

5. **Major — `skin_artifact.py`ではTP-1187の計測が伝導に汚染されていないとは判定できない。**

   [skin_artifact.py:13](/home/sano/work/forge/case/56.gap_tp1187/tools/skin_artifact.py:13)は、衝突加熱を含まないcase/55の2次元分布を熱源として借用しています。その小さい熱源から得た値を、衝突域の大きな実測値と比較しても、実際の衝突加熱に伴う伝導寄与の上限にはなりません。

   また、コードが出すのは伝導後の**見かけ熱流束全体**であり、伝導による増分`q_meas−q_conv`ではありません。[README:176](/home/sano/work/forge/case/56.gap_tp1187/README.md:176)の「滲みの寄与」という列名も不正確です。原論文本文p.6には伝導・放射損失を2%未満と見積もった記述がありますが、今回の代替熱源計算でそれを独立に確認したことにはなりません。

   **対案:** 「cleanと実証済み」を外す。3Dの実際の熱源分布に薄板モデルと原報の0.25 s平均化・差分処理を適用し、補正前後の差を評価する。

7. **Major — T2の探索降格は支持するが、「第一原理から再構成不可能」は証明されていない。**
