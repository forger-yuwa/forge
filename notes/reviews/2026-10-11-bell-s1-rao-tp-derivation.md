- **date**: 2026-10-11 (このセッションの諮問は Fable — ユーザ指示)

- **結論 (原文)**: 凍結 TP でも Rao の制御面条件は CPG と同じ式 (Φ₂ = V cos(θ−μ)/cos μ、Φ₃ = r ρ V² sin²θ tan μ が DE 上で一定) になり、比熱比は陽に現れない。固定 (L, ε) では縁条件 (Cain 4.3) は落ち、未知数は κ_B (外)・θ_B (中)・D の位置 s_D (内) の 3 つの入れ子の 1 次元根で閉じる。S1 は閉じる見込みが高い。

## 導出の要点 (Shyne & Keith 1990 pp.4–6、Cain 2010 p.9 を V を状態変数に取り直して再実行。sympy で検算と報告)

- 熱力学で使うのは dp = −ρV dV と dρ = −ρ(M²/V) dV だけ (任意の EOS で成立)。
- DE 上: (R0) φ = θ + μ (制御面は C⁺)、(R1) Φ₂ = V cos(θ−μ)/cos μ = const、(R2) Φ₃ = r ρ V² sin²θ tan μ = const。(R1)(R2) で引いた線は軸対称の C⁺ 適合式を任意の a(V) で満たす (残差 ≤ 3e-17、源項の符号を反転すると 5e-2〜1.6e-1)。
- 自由 r_E の縁条件は p_E − p_a = ½ρ_E V_E² tan μ_E sin 2θ_E (Cain 4.3) と同形。**固定 (L, ε) では端点項が消え縁条件は課さない**。固定 (L, ε) の停留輪郭は p_a に依らない。F(E) は感度 (∂F*/∂r_E|_L = 2π F(E)) として報告。
- D には追加条件が要らない (被積分関数が φ に依らない)。
- TP 固有の量 (k = d ln a/d ln V) が入るのは C2 接続の条件と Goursat 領域の出だしの微分だけ。

## 構成手順

- kernel: κ(s) = 1/R_t + (κ_B − 1/R_t)·S(s/s_B) (既定 S(u) = u)、θ_B で s_B が閉じた形。古典円弧は `kind="arc"`。B の先は直線延長。
- kernel 場は `forward_moc` (analytic・converge)。**BD は B から下流へ出る C⁻ を net 場の補間で追跡する** (Rao の作動域 θ_B > μ_B では net の前線は逆向きで BD に使えない)。BD は軸まで (ε 50 で x ≈ 10–15 r_t)。
- DE: M をパラメータに θ(M) = μ − σ_D arccos(Φ₂ cos μ / V)、r(M) = Φ₃/(ρV² sin²θ tan μ)、流量が ṁ_BD(s_D) に達する点を E。折り返し (dr/dM ≤ 0) と |c| > 1 は解なし。
  - **撤回 (2026-10-11、[生成器の穴の諮問](2026-10-11-bell-s1-generator-holes-diagnostician.md))**: DE 上で c = cos(θ−μ) ≤ 1 が恒等的に成り立ち、c = 1 (θ = μ) は M の極値で線の折り返しにすぎない。「|c| > 1 は解なし」と「折り返し (dr/dM ≤ 0) は解なし」は誤り。DE は r (弧長) をパラメータに引き、解なしは θ ≤ 0・θ+μ ≥ 90°・M が表の外・流量に達しない、の 4 条件とする。
- 入れ子の根: 内 s_D (r_E = √ε)、中 θ_B (z_E = L)、外 κ_B (C2)。全符号変化を候補にし、複数なら MOC 推力最大。
  - **撤回 (2026-10-11、[主枝と C2 の諮問](2026-10-11-bell-rao-mainbranch-c2-diagnostician.md))**: linear 族 (kernel の終端曲率 κ_B を振る族) には C2 の根が存在しない。κ_B の影響は B から D までの特性線 (長さ約 6.7 r_t) でほぼ失われ (Δκ_B 0.6 で kernel 側 0.006)、g̃ は −0.069〜−0.063 (L100)、−0.17〜−0.3 (L70) で符号を変えない。「外 κ_B: C2 で閉じる」は誤り。(M) は円弧 kernel・B で C1 とし、曲率の跳びと g̃ を記録する (ユーザ了承 2026-10-11)。
- **C2 の根の関数は g̃(κ_B) = (dθ/dσ)_{DE, D} − (dθ/dσ)_{kernel C⁺, D}** (弱不連続の輸送で B の曲率連続と等価)。plan の κ_Rao(B⁺) − κ_B は根の後の検算。
- 領域 BDE は Goursat 問題で `interior_vec` (符号付きなので C⁻ を逆向きに積分してよい)、壁流線は質量流量 (`moc_inverse.py` の `fill_levels`・`wall_streamline` が手本)。

## 受理の試験 (plan §6 V1 を置き換え)

T1a CPG・円弧 kernel・チャートの R_t (0.382) と γ で θ_n・θ_e が ±1°、T1b 平面縮約が `rao_planar.theta_lip` と 1e-8、T1c 自由 ε と固定 ε の等価、T1d 定比熱の擬似種で CPG と 1e-8、**T2 包絡線の恒等式** dF/ds_D = 2π[Φ₃ dL/ds_D + F(E) dr_E/ds_D] が相対 1e-5 (forward MOC なしに式レベルで検査)、T3 保存 (閉合 |W_m − E| と推力の 2 会計 ≤ 1e-4、n で減る — 「DE の流量 = スロート流量」は構成で恒等なので試験にならない)、T4 TP の停留性 (壁の摂動族で一次の係数 |c₁ϵ₀| ≤ 0.05|c₂ϵ₀²|、負対照の 5 % 以下、n で減る、c₂ の符号を記録)、T5 C2 (|g̃| ≤ 1e-8、κ_W(B⁺) − κ_B は検算)、T6 分解能 (n 161/321/641 で単調)。

## 成立の見込みと TIC への切り替えの目安

見込みは高い。危ないところ: BD の追跡、D が BD の軸側の端近く、折り返しと c > 1 (その L_k は (M) で作れないという結果)、g̃ の根の存在 (未確認)、T4 の雑音。切り替えの目安: ε 50 の 5 本の L_k のうち 2 本以上で根が括れない、T2 が n 倍で収束しない、T4 の c₁ が負対照の 5 % に落ちない ((ii)(iii) は 1 回だけ修正を試してから)。
