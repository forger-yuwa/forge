# codex 切り分け — 保存形 `iface_q_eff` のリップルが勾配形より大きい理由 (2026-09-21)

対象 plan: [`plans/active/boundary-conjugate-heat-transfer.md`](../../plans/active/boundary-conjugate-heat-transfer.md)
依頼種別: 自由形式の切り分け (plan/result 段のレビューではない)
プロンプト: `scratchpad/codex_qeff.txt` (指標定義 / 4 run の実測表 / 既に潰した候補 7 件 / 読んでよい 5 ファイルの行範囲)

## 依頼内容

`iface_q_eff = (Rraw - Fw)/A` の 2 節点交番が `iface_q_compact = k_eff(T_1-T_w)/d_1` より
一貫して 0.08–0.14 pt 大きい。支配要因の仮説を 1 つに絞り、切り分ける A/B を 1 つ設計してほしい。
候補として (a) 拘束反力 `Rraw` (b) 半 CV 面積の交番 (c) float32 桁落ち (d) 壁半割面の離散、を提示。

## 結論 (codex)

1. **仮説は (a) 一つに絞る** — `Rraw/A` の交番成分が追加リップルを支配している。
   規模の裏付け: `|Rraw|/(|Fw|+|Rraw|) × (Rraw の 2 節点)` = 0.094 / 0.174 / 0.167 / 0.184 % で、
   実測の追加分 0.079 / 0.124 / 0.106 / 0.140 pt を説明できる大きさ。
2. **こちらの言い方への訂正**: 「未収束の反復残差」と呼んではいけない。`Rraw` は
   **拘束反力の素材であり収束後にも非零であり得る** (`nodeWallDirichlet_d.cu:90–102`)。
3. **代数の指摘**: 壁寄与を `Fw`、残りを `Rother` とすると `Rraw = Fw + Rother`、
   すなわち `q_eff = Rother/A`。**壁半割面の熱流束だけを変えてもその直接寄与は差引きで消える**
   (`viscousFlux_d.cu:633–634`)。→ 候補 (d) は構造的に棄却。
4. **A/B**: 同一状態で診断式だけを `-Fw/A` に替える。事前判定 `|D_B| <= 0.020 pt`
   (追加差の 75 % 以上が消えること)。
5. **限界の明示**: この A/B で分かるのは寄与元まで。反復誤差か収束後も残る拘束反力かは区別できない。

## 当方の採否

**全面採用。A/B はコード変更なしで実行できた** — `ifaceFw` / `ifaceRraw` / 面積がすべて壁ダンプに
あるので、保存済みスナップショットから直接評価した (再計算も `conjugateWall.cpp` の変更も不要)。

| run | `q_compact` | `q_eff` | **`-Fw/A`** | `Rother` | 面積 `A` |
| --- | ---: | ---: | ---: | ---: | ---: |
| `run_0108_cf0_su2turb_long` (C3X 一様壁) | 0.0450 | 0.1238 | **0.0450** | 0.1161 | 0.0183 |
| `run_0107_prod_su2turb_long` (C3X 実測 Tw) | 0.2788 | 0.4025 | **0.2788** | 0.4015 | 0.1090 |
| `run_0019_tecut_long` (MkII 実測 Tw) | 0.2849 | 0.3907 | **0.2849** | 0.3978 | 0.0993 |
| `run_0008_smooth_uniTw` (MkII 一様壁) | 0.2319 | 0.3723 | **0.2319** | 0.3795 | 0.1036 |

**`D_B = 0.0000 pt`** (4 run とも小数 4 桁で `q_compact` と一致)。事前基準 0.020 pt を大きく下回るので
**仮説は支持**された。

さらに強い同定ができた: `-Fw/A` は **`iface_q_recon` と相対 1.2e−8 で同一**、
`iface_q_compact` とも 3.8e−4 で一致する。つまり

- `-Fw/A` ≡ 壁面自身の粘性流束 (= `q_recon`)
- `q_eff` = `q_recon` + (壁ノード双対 CV の不釣合い)/`A`

で、**追加リップルは全部が後者**。平均値でも `q_recon` 151623 対 `q_eff` 155351 W/m² (+2.5 %) で、
この 2.5 % が拘束反力そのもの。**壁ノードはエネルギー方程式を Dirichlet でピンしているので、
完全収束しても内部流束と壁流束は一致する必要がなく、差は反力として残る** (codex の 2. が正しい)。
「未収束だから」という当方の当初説明は**撤回**する。

## 残る問い (plan §5.1 に登録)

反復誤差と収束後の反力を分けるには、**残差が実際に落ちきるケース** (V1 の 1D スラブ) で同じ
分解をする必要がある。翼 (プラトー 2.4 桁) では区別できない。
