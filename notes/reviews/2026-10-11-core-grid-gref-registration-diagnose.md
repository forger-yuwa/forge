結論: **Gref をキー 1・既存と同じ FP64/B0 構成で20万 step 回す1本に絞り、固定長を予算上限、末尾の自己変化を判定資格、反復感度を最終採否の条件として分離して登録する。**

登録案は次のとおり。

- **構成と保存**：`run_0183` の `res_100000` から `interp_field.py` で移送し、この起点を step 0 とする。2500 step 間隔、少なくとも160k〜200kの17出力を残す。バイナリ・変換器・実効設定を既存キー 1 の腕と照合する。Gref の準備検査完了を投入条件とする。
- **停止**：水準到達では止めず200kで停止する。200k未満の非有限・異常終了は別扱い。固定長完走を「収束」「準定常」と呼ばない。
- **集計**：各出力で §4.5 の登録指標を計算し、180k〜200kの時間窓平均 μ_G を比較値にする。時間平均は台形積分を窓長で割る。G0 は `run_0485_kab_k1` のローカル40k〜60kを使う。
- **判定資格**：同じ量・閾値・窓指定で `check_quasisteady.py` を実行する。`DRIFTING`・`TRANSIENT-UNSETTLED` は判定不能。`OSCILLATING` は平均±振幅を診断として報告するが、今回の定常場の採用判定には通さない。`check_convergence.py` は数値設定が同一の区間で判定し、非有限・発散・入力不備を除外する。`NOT CONVERGED` は明記し、s の確認なしに採用しない。
- **過渡の扱い**：G0 の再開後40kを捨てたこと、Gref を200k回したことだけでは、再開・移送の影響が消えたとは認定しない。以下の窓検査は残留過渡の検出であり、初期値依存がないことの証明ではない。

量ごとに、相対量は共通分母 D = |μ_ref| で百分率化する。軸・η=0.1 の指標は既定どおり %pt を使う。異なる分母で算出された既存の p も、この単位へそろえる。

```text
μ_G = 180k〜200k の時間窓平均
d_G = |平均(160k〜180k) − μ_G|
U_G = max［160k〜200k の各出力について |q_G − μ_G|］

E_G = |μ_G − μ_ref|
B_G = E_G + U_G + U_ref + s_G + s_ref + p_G + p_ref
```

**新しい運用上の予算として**、全判定量で d_G ≤ τ/8、U_G ≤ τ/4 を要求する。単調な `STEADY` は漸近値も併記し、その最終窓平均からの差が τ/8 を超えれば保留する。これらは誤差上限や信頼区間ではない。

採用条件は判定資格を満たしたうえで B_G ≤ τ、既存の壁解像条件を満たすこと。τ は暫定値なので、通過しても「暫定許容差での候補」とする。s 未測定では、E_G + U_G + U_ref + p_G + p_ref が小さくても合格にしない。予算を超えても、直ちに「真の格子誤差が許容差外」とは断定しない。

G1・G1x に残る180k〜200kの9出力だけでは、この40kの判定資格を満たせない。保存済みの**同じ定義の全判定量の系列**が160kから残っていれば利用し、なければ暫定比較に限定する。

第 1 仮説: **水準未到達には、有限反復の揺れを拾う停止判定が寄与しており、未到達だけから窓平均の有用性は決められない。** 確度: 中  
  根拠: `m9_watch.py:154–157` は θ_r のドリフト条件を連続して要求する。計画上、G1・G1x の Q_w の出力差分 RMS は0.22〜0.35 %だが、これは窓平均のドリフト量ではない。一方、G0 は `CHECK FAILURES` と既定閾値の `ALL STEADY` が併存する（[plan:416](/home/sano/work/forge-coregrid/plans/active/tooling-nozzle-core-grid.md:416)）。  
  反証条件: 同一定義・同一閾値で窓を移しても平均が τ/8 を超えて動く、または `DRIFTING`・`TRANSIENT-UNSETTLED` となる場合、その量について「主に停止判定が揺れを拾っている」という説明を退ける。

第 2 仮説: 格子・反復条件・移送後の過渡による偏りが残る。**未確認**。Gref を同じ200kにそろえても除外できない。  
第 3 仮説: 追加しない。キー 1 が揺れの主因という主張は、現在の登録済み A/B では支持されていない。

判別 A/B: **追加の solver run を作らず、変更点を評価終了 step だけにした窓の A/B を行う。** Gref の1本を200kまで回し、A = 160k〜180k、B = 180k〜200kで全登録量の平均・観測幅・準定常 VERDICT を比較する。既存格子にも系列が残っている範囲で同じ検査を当てる。  
  → **両窓で資格を満たし、全量の平均差 ≤ τ/8**なら、その40k内で予算を超える平均ドリフトという仮説を退け、暫定比較へ進む。  
  → **いずれかが外れる**なら、「200k時点の9出力で採否を決められる」という方針を退け、判定不能とする。  
  これは窓長の検査であり、揺れの物理原因や初期値依存を分離する実験ではない。

やらない方がよいこと: **既存格子の再投入、全格子への point 継続、キー 0 への変更を今まとめて追加すること。** まず Gref の1本で情報を増やす。後に s を測る場合も、point 切替前後の差には自然な時間変化が混ざるため、基準窓が準定常でなければ反復方式の効果と帰属しない。`mesh.axisSegmentRWeight` は変更しない。

呼び出し側の前提への異議: **「変換器 A/B を退けた」ことと「揺れの原因が分かった」ことは別である。** 確認されたのは G0・キー 0・指定窓での Q_w の J 比1.05・0.92であり、キー 1 を含む一般的な無影響ではない（[plan:415](/home/sano/work/forge-coregrid/plans/active/tooling-nozzle-core-grid.md:415)）。ただし、旧変換器の G1 試験を再提案する根拠もない。また、E_G は Gref との差であって真値への誤差ではなく、固定長の費用は「判定可能な状態までの最小費用」とも異なる。
