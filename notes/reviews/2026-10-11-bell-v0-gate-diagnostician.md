- **結論 (原文)**: 今回の V0 は「中間」ではなく「判定不能 (標本が退化)」として記録し、(D) の族の x_m を設計変数から外して内部で解く (L, θ_e, θ_max の 3 変数) 最小変更を入れてから V0 を回し直す (CFD なし)。初期線は Hall n ≤ 321 のまま + 「前線 1 の反転 = 初期線アーチファクト」ガード。軸の θ_r 代用は今回の合否に効いていない。TOP の全点不受理は「向きが既知の物理と一致」までで、本ノズルでの定量対応は §4.5 の TOP 3 点 CFD で測る。

## 要旨

1. **V0 の解釈**: 成立 8/135、L_k 90・100 % で成立 0、7/8 が x_m/L 0.1 に集中 → 事前登録の前提 (標本の被覆) が破れている。「中間」でなく判定不能。退化の真因 (確度高) は x_m を L の比で持たせたこと: 成立帯は L によらず絶対値 1.1〜2.1 r_t (R_t に縛られる)。最小の変更 = x_m を設計変数から外し、0.5〜4.0 r_t の走査で成立区間を求め、その中で J = ∫(r''')² 最小の x_m を黄金分割で決める (設計変数は L・θ_e・θ_max の 3 個 = TOP と同じ次元)。回し直しの格子は θ_max {20,25,32.5,40} × θ_e {5,10,15} × L_k 5 本 = 60 点。事前登録に有効条件 (各 L_k に成立 ≥ 3・合計 ≥ 15、満たさなければ判定不能) を追加。L80・32.5°・5° の通過点は C⁻ 間隔比が n とともに減り続ける marginal。H2 (x_m/L 0.1 に集まる = TIC 的) は選択効果として却下。
2. **初期線**: Hall n ≤ 321 を採る。13 点の合否は Hall 161/321 と整合初期線 321/641/1281 で同一 → 1.1e-2 rad の不整合は合否に効いていない。整合初期線は混成で標準にしない。ガード: Hall (R_t ≤ 1) で n > 321 を拒否、前線 1 の反転は「判定不能 (初期線不整合)」(Hall n641 で `classification: B` が出たのは誤判定)。
3. **軸の θ_r の 1 次代用**: 合否に効いていない (不受理の開始は軸から遠い内部点、n 161→1281 で不変)。安全策として不受理の根拠に軸からの添字 j を記録し、j ≤ 2 の点だけなら「判定不能 (軸近傍)」。
4. **TOP の書き方**: 「L_k 5 本すべてで不受理、最初の C⁻ 交差は x 3.9〜5.0 r_t・r 0.86〜0.96、case/40 で forge・SU2 が確認した TOP の内部衝撃波と向きが一致」まで。本ノズルで衝撃波を CFD で確認したとは書かない、交差後の間隔比を強さとして書かない、真空 η の優劣に結びつけない。定量対応は §4.5 の TOP 3 点の CFD で、衝撃トレースの立ち上がり x とゲートの交差開始 x を併記 (±1.5 r_t なら整合、合否にしない)。
