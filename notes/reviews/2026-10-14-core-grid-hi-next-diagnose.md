結論: **既存 C の後半窓を対照として固定し、H だけを同条件で追加 4 万 step 継続する、新しい判定を事前登録する。**

ユーザに今言えるのは次の 3 文です。「入口半径を半分にした形では、今回の 6 万 step の後半に、縮流部の残差が元の形の約 1/36〜1/42 まで下がりました。ただし両腕とも `NOT CONVERGED` で、H の θ_r も `TRANSIENT-UNSETTLED` のため、旧判定は判定不能を維持します。形状・格子・境界層の履歴が同時に変わっているので、入口マッハ数の下限はまだ決められません。」

第 1 仮説: **H の形状・格子の変更による残差の改善は、境界層の再形成が落ち着いた後にも持続する。** 確度: 中  
　根拠: `case/45.isobutane_m6_d155/run_0915_hi_h_main/` の縮流部の ρ・ρE は、W2/W1 がそれぞれ 0.256・0.146。対照の `case/45.isobutane_m6_d155/run_0912_hi_c_main/` は 1.023・1.024。判定 JSON で確認した。ただし本段の `check_convergence` は **C/H とも `NOT CONVERGED`** と記録されている。[plan §4.99:1385](/home/sano/work/forge-coregrid/plans/active/tooling-nozzle-core-grid.md:1385)  
　反証条件: 物理量が準定常になった新しい二つの窓で、両主成分の H/C がともに 2/3 以上へ戻り、H の窓間比も 0.8 以上になる。これは「改善が持続する」を退ける条件であり、低マッハ仮説全体の反証ではない。

第 2 仮説: 現在の大きな改善は、移送後の境界層の再形成中に限られる。確度: 低〜中。θ_r の `TRANSIENT-UNSETTLED` が残るため未除外。  
第 3 仮説: 改善の主要因はマッハ数そのものより、格子の形・局所刻み・境界層履歴の変化である。確度: 中。既存の Grefc でも形状を変えずに残差が大幅に低下しており、競合説明として残る。今回の延長でも寄与の分離はできない。

判別 A/B: **固定対照 C 対 H の継続。新規計算は H の 1 本だけとし、変更するのは継続長のみ。**

1. **比較窓を先に固定する。** C は `run_0912_hi_c_main` の本段 (40k, 60k] の窓平均を固定する。H は `run_0915_hi_h_main/res_60000.h5` から同じ格子・バイナリ・実効設定で継続し、本段通算 (60k, 80k]、(80k, 100k] を評価する。出力間隔は従来の 1000 step。これは固定した停滞水準との比較であり、同じ計算時間での速度比較ではない。

2. **残差の判定を独立させる。** 主指標は従来どおり、縮流部 x/r_t ∈ [−8, −2] の体積重み付き q の ρ・ρE。新しい各窓と固定 C の比、および H の新しい窓間比 d を使う。
   - **結果 A:** 両窓・両成分で H/C ≤ 1/3、H の d ≤ 1.1。既存の他成分・領域の悪化防止条件 H/C ≤ 1.5 も満たす。
   - **結果 B:** 両窓・両成分で H/C ≥ 2/3、H の d ≥ 0.8。
   - その他は中間として記録する。残差が下がり続けることを資格違反にしない。

3. **物理量の準定常性を別に判定する。** θ_r[65,75]・Q_w の新しい 40k 区間について、`check_quasisteady` の VERDICT を取得する。`STEADY` でない場合も残差の A/B は記録し、「物理量は未定常」を併記する。両者が `STEADY` でも、確認できた範囲はこの二つの量に限る。単調な系列は漸近値を併記する。

4. **資格は測定の成立条件にする。** restart の保存量・型の一致、実効設定の一致、各窓 20 出力の充足、全出力の有限性・正値を確認する。全保存量の収束判定も別途残し、同じ設定の本段と継続区間を対応付ける。A 判定だけで「収束した」と呼ばない。

**A かつ物理量が準定常なら、観測した改善がその二量の過渡中だけだったという説明を退ける。B かつ準定常なら、第 1 仮説を退ける。物理量が未定常なら、その切り分けは未完了とする。** 4 万 step は今回提案する固定予算であり、旧判定を救済するための延長ではない。

やらない方がよいこと: 旧判定を事後的に A へ変更すること、入口 M ≈ 0.0565 を設計下限にすること、半径の多段試験を直ちに増やすこと。入口切断も今回は選ばない。新しい境界条件の再現性まで持ち込む前に、既存 H の未完了の確認を終える。
