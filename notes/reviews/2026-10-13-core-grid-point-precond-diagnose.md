第 1 仮説: **Gref の point では、右辺を変えずに Γ と Δτ′ を有効にすると、固定反復数での平均流残差低減が実用上改善する。** 確度: 中  
  根拠: `timeIntegration_d.cu:1795`–`:1800` は `=3` でも前処理カーネルを選び、右辺を保つ。`setDT_d.cu:417`–`:432` は刻みも拡大する。backstep の0/2/3比較では `=3` による残差低下が記録されている (`backstep-lowmach-checkerboard.md:109`)。ただし、Grefでの有効性は未確認。  
  反証条件: 下記の実装・比較資格を満たし、ρ・ρEの P/C が両窓とも0.8以上なら、**「この設定で2万 step以内に大きく改善する」**という仮説を退ける。前処理全般を除外する条件ではない。

第 2 仮説: 右辺の圧力差に対する質量流束結合の変更も必要で、`=3` だけでは改善しない。確度: 低。`=2` は今回試さないため、結果Bでも残る。

第 3 仮説: 刻み拡大に伴う乱流・化学種の更新の不整合が効果を覆う。確度: 低、Grefでは未確認。初期組成が一様という観測だけでは、更新後の組成保存までは保証しない (`procedures/solver-settings.md:156`–`:171`)。

判別 A/B: **変更点は `time.deltaT.lowMachPrecond` の0対3だけとする。**

- C、P3とも `run_0608` の `res_60000` から `restart_field.py` で作る。新しい同一バイナリ、同一メッシュ・BC・空間離散化を使う。旧 `run_0611` は背景資料に限る。
- 共通設定は point、`timeIntegration: 11`、`blockDPLUR: 1`、`lineImplicit: 0`、`lineDtDirectional: 0`、`implicitThermalJacobian: 0`、`cfl_pseudo: 1`、`implicitRelax: 0.7`、`nStepInner: 5`、`precondEps: 0.15`。各20,000 step、2500ごとに出力。失敗後の片腕だけの設定変更や自動延長はしない。
- 主指標は既存定義の q = √(ΣV(R/V)² / ΣV)。縮流部 x/r_t ∈ [−8, −2] のρ・ρEについて、W1 = 10k〜15k、W2 = 15k〜20kの窓平均比 P3/C を取る。初期値からの低下率と全出力の推移も併記する。

**比較の資格**

1. **実際の前処理動作を確認する。** 設定表示だけでは足りない。実行ファイルのハッシュと修正ソースの対応、前処理カーネルの選択経路、同一初期状態での `dt_local` の倍率を確認する。M = 0.02〜0.08、ε = 0.15なら、コード上は β = 0.0225、刻み倍率は約5.5〜6.4になる。これは測定値ではなく、`lowMachPrecond_d.cuh:21`・`:48` と `setDT_d.cu:269`–`:274` からの期待値である。
2. 初期保存量が同一で、更新前の右辺がGPUの加算順による差の範囲で一致すること。境界修正についても、非拘束成分の更新が退化した粘性対角で凍結していないことを確認する。
3. 全保存量・中間場の非有限と物理性を確認する。組成の一様性も追う。`speciesImplicitCoupling` と `speciesPrecondDt` の実効値を記録し、必要な共通設定の訂正は投入前に両腕へ反映する。
4. **Cの停滞は資格にしない。** pointの加速試験なので、対照が自然に下がっていても比較できる。B0用の「対照が停滞する」という資格は流用しない。

**事前の読み方**

- **A:** ρ・ρEとも両窓で P3/C ≤ 1/3。さらに、縮流部とその外の運動量・エネルギー・乱流残差に悪化を移していないことを確認する。実務上の事前閾値として、他の有意な残差成分の比 ≤ 1.5を採用する。ゼロ近傍の成分は比で判定せず、投入前に絶対許容値を定める。  
  → **同じ離散方程式に対する、pointでの固定予算内の残差低減を支持する。** ラインへの Γ・刻み処理の実装を検討する材料になる。
- **B:** 資格を満たし、ρ・ρEとも両窓で P3/C ≥ 0.8。  
  → **この設定・予算では大幅な改善なし。** 今回の結果を根拠としたライン実装への着手は見送る。
- 中間、成分間の不一致、悪化の移動、資格不足は判定不能。P3だけが発散した場合は「この構成が不安定」であり、安定時の加速能力は未判定とする。

両腕の `check_convergence.py` の VERDICT は、それぞれの point 区間について必ず添える。上のAは収束判定ではない。θ_r・Q_w等の定常値や解の一致は、`check_quasisteady.py` の資格なしには主張しない。

やらない方がよいこと: **P2の残差低下を Γ 単独の効果と呼ぶこと、P3の成功をB0停滞の原因特定と呼ぶこと。** `=3` でも Γ と Δτ′ が同時に変わる。またB0からはライン結合・方向別刻み・ITJも変わるため、この試験は Δx 依存の機構を分離しない。Aでも、ライン上での有効性は未検証である。

呼び出し側の前提への異議: 「pointは停滞しない」は強すぎる。記録は、途中で残差が低下した後、通算20万 stepで **`NOT CONVERGED (プラトー)`**、派生量については指定窓の自己変化資格を満たした、である。また「`=3`は解不変」は離散定常方程式を保つという意味であり、有限反復の場や反復安定性が不変という意味ではない。
