## 結論 (原文要約)

**T4 は登録の線では「判定不能」と記録し、格下げも振幅の引き上げもしない。#4 に書いてある「1 回修正」を評価器に使う — Hall 初期線をやめ、n 321 の Hall マーチの整合な C⁻ 前線 k₀ を N {321, 641, 1281} に再標本化した初期線で k1 を回し直す。S1 はその結果が出るまで閉じない。**

- **床の正体 (ブリーフの読みの訂正)**: c₁ の床は**壁圧の求積 (BE の壁節点の粗さ)** が支配。同じ run でスプラインと台形の推力から当てはめ直すと c₁ε₀ が sin_c1 k1・L100 で +0.643/+0.130/+0.325e-6 対 −0.581/−0.331/+0.014e-6 (n_eval 161/241/321)、2 会計の差 1.22e-6 → 0.46e-6 → 0.31e-6 で c₁ と同じ桁。c₂ε₀² は両会計で 1 % 一致。kernel・Hall 側は床ではない (c₁ は n_eval で決まり n_gen にほぼ依らない。n_eval = n_gen なら kernel 場は生成器と同一で Hall の不整合は ε 差分で相殺)。F0 − F_cs は ε に共通の偏りで c₁ に入らない — 床の指標にしない。c₁ の意味: ε* = |c₁/(2c₂)| = 離散評価器の最適点と壁のずれ = 6.5e-4 / 1.3e-4 / 3.3e-4 r_t。登録の線は ε* ≤ 1e-4 r_t と同値で評価器の分解能より厳しい。懸かる推力 c₁²/(4|c₂|) ≤ 5e-8 (F_1D 比 6e-9)。
- **問 1 (確度 高)**: (a) 格下げは結果を見てから合格条件を変えること、(c) 振幅を上げるのも同じ。効くのは BE の壁節点密度で、それは初期線の点数 N で決まる。Hall は n ≤ 321 のガード (`moc_forward.py:119-141`、級数の不整合 1.1e-2 rad) で増やせないので、**Hall でない整合な前線** (n 321 の Hall マーチの `net` の前線 k₀) を r 等間隔に N+1 点へ 3 次補間する (補間誤差 O(h⁴)、前線 1 の交差は起きない)。新規関数 1 本。
- **問 2 (確度 中)**: `ctrl_plus` は登録どおりで妥当 (L・ṁ・B・kernel を保ち ε だけ +1.6 %、σ の族で x = L で切って √50 を通るのは (M) 自身だけ — 注記して採用)。比の線は負対照の c₁ が床の 10 倍以上ある k1 でだけ意味があり、今は判定不能。`ctrl_minus` は別の (L′, ε′) の Rao 輪郭なので**正対照** (同じ床の第 2 標本) として記録する。拘束を厳密に保つ負対照が要るなら T1a′ の (D) 壁 (θ_max 28.21°・θ_e 5.26°) に同じ摂動族を当てる (任意)。
- **問 3 (確度 高)**: 物理の所見として書く — 軸近傍の判定不能とは別 (根拠の j は 16〜193 で `NEAR_AXIS_J` ≤ 2 ではない、位置は n_eval で動かない)。文言: 「(M) の Rao 輪郭は DE の下 (L100: x ≥ 15.8 r_t = 0.70 L・r ≤ 0.34、L70: x ≥ 9.0〜9.4 = 0.57〜0.60 L・r ≤ 2.9) で壁 BE 直後の圧縮 C⁻ が軸近くで集束し交差 — Rao の構成が制御しない領域の内部衝撃波。推力会計には影響しない。TOP (x 3.9〜5.0・r 0.9) より下流・軸寄り」。「(M) は内部衝撃波が無い」とは書かない。V2 の Euler run でこの位置に圧縮・衝撃が出るかを記録項目に足す。
- **問 4 (確度 高)**: T1c は「自由 ε の解を固定 ε = ε_free で解き直した差が根の許容 XTOL 1e-12 以内 (観測 ≤ 3.3e-13)」に言い換えてよい。
- **問 5**: S1 はまだ閉じない (T4 だけが判定不能、§4.4 の「MOC の細分化」が Hall ガードで 321 止まり)。V2 (評価器の整合、Euler 1 本) の準備は並行してよいが、その例外は親が plan に書いて決める。
- **次の一手 (A/B)**: 壁 = `rao_t6_parts/L100_n321_mq2_wall.npz` の BE、初期線 = n 321 Hall マーチの前線 k₀ を N ∈ {321, 641, 1281} に再標本化、族 sin_c1 k1、ε ±{1, 2, 4}e-3 (7 点)、スプラインと台形の両会計で c₁ε₀・c₂ε₀²。**A**: N 1281 で |c₁ε₀| ≤ 1e-7 かつ両会計の c₁ε₀ の差 ≤ 1e-7 かつ 641 → 1281 で |c₁ε₀| が減る → k2・k3・L70・`ctrl_plus` を N 1281 で回して T4 PASS、S1 を閉じる。**B**: 両会計の差 ≤ 1e-7 だが |c₁ε₀| が 641 と 1281 で 30 % 以内に一致し両方 > 1e-7 → 壁は ε* だけ非停留。T4 FAIL と書き、ε* と懸かる推力を記録し、S1 の扱いはユーザ判断 (推奨: 「停留輪郭 (ε* ≤ X r_t)」の札つきで閉じる)。追試は n_gen 161/241 の壁を N 1281 で。**C**: N 1281 でも 2 会計の差 > 1e-7 → 評価器はこの線を解像できない。T4 は恒久に判定不能、床の値を上限として記録し B と同じ扱い。
- **やらない**: T4 を記録に格下げして閉じる、ε₀ を上げて通す、CFD ピン初期線を床対策に使う、#4 の TIC 切り替えを発動する、生成器を n 641 で回す、`sin` 族の符号反転を壁の非停留の証拠にする (B の角に対する評価器の 1 次誤差)、ゲートの不受理を軸のアーチファクトと書く、「(M) は内部衝撃波が無い」と書く。
- **異議**: 呼び出し側 — 床を Hall の不整合と F0 − F_cs で説明したのは数値と合わない。選択肢 (a) を「S1 を閉じる道」として並べたこと自体を受け入れない (条件の後出し)。前回の自分 — T4 の線を登録しながら評価器の分解能の事前検査を線に付けなかった。線は変えず、分解能の検査を今回 A/B として付ける。
