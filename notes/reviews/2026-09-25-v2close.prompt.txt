## 問い (主) — V2 の case/48 段を「判定不能」のまま閉じてよいか

本計画は §6 V2 に **2026-09-24 に、実施前に**次を登録した (case/48 段):
- (i) 平均: |平均Tw_forge − 平均Tw_SU2| / (平均Tw_SU2 − 300 K) ≤ 2 %
- (ii) 局所: 各点で |ΔTw| / (Tw_SU2 − 300 K) ≤ 2 % を全点で
- (iii) 壁全体の ∫q ds の相対差 ≤ 3 %
- 比較の組は forge `fem2d` (帯メッシュ=面内伝導あり) ↔ SU2 の 2D 固体ゾーン (同じ方程式)。

実測 (2026-09-24):
- **forge 側は完了**: run_0035_v2_fem2d_nl8 / run_0036_v2_fem2d_nl16 / run_0037_v2_local1d
  (各 40000 step、3 本とも界面収束ゲート G-if PASS)。固体格子収束 (厚さ 8→16 層) 平均差 −0.0009 K・
  局所最大 0.45 K。シェル近似誤差 (local1d ↔ fem2d) 平均差 −0.0482 K・局所最大 16.22 K (前縁集中)。
- **SU2 側が収束しない**: 界面は効いている (流体側 664.314 K と固体側 664.44 K が 0.13 K 一致) が、
  固体の Tw から逆算した q = 79 kW/m² に対し流体の HF = 49.8 kW/m² で **60 % 食い違う**。
  bgs[w] +6.4。HF の 1 外反復あたりの変化が −8 W (流体 40000 反復時点)。
  設定を 4 通り変えた (自由流開始 / 固定壁解から再開 + CFL 適応の積 ≥1 / 再開ファイル名をゾーン番号付きに /
  壁 604 K で暖機してから連成、rms[Rho] −12 まで 3677 反復) が **いずれも収束せず**。
- **別段で通っている**: 同じ SU2 multizone CHT を **1D スラブ**で回した段 (#81) は、
  SU2 の界面温度 316.261809 K = 解析解 316.2618 と +0.00001 K。forge との差は
  ソルバ内 local1d −0.02471 K / 外部ループ shell2d +0.00409 K で、登録許容 0.0325 K 内で PASS。

選択肢は 2 つ。**どちらか一方を推奨してほしい**。

- (A) **判定不能のまま閉じる**。理由として本計画が挙げているのは (a) 連成の定式化の検証は 1D スラブ段で
  SU2 と 1e-7 K 一致済み、(b) case/48 段が足すのは乱流+面内伝導のコード間照合で forge 側が求めていた
  2 つの分離 (固体格子収束・シェル近似誤差) は取れている、(c) 残るのは SU2 の乱流 CHT を収束させる作業で
  本計画の外に寄っている。**「判定不能」は合格ではない**ので、閉じるなら「事前登録した許容に対して
  判定を出していない」と明記する。
- (B) **判定を出してから閉じる**。SU2 を収束させる作業を続ける。

判断にあたって特に見てほしい点:
1. (a) の論法 — 「1D スラブで一致したから、乱流 + 面内伝導のコード間照合は省いてよい」は成立するか。
   1D スラブが検証していないのは具体的に何か。それを省いたときに見逃しうる不具合の型を挙げてほしい。
2. 事前登録した許容に対して判定を出さずに閉じることの手続き上の問題。本リポジトリの規範
   (AGENTS.md「plan §6 に事前に書いた参照値・許容差との比較が FAIL または判定不能」はエスカレーション条件)
   に照らしてどう扱うのが正しいか。
3. (B) を選ぶ場合、SU2 側の未収束の原因として最も可能性が高いものを 1 つ挙げてほしい
   (固体の熱容量が実質ゼロで BGS が振動する / 緩和係数 / 界面の補間 / 乱流壁関数と等温壁の組合せ 等)。
