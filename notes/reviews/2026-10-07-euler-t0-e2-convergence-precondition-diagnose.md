第 1 仮説: **G1 の半径方向配点が、固定した計算手順で観測される全温異常に支配的に寄与する。** 確度: **中**
  
  根拠: `plans/active/verification-case45-euler-total-enthalpy.md:75–76` と前回諮問の記録では、スロートの壁側間隔は約4.4〜4.6×10⁻⁶ r_w、`run_0114` の |T₀−1600|>100 K の252節点が同区間に集中する。ただし、これは**既存記録の引用であり、今回 run を再測定していない**。配点との因果関係は未確認。
  
  反証条件: 下記の診断前提を満たし、両側に異常が残り、全領域の主指標が両評価窓の全保存時点で1 K以内の差なら、**今回の配点変更がこの観測区間の異常を支配的に変える**という仮説を退ける。収束解に対する配点依存までは否定しない。

第 2・第 3 仮説: **第2：配点変更が停滞・過渡の進行速度を変える。確度：中、機構は未確認。** 前回諮問の `NOT CONVERGED` はこの候補を残す。plateau と主指標の整定だけでは除外できない。第3は追加しない。

判別 A/B: **変更要因は半径方向配点プロファイル一つ。**

- A：`case/45.isobutane_m6_d155/run_0161_euler_t0cluster_g1/`。両キーは既登録のG1値。
- B：`case/45.isobutane_m6_d155/run_0162_euler_t0cluster_u5em3/`。`wall_first_frac` と `wall_first_frac_throat` をともに0.005。
- 長さは既登録の **soft 3000＋本段18000 step**。他条件を固定する。
- 本段の全残差列を確認し、両側が `PASS` または**不合格理由が停滞だけ**。主指標は6000〜18000の13枚と末尾5枚について、`--tail 1` の `STEADY` **かつ時間変動幅 ≤0.1 K**を要求する。
- → **Aのスロートで>100 K、Bが全領域±1 K以内を評価窓全体で維持**なら、「総点数だけで異常が決まる」説を退け、配点介入への依存を支持する。
- → **両側に異常が残り、全主指標の差が評価窓全体で≤1 K**なら、第1仮説の支配性を今回の観測区間について退ける。
- → 前提未達・中間的改善は判別不能。延長や窓変更で救済しない。

やらない方がよいこと: **plateau を `PASS` と読み替えること、差が小さいことを「収束解が一致」と表現すること、改善を float32 幾何誤差の証明にすること。**

呼び出し側の前提への異議: **「正常な全温の run も未収束」は、収束基準を緩める根拠にはならない。** また「E2もplateauになる」は予測であり観測ではない。今回許容する理由は、E2の目的を限定した原因切り分けに置くためである。MOCの既存前提も妥当性の証明にはならない。
