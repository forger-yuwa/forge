結論: **Q₀・Q₁・δを固定し、左辺の粘性スカラー対角の作用 Dνδ だけを予測から差し引く A/B を行う。** 右辺の粘性を切る案ではなく、左辺の寄与を直接測る診断を推奨する。

第 1 仮説: **近傍との差を持たず全5成分に加わる粘性スカラー対角が、1次化後にも残る応答のずれの主要部分を担う。** 確度: 中  
　根拠: [timeIntegration_d.cu:976](/home/sano/work/forge-coregrid/solver_density_cuda/cuda_forge/timeIntegration_d.cu:976) で面ごとの `viscous_diag` を作り、[同:1036](/home/sano/work/forge-coregrid/solver_density_cuda/cuda_forge/timeIntegration_d.cu:1036) で ITJ 5 の全5行に加えている。ITJ 5→0 でも、このスカラー対角は残る（[同:1052](/home/sano/work/forge-coregrid/solver_density_cuda/cuda_forge/timeIntegration_d.cu:1052)）。したがって M-a はこの仮説を除外していない。

　M-o の `mis_judge.json` では、島の1次化後のずれ ‖e₁‖/‖R₀‖ は ρ **0.0530**、ρE **0.1183**、R₀方向への射影は **+0.0350、+0.0951**。この符号と大きさを Dνδ が説明するかは、まだ測られていない。

　反証条件: 下記の固定δの診断で、Dνδ を差し引いても、ρ・ρE両方のずれのノルムと射影を半減できなければ、「この対角が両成分の主要部分を説明する」という仮説を退ける。

第 2 仮説: SLAU の残差応答と閉形式 FVS の左辺の違いが主要因。確度: 低。流束の違いは確認できるが、このδに対する寄与は未測定。

第 3 仮説: 粘性・熱伝導の近傍結合、係数のQ依存、有限振幅の非線形応答が主要因。確度: 低。SST保存量の凍結は μt の固定ではなく、F1では μt が出力間で1.8〜4.2%動いている（[plan:780](/home/sano/work/forge-coregrid/plans/active/tooling-nozzle-core-grid.md:780)）。

判別 A/B: **変更点は、固定δへの左辺の予測に粘性スカラー対角を含めるかだけ。**

- 起点は `case/45.isobutane_m6_d155/run_0634_cg_mis_base/` の Q₀・Q₁・δ。右辺は既存の `run_0637_cg_mis_o1q0/`・`run_0638_cg_mis_o1q1/` の1次評価を使う。
- 対照は e₁ = ΔR₁ + Aδ。変更側は **e₁⁻ = ΔR₁ + (A − Dν)δ = e₁ − Dνδ**。時間項、緩和、熱の交差微分、右辺、δは固定し、補正を解き直さない。
- Dν は、実装が実際に加えたスカラー対角の**全対象面の和**。既存の `dbgLineVisc` はライン面だけなので不足する（[timeIntegration_d.cu:977](/home/sano/work/forge-coregrid/solver_density_cuda/cuda_forge/timeIntegration_d.cu:977)）。同じ計測内でライン面／ライン外面の内訳も保存する。係数には実装どおり `cfg.visc` と μt を使い、右辺の局所層流粘性で代用しない。
- 比較自体は**追加の時間積分0 step**。必要な係数が未保存なら、診断出力だけを追加し、baseと同条件の2外反復を1回再現する。M-oの再現資格を維持し、診断追加で元の応答が変わっていないことを確認する。
- 判定領域・重み・拘束除外は M-o と同じ。島のρ・ρEそれぞれで、  
  **‖e₁⁻‖/‖e₁‖ ≤ 0.5**、かつ  
  **|⟨e₁⁻,R₀⟩|/|⟨e₁,R₀⟩| ≤ 0.5**  
  を事前条件とする。高さ別の値と符号も併記する。

→ **結果A**なら、スカラー対角がこの補正への予測誤差の主要部分を説明する。「その寄与は小さい」を退ける。  
→ **結果B**として、資格を満たしても上の共同条件を明確に満たさなければ、第1仮説を退ける。粘性全般の無関係や第2仮説の確定とはしない。誤差範囲で閾値をまたぐ場合は判定不能とする。

やらない方がよいこと: この診断前にスカラー対角を実際の更新から削除する、`SLAU→ROE` と1次化を同時に行う、低マッハ補正や Rhie–Chow 型補間を実装すること。**予測誤差への寄与を特定することと、その項を外した反復が安定・高速になることは別**である。

呼び出し側の前提への異議:

- **[Major]「残り8割」は加算可能な内訳ではない。** `C_rec = e₂ − e₁` はベクトル差であり、ノルムは足し算できない。実際、1次化後に残るノルムは元の **90%・95%**、射影は **83%・94%**。根拠は [cg_mis_an.py:59](/home/sano/work/forge-coregrid/case/45.isobutane_m6_d155/cg_mis_an.py:59) と `mis_judge.json`。対案は、「残り8割」ではなく **e₁そのもの**を次の診断対象にすること。
- **[Major] 射影 −0.001 は、残差ノルムが0.1%減る意味ではない。** p = ⟨ΔR,R₀⟩/‖R₀‖²、r = ‖ΔR‖/‖R₀‖ とすると、ノルム比は **√(1 + 2p + r²)**。提示された60〜69帯のρでは約0.04%減である。[plan:876](/home/sano/work/forge-coregrid/plans/active/tooling-nozzle-core-grid.md:876) の表現を訂正し、射影と実際のノルム比を分けて報告すべき。
- **[Major] 右辺の粘性OFFでは、左辺のスカラー対角の寄与を直接分離できない。** 固定状態で右辺の粘性応答を消しても、問題にしている Dνδ は左辺に残る。対案は上記の作用分解である。
- **[Major] dx依存の仕組みは未確定。** コードの係数から、局所直交格子では流れ方向面の Dν/V が概ね ν_eff/Δx² に比例する、という候補は立つ。一方、どの方向の項が今回のずれを担うか、その項が実際の反復停滞を生むかは未測定。現時点で言えるのは「測定した補正について、十分解いた近似左辺の予測と有限の残差応答が大きく異なる」までである。

不足情報: **全対象面の Dνδ と、その方向別内訳**。これが今回の次の計測対象。M-oの正式判定は「判定不能（中間）」のまま維持する。ファイル変更・forge実行は行っていない。**plan未反映**であり、呼び出し側が `plans/active/tooling-nozzle-core-grid.md` §4.49に続く事前登録へ反映する提案である。
