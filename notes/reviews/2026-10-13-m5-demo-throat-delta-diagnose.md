第 1 仮説: **異なる `r_t` の座標を直接照合した誤差が帯選択・平滑化で増幅され、run_0009 のスロート付近の異常を生んだ。** 確度: **中**
  
  根拠: `design/forge_design/metrics/deltastar.py:90,424–443`。共通尺度への換算がないことは確認済み。ただし、尺度差 0.017 %が提示された δ_E = 0.24〜0.70 r_t まで増幅されたことは未確認。`delta_E` は生の抽出値ではなく、`feedback/deltastar_loop.py:87–109` の平滑化後の値である。
  
  反証条件: 共通尺度に直しても、0 ≤ x/r_t ≤ 3 の δ_E 異常がほぼ残ること。これなら「寸法差が巨大な異常の主因」という H1 を棄却する。

第 2・第 3 仮説:
  
- **第 2〔Major、中〕**: 冷却壁の負または符号を跨ぐ δ に対する `edge` の正値限定が、帯位置と平滑化を壊している。正値限定はコードで確認済み（`metrics/deltastar.py:327`）。該当 run の梯子が実際に負だったかは未確認。
- **第 3〔Major、中〕**: 出口 M・流量・スロート境界層に未整定成分が残る。`case/70.m5_air_wt_demo/run_0010_ns_c2b_final/` の提示判定は `check_convergence: PASS`、`machmax,pmax: ALL STEADY` だが、**出口コア M・流量・δ_r の定常性判定ではない**。局所熱量も未整定と記録されている。

判別 A/B: **変更点は Euler 座標の尺度換算だけ。forge は 0 step、同じ固定場を二通りに後処理する。**

- 対象: `case/70.m5_air_wt_demo/run_0009_ns_c2_final/` と `case/70.m5_air_wt_demo/run_0003_euler_36k/`。読み込む snapshot を固定する。
- **腕 A**: 現行処理。
- **腕 B**: 読み込み後の Euler の `x,r` をともに `S_E/S_NS` 倍し、NS の尺度へ揃える。`q=ρUx`、NS 配列、帯・平滑化設定は変えない。
- 全断面で `delta_r_raw`、`delta_E`、帯位置、帯感度、`hard_ok`、平滑化の絶対誤差を記録する。主判定量を **D = max₀≤x/r_t≤₃ |δ_E|** とする。
- **B で D が A の 10 %以下かつ 0.01 r_t 以下** → 尺度混在が大異常の主因という H1 を支持。ただし抽出の物理的妥当性までは合格にしない。
- **B でも D が A の 90 %以上** → H1 の「主因」を棄却し、符号付き帯選択を優先する。
- 中間なら判別未了。結果を見て閾値を変更しない。

これは同じ場に対する後処理の感度試験なので、未収束の二つの流れを「一致」と評価する試験ではない。

やらない方がよいこと:

- **流量比 1.0077 を、そのまま「スロートの負の δ* が原因」と読むこと。** 提示値から計算すると、run_0009 の尺度補正後の比は `1.009005 → 1.008662`、流量等価補正は `−0.003420 → −0.003250 r_t`。尺度差だけでは流量超過は消えないが、残差分が局所境界層に由来する証明にもならない。
- 壊れた抽出を `solve_rt_throat --prev` に渡すこと。ここは δ_E **全分布**で寸法と壁を作るため（`feedback/deltastar_loop.py:295–300`）、異常を形状全体に移す。
- #18 の許容で #15 の実際の出口切断まで吸収すること。提示された終端差は約 **20 nm**だが、小さいことだけでは丸めと断定できない。元座標の float32 丸め幅・同じ出口点という対応を確認し、再構築後の位置・導関数・既存の壁品質検査を通す。

呼び出し側の前提への異議:

**〔Major〕「C2 では直らない」「流量超過が出口 M 低下の原因」は、現時点では解釈である。** run_0006・0009 は `NOT CONVERGED`、run_0010 は対象量の定常性が未提示で、C2 更新と格子変更も重なっている。対案は、抽出の問題を解いた後、対象量の時系列を確認し、検証済み δ_r 全分布 → `solve_rt_throat` → 同じ補正表による物理壁、という一つの経路で進めること。

最終合格は **4.9975 ≤ 出口コア M ≤ 5.0025**。同じ数値設定区間の `check_convergence` と、出口コア M・流量・使用する δ_r の `check_quasisteady` の判定を揃える。`machmax,pmax` の判定で代用しない。
