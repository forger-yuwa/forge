### 4.1 (A) 気相組成の輸送物性

- **2026-09-27 改訂 (輸送物性の作り直し後)**: μ・λ は種ごとの輸送物性 (`viscMethod: 2` + `physProp.transport`; plan `thermophysics-solver-owned-species-db` §4.3c、`feature/species-transport`) になり、セル・壁とも `transport_mix_Y` / 表引き `transport_mix_Y_tab` (`cuda_forge/transportMix_d.cuh`・`transportTables_d.cuh`) が輸送種の Y から組成を作る。旧 Wilke 経路は撤去済み。
- 凝縮 carrier (TP) のとき、この入口に渡す組成を気相組成にする: `Y_s^gas = Y_s/(1−g)` (s ≠ 凝縮種), `Y_w^gas = (Y_w − g)/(1−g)` (液を除き再正規化)。その後は通常どおり輸送種 X → lump 展開 → CEA 形混合。
  変更は組成を作る関数 (表引き `gas_transport_cell_rY`・直接評価 `gas_transport_cell_Y`・壁・probe・拡散係数の組成) を 1 つの気相組成関数に通すことに限り、`transport_mix_Y` の式は変えない (§5.1 #3)。
- 化学種拡散係数 (混合平均、`thermo_Dmix_species_f`) も同じ気相組成で評価する。CPG carrier (空気) と `viscMethod 0/1` は組成を見ないので変更なし。

### 4.2 (B) 拡散作用素 — 気相内の分子拡散 + 全相共通の乱流混合 (2026-09-27 改訂, codex plan 段 C1/M2/M4/M5 反映)

記号: 気相密度 `ρ_g = ρ(1−g)`、気相内の質量分率 `z_k = Y_k/(1−g)` (k ≠ 水)、`z_v = (Y_w − g)/(1−g)`。輸送変数は現行のまま
(`roY_k`, `roY_w` = 総水分, `rog` と `Q0/Q1/Q2`)。

- **分子拡散 (気相のみ)**: `j_k⁰ = −ρ_g D_k ∇z_k` (k は水蒸気を含む全気相種、D_k は §4.1 の気相組成で評価した混合平均)、
  補正は**気相内で** `j_k = j_k⁰ − z_k Σ_j j_j⁰` (`Σ_気相 j_k = 0`)。駆動変数は混合物基準の Y ではなく気相基準の z
  (旧案の `−ρD_k∇Y_k` は D_k が種ごとに違うと、気相一様・g 非一様で偽の分離流束 `ρ z_k (D_k − Σ z_j D_j)∇g` を作る: codex C1)。
  液の分子拡散は 0。**有限 `Sc_l` は本 plan では実装しない** (§5.1 #8 に分離。g だけ拡散すると Q3 が動き実現可能性 `Q2² ≤ Q1Q3` を壊す、
  小さい Sc_l は強い拡散である: codex M5)。
- **乱流混合 (全相共通)**: 全輸送量 (気相種の Y_k、総水分 Y_w、液 g、Q0/Q1/Q2 を質量当たりにしたもの) に同じ `−(μt/Sc_t)∇(·)`。Σ∇Y = 0 なので補正不要。
- **組み立て**: 総水分の流束 `J_w = j_v + J_t(Y_w)`、液 `J_l = J_t(g)`、蒸気 `J_v^tot = J_w − J_l = j_v + J_t(Y_w − g)`。
  エネルギー流束 `Σ_{k≠水} h_k J_k + h_v J_w − L(T) J_l` (h_l = h_v − L; 既存 EOS `e = e_gas + g(R_wT − L)` と同じ基準。
  L 項と EOS の −L r_g が相殺して温度に効くのは −R_wT r_g、§3)。**液と Q の乱流流束を入れずにエネルギーだけ直すことは禁止**。
- **面流束を 1 回だけ作り共有する** (codex M4): 新カーネル `twoPhaseDiffusion` が面ごとに上の流束を作り、化学種残差・`rog`/Q 残差・エネルギー残差・
  dual-time FCT の低次作用素と面流束履歴 (`passiveFct_d.cuh` の `qDiff` を液・Q・総水分へ拡張) に同じ値を足す。
  呼び出し位置は**全残差の初期化 (`passiveAdvection_d_wrapper` の液残差ゼロ初期化) の後、境界ピン・周期集約の前**。凝縮 TP では既存の化学種拡散
  (`speciesTransport_d.cu:259` 付近) の水・気相種の分子拡散をこれで置き換え、二重に足さない。
- **更新の契約 (codex M2 + diagnose 2026-09-27)**: 保存を求めるのは**離散方程式**である。定常 (局所 dt の擬似時間) では収束した固定点が、
  dual-time では各物理時間ステップで解き切った状態が、**全輸送量で共通の輸送行列 (移流 + 本節の拡散の非対角を含む) を持つ保存形の後退 Euler / BDF 方程式**を満たすこと。
  点対角 (蒸気: 分子 + 乱流、液・Q: 乱流) はその反復の前処理にすぎず、1 擬似反復ごとの保存は求めない (局所 dt の擬似時間は forge の全保存量で 1 反復ごとには保存しない)。
  ただし前処理を種ごとに変えると中間状態の比 (液/総水分) がずれるので、蒸気 `ρv = ρY_w − ρg` と液 `ρg` を変数に増分を作り `Δ(ρY_w) = Δρv + Δρg` で戻す。
  拡散の離散形は現行と同じ二点差分 (`speciesTransport_d.cu:263`; 非直交補正は現行も無い)。
  化学種の再正規化で `ρY_w` に掛けた係数を `ρg` と Q にも掛ける (現行は液更新の前に水だけ再正規化される, `main.cpp:2094` 付近)。
  実現可能性クランプは保険として残し §4.3 で監視する。**再正規化・クランプで吸収した後に保存を判定しない** (§6)。
- **対象外 (明示)**: CPG carrier (空気凝縮, `speciesEnabled` を通らない単成分) は本 plan では現行のまま (液は拡散しない)。起動ログに
  「CPG carrier: 二相拡散は未対応」と出す。cell 離散化は経路のコード確認のみで実行検証しない (「cell 未検証」と記録)。

## 2. 実装設計 (案; 未確定箇所は §4)

### 2.1 新カーネル `twophase_diffusion_d` (面ループ、float32)

- 入力: `roY[s]`, `rog`, `roQ2/1/0`, `ro`, `T`, `P`, `vis_lam`, `vis_turb`, 幾何 (現行 `species_diffusion_d` と同じ `fx/sx/sy/sz/ss/cc*`)、`GasPhaseLiquid liq`。
- 面ごと: セルの $\rho_g=\rho-\rho g$、$\rho v=\rho Y_w-\rho g$、$z$ ($\Sigma z$ で正規化) → 面の $\rho_{g,f}$・$z_f$ → 気相組成の混合平均 $D_k$ (`species_transport_X_f` の気相組成と同じ) →
  $j_k^0$、$\Sigma j^0$、補正 (面の $z$ は §4-1) → 乱流係数 $c_t=a_f\mu_{t,f}/Sc_t$ で $J_t$ → $J_v=j_v+J_t(v)$、$J_l=J_t(g)$、$J_w=\mathrm{fl}(J_v+J_l)$、$J_Q$ →
  残差 `res_roY[k]`, `res_roY[iw]` ($J_w$), `res_rog`, `res_roQn`, `res_roe` ($\sum h_kJ_k+h_vJ_w-L(T_f)J_l$) へ atomicAdd。
- 対角: 非水 `transport_diag_Y[k]` に $a\rho_{g,f}D_k/\rho_{g,i}+c_t/\rho_i$ (+補正の流出分)、水 `transport_diag_Y[iw]` は**蒸気の対角** $a\rho_{g,f}D_v/\rho_{g,i}+c_t/\rho_i$、液・Q の対角に $c_t/\rho_i$。
- 面係数の共有: dual-time FCT が同じ値を使えるよう、$c_t$ (と必要なら分子の面係数) を面バッファに書く (FCT 側で再計算しない; plan §4.2「面流束を 1 回だけ作り共有」)。
- `species_diffusion_d` 側: TP carrier 凝縮のときは起動しない (水・気相種の分子拡散を二重に足さない)。凝縮 OFF・CPG carrier・pure は現行カーネルのまま (コード経路不変)。
- **g=0 のビット一致**: 面の両セルで `rog == 0` のとき、現行 `species_diffusion_d` の面計算 (乱流を $D$ に足して 1 本の補正に含める式) をそのまま呼ぶ (device 関数に切り出して共有)。
  新式は $g=0$ で代数的に一致するが丸めは一致しない ($\rho(D_s+D_t)$ を 1 つにまとめた現行と、分子と乱流を分けた新式) ので、分岐で担保する。
  注: 残差の atomicAdd 順序はビット再現しない ([res0-is-not-the-flux-state] の既知事項) ので、#5 の「ビット一致」は G0 と同じ 0 step の probe 比較か、
  atomics の影響を受けない量で判定する必要がある (判定法は #5 で決める)。
- CPG carrier: 対象外ログ「CPG carrier: 二相拡散は未対応」を `condensationInit_d` (`condensationTransport_d.cu:152`) で 1 回。cell: 経路は同じ面ループ (ghost で閉じる) だが実行検証しない。

### 2.3 更新 (蒸気/液の増分)

- 定常 (`main.cpp:2127-2152`) の順序を「非水種と蒸気の増分 δρ_k, δρv を作る → 液・Q の更新 (ソース・θ・床込み) で Δρg を確定 → 水を
  $\rho Y_w=\rho Y_w^N+\delta\rho v+\Delta\rho g$ で commit → 再正規化 (係数を ρg・Q にも) → 実現可能性クランプ」に変える。
  現行は化学種を commit・再正規化してから液を更新するので、**水の commit を液の更新の後へ遅らせる**必要がある (`speciesImplicitDPLURSolve_d_wrapper` の commit

## 4. 未確定事項 (方針の穴になりうるもの; 実装前に上位の判断が要る)

1. **補正項の面の z** (plan §4.2 は $z_k\Sigma j^0$ の面値を定めていない; `species_diffusion_d:307` の現行は算術平均)。
   算術平均は隣セル分が負の非対角になり M 行列でない。通常の組成 (D 比 ≤3) ではランダム試験で負にならないが、D 比 100・段差 1 の反例で蒸気 0 のセルが負になる。
   補正の質量流束 $-\Sigma j^0$ が出ていく側の z (風上) なら点対角 1 回は非負。H2 を含む燃焼ガス (D 比 ~3–4) で段差の大きい面がどれだけあるかは未調査。
2. **相変化ソースと更新クランプが蒸気の増分にどう入るか** (plan §4.2 の「蒸気/液を変数にした増分」は輸送だけを想定した書き方)。
   現行: ソースは `res_rog` だけ (総水分にソース無し)、液の増分全体に θ (`condensationUpdateLimiter_d.cuh:58-91`)、成分ごとの非負化 (`:92-113`)、$\phi_N\delta\rho$ 項、θ_b、bounds が掛かる。
   $R_v=R_w-R_g$ を蒸気の対角で割ると、ソース分 $S(1/D_g^{\rm eff}-1/D_v)$ が反復の途中で総水分を動かす (固定点では消えるが、θ が固定点でも効いていると消えない)。
   候補: (P1) 蒸気の増分 = 輸送分 $R_v^{\rm tr}/D_v$ − 液の増分のうちソース分 (液と同じ θ・床を通した後の値)、総水分の増分 = 輸送分だけ。
   (P2) 総水分は現行どおり総水分の増分 (ソース無し) で作り、蒸気の非負は液側の θ (蒸気枯渇) とクランプに任せる — ただしこれは codex M2 の 2 セル例で蒸気が負になる元の形。
   (P3) 輸送 (拡散・移流) とソースを分割ステップにする。どれも §4.2 の文言からは決まらない。
3. **総水分の dual-time FCT**: 化学種は FCT を通らない。末尾 FCT で液だけ反拡散補正すると蒸気が動く (移流でも既存の不整合)。
   plan §4.2 は「FCT 履歴を液・Q・総水分へ拡張」と書くが、総水分 (化学種) を受動種 FCT に入れるのか、蒸気を受動種として扱うのか、が決まっていない。
4. **float32 での §6 の許容**: (i) の許容 $10^{-6}\rho_g D|\nabla g|$ は ∇g 基準なので、面あたり Δg が小さい (細かい格子) と float32 の z の丸め
   ($\sim\varepsilon_{32}z/\Delta g$) で満たせない (dx 1 mm・Δg 1e-4 で 98 倍)。保存 1e-6/1000 更新は float32 の停止基準 (残した残差) で決まり、16ε 床では超える。
   カーネル (float32) の受け入れ試験の許容を、ハーネス (float64) の条件と別に事前固定する必要がある。
5. **g=0 のビット一致の判定法** (#5): 残差の atomicAdd 順序は run ごとに変わるので、run 全体のビット一致は分岐を入れても保証できない。0 step probe で判定するか。

### 6.1 非分割更新 B の limiter と commit (ハーネス `vl_limit_commit`, `vl_increments`)

入力は前処理済みの増分 $\delta\rho v=R_v/P_v$、$\delta\rho g=R_g/P_g$、$\delta\rho Q_n=R_{Q_n}/P_g$。ここで $R_g$ は輸送 + 相変化ソース + BDF の全残差、
$R_v=R_w-R_g$ ($R_w$ は総水分の全残差 = 輸送 + BDF、ソース無し)。

1. **閾値** $\theta_{thr}=\min(1,\ g_{max}/|\delta\rho g/\rho|,\ \Delta T_{max}/(|\delta\rho g/\rho|\cdot L/c_{v,eff}))$ — 全増分 (輸送 + ソース + BDF) に対して
   (現行の `dg_max`/`dT_max` の役割。現行は液の増分 = 輸送 + ソースに掛けているので量は同じ)。
2. **対 (蒸気, 液) の非負** $\theta_{vg}=\min(1,\ \rho v/(-\delta\rho v)\ [\delta\rho v<0],\ \rho g/(-\delta\rho g)\ [\delta\rho g<0])$。蒸気は**更新前**の $\rho v=\rho Y_w-\rho g$。
   現行の液用 θ は更新済み総水分で $avail=Y_w-g$ を見るため、蒸気/液の増分を同時に作る形では意味を失い、$avail=0$ で枯渇制限が掛からない
   (`condensationUpdateLimiter_d.cuh:78-80`) — これをそのまま移植しない理由。
3. $\theta=\min(\theta_{thr},\theta_{vg})$ を $\delta\rho v,\delta\rho g,\delta\rho Q_n$ の**全部に共通に**掛ける (蒸気と液を別々に切ると総水分が勝手に増減する)。
4. $Q_n$ は成分ごとの非負化 ($\theta\delta\rho Q_n<-\rho Q_n$ なら $-\rho Q_n$ に切る; 切った量を補正として数える。現行 `boundByTheta` と同じ)。
5. **commit**: $\rho g'=\rho g+\theta\delta\rho g$、$\rho Y_w'=\rho Y_w+\mathrm{fl}(\theta\delta\rho v+\theta\delta\rho g)$ (増分形; 増分 0 なら格納値は不変)。
   丸めで $\mathrm{fl}(\rho Y_w'-\rho g')<0$ なら $\rho Y_w'=\rho g'$ (補正として数える; 正確な算術では $\theta_{vg}$ が蒸気 ≥ 0 を保証)。

残差が 0 なら θ に依らず全増分 0 で、固定点は動かない。

### 10.2 合格条件 (各 variant について; すべて満たして合格)

1. **原方程式残差** (独立評価)。
   - 格納値を float64 に上げる。T は EOS (`cond_twophase_resid` の double Newton、残差 1e-9|e| + 0.05 J/kg) で解き直す。
     ソースはその T で同じ float 関数から評価し直す。そのうえで定常残差 R(φ) を組む。
   - 対象成分: N2、総水分 w、**蒸気 v = w − l (必須)**、液 l、Q0・Q1・Q2、E。
   - 成分ごとに max_i |r_q,i| ≤ max(1e-7·r0_q, 6ε₃₂·A_q) を満たすこと。
     - r0_q は初期状態の同じ残差。
     - A_q は成分 q の残差を作る項の大きさの最大: max_i (Σ_面 |移流流束| + Σ_面 |拡散流束| + |S_q| V)。
   - この判定は**停止判定そのもの**で、毎反復評価する。
2. **反復上限 = FAIL**。上限は 20000 擬似反復。上限で止まった variant は、そこで何が起きていても不合格。
3. **非負**。
   - 全反復の commit 後に ρv ≥ 0、ρg ≥ 0 (vl_limit_commit の保証を実測で確認する)。
   - ρQ_n ≥ 0 は Q の非負化カットで保つ。
   - 状態を書き換えた補正 (Q_cut・v_round) は最終反復で 0、かつ**最後の 10 % の反復で累積 0**。
4. **制限の解除**。最終反復で θ = 1 (全セル) かつソースの θ_src = 1 (全セル)。
   収束しても制限が掛かったままなら不合格 (`procedures/recommended-settings.md` の「収束時 condLim ≈ 1」と同じ趣旨)。

### 10.3 記録する監視量 (合否の外)

- 残差の履歴: 成分ごとの比 max|r|/許容。100 反復ごと。

- min ρv・ρg・ρQ_n (全期間)。

### 10.4 比較条件 (事前固定)

- **緩和係数**
  - 比較: 同じ前処理 (対角) で ω = 1 と ω = 0.5。変えるのは ω だけ。
  - ω = 1 が合格なら初版は **ω = 1** (少ない反復; 1 ULP 未満の停滞を避ける)。
  - ω = 1 が不合格で 0.5 が合格なら ω = 0.5。
  - 両方合格でも、ω = 1 が状態補正 > 0 なら 0.5。
  - 両方不合格なら採用せず、上位へ諮る。
- **2×2 連成**
  - 比較: 上で採った ω で「対角」と「2×2」。変えるのは前処理の結合だけ。
    - 対角: 現行の src_jac の形 = 液に sj_g、Q1 に sj_Q1、蒸気にはソース項なし。
    - 2×2: (蒸気, 液) の点ブロック。∂S_g/∂ρv と ∂S_g/∂ρg を T 経由で差分した値を入れ、Q の対角は同じ。
  - 対角が不合格で 2×2 が合格なら、2×2 を**必須**とする。
  - 両方合格なら必須にしない (反復数を記録)。
  - 対角が合格で 2×2 が不合格なら、2×2 は採らない。
  - 両方不合格なら上位へ諮る。
- 結果は**この 1D 問題についてのもの**で、CFD (case/16) の収束・準定常性は判定しない。

## 14. #4e 定常専用初版カーネルの実装記録 (2026-10-02; HEAD `b900550c` + 未 commit)

### 14.1 実装上の選択 (plan の文言から一意に決まらなかったもの; 親の確認対象)

1. **カーネルの構成**: 面ごとの代数を `cuda_forge/twoPhaseDiffusion_d.cuh` の `__host__ __device__` 関数 (`tp_face_flux`) に切り出し、
   本番カーネル `twophase_diffusion_d` と GPU 単体試験の probe が同じ関数を呼ぶ (probe は atomicAdd 前の面流束・対角・エネルギーを書く)。
2. **z** は §2.1・Python ハーネスどおり Σz で正規化 (C++ 1D ハーネスは 2 種で正規化なし; 差は丸め)。面の ρ_g は面重み f の内挿。
   **D_k** は #3 の気相組成 (`species_transport_X_f`) と `thermo_Dmix_species_f` (diffMethod 1)。diffMethod 0 (定数 Schmidt) は
   ρ_g,f D = μ_f/Sc とした (D = μ_f/(ρ_g,f Sc))。
3. **補正の面 z** は風上 (補正流束 −Σj⁰ の流出側)。forge の向き (ic0 へ入る向きが正) では Σ(ic0 向き j⁰) ≥ 0 のとき ic0。
4. **対角** は C++ 1D ハーネスと同じ: 気相種 (蒸気含む) に分子 ρ_g,f D_k·|δ|/dcc/ρ_g,i、補正の流出側セルに |Σj⁰|/ρ_g,up、全輸送量に乱流 c_t|δ|/dcc/ρ_i。
   水の `transport_diag` は**蒸気の対角**。エネルギーの対角は持たない (流れのブロックが担う)。
5. **エネルギー** Σ_{k≠w} h_k J_k + h_v J_w − L(T_f) J_l。h_k は既存カーネルと同じ float の `thermo_h_mass_f`、L は EOS と同じ `cond_latent` (double を 1 回評価して float 化)。
6. **更新の前処理**: 蒸気・液・Q は**点対角** (#4c で検証した形; `passiveImplicitCoupling` の DPLUR は新経路では使わない)。非水種は現行の更新 (DPLUR/点陰的) のまま。
   → #1b の A/B は「拡散作用素」と「モーメント・水の前処理 (DPLUR → 点対角)」が同時に変わる (交絡; 親の判断事項)。
7. **δρ の扱い**: 新経路ではモーメントに φ_N δρ (#19, `passiveAddRhoTerm`) を足さず、水・液・Q を化学種と同じく再正規化係数 ρ/ΣρY で揃える
   (plan §4.2「再正規化係数を ρg と Q にも」)。φ_N δρ と係数の両方を掛けると液だけ δρ を二重に受け、vl_limit_commit の基点 ρv = ρY_wᴺ − ρgᴺ と合わない。
   固定点 (δρ = 0、ΣρY = ρ) では両者とも無作用。θ_b (`passiveLimitIncrement`) も vl_limit_commit が代わるので新経路では掛けない。`passiveBounds` (最後の砦・記録) は残す。
8. **θ ≥ 0** (既存クランプの 1e-12 床は持たない; §6.1・ハーネスと同じ)。θ = 0 の停止は残差が下がらないことで監視に出る。
9. **監視**: 蒸気残差 `res_roYv = res_roY_w − res_rog` を毎反復の組立て後に作り、`residual_history.csv` に `rms_roYv` 列を足す (新キー ON のときだけ)。
   これは毎反復に格納状態から EOS・流束・ソースを組み直した float32 残差の差であり、**float64 の独立再評価ではない** (#4c の停止契約の「丸めた f32 残差の double 化では不可」に対して、
   CFD の収束判定は桁落ち床より何桁も上の rms 低下で行うという前提の近似; 親の確認対象)。`check_convergence.py` は `rms_roY` 接頭辞で自動的に検査対象に入れる (必須列にはしていない)。
10. **起動時の検査**: dual-time 併用・陽解法 (timeIntegration ≠ 11)・`speciesImplicitCoupling 2`・`passiveScalarScheme 0`・`condEquilibrium ≠ 0`・`condLimiterMode 0` は拒否 (エラー終了)。
    CPG carrier・pure 凝縮・Euler (viscMethod 0)・凝縮 OFF は「不活性」をログに出して現行経路。cell は「未検証」をログに出して実行。

### 16.5 再正規化の許容の定義案 (上位の確定待ち; 本メモは提案のみ)

前提: 再正規化は ΣρY = ρ への射影で、係数 f = ρ/ΣρY_s を化学種 (B では液・Q にも) に掛ける。定常の固定点では化学種の増分と流れの δρ が 0 なので、
f − 1 は格納 float の丸め (ρY_s を float に戻すときの丸めと n_s 項の和) だけになり、|f − 1| ≲ (n_s/2 + 1) ε₃₂ 程度。成分 q の補正は Δq = (f − 1) q なので、
各成分の自分の総量で割った相対補正は max|f − 1| で上から抑えられる (成分ごとの値は「再正規化以外の経路で液・Q が動いていない」ことの照合になる)。
**案**: 末尾 10 % の全更新 (区間の集計がその窓を覆うように monitorInterval を取る) で
1. 局所の係数偏差 max_i |f_i − 1| ≤ 2 n_s ε₃₂ (n_s = 化学種数; case/16 は 2 → 4.8e-7)、
2. 成分ごとの相対補正 Σ|Δq|V / Σ q V ≤ 2 n_s ε₃₂ (q = ρY_w, ρg, ρQ2, ρQ1, ρQ0; 総量 0 の成分は絶対量 0)。総液量で割った値は使わない。
係数偏差が下がらない (流れの連続の式と化学種の増分の不一致が残る) run は未収束として扱う。2 step の実測 (7.9e-5 / 1e-7) はこの案より桁で大きいが、
過渡の値で、収束時の値は #1b の run でしか得られない。閾値を観測値から決めない (diagnose 論点 3)。
