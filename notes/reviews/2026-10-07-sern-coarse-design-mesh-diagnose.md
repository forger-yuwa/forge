**結論:** 壁別の粗化候補について、遷移なし31ブロック案の全長分割数・共有節点・メモリを先に集計し、500〜600万節点に収まる証拠を得てから全体生成へ進む。

**第 1 仮説:** 壁第一層の緩和だけでは、細い帯と端面細分が全域へ伝わる現接続を500〜600万節点に収められない。 **確度: 中**

  **根拠:** 保存された全長断面診断では、`scale=1→0.5` で `NL` は30→26、`NR` は62→52、`NZ` は50→46にしか減らない。生成器の式を読み取り実行しても、第一層16→32 µmで `NZ` の下限は50→46だった。[細側の分割数](/home/sano/work/forge-sern-design/notes/investigations/2026-10-06-sern-b4a5/secxB_s1.0_secx.json:4985)、[粗側の分割数](/home/sano/work/forge-sern-design/notes/investigations/2026-10-06-sern-b4a5/secxB_s0.5_secx.json:4985)。ただし、これは壁別粗化後の全体集計ではなく、不可避性の証明ではない。

  **反証条件:** 以下の粗化候補で、必要領域・端面解像・接続品質を保持した正確な集計が600万節点以下となり、生成・検査・変換・本体それぞれのメモリが実効予算内に入ること。

**第 2 仮説:** 粗格子の設計差を支配する誤差は、側壁の未解像による摩擦・境界層排除効果である。 **確度: 中、有限厚形状では未確認。** 低 Re 経路は距離に依存する ω 壁条件を使い、粗くしても壁関数へ自動移行しない。[`ransBoundary_d.cu:62`](/home/sano/work/forge-sern-design/solver_density_cuda/cuda_forge/ransBoundary_d.cu:62)。

**第 3 仮説:** 壁別第一層を導入しても、隅の共有辺拘束によって細かい側の分割が残り、想定した節点削減を得られない。 **確度: 中。** 現行の `F`・`Fc` とリング分布の連動が根拠で、異方的な壁別写像での成立性は未確認。

**判別 A/B:** **変更因子は z 法線壁群の第一内部点距離だけ**とし、A＝16 µm、B＝32 µmで、全長の分割集計と代表接続試験片を比較する。**CFDは0 step**。一般の全体格子はまだ生成しない。

共通設定と、Bを設計用の最初の試験値にする場合の具体値は次とする。いずれも**精度を認定した採用値ではない**。

| 対象 | 試験値・扱い |
|---|---|
| `ramp`・`cowl_in`・`cowl_out` | h₁＝**16 µm**を保持。設計用の配置目安は代表部 y₁⁺≲5 |
| `sidewall_in/out`・`vehicle_side`・`cowl_side` | Bは h₁＝**32 µm**。配置目安は代表部 y₁⁺≲20。400 µmへの復帰は推奨しない |
| `vehicle_top` | h₁＝**64 µm**を試験値とする。生産 YAML の既存指定60 µmに近い |
| `vehicle_base` | 既存の **17 µm**を比較起点として保持 |
| `cowl_base`・`sidewall_end` | h₁e＝**0.1 mm**を保持 |
| カウル・側壁後流 | 各端面から **0.02 H** の全区間で **Δx≤0.1 mm**を保持 |
| 一般の x 間隔 | `HX=0.10 H`、`HX_FAR=0.16 H`を粗化試験値とする。曲率・端面付近の局所細分は保持 |
| 遠方間隔 | 当初は **`HFAR=0.10 H`**。領域寸法を保持し、プルーム通過域を無条件に遠方扱いしない |
| 成長率・`NZ` | 実測隣接比≤1.2。`NZ` は共有辺から再計算する。32 µm単独の式では下限46だが、16 µm側の拘束で50以上残る可能性がある |

y₁⁺の目安は受理条件ではない。壁別の分布・最大値・超過位置と、後述の目的量の感度で判断する。旧生産記録の壁応力を固定した単純比例なら、側壁32 µmは y₁⁺≈17だが、**新しい場での予測保証にはならない**。

A/Bでは重複除去した全体節点数、区間別内訳、実第一層、最大間隔を記録する。試験片は両者30万節点以下とし、float32頂点 Jacobian・共有面・間隔比・壁距離・変換後閉性を確認する。

→ **Bが600万以下で試験片も合格**なら、第1仮説を棄却し、遷移を後回しにして全体試作へ進む。  
→ **Bが予算超過、または共有辺拘束で粗化できない**なら、この壁別粗化だけで十分という案を棄却し、B4b-0を設計段階に残す。全ヘキサ一般の不成立とは解釈しない。

600万節点は提示されたモデルで変換約**8.94 GiB**、本体約**7.78 GiB**。これは計算値で、生成・検査のピークや共有環境での実行可能性は別途確認が必要である。

**やらない方がよいこと:**

- メモリに載るまで壁・後流を粗くし、その結果を精度の裏付けにする。
- `scale=0.5`で後流も粗くした結果を、0.1 mm要件を保持した試験として扱う。
- 低 Re SSTの y₁⁺14–64を、壁関数相当の許容帯とみなす。SSTの壁間隔感度は一次資料でも確認されているが、SERNの許容誤差を与えるものではない。[Turbulence Modeling Resource](https://tmbwg.github.io/turbmodels/flatplate_val_ypluseffect.html)。
- 局所模型のPASSを、全体の力係数・設計順位の受理へ流用する。

**呼び出し側の前提への異議:**

1. **「現行 g3と同じ解像＋有限厚」は比較起点としては妥当だが、精度基準にはならない。** 旧カウルは全体が厚さ0ではなく、後縁・側端へ厚さを絞っている。[旧メッシャ:207](/home/sano/work/forge-sern-design/design/forge_design/meshing/mesh_sern3d.py:207)。新形状では内壁位置も変わる。また、m10_onの既知の冷点は後縁壁ノードではなく、その下側の内部節点である。[chain plan:439](/home/sano/work/forge-sern-design/plans/active/tooling-nozzle-sern-chain.md:439)。

2. **細格子が回せない段階の受理は、限定された設計探索への受理とする。** 同じ有限厚生成器で代表2候補×粗・中を評価し、δq＝q候補B−q候補A、格子による設計差の変化を |δq中−δq粗| として比較する。将来の検証計画には、例えば次を事前登録する。
   - 時間窓条件は既存どおり、推力2量・`C_L` が5e−5、`C_M` が5e−4。全量の `STEADY` と残差VERDICTを併記する。`NOT CONVERGED`を消さない。
   - **設計差の格子感度の暫定上限案**は、推力2量・`C_L` が5e−4、`C_M` が0.0125。これは今回の提案値で、既存の受理条件ではない。
   - 0.002規模の利得を主張するなら、さらに **|δJ|−時間変動幅−格子感度幅 > 0.002** を要求する。Jは実際の重み付き目的関数。順位が同じだけでは合格にしない。
   - 壁別摩擦・熱流束は、面積積分した分布差を中格子の絶対値積分で正規化し、まず**5%以下**を暫定目標にする。ゼロ近傍では別の絶対許容が必要。熱設計の最終保証には使わない。
   - m10_onの末尾判定区間で床到達0を確認し、新端面・近傍内部点への冷点移動も検査する。

3. **壁解像ツールの表示にも注意が必要。** 現在の「面積割合」は実装上、節点の個数割合である。[`check_wall_resolution.py:368`](/home/sano/work/forge-sern-design/solver_density_cuda/tools/check_wall_resolution.py:368)。面積割合として再利用しない。
