**判定は次の順序に固定する。**

1. **正式な停止条件への初回到達**

   `stop_rule.py` と同じ定義で、直近 20k・9 点以上について以下をすべて満たした最初の出力を記録する。

   - 質量収支: |窓平均| ≤ 0.05 %、半振幅 ≤ 0.5 %。
   - θ_r: x/x_E = 0.4・0.7・0.95 の全断面で、D ≤ 0.05 %/20k、相対半振幅 ≤ 0.5 %。
   - 抽出帯・Euler 参照・座標定義・判定コードの版を固定する。

   **初回到達の `REACHED` は変更しない。** 今回は停止させず、その後の確認を独立に記録する。既存の `watch_main_stage` は `REACHED` で計算を止める仕様なので、そのまま使うと確認区間が得られない（指定ブランチ `stop_rule.py:31`）。

2. **初回到達後の確認と参照資格**

   L は初回到達後の 40k、P は切替後の直近 40k・17 出力を評価する。8 量は θ_r・δ_loc の二窓、Q_w、出口主流 M、軸 M、η = 0.1 の M。

   §4.30 と同じく、後半 20k の平均を μ、前後半平均の差を d、40k 内の最大偏差を U とし、全量で以下を要求する。[plan:649](/home/sano/work/forge-coregrid/plans/active/tooling-nozzle-core-grid.md:649)

   - `check_quasisteady --tail 1.0`: **STEADY**
   - d ≤ τ/8、U ≤ τ/4
   - 単調な量は漸近値も報告し、漸近値と最終値の差 ≤ τ/8
   - 非有限なし、物理性を満たす

   L は確認区間中の各出力で正式な停止条件も維持する。一度外れたら「初回到達だけでは落ち着いたと判断できなかった」と記録し、上限内で後続の連続 40k を確認する。停止規則の初回到達時刻を後から書き換えない。

   **残差に `STEADY` を要求しない。** 残差が下がり続けることは失格理由ではない。§4.99 の誤りはこの混同だった。[plan:1384](/home/sano/work/forge-coregrid/plans/active/tooling-nozzle-core-grid.md:1384)。全保存量の `check_convergence` は方式ごとの区間で別途実行し、VERDICT をそのまま併記する。

3. **方式差と形状差**

   両腕の資格取得後、8 量で次を判定する。

   `|μ_H,B0 − μ_H,point| + U_H,B0 + U_H,point + p_diff ≤ τ`

   τ は既存の θ_r・δ_loc・Q_w の 1.5 %、出口主流 M の 0.05 %、軸・η = 0.1 の M の 0.05 %pt を採用し、換算尺度も §4.30 に固定する。`p_diff` は差に残る抽出誤差の予算で、共通処理だから自動的にゼロとはしない。

   形状差の主報告は **μ_H,point − μ_C,point** とし、両者の U と抽出誤差を添える。これは「今回の C/H の形状・格子構成の差」であり、入口マッハ数単独の効果や真値への誤差とは呼ばない。

**結果の読み方は事前に次へ固定する。**

- **結果 A:** L が本段 200k までに `REACHED`、40k 確認に合格し、P も参照資格を取得、全 8 量の比較予算が τ 以内。今回の起点・条件では B0 の到達予算と point に対する許容内の結果を支持する。
- **結果 B:** 正常な計算・有効なデータで L が 200k までに未到達、確認が上限内に成立しない、または両腕が資格を得ても比較予算が超過する。前二者は**今回の予算不足**、後者は**この参照・許容差での B0 採用を見送り**と区別する。
- **判定不能:** P が上限までに参照資格を得ない、抽出定義や履歴を再現できない、必要量の欠測、実行・データの異常。L の到達実績が得られていれば、その部分は報告してよい。参照不足から形状差を確定しない。発散は `DIVERGED` と明記する。

**「何 step」の定義**

L は `N_reached = 100,000 + 継続内の到達 step` と、確認完了の `N_confirmed` を別々に示す。H の起動 4,000 step は別記し、移送元 C を作った計算費用も除外した条件付き実績と明示する。P は **point 切替後の step 数**で数える。到達時刻の分解能は出力間隔の 2,500 step。

今回は標準起動の第 3 腕を足さない。他セッションが倣うのは、この測定・判定手順である。H の step 数は予算見積もりの参考に限り、370 K・別形状・別ガス・準一次元 IC からの必要 step 数として採用しない。

やらない方がよいこと: 12 万 step の外挿を到達実績にする、最初の `REACHED` だけで停止確認を終える、`point` の結果を見て閾値を変更する、C の B0 を再び長時間回す、入口半径半減というユーザ判断を蒸し返す。
