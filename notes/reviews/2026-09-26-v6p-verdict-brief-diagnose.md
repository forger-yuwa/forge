再確認した証拠を示す。以下の run はすべて `case/58.conjugate_slot/` 配下。

- `eval_v6p.py` は4 run とも、提示された6条件の `VERDICT: PASS` を再現した。ただし上記のとおり、(e) の意味が誤っている。
- `check_convergence.py` を再実行し、4 run とも **`NOT CONVERGED (stalled/plateau)`**。最終 step は99999。
- `run_0010_v6p_fp64` の保存済み全域 G-if は **`VERDICT: NOT CONVERGED`**。判定区間96000–99950、絶対残差28.4089 W/m²、相対残差0.0020206。
- 各 run の最終帯を固定し、壁ダンプ20枚、step 5000–100000を CSV 入力で `check_quasisteady.py` に渡した。`--tail 0.5 --drift 0.001 --osc 0.001`、末尾判定区間55000–100000では、4 run とも帯平均の **`Tw−300`、`q_front`: `STEADY`**、**`OVERALL: ALL STEADY`**。ファイルは作成せず標準入力を使用した。

ただし、同じツールの判定関数を局所系列に適用すると、`20/50` と `5/200` はそれぞれ13点の温度が `DRIFTING` または `TRANSIENT-UNSETTLED`。`20/200` は温度7点が `TRANSIENT-UNSETTLED`、熱流束6点が `DRIFTING`。**帯平均の静定は局所量の静定を保証していない。** また `20/200` の帯平均温度は単調増加で、ツールの外挿は約394.200 K、最終値は394.1294 Kだった。外挿は確定解ではない。

保存された固体温度と既存の `Fem2DOperator.assemble_full` から、最終スナップショットの物理的不釣合いも再計算した。節点座標の対応を確認し、集中辺長で規格化した。

数値は0.5%以内だが、局所静定と帯内 G-if が揃っていないため、**収束解の感度が合格したとは判定しない**。

結論: **V6′ は「判定不能」と記録し、次は条件 (e) の物理残差への修正と、帯内 G-if を毎更新で測る診断出力を整備する。**

第 1 仮説: 現行 (e) は受け渡した流体荷重を再比較しており、未解消の固体・流体不釣合いを PASS の背後に隠している。確度: **高**。  
　根拠: `conjugateWall.cpp:818` のコピーと、`run_0011_v6p_df20_i200` の **0.0044% 対0.46072%**。  
　反証条件: 同じ帯・保存時点で固体作用素から再構成した不釣合いも全 run で0.1%以下となること。今回の読み取り検証では満たさなかった。

第 2 仮説: `20/200` の偏差には、大きい `D_f` と少ない更新数による緩和の遅さが寄与している。確度: **中**。`D_f` はコード上固定点ではなく反復経路に作用する一方、局所量には未静定が残る。固定点の偏りとはまだ判別できない。

判別 A/B: **読み取りだけで実施済み、追加 forge 計算0 step。** 同一 run・同一最終帯・同一100000 stepで、(e) の固体側入力だけを「保存された `q_iface`」から「`K_s u−b_s`」へ変更した。物理残差も全 run で0.1%以内なら「有意な不釣合いを隠している」という仮説を棄却、超過するなら採用、とした。**結果は後者**。

やらない方がよいこと: 現行6条件の PASS を総合 PASS に格上げすること、G-if の閾値を緩めること、帯をさらに削ること、流体残差ツールの定型文だけから数値スキームを変更すること。

呼び出し側の前提への異議: `q_iface` を固体応答とみなす点、run ごとに異なる帯の平均誤差を感度とみなす点、490更新だけで `20/200` の偏差を説明する点を受け入れない。

不足情報: 固定した帯の**最後の80更新分の更新前残差・流体荷重・温度更新量**と、その正式 VERDICT。今回の提案は **plan 未反映**。依頼どおりファイル変更・forge 起動は行っていない。
