結論: **同方向対角を維持し、軸方向端面の「自然断熱／周期同一視」だけを変える固体直接求解 A/B を先に行う。**

第 1 仮説: **実装誤りより、同方向対角の P1 要素と自然断熱端面の組合せによる離散化誤差が支配的である。** 確度: **高**  
  根拠:

- `solidFem2d.cpp:167–178,189–201` の剛性・Robin 組立ては弱形式と整合する。形状関数を座標から解き、面積・辺の数値積分で独立に組み直した結果、`N=4,16,32` で既存 Python との差は、行列相対最大 `2.81e-15`、荷重相対最大 `3.34e-16`、温度最大 `4.73e-11 K`。
- メモリ上の Python 直接求解で、ブリーフの誤差列を再現した。`N=32` は全節点最大 `0.0171152 K`、最大位置 `(0, 0.01)`。
- `rect_mesh` の同方向分割では、この角に接する三角形は **2 個**（`test_solid_fem2d_axisym.py:150–152`）。半径方向の一次元 FE 解を代入すると、角の方程式に
  \[
  (KT-b-Q)_{\rm corner}
  =\frac{q_1r_1\,\Delta x\,\Delta r}{12(r_1+\Delta r/2)}
  \]
  が残る。`N=32` の独立組立てでも **`8.54700855e-4 W/rad`**。これは線形求解の残差ではなく、一次元 FE 解が二次元端点方程式を満たさない量である。

  反証条件: **端点を周期同一視しても、二次元解が下記の一次元 FE 解に `1e-8 K` 以内で一致しない場合**。「端面の非対称な要素配置が支配的」という説明は不十分になる。

第 2 仮説: **最大誤差の次数は細分化に伴って 2 に近づくが、粗格子では遅い。** 確度: **中**。追加の Python 求解では `N=64,128` の誤差が `0.00492107 / 0.00139032 K`、次数が `1.79824 / 1.82355`。ただし、**漸近次数の確定にも旧 FAIL の取り消しにも使わない**。

判別 A/B: **変えるのは軸方向端点自由度の同一視だけ**。同方向対角・`N=8,16,32`・軸分割 `3N/4`、物性・荷重・Robin 積分は固定する。時間発展なし、各格子を一度直接求解する。

- **A:** 現状の自然断熱。最大誤差 `0.189865 / 0.0581017 / 0.0171152 K` を再現する。
- **B:** 同じ半径の `x=0,W` 節点を同一自由度にし、行列・荷重の寄与を**加算**する。比較先は独立な一次元 FE 解
  \[
  T_N=T_c+\frac{q_1r_1}{hr_2},\qquad
  T_j-T_{j+1}=\frac{q_1r_1\Delta r}{k(r_j+r_{j+1})/2}.
  \]
  その解析解に対する最大誤差は事前計算で **`0.0648835 / 0.0162622 / 0.00406814 K`**、次数 **`1.99633 / 1.99908`**。

→ **A の誤差が B でこの一次元値へ落ちれば、第 1 仮説を支持し、端面と無関係な半径方向組立て誤りを主因から外す。B が一次元解と一致しなければ、第 1 仮説の説明力を棄却し、組立て・境界対応を再調査する。** 両者とも全節点誤差と線形相対残差を確認し、残差 `≤1e-11` を比較成立条件とする。

やらない方がよいこと: **角節点の除外、端点荷重の倍増、合格する対角への限定、細分化後の次数を使った旧判定の上書き。** 円筒内面では `r_i=r_j=r1` なので、`solidFem2d.cpp:114–119` の端点荷重は厳密に `q1·r1·L/2`。片側の辺しか持たないこと自体は誤りではない。

呼び出し側の前提への異議: **「最大位置が角」と「誤差が角だけに局在」は別である。** `N=32` で四隅を除いても最大誤差は **`0.0130141 K`**、全節点最大の約 **76%** 残る。また、登録 A/B の FAIL は「指定格子で閾値未達」を確定するが、実装誤りまでは確定しない。
