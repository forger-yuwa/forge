## 依頼内容

面の再構成変数 (`space.reconT`) と面のリミッタ ($\psi_T$) を SU2 に揃えても
$(\delta P/P)/(\delta\rho/\rho)$ が 1.049 (SU2 0.995) から動かない。
セル値のこの比を決めているのは面再構成ではない。仮説を 1 つに絞り、A/B を 1 つ設計せよ。

## 結論 (原文要約)

> **次は (b)、保存量への更新を書き戻す際の float32 丸めが、交番モードの停止位置を決めている、
> という仮説を試すことを勧めます。** ただし、現時点で真因と断定する証拠はありません。

- **自分の前回予測を撤回**: 「専用 `psi_T` にすれば改善する」は外れ。
  「専用制限の実装上の整合性」と「交番の原因であること」を混同していた。
  $\psi$ の平均差 0.0499・最大差 0.4870 があって L1 の温度射影が両者 −0.0011 % なら、
  **リミッタの選択を原因として追う根拠はない**。ただし再構成変数の変更自体は効いているので
  「面再構成は無関係」とまでは言えない。
- **(a) 連続式とエネルギー式の非対称性**: 正確な定常解なら比を決めるのは離散残差の連立零点であり、
  「両者とも保存量を解く」ことは離散作用素が同じことを意味しない。ただし**今回の許可範囲では
  質量流束・エネルギー流束の組み立てを確認できず、具体的な不整合は指摘できない**。
- **(b) float32 の停止位置 (推奨)**: float32 で実際に停止する条件は $R=0$ ではなく
  $\mathrm{fl}(U_j+\Delta U_j)=U_j$。ブロック解法で結合して求めた更新でも
  **最後の書き戻しは各保存量の桁で丸められる**ので停止条件は成分ごとに異なる。
  エネルギー成分の停止が密度成分とずれれば温度の交番が残りうる。
  **既実施の「陰解法 double」が線形解法だけの倍精度化なら、この仮説は未検証**。
- **提案 A/B**: 線形解法後の保存量更新で**エネルギー成分の加算だけ** `roe[i] += 0.5f*delta_roe[i]`
  にする。正確な演算なら固定点は変わらないが、丸めで止まる閾値が変わる。
  判定は符号つき $A_P, A_\rho, A_T$ と比。**4000 step 後の差だけでは判定できない** (過渡と停止位置の区別が要る)。
- **(c) 近壁熱伝導の減衰差**: 第一候補にしない (非直交補正の変更が既に無効だったため)。
  ただし**分子熱伝導率・乱流 Pr の SU2 との一致は今回の読み取り範囲では確認不能**。

## 当方の採否

| 指摘 | 採否 |
| --- | --- |
| 前回予測 (専用 $\psi_T$) の撤回 | **採用**。A/B 実測で 4 桁一致、$\psi_T\ne\psi_P$ は `run_0078_psiTdiag` で確認済み |
| (b) float32 の停止位置が真因 | **採用 (仮説として)**。ただし**より直接的な試験を先に行う** — `flowFormat.hpp` を `double` に切り替えた**全体 double ビルド** (`build-double`) で同じ A/B を回す。これなら「エネルギー加算だけ半分」という間接プローブより強く、float32 丸め説を一撃で棄却/支持できる。codex の 0.5 倍案は、全体 double が **無効** だった場合の次手として保留 |
| (c) 分子熱伝導率・乱流 Pr の一致が未確認 | **採用 (残作業)**。SU2 と forge の $k_{\rm lam}$ (Sutherland vs 一定)・$\mathrm{Pr}_t$ の設定一致を明示的に照合する |
| (a) 連続式とエネルギー式の非対称性 | **保留**。codex は読み取り範囲の制約で具体化できなかった。全体 double が無効なら、流束組み立てを読ませ直して再照会する |

## 追記 (2026-09-21): 依頼の前提が誤っていた + 推奨仮説は棄却

この依頼で codex に渡した「$\psi_T$ は 4 桁一致で空振り」という前提は **4000 step 時点の値で、過渡を掴んでいた**。
codex 自身が「**4000 step 後の差だけでは判定できない**」と本文で警告していたのに、当方がそれを
$\psi_T$ の A/B にも適用していなかった。16000 step・1000 step ごとのスナップショットで
`check_quasisteady.py --series-csv <run>/nyquist_series.csv --series-cols ratio,A_T` に掛け直すと:

| 条件 | 比 (末尾平均) | VERDICT |
| --- | ---: | --- |
| 専用 $\psi_T$ (`run_0079_reconT_long` / `run_0082_psiT_rep`) | **1.027 / 1.027** | `STEADY` |
| $\psi_P$ 流用 (`run_0081_psiP_long` / `run_0083_psiP_rep`) | **1.037 / 1.037** | `STEADY` |
| 専用 $\psi_T$ × **全体 double** (`run_0080_double_long`) | **1.027** | `STEADY` |
| SU2 | 0.995 | (収束解) |

- **codex の前回予測 (専用 $\psi_T$ で改善する) は正しかった** — $|比-1|$ −27 %、$A_T$ −23 %。
  撤回すべきだったのは codex の予測でなく**当方の A/B の測り方**。前回この記録に書いた
  「撤回を受け入れリミッタ流用説を棄却」は**取り消す**。
- **本レビューの推奨仮説 (b)「float32 の書き戻し丸めが交番モードの停止位置を決める」は棄却**。
  間接プローブ (エネルギー加算だけ 0.5 倍) ではなく**全体 double ビルド**で直接試験したところ、
  比も $A_P,A_\rho,A_T$ も float32 と 1–2 % 以内で一致した。交番は丸めの残差床でなく
  **離散作用素が持つ定常モード**である。
- したがって残るのは **(a) 連続式とエネルギー式の離散化の非対称性** (codex は読み取り範囲の制約で
  具体化できなかった → 流束組み立てを読ませて再照会する) と、**(c) 分子熱伝導率・乱流 $\mathrm{Pr}_t$ の
  SU2 との一致の照合** (未実施)。
- **教訓 (skill `codex-review` に反映済み)**: codex が判定期間について警告したら、それを
  **その依頼の前提データにも遡って適用する**。
