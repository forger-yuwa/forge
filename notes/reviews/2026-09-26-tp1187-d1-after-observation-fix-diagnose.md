結論: **(b) を選び、仮想原点・実際の入口抽出位置・熱流束の評価方法を揃えた後処理 A/B で、「平板 −13 %」が実際の場の差かを先に判別する。**

第 1 仮説: **比較座標・抽出方法の不整合が「−13 %」に混入している。** 確度: **中**。全差を説明するかは未確認。  
  根拠: **Major** — [README:98](/home/sano/work/forge/case/56.gap_tp1187/README.md:98) は 77.34 kW/m² の評価位置を「物理 1.88 m → CFD 1.75 m」とする。一方、[extract_inlet_table.py:4](/home/sano/work/forge/case/56.gap_tp1187/tools/extract_inlet_table.py:4) は入口抽出を **1.88−|x_in|** と定義し、[case_setup.json:14](/home/sano/work/forge/case/56.gap_tp1187/run_0065_L15_v2/case_setup.json:14) は 1.7076 m を指定している。さらに比較対象は **3D の領域平均と 2D の単一位置**である。現状の −13 % を格子誤差と呼べない。対案は、実際の抽出断面から座標対応を再構成し、同じ位置・同じ熱流束定義で比較すること。  
  反証条件: 整合した抽出でも差がほぼ維持され、抽出変更による差が事前に定めた数値誤差以内なら、**比較不整合を −13 % の説明から外す**。

第 2 仮説: 縦すきま口の半径省略が給気と衝突域の加熱分布を変えている。確度: **中**。省略は [gen_mesh_gap3d.py:41](/home/sano/work/forge/case/56.gap_tp1187/gen_mesh_gap3d.py:41) で確認できるが、影響の向き・大きさは未確認。  
第 3 仮説: 整合比較後にも残る平板差は、入口移送後の再発達または離散化による熱境界層の変化である。確度: **低・未確認**。現在の資料では両者を分離できない。

判別 A/B: **保存場を固定し、比較抽出の規約だけを変更する。追加 CFD は 0 step。**

- **A＝従来抽出**：3D 上流領域の 67.07 と、登録済み位置 II の 77.34 を比較。
- **B＝整合抽出**：入口の実抽出座標 x₀ と実入口位置 x_in を使い、**x₂ᴅ＝x₀＋(x₃ᴅ−x_in)** で対応づける。現行の名目値なら 3D の −10〜−2 cm は 2D の **1.78〜1.86 m**に対応する。位置 II の 1.75 m とは別である。両側で同じ熱流束定義を使い、断面別比較と共通の面積重みで集計する。併せて第一内部点距離、接線応力由来の y₁⁺、近壁の T・U・k・ω を確認する。

既存の保存系列で比較量にも `check_quasisteady.py` を適用する。判別用の許容差は、例えば **5 % と事前固定**し、抽出・時間変動の不確かさがそれより十分小さいことを条件にする。

→ **整合後に差が 5 % 以内なら**、「平板 −13 % は実際の場の不足」という根拠を撤回する。  
→ **整合後も 5 % 超の不足が残れば**、比較不整合だけによる説明を退け、入口移送・再発達・離散化を候補に残す。**この結果だけで格子を真因とはしない。**

やらない方がよいこと: **L30 再投入や Version B の製作を、この安価な判別より先に進めない。** また、平板差を一律補正して D1 を説明しない。仮に全量を 77.34/67.07 倍しても、TC95 の step 値は **1.145→1.320**で、実測下端 **2.57**に届かない。これは補正の推奨ではなく、共通倍率だけでは説明できないという確認である。
