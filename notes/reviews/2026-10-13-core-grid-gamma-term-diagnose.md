結論: **候補 (c) を修正採用し、同一の凍結場・同一刻みで Γ だけを切り替え、内部反復の解き残しと、十分解いた補正に対する実際の残差応答を分けて測る。**

第 1 仮説: **β < 1 による悪化は、内部 Jacobi の収束不足よりも、Γ と sweep 内緩和が作る実効的な左辺によって、外反復の圧力残差の低減が弱まることが主因である。** 確度: 中

根拠:

- `case/45.isobutane_m6_d155/run_0694_pk_0/` と `run_0695_pk_3/` は、Γ = I で縮流部の水準比 1.01、減衰率比 0.996。§4.89 の「Γ 以外のカーネル差だけでは今回の悪化を説明できない」は、この条件内で採用する。
- 実装は近傍補正を右辺に加え、解全体に `implicitRelax` を掛けている。[timeIntegration_d.cu:1410](/home/sano/work/forge-coregrid/solver_density_cuda/cuda_forge/timeIntegration_d.cu:1410)、[同:1483](/home/sano/work/forge-coregrid/solver_density_cuda/cuda_forge/timeIntegration_d.cu:1483)。拘束自由度を除き、対角を D、非対角を N、コードの右辺を b、緩和率を ω とすれば、

  `δₖ₊₁ = ωD⁻¹(b − Nδₖ)`

  したがって十分反復して解く系は、**`(D/ω + N)δ = b`** である。T = ΓV/Δτ、近似空間 Jacobian を A = D + N − T とすると、

  `H = D/ω + N = T + A + (1/ω − 1)D`

  ω = 0.7 では **追加項 (3/7)D が残る**。ブリーフの `T + A` だけでは、実装の補正を説明できない。
- 内部の反復行列 `G = −ωD⁻¹N` と、十分解いた補正による外側の残差応答は別物である。Γ の変更で内部反復が速くなっても、外側の残差低減が遅くなることはあり得る。

反証条件: 同じ場・刻みで、β < 1 の補正を十分解けば圧力残差の低減が Γ = I と同程度まで戻り、5 sweep 時の悪化の大部分が消えるなら、この仮説を退ける。

第 2 仮説: β < 1 で、現在の右辺に対する **5 sweep の解き残し**が増える。確度: 低、未測定。§4.45 の除外は Γ を使わないライン経路の測定であり、今回へは移せない。

第 3 仮説: 境界拘束と Γ の組み合わせが近壁の補正を悪化させる。確度: 低。拘束行では `gvec` をゼロ化しており、内部点の Γ と作用が異なる。[timeIntegration_d.cu:1464](/home/sano/work/forge-coregrid/solver_density_cuda/cuda_forge/timeIntegration_d.cu:1464)

判別 A/B:

**変更するのは Γ のランク 1 項の有無だけ。** `case/45.isobutane_m6_d155/run_0693_pdt_off/res_20000.h5` の同一状態を両腕へ与え、同じ前処理カーネルの係数から次を組む。

- 対照: Γ = I。
- 試験: `precondEps = 0.15` に対応する局所 β の Γ。
- 両腕とも刻みの拡大なし。Δτ・物理 FVS・粘性対角・軸対称項・境界拘束・ω = 0.7 を固定する。**外反復を進める長い run は不要**で、凍結した一状態の診断とする。
- 各腕でゼロ開始の δ₅ と、`Hδ = b` を十分解いた参照補正 δ★を求める。参照解は回数ではなく、無次元化した線形残差 `‖Hδ★ − b‖/‖b‖ ≤ 10⁻⁸` で資格を確認する。近傍結合は保持し、集計だけを縮流部・島・`throatwall` に分ける。
- 同じ状態で残差 b を再評価し、δ₅・δ★への実際の応答を測る。SST 保存量と組成を両腕共通で固定し、EOS・輸送係数・境界処理の再評価条件をそろえる。微小振幅を半分にして方向微分が 5 % 以内で変わらないことを資格とする。

測るのは、補正の解き残し `u₅ = ‖δ₅ − δ★‖/‖δ★‖`、圧力残差の低減、および **近似 Aδ と実際の Jδ の差**。ここで J = −∂b/∂Q。圧力射影 r/c² は共通の基準状態に固定し、ノルムだけでなく残差への符号付き射影も出す。

事前の読み方は次とする。閾値は今回提案する診断基準である。

- **結果 A:** 両腕の `u₅ ≤ 0.01` なのに、試験腕の十分解いた補正による圧力残差の低減が対照の半分以下 → 大きな内部解き残し説を退け、第 1 仮説を支持する。
- **結果 B:** 試験腕の `u₅ ≥ 0.3` で、十分解くと圧力残差低減が対照の ±10 % に戻り、5 sweep 時の低減不足の 80 % 以上が消える → 第 1 仮説をこの状態では退け、第 2 仮説を支持する。
- 中間・領域間で不一致・信号不足は判定不能とする。

**「左辺の不整合」を調べる直接の量は `(A − J)δ` である。** 内部反復行列のスペクトル半径だけでは判別できない。ただし、この試験が示すのは一状態での補正機構までであり、20,000 step の悪化全体や、その差の出所が対流 FVS だけであることまでは確定しない。

やらない方がよいこと:

- ε = 0.3・0.5 の長い run を先に増やす。感度は分かるが、内部解き残しと外側の応答を分離できない。
- 「Γ と整合させる」として直ちに固有値だけを置換する。固有ベクトル・対角・近傍結合を含む変更の妥当性は未確認。
- 数節点を切り出して近傍を落とした行列のスペクトル半径を、全体の反復の説明に使う。

呼び出し側の前提への異議:

- **Major —「物理 FVS と Γ の併用だから不整合」は未成立。** 固定した残差 F に対する時間前処理は `ΓV/Δτ + ∂F/∂Q` と書け、物理 Jacobian を残すこと自体は誤りではない。[theory.md:210](/home/sano/work/forge-coregrid/methods/time_integration/theory.md:210)。一方、この連続的な説明から「実装の物理 FVS が離散残差の真の Jacobian」とも言えない。対案は上記の Aδ と Jδ の照合である。
- **Major — 圧力成分の大きさは、圧力の釣り合いが遅れる証明ではない。** §2 は別々に進んだ未収束場の単一時刻の比較であり、増加の生成源・減衰率を分離していない。固定組成の内部点ではこの分解は有用だが、二つの RMS は直交した残差エネルギーの内訳ではない。対案は同一状態での圧力補正と残差応答を測ること。
- **Major — 残差と状態の評価時点の照合が必要。** plan §4.45 は保存された残差が更新前、保存量が更新後である例を記録している。今回の抽出もそうなら、`r(Q)` と R の時点がずれる。§2 の数値を機構の根拠にする前に、同一状態で再評価する。
- **Major —「圧力方向の時間項が 1/β 倍」を壁節点へ一律に適用できない。** `gvec` の拘束行を消した後は、内部点の `rᵀg = c²` をそのまま使えない。対案は壁節点・第一内部節点以降を分け、実際の拘束後の行列で評価する。[timeIntegration_d.cu:1436](/home/sano/work/forge-coregrid/solver_density_cuda/cuda_forge/timeIntegration_d.cu:1436)
- **Minor — 倍率の修正。** β = 0.0225、刻み倍率 6.03 なら時間係数比は `44.44/6.03 ≈ 7.37`。約 6.6 は刻み倍率が約 6.67 の場合である。β も全域一定ではなく、局所速度に依存する。[lowMachPrecond_d.cuh:18](/home/sano/work/forge-coregrid/solver_density_cuda/cuda_forge/lowMachPrecond_d.cuh:18)
