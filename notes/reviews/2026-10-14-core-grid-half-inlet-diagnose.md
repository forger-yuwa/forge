第 1 仮説: **入口半径半減を含む上流形状の変更によって、B0 の縮流部の残差停滞を60,000 step以内に大幅に緩和できる。** 確度: **低**。

根拠: ブリーフの停滞帯は M=0.02〜0.08。ただし、直接確かめられているのは流れ方向の粗化への感度であり、マッハ数への因果依存ではない。[plan:743、§4.36](/home/sano/work/forge-coregrid/plans/active/tooling-nozzle-core-grid.md:743)。

反証条件: 後述の資格を満たし、入口と対象帯のマッハ数が実際に増えたにもかかわらず、新形状の残差が対照と同程度以上で停滞する場合、この**形状・設定・予算で大幅に緩和できる**という仮説を退ける。「低マッハは無関係」とは結論しない。

第 2 仮説: 改善が出ても、主な寄与はマッハ数の増加ではなく、半径方向の格子形状・局所刻み・境界層履歴の変化である。確度: 中。この A/B だけでは第 1 仮説の機構と分離できない。

判別 A/B: **操作因子は上流形状の二水準とする。マッハ数だけを変更する試験とは呼ばない。**

1. **形状と格子**
   - 対照 C は現形状。試験 H は `r_U=3.2425`、`L_U=9.0`、配管長約 `3.5`。x≥0 の実壁と物理スケールは保存する。
   - 縮流部は、入口側 `(r_U,0,0)` と既存実壁の x=0 の半径・勾配・曲率を結ぶ5次 Hermite とする。名目終端 `(1,0,1/2)` なら μ=18.060≤20。ただし**実壁に合わせた後の単調性・接続性を別途確認する**。
   - Gref の x station をそのまま使う。`nj=160`・`axis_cap_frac=0.015` は維持し、第一層の比は、旧格子の実寸壁法線距離を再現するよう変更する。第一近似は `旧比×旧壁半径/新壁半径`、最終確認は生成座標で行う。
   - 下流の節点座標の保持、実寸第一層厚、AR・skew・格子線の折れを検査する。`check_mesh_quality.py` が合格しなければ投入しない。第一層の実寸を保持しても、新流れの y₁⁺ が同じになる保証はない。
   - 設計チェーンを回し直して壁を再設計しない。既存の `cmd_prep` は `_prepare_ns` と全壁の生産形状照合を呼ぶため、そのままでは今回の準備手順にならない。[core_grid_mesh.py:580](/home/sano/work/forge-coregrid/case/45.isobutane_m6_d155/core_grid_mesh.py:580)。

2. **初期値・設定・長さ**
   - 共通ドナーは提案どおり `run_0608/res_60000.h5`。これは**停滞場**として使い、収束場とは呼ばない。C は `restart_field.py`、H は `interp_field.py`。H の壁距離は新メッシュで作り、壁 BC と乱流量の整合を確認する。
   - 両腕とも同じ短い起動段を置く。提案は、方程式・BC・離散化を保ち、CFL 0.5で2,000 step、1で2,000 step、その後 B0 の CFL 4で60,000 step。これは安全を保証する長さではなく、事前固定する予算である。
   - 同一バイナリ・変換器を使い、`thermoFloat: 1`、前処理、ITJ、ライン設定、緩和、入口全条件を固定する。片腕だけ設定を調整しない。
   - 対照も新しく作る。`run_0619_cg_gref_b0_ctl/` は停滞再現の参考とし、今回の共通起動段を通した対照の代用にしない。

3. **主指標と事前判定**
   - 本段で1,000 stepごとに集計する。窓は **W1=(20k,40k]、W2=(40k,60k]**。
   - 主領域は両形状とも x/r_t∈[−8,−2] の全断面。主指標は §4.36 と同じ **q=√(ΣV(R/V)²/ΣV)** の ρ・ρE。`q̄_H/q̄_C` と各腕自身の `d=q̄(W2)/q̄(W1)` を併記する。形状が違うため、同じ離散問題の収束速度比較とは扱わない。
   - **資格**: 対照が停滞を再現する、非有限がない、入口だけでなく旧停滞帯の x 範囲でもマッハ数の増加を確認できる、評価窓が境界層再形成の大きな過渡に支配されていないこと。壁から60〜100節点目を同じ物理位置とは扱わない。
   - **結果 A**: 両窓・両主成分で `q̄_H/q̄_C≤1/3`、H の `d≤1.1`、他の保存量や上流配管・スロート・下流へ顕著な残差悪化が移っていない → **この形状変更による停滞緩和を支持**。
   - **結果 B**: 両窓・両主成分で `q̄_H/q̄_C≥2/3`、H の `d≥0.8` → **この半径半減案で大幅に緩和できるという第 1 仮説を退ける**。
   - 中間、成分で結果が割れる、起動失敗、過渡が残る場合は判定不能。上の閾値は診断用の提案値であり、収束基準ではない。予算到達後に自動延長しない。
   - 全保存量の `check_convergence.py` の VERDICT と判定区間を残す。流量・熱流束・境界層量の定常性は `check_quasisteady.py` で各腕自身を判定する。異なる形状間の量の一致は要求しない。

やらない方がよいこと: **入口半径変更と同時に x を粗化する、`thermoFloat` を0にする、低マッハ前処理を追加する、移送後の大きな残差からの低下桁数だけで成功とすること。** いずれも今回見たい効果の判別を崩す。

呼び出し側の前提への異議:

- **[Major]「縮流部の流速は4倍」は成立していない。** 4倍は入口面積と、流量・密度がほぼ不変という仮定からの見積もりに限る。提示された名目 Hermite を計算すると、旧／新の断面積比は x/r_t=−6で **2.46**、−4で **1.68**、−3.25で **1.45**。停滞帯全体が4倍速になる試験ではない。局所マッハ数を測って操作の効きを確認する。
- **[Major] 前処理の失敗は低マッハ仮説の除外証拠ではない。** `=1` は B0、`=2,3` は point での試験であり、判定はその設定・予算に限られる。今回も成功から低マッハ単独の原因同定、失敗から低マッハ全般の否定はできない。
- **[Major]「止まる先」は確定した収束解ではない。** §4.97 は4本とも `NOT CONVERGED`、主判定も資格不足による判定不能。実行間差の約0.1%を、今回の残差指標の誤差幅として転用してはいけない。[plan:1352](/home/sano/work/forge-coregrid/plans/active/tooling-nozzle-core-grid.md:1352)。
