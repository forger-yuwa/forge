結論: **次の一手は、評価器の被覆検査を直したうえで、生成済み入力を固定した V2d-2 の nSub 20／40 を各3回比較し、設定差と実行間変動を分離することです。**

第 1 仮説: **V2d-2 の単発比較には、1%基準に対して無視できない実行間変動が混入している。** 確度: **中**

根拠: `case/58.farfield_verification/run_0142_v2d2_tp2_ac_short_dt4` 相当の既存 run と `run_0152_v2d2_tp2_short_dt4_n20` の報告差は **1.383%**、`run_0152` と `run_0153` の nSub 差は **1.559%**。ただし前者の完全な入力同一性は未確認です。`atomicAdd` は候補ですが、発生源の同定ではありません。

反証条件: 入力・実行条件を照合した反復で両群の再現性幅が **0.2%以下**となり、群間差がばらつきを超えて残るなら、「再実行幅が今回の差の主要な説明」という仮説を棄却します。旧 run との入力差が判明した場合も、1.383%を非決定性の証拠から外します。

第 2 仮説: **nSub に依存する系統差が残っている。** 確度: **中、未確認**。反復不足と、反復を増やすことで変わる丸め誤差はまだ区別できません。

第 3 仮説: **V2c の停滞は二次再構成を含む離散化・反復の組合せに依存する。** 確度: **中**。次数への感度は支持されますが、一次場から再開すれば解消するかは未確認です。

判別 A/B: **変更する設定は `time.nSubIterDualTime` の20／40だけ。各3回、合計6標本を使います。**

- tp2・短領域・`--left-hot`・dt≈2.2087e−7を固定し、毎回同じ元のパルス初期場から開始します。継続計算を反復標本にしません。
- バイナリ SHA256、生成済み格子・初期保存量・BC・物性 DB・プローブ節点、GPU・実行環境変数を照合します。格子と初期場を毎回再生成しません。
- `run_0152`／`run_0153` は同一性を確認できれば各1標本として再利用し、**追加は各2本**。9月29日の `run_0142` は、まず過去結果との照合用に分けます。
- 全標本を固定区間 **[0, t_ref＋w_ref] ≈ [0, 1.667e−3] s** まで取得します。分母 A_inc は同じ長領域から固定。dt比較では両系列の時刻の和集合と区間端点で比較し、引数順による最大差の取りこぼしを避けます。
- 群ごとの再現性幅を **Fₙ＝maxᵣ<ₛ maxₜ|Pₙ,ᵣ−Pₙ,ₛ|／A_inc** とします。これは3標本で観測した幅であり、将来の誤差上限でも普遍的な「床」でもありません。
- 群平均波形の差を D、各群の平均波形からの最大偏差を E₂₀・E₄₀ として、**D＋E₂₀＋E₄₀ ≤ 1%** を満たした場合だけ、観測した反復を含めて nSub 感度が許容内とします。**dt半減比較にも別途同じ1%条件が必要**です。

→ **A：同一群内でも1%以上の差を再現するなら**、単発の nSub 差を反復不足だけに帰属する説明を退け、時間精度の合格を保留します。

→ **B：両群 Fₙ≤0.2%、かつ D−E₂₀−E₄₀>1%なら**、実行間変動だけでは説明できず、「nSub 20で十分」を棄却します。

中間は判定保留です。ばらつきが大きいほど合格しやすくなる規則にはしません。

やらない方がよいこと: **差から F を引くこと、反復の平均だけで合格にすること、dtをさらに細分するだけの試行、一次の V2c で二次の未達を置き換えること。** 現行ソースには当該経路の決定的加算へ切り替える機能を見つけませんでした。`FORGE_CUDA_BLOCKSIZE` の固定は加算順の保証ではありません。`qAccumulatorFP64` も dual-time は明示拒否です（[main.cpp:2864](/home/sano/work/forge-sern-design/solver_density_cuda/main.cpp:2864)）。

呼び出し側の前提への異議:

- **V2c の段階起動は次段として採用**します。`run_0151` の最終場から保存量を同一格子へコピーし、`convMethod: 1` に戻します。二次区間で6000 step、未達なら6000ずつ延長、最大24000 step。全節点・全5成分の Rmax≤1e−5、W<0.001、`check_convergence: PASS`、対象量の `check_quasisteady` 判定、NaN・置換等ゼロを要求します。一次区間を二次区間へ連結して低下桁数を稼いではいけません。
- 二次で条件を満たせなければ **V2c は未収束・判定不能のまま**です。満たしても B 単独では合格せず、登録済み2系列の A/B/C 全線比較が必要です。一次結果は補助検証として残せますが、汎用境界の受入れを代替しません。
- **accepted への順序は基本的に維持**します。V2c・V2d-2の未達解消 → 独立参照の精度確認・比較記録 → docs整合 → resultレビュー → accepted。ただし帳簿対応 **#4d は今回の plan では実装済み**なので、未実装として再提案せず resultレビューの確認対象に移します。独立参照は完了に必要な記録作業であり、境界の合否条件とは区別します。
- 再実行幅が dt 細分で増えるという説明は、各 dt で反復を測るまで未確認です。**決定的な丸めバイアスは反復間差では測れません。**
