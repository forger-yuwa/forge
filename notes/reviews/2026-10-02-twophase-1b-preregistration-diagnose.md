結論: **事前登録は現状では確定不可とし、まず A の旧作用素監査と再正規化の成分別計測を揃える。**

第 1 仮説: 現案の主要な問題は、受入条件と計測手段が一致しておらず、計算を延長しても判定を完結できないことである。 確度: 高  
  根拠: plan `plans/active/condensation-two-phase-transport.md:125` の「両 run の監査 PASS」と、設計メモ `notes/investigations/2026-10-02-twophase-diffusion-kernel-design.md:728` の「新キー ON のときだけ」が矛盾する。補正についても、ブリーフには再正規化係数の局所偏差・成分別の補正量・集計窓がない。  
  反証条件: A の**旧作用素**を独立評価した有効な監査と、丸めの許容を判定できる補正計測が既に存在し、その定義と対象区間を提示できること。

第 2 仮説: 再正規化の WARN は、総液量を分母にした尺度によって増幅された丸めを含む可能性がある。 確度: 中。ただし `6.0e-5` だけでは、補正が固定点へ影響する可能性を除外できない。  
第 3 仮説: 通常残差 PASS と監査 NOT CONVERGED の併存は、RMSの低下量と独立残差の最大値・丸め床という判定の違いで説明できる。 確度: 高。実 run でどの成分が律速になるかは未確認。

判別 A/B: **上記の計測不足を解消後、変更する設定は `condensation.condTwoPhaseDiffusion` の OFF／ON だけとする。** 同じバイナリ・共通初期場から4000 step、200 stepごとに出力する。事前登録は次の内容に固定する。

- **収束区間・方式**：各 run の開始から終了まで、`check_convergence --drop 3 --tail 0.2`。流れ・SST・化学種・液・全モーメントの列を確認し、B は `rms_roYv` も必須とする。ツールはこの蒸気列の存在自体を必須にしていないため、欠落を別途拒否する（設計メモ `:618–620`）。
- **監査**：両者とも各自の作用素について、元の `max|r| ≤ max(1e-7·r0, 6ε₃₂·max A)` を維持する。通常残差 PASS でも監査未達なら受入不可。異なる二つの計算長で連続してこの状態になれば延長を止め、成分別の残差・許容・最大残差位置を添えて再諮問する。同じ終了状態を二度評価して「2回」と数えない。
- **末尾10 %の補正**：各更新を含む区間集計で、θ<1 の件数0、ソース側 θ_src も解除、Qcut=0、vround=0、射影・負値床・増分制限・受動種 floor の**補正量0**を要求する。monitor時点だけの0では不十分。非正規数Qcutの免除は今回は採用せず、未達なら成分・単位・発生箇所を特定する。**再正規化の許容だけは未確定**であり、観測された `6.0e-5` をそのまま閾値にしない。
- **定常性**：指定の7報告量に上表の厳しい許容を適用し、すべて STEADY。温度では約0.02～0.03 Kの末尾変動尺度になる。p95|ΔT|などの場の比較統計にも、それ自体の時系列判定を要求する。
- **延長・上限**：共通初期場から4000→8000→16000→32000 stepで両者を再実行する。**連続する二つの計算長で受入条件を満たすこと**を要求し、計算長を変えた報告量の変化も記録する。上限未達は「受入条件未達」であり、物理モデルの誤りとも、影響なしとも判定しない。
- **有限性**：NaN/Infなしに加え、蒸気・液・各Qの非負を確認する。抽出スクリプトの `nonfinite` は限定された原始量しか見ないため、これだけでは代用できない（`twophase_ab_series.py:151`）。

→ **両者が全条件を満たし、B−Aが時間変動・計算長依存より明瞭に大きいなら、当該条件で識別可能な作用素変更の影響を支持する。両者が合格しても差がその幅に埋もれるなら、その精度では影響を検出できない。片方でも未達なら判別不能。** 1 Kは大小の分類にだけ使う。

やらない方がよいこと: 監査の6εを通常残差 PASS に合わせて緩めること、旧 run と新 run の残差を連結すること、補正件数だけから無害と判断すること、再開ごとに変わる基準値で延長履歴を接続すること。

呼び出し側の前提への異議:

- 「再正規化は常時 WARN の予想だから許容できる」は採用しない。予想された警告と、影響が無視できる証拠は別である。
- 「両者の平均量が STEADY だから最終 p95|ΔT|も定常」は採用しない。
- **Minor：漸近値の自動出力も無条件に信用しない。** `check_quasisteady.py:327–334` は増分比が1に極めて近い場合の外挿を安定化できていない。人工的な283.4→283.2 Kの線形系列では、許容0.1 %で STEADYと約−1.76e9 Kの外挿値を同時に返した。外挿値を受入根拠にせず、計算長を増やした実際の変化で確認する。

不足情報: A用の旧作用素監査、再正規化係数の局所偏差と成分別・区間別補正量、θ・θ_src・各補正の全更新を覆う集計仕様。この三点が揃うまで、空欄をすべて埋めた「確定済み事前登録」とはできない。
