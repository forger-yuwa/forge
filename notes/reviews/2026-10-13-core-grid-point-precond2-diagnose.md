結論: **既存 C を対照に流用し、同一起点・同じバイナリ・point・`cfl_pseudo: 1` で `lowMachPrecond: 2` の 20,000 step を 1 本だけ追加する。ただし主判定は各腕自身の残差の減衰率とし、「元の離散方程式の収束加速」とは区別する。**

第 1 仮説: 圧力差に対する質量流束の結合も変更する `=2` なら、今回の point 構成で、変更後の方程式の残差を C より速い割合で持続的に減らせる。確度: **低**。

- 根拠: [`convectiveFlux_slau_d.inc.cuh:581`](/home/sano/work/forge-coregrid/solver_density_cuda/cuda_forge/convection/convectiveFlux_slau_d.inc.cuh:581)・587 では、`=2` が `P_del/c_diss` を変更する。`=3` の失敗では、この変更の効果は試されていない。backstep には 0/2/3 の比較記録があるが、node では ω の残差停滞が残っているため、本ケースでの成功までは裏付けない (`notes/investigations/backstep-lowmach-checkerboard.md:109,118`)。
- 反証条件: 以下の資格を満たした試験で結果 B となること。反証する範囲は**この設定・20,000 step の予算での実用的改善**に限る。

第 2 仮説: `=2` の質量流束変更を加えても、Γ と拡大した擬似刻みを使う更新の悪化が残る。確度: 低。`=3` の増加傾向は整合するが、その原因は未同定 (`plans/active/tooling-nozzle-core-grid.md:1196`)。

判別 A/B: **変更点は `time.deltaT.lowMachPrecond: 0 → 2` の 1 点。**

**腕の組み方**

- C: `case/45.isobutane_m6_d155/run_0688_pp_c/` の既存系列。
- P2: `case/45.isobutane_m6_d155/run_0608/res_60000.h5` から新規 run を作り、20,000 step、2,500 step ごとに同じ集計を保存する。
- バイナリは C と同じ `d58ed787…`。point、`cfl_pseudo: 1`、`implicitRelax: 0.7`、`nStepInner: 5`、`precondEps: 0.15`、ITJ 無効など、§4.82 の条件を維持する。片腕だけの CFL 変更・自動延長はしない。
- C の流用は、バイナリ・初期保存量・実効設定・領域マスク・集計定義の同一性を保存記録で確認できることが条件。確認できなければ資格不足とする。同時実行だった C と単独実行の P2 から、実時間の速度向上は判定しない。

**主指標と事前閾値**

縮流部 x/r_t ∈ [−8, −2] の体積重み付き RMS を、各腕の演算子で評価した q とする。W1 = 10,000〜15,000、W2 = 15,000〜20,000 とし、保存出力の平均から、保存量ごとに

`d_C = q̄_C(W2)/q̄_C(W1)`  
`d_2 = q̄_2(W2)/q̄_2(W1)`  
`H = d_2/d_C`

を計算する。**`q̄_2/q̄_C` の水準比は主判定に使わない。**

- **結果 A**: ρ・ρE の双方で `d_2 ≤ 0.5` かつ `H ≤ 0.5`。さらに、P2 の 10k〜15k・15k〜20k の各区間で `log q` の傾きが負で、末尾だけの急落による合格でないことを確認する。
- 悪化の移動を防ぐため、縮流部の運動量・乱流残差、および縮流部外の平均流・乱流残差についても、`d_2 ≤ 1` かつ `d_2/d_C ≤ 1.5` を要求する。全域の全残差列の時系列も併記する。
- **結果 B**: ρ・ρE の双方で `H ≥ 0.8`、または双方で `d_2 ≥ 1`。
- 成分間で割れる、中間域、悪化の移動、測定床・ゼロ分母、資格不足は**判定不能**。P2 の非有限発生は「この構成が不安定」とし、安定な場合の減衰率は未判定とする。

これらは今回の選別のための提案閾値であり、物理的な収束基準ではない。W1・W2 は 15k の出力を共有するので、独立した二つの証拠とも扱わない。全出力の推移と全残差系列を確認し、短い窓の値だけで機構や定常性を結論しない。

**資格**

1. 初期保存量のビット一致と、許可した設定差分だけであること。`=2` では**step 0 の残差一致を要求しない**。
2. `lowMachPrecond`・`precondEps`・`speciesImplicitCoupling`・`speciesPrecondDt` の実効値を確認する。キーは正しい階層に置く。
3. 刻みの効きは、**P2 の同一状態から計算した前処理あり／なしの期待値**で検査する。異なる状態へ進んだ P2/C の `dt_local` 比を、そのまま前処理倍率としない。
4. 境界更新、非有限、ρ・P・T の正値性、組成一様性を再確認する。初期・資格確認用の出力を判定前に消さない。
5. 両腕の `check_convergence.py` の VERDICT と判定区間を添える。結果 A でも、それだけでは収束ではない。

→ **A なら**「この構成では `=2` でも有限予算内の改善を得られない」を退け、変更後の方程式での減衰改善を支持する。  
→ **B なら**第 1 仮説を今回の設定・予算内で退ける。第 2 仮説は残るが、原因が刻み・Γ・乱流更新のどれかまでは決まらない。

やらない方がよいこと: **P2/C の残差水準だけで勝敗を決めること、P2 の成功から直ちにライン経路へ Γ を実装すること、失敗から低マッハの見立て全体を閉じること。** A でも言えるのは「変更後の方程式に対する有限区間の残差減衰が改善した」までである。元の離散方程式への収束加速には共通演算子での評価が、解の妥当性には収束・準定常性と精度の検証が別途必要になる。
