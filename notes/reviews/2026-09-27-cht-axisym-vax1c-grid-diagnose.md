結論: **最初の FAIL を正式に残して V-ax1 の包括的 PASS を保留し、対角を揃えた円筒殻で「半径方向のみ細分化／両方向細分化」の A/B を登録して実行する。**

第 1 仮説: **`r` 重みを持つ離散系で、対角の向きと軸方向未細分化の組合せが節点最大誤差の低次成分を残している。** 確度: **中**  
  根拠: [試験:133](/home/sano/work/forge-cht/solver_density_cuda/tools/test_solid_fem2d_axisym.py:133) の格子生成と既存 `Fem2DOperator` を使い、ファイルを作らずメモリ上で直接求解したところ、以下を再現した。単位は K、誤差は全節点最大値。

| 軸方向分割・対角 | 半径 4 層 | 8 層 | 16 層 | 32 層 | 倍増ごとの次数 |
|---|---:|---:|---:|---:|---|
| 3 固定・交互 | 0.366748 | 0.139264 | 0.046577 | 0.013003 | 1.397 / 1.580 / 1.841 |
| 3 固定・同方向 | 0.577422 | 0.285705 | 0.141315 | 0.069104 | 1.015 / 1.016 / 1.032 |
| 3/6/12/24・交互 | 0.366748 | 0.095214 | 0.024245 | 0.006116 | 1.946 / 1.974 / 1.987 |

  同方向系列の最大誤差は全解像度で **`x=0, r=r1` の角節点**にあった。線形方程式の相対残差 `||Ku−b||∞/||b||∞` は全系列で **1.3e−13 以下**。この Python 再現において、反復不足を第一候補にはしない。`c2a0f8a7` の `solidFem2d.cpp:173` の重心半径による剛性重みも、一定 `k`・線形三角形では要素積分に整合している。  
  反証条件: 対角を揃えたまま両方向を細分化しても、後述の最大誤差次数が回復しない場合、「軸方向未細分化が主要因で、その解消で十分」という仮説を棄却する。

第 2・第 3 仮説: **共通の組立て・境界荷重の誤りは未除外。** C++ と Python の一致だけでは排除できない。ただし、確認した実装差分から明白な式の誤りは見つからず、現段階では第 1 仮説より低い。

判別 A/B: **変更点は軸方向分割数の細分化則だけ。** 物性・幾何・荷重・全セル同方向の対角を固定し、半径方向 `N=4/8/16/32` に対して **A=`Nx=3`、B=`Nx=3N/4`**。固体の直接求解を各 4 回行い、全節点最大誤差・内面最大誤差・最大誤差位置・線形方程式残差を見る。時間積分は不要。判定は実行前に次で固定する。  
  → **A の約 1 次が再現され、B の 8→16・16→32 がともに ≥1.8**なら、「対角を揃えると必ず 1 次になる」は棄却でき、第 1 仮説を支持する。  
  → **B がこの条件を満たさなければ**、縦横比固定だけで説明・解決できるという判断を棄却する。直ちに実装誤りが確定するわけではない。

やらない方がよいこと: 最初の FAIL を「参考・判定外」に移して全件 PASS とすること、交互対角を合格のための必須条件にすること、今回の結果だけで生産格子の AR 上限を決めること。

呼び出し側の前提への異議: **「観測された格子依存性」は確認できたが、「超収束の喪失」は未確認。** 固定・交互系列では 16 層の内面誤差は約 **0.0504 %**で、温度誤差の閾値には合格している。FAIL は次数条件によるものなので、これを即「生産温度が不正確」と読み替えるのも誤り。
