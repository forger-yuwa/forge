## 0. 結論 (先に)

1. **δ\* の与え方に系統誤差がある。スロートで与えた補正量は、Euler と同じ質量流量へ戻すための等価補正量の 3〜12 倍過大**である。
   与えた δ\*$_t$ = 0.005〜0.020 $r_t$ に対し、質量流量から得た等価値は **0.0013〜0.0021 $r_t$**
   (3 case・5 設計・CPG/TP・SST 2 種の 14 run で同傾向)。これは局所プロファイルから定義した境界層 δ\* との厳密な同一性までは主張しない。
   原因は、相関 (乱流平板 + 入口起点弧長) が収縮部の強い加速による境界層の薄化を表現できないこと、
   および v3 で $x<x_{lo}$ を「相関 × $x_{lo}$ での比」で埋めているため $x_{lo}$ の比 (0.67) がスロートの等価比 (0.13) を代表しないこと。
2. **スロート径を動かすこと自体は物理的に正しい** (有効音速面積 = 幾何スロート − δ\*$_t$ の分だけ広げないと質量流量と面積比が狂う)。
   問題は動かす**量**で、過大な δ\*$_t$ でスロートを広げた結果、**NS の質量流量が Euler 設計より 0.8〜3.7 % 多い**
   (= 有効スロート面積がその分大きい)。面積比 $A/A^*$ の 1D 感度 $d\ln M / d\ln(A/A^*) \approx 1/5$〜$1/6$ から、
   これだけで**試験部 M が −0.2〜−0.7 %** ずれる。観測されている NS 残差 (v3 で −0.24〜−0.43 %、v1 で −0.5〜−0.7 %) は
   **この一項で大きさ・符号とも説明できる**。これまで「law 側残差」「δ\* 非表現」と分類していた近スロート残差の主因はこれである。
3. 「δ\* は 1〜2 反復で固定点」という確認は $x \ge x_{lo}$ にしか効いていない。固定点 = 正しさではない ($x<x_{lo}$ は検証外、抽出器の偏りは固定点でも残る)。
4. **Md トリム (case/45: 6.0→6.0144) は、この面積誤差を設計面積比の側でキャンセルする対症療法**であり、
   (a) 原因がスロート側にあるのに輪郭・全長・出口径の側を変える、(b) case ごとに NS 2 回の較正が要る、
   (c) 誤差配分 (スロート / 膨張部 / 出口 / SST モデル) を見えなくする、の 3 点で「イマイチ」という直感は正しい。
   同様に**「軸 M を見て law 側を帰還する」のも、δ\* が正しくなる前にやると粘性誤差を非粘性設計へ焼き込む**ので順序が逆。
5. 打ち手 (§6) は、①質量流量による有効スロートの帳簿付け (即効・ゲート化)、②非一様な inviscid core を基準に δ\*(x) を CFD 抽出する、
   ③v1 相関を運動量積分法に置換、④オフセット方向 (法線 vs 半径) の整合、
   ⑤トリムは Md でなく「質量流量で決めるスロート較正」に置換し、法則側帰還は δ\* 確定後の局所残差にだけ使う、の順。
   主仮説は case/45 の NS 1 本 (~200 s) で判定し、固定点は 2 本目で確認する (§7)。

## 1. 現状の排除厚さの計算方法

### 1.1 v1: 経験相関 (`feedback/deltastar.py::dstar_flatplate`)

$$\delta^*(s) = 0.0463\, s\, Re_s^{*\,-1/5}\, H_c(M_e),\qquad
Re_s^* = \frac{\rho^* u_e s}{\mu^*},\quad
\frac{T^*}{T_e} = 1 + 0.115(\gamma-1)M_e^2,\quad
H_c = 1 + 0.4\,\tfrac{\gamma-1}{2}M_e^2$$

- 乱流**平板 (零圧力勾配)** の局所相関 + Eckert 参照温度 (断熱壁)。**履歴を持たない** (その場の $s$ と $M_e$ だけで決まる)。
- $s$ は A13 以降**入口起点の壁弧長** (直管 + 収縮部 $L_U$=6〜12 $r_t$ を含む)。縁 Mach は $x<0$ で $A/A^*$ の亜音速枝、$x \ge 0$ で MOC 壁の $M$。
- 結果、スロートで $s \approx 10$〜$13\,r_t$、$Re_s \sim 10^8$ となり **δ\*$_t$ = 0.011〜0.020 $r_t$** (case/45: 1.3 mm)。
  これは「1 m の平板を流した後の乱流境界層」の値で、**収縮部で M 0.02→1 に加速される流れの境界層とは別物**。
  強い順圧力勾配 (加速) では運動量厚さ θ が減少し (運動量積分 $d\theta/dx = c_f/2 - \theta(2+H-M_e^2)\,u_e'/u_e$ の第 2 項)、
  スロートで必要な等価補正量は平板相関より一桁小さい。§4 の質量流量帳簿がそれを示す。

### 1.2 v3: CFD 抽出 (`metrics/deltastar.py::deltastar_from_run`) + 合成 (`build_dstar_v3_*.py`)

- 各 $x$ ステーションで壁から半径方向に $\rho U_x$ を線形補間し、**縁 = 壁から見て初めて $0.995 \max(\rho U_x)$ に達する $y$**。
  欠損を軸対称質量収支で積分: $\delta^*(1-\delta^*/2r_w) = \int_0^{y_e}(1-\rho u/(\rho u)_e)(1-y/r_w)\,dy$ (2026-09-01 導入。導出は §3.1 で再確認、正しい)。
- **コアが半径方向に非一様な区間 ($\rho U_x$ の極大が境界層縁でなく軸側にある区間) では縁判定が破綻**するため、
  信頼下限 $x_{lo}$ を case ごとに手で決めている (case/44: 3、M5: 12、M6: 14)。
- 合成 (v3 CSV): $x \in [x_{lo}, x_{hi,trust}]$ は抽出値の平滑化スプライン (λ=1e-2)、
  **$x < x_{lo}$ は相関 × (抽出/相関 比 at $x_{lo}$)**、$x > x_{hi}$ は端勾配の線形外挿、全域を再平滑化 (λ=1e-3)、負値クリップ。
- 固定点確認 (「2 巡目比 median 1.00」) は**抽出できた $x \ge x_{lo}$ の範囲だけ**で取っている。

## 2. 現状の δ\* の与え方 (幾何)

`geometry/wall_axismach.py::PhysicalNozzleWall` (A13):

1. 非粘性設計壁 (MOC C⁺ 壁点を補間する 5 次 B-spline + 上流 Hermite) を $x \in [x_{in}, x_F]$ で 3000 点サンプル。
2. $x \ge -0.8$ の各点を **壁法線方向に δ\*(x) だけオフセット**: $x_W = x - \delta^*\sin\theta_w$, $r_W = r + \delta^*\cos\theta_w$。
3. オフセット点群から**真の幾何スロート** ($r_W'=0$) を平滑化スプラインの根で探索し、曲率は $r-r_t=\frac{\kappa}{2}(x-x_t)^2$ の 1 パラメータ LSQ。
4. 下流: 新スロートを $(r'=0, r''=\kappa)$ でクランプした**補間** 5 次 B-spline (オフセット点をそのまま通す。多項式近似ではない)。
   上流: 入口 → 新スロートの 5 次 Hermite を作り直し (C² 接合)。
5. メッシュ (`meshing/mesh2d.py::generate_axisym_mesh`) は**このスプライン $r(x)$ を $n_i$ 点でサンプルして生成**する。
   つまり「メッシュ点を動かす」のではなく「壁曲線を作り直してメッシュを切り直す」方式。

ユーザの問いへの直接回答:

- **多項式近似か?** → 壁は補間スプライン (近似なし)。**δ\*(x) 側は平滑化スプライン** (v3) または相関の補間 (v1)。
- **メッシュ点を動かしているか?** → 動かしていない。曲線を作ってからメッシュ生成。
- **スロート径を動かしているか?** → 動かしている ($r_{t,W} = 1 + \delta^*_t$、M6 で +1.1〜2.0 %)。方針は正しいが**等価帳簿に対して量が過大** (§4)。

細部の不整合 (影響は小さいが無料で直せる):

- **オフセット方向と抽出方向の不一致**: 抽出は $x$ 一定線 (半径方向) で δ\*$_{rad}$ を測るが、オフセットは法線方向に同じ値を使う。
  半径方向の変位は $\delta^*/\cos\theta_w$ になるので固定点でも $1/\cos\theta_w - 1$ (θ 16〜20° で 4〜6 %) の系統誤差が膨張部に残る
  (δ\* 0.03 の 5 % = 0.0015 $r_t$ — スロートの等価補正量と同じ桁)。
- `prepare_info.json` の `throat_physical.dstar_throat` は v3 でも**相関値**を書いている (実際に使った値は `r-1`)。帳簿の誤記。

## 3. 「排除厚さの計算方法」自体の検算

### 3.1 軸対称の定義 (正しい)

非粘性コアが半径 $r_{inv}$ を流れる質量と、実流が物理壁 $r_w = r_{inv}+\delta^*$ の中を流れる質量が等しい条件は
$\pi r_{inv}^2 (\rho u)_e = \pi (\rho u)_e\,[r_w^2 - 2 r_w I]$, $I=\int_0^{y_e}(1-\rho u/(\rho u)_e)(1-y/r_w)dy$ で、
整理すると $\delta^*(1-\delta^*/2r_w) = I$。実装と一致する。

### 3.2 破綻するのは「縁」の判定と「相関で埋めた区間」

- $\rho U_x$ 最大縁は、$\rho u$ が $M=1$ で極大なので**壁側のほうが軸より低 M の膨張部** (M6 で $x$=14〜40、$q_{axis}/q_{max}$ = 0.5〜0.8) では
  境界層縁と一致するが、**コアが一様に近い近スロート** ($x \lesssim 8$、$q_{axis}/q_{max}$≈1)
  では極大が軸に来て $y_e \sim r_w$ となり無意味な値 (0.07〜0.22) を返す。これが $x_{lo}$ の正体。
- 近スロートの局所 δ\* は現行抽出器では未確定である。熱境界層を質量流束境界層の縁へ流用する方式は採らない。
- 根治には、対応する Euler 場または局所外部流の外挿値を inviscid-core 基準として使い、コアの半径方向勾配と壁面の質量欠損を分離する必要がある。

## 4. 実測: 与えたスロート補正は質量流量の等価帳簿に対して過大

### 4.1 質量流量による有効スロート (縁判定に依らない等価帳簿)

同一設計 (同一 $r_t$・$x_E$・$M_d$・ガス) の **Euler run (設計壁)** と **NS run (物理壁)** の質量流量比
$\dot m_{NS}/\dot m_E$ は、有効音速スロート面積の比に等しい。NS の物理スロート幾何面積は $r_{t,W}^2$ なので、
$C_{d,rel} = (\dot m_{NS}/\dot m_E)/r_{t,W}^2$ が「幾何スロートに対して境界層が塞いだ割合」、
$\delta^*_{t,eq} = r_{t,W} - \sqrt{\dot m_{NS}/\dot m_E}$ を、Euler と同じ質量流量へ戻すための**等価スロート補正量**と定義する。
これは Euler/NS の遷音速流量係数が同じという一次近似を含み、局所プロファイルの排除厚と厳密に同じ量ではない。
質量流量は構造格子の各 $x$ 一定列で $2\pi\int \rho U_x\, r\,dr$ を台形積分 (列間ばらつき 1e-4、保存)。
最終 `res_*.h5` を使用。$\Delta M/M$ 推定は $-(\dot m_{NS}/\dot m_E - 1)/n$、$n = d\ln(A/A^*)/d\ln M$ (γ=1.3: M4.2 で 4.6、M5 で 5.1、M6 で 5.5)。

### 4.2 近スロートの局所 δ\* は未確定

近スロートでは $\rho U_x$ 最大縁が軸側へ飛ぶため、現行のプロファイル抽出から局所 δ\* の真値は決められない。
任意に選んだ積分上限までの累積値は、非一様な inviscid core の半径方向勾配を欠損へ混入するため採用しない。
本ノートで確定しているのは §4.1 の**質量流量に基づく等価スロート補正量**であり、局所排除厚との一致は未検証である。

### 4.3 残差の構造とのつながり

質量流量の等価帳簿では M6 v3 のスロート補正が約 +0.010 $r_t$ 過大で、有効スロート面積は約 +2 % である。
1D では試験部 M の −0.35 % に相当し、`run_0004` の残差の大きさ・符号と整合する。
ただし $x<x_{lo}$ の局所 δ\*(x) は未確定なので、誤差輪郭がどの区間で閉じるか、弱い圧縮波をどこで作るかまでは断定しない。$x_E$ で −0.74 % まで育つ分は
Euler では 0.036 % しかないので、物理壁・境界層・粘性数値設定を含む NS 側の差であり、$x_{lo}$ 以降の抽出・外挿・オフセット方向の系統誤差の重ね合わせが候補となる
(§7 の検証 run で切り分ける)。

## 6. 打ち手 (優先順)

### 6.1 即効: 質量流量による有効スロートの帳簿付けをゲートにする (実装 1 時間)

- `runner_axismach.collect` に **$\dot m_{NS}$、$\dot m_{E}$ (同設計の Euler run または 1D 理論 × Euler の $C_d$)、比、$C_{d,rel}$、δ\*$_{t,eq}$** を追加。
- ゲート: $|\dot m_{NS}/\dot m_E - 1| \le 0.3\,\%$ (→ M で 0.05 %)。破れば「δ\* 与え方の問題」であって law 側ではない、と機械的に切り分ける。
- 出口側にも同じ帳簿: $A_{eff,e} = \dot m/(\rho u)_{core}$ → δ\*$_{e,eff} = r_w - \sqrt{A_{eff,e}/\pi}$ を抽出 δ\*$_e$ と突き合わせる (抽出器の偏り検出)。

### 6.2 根治 A: inviscid core 基準で δ\*(x) を CFD 抽出する

- 対応する Euler 場、または境界層外の局所 $\rho U_x$ 分布を壁まで外挿した値を基準にし、非一様コアと壁面質量欠損を分離する。
- $x \ge x_{lo}$ では現行の $\rho U_x$ 最大縁抽出と比較し、差をゲート化する。近スロートでは単純な断面最大値を使わない。
- 既存場だけで抽出器を検証してから、直管〜$x_F$ の CSV を作る。検証が終わるまで `ratio_lo` 補完を置換しない。
- 固定点確認を全域で取る。スロートでは局所 δ\* と別に、§4.1 の等価補正量と $\dot m$ 比をゲートとして保持する。
- 実装場所: `metrics/deltastar.py` の抽出器を拡張し、`build_dstar_v3_*` を forge_design 本体 (`feedback/deltastar_cfd.py`) へ配管する (plan A12 残件)。

### 6.3 根治 B: v1 相関を運動量積分法に置換 (実装 1〜2 日)

- 第一候補は、入口から設計壁の $M_e(x)$ に沿って履歴を積分できる Sasman–Cresci 法 (圧縮性・任意圧力勾配・熱伝達・軸対称)。
  CONTUR は独自の軸対称 von Kármán 積分をスロートから開始する別方式なので、同一視せず比較基準とする。
- fully turbulent SST の初期壁を作る段階では、加速パラメータ $K=\nu u_e'/u_e^2$ は診断値に留め、再層流化を切替条件にしない。
- 役割: v1 の初期壁 (固定点までの反復回数を減らす) と、抽出不能区間のフォールバック。**較正**: case/42/44/45 の抽出 δ\*(x) に対し
  スロートを含む全域で ±30 % 以内を合格とする。
- 平板相関は廃止 (履歴なし・加速無視で、そもそも収縮部を通った境界層に適用できない)。

### 6.4 幾何: オフセット方向の整合と帳簿修正 (実装 1 時間)

- 抽出が半径方向なら**半径方向オフセット** $r_W(x) = r_{inv}(x) + \delta^*_{rad}(x)$ にする (法線オフセット + $x$ シフトをやめる)。
  真のスロート探索・上流 Hermite 再生成の機構はそのまま (量が小さくなるだけで機構は正しい)。
- `prepare_info.throat_physical.dstar_throat` を実際に使った値に修正。

### 6.5 トリムと帰還の役割整理

1. **$\dot m$ 比 ≠ 1** → スロート側の問題。6.2 で解消。残るなら「質量流量で決めるスロート較正」
   $r_{t,W} \leftarrow r_{t,W}\sqrt{\dot m_E/\dot m_{NS}}$ (測れる量で、しかも誤差のある場所を直すスカラー。輪郭・出口径は不変)。
2. **$\dot m$ 比 = 1 なのに試験部 M が一様にずれる** → 出口側 δ\* (抽出偏り or SST モデル)。6.1 の出口帳簿で切り分け。
   SST 形式差 (dilatation ±5 % δ\* → M6 で ±0.1〜0.15 %) は設計で消せない不確かさとして仕様に明記する (実風洞は校正で吸収する量)。
3. **局所残差 ($x_E$ ディップ等)** → ここで初めて law 側帰還 (既存 `euler_loop` の凍結 C⁻ マップに NS を評価器として接続)。
   Md トリムは廃止。

## 8. Codex レビュー結果 (2026-09-04)

1. §4.1 は**等価面積ゲートとして採用**。局所 δ\* との厳密な同一性は主張しない。曲率差による Hall $C_d$ の差は 0.3 % ゲートより小さい。
2. 熱境界層を質量流束境界層の縁へ流用する方式は不採用。非一様 inviscid core を基準に質量欠損を分離する。
3. 保存量は半径方向補正 $\Delta r(x)$ に統一する。法線 δ\* を出す積分法は $\Delta r=\delta_n^*/\cos\theta_w$ へ変換する。
4. Hall は非粘性の有効スロート基準のまま維持する。質量流量に加え、有効スロート位置・曲率・sonic line・コア全圧損失をゲートにする。
5. v1 の第一候補は入口から履歴を積分できる Sasman–Cresci。CONTUR は別方式なので同一視しない。fully turbulent SST との比較中は再層流化を切替条件にせず診断値に留める。
