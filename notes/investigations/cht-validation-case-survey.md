# CHT の一次適用先 — 公知試験データの棚卸し (2026-09-19)

- **目的**: [`plans/active/boundary-conjugate-heat-transfer.md`](../../plans/active/boundary-conjugate-heat-transfer.md) §8-1
  「一次の適用先をどれにするか」を、**ユーザ指示 (2026-09-19)「公知文献の試験結果があるもの」**に沿って決めるための調査。
- **結論 (ユーザ指示「超音速系だとなお良い」2026-09-19 を反映)**: 一次適用先は
  **NASA CR-168015 (Hylton et al. 1983 / NTRS 19830020105) のタービン翼**。
  **主 = Mark II 翼 case 5411 (= run 42, 出口 $M_2$=1.04, 超音速出口)**、**従 = C3X 翼 case 4411 (= run 108, 出口 $M_2$=0.90, 亜音速出口)** を先行の足場にする (run 番号と $M_2$ は codex が報告の表 VIII・IX で確認。一次資料で再確認する)。報告自身のデータ整理も **2D 伝導 FEM** を使っている。
  同一報告・同一の固体モデル配管で両方が回せるのが決め手。極超音速側は**公知の「共役」試験が乏しい**ため、
  壁温を実測値で与える (`wallProfile`) 形の**流体側検証**として扱う (§4 の分解)。

## 1. 「CHT の検証」に要る条件

| 条件 | 意味 |
| --- | --- |
| (a) 固体の熱境界条件が公開されている | 材料・厚さ・$k_s(T)$・背面 (冷却孔・冷却剤・断熱) の条件が数値で分かる |
| (b) **壁温が結果として測られている** | $T_w$ が「与件」でなく「解」。ここが無いと連成の検証にならない |
| (c) 流体側の条件が閉じている | 入口・出口・乱流状態が再構成できる |
| (d) 入手可能 | 一次資料が公開されている |

**(b) が効く**。極超音速の熱伝達試験の大半は薄肉過渡カロリメトリか冷却壁で、$T_w$ は与件か測定値として
**境界条件に使う**側であり、固体を解いて当てにいく対象ではない。

## 3. C3X を採るときの既知の注意 (検証設計に効く)

1. **固体は薄肉シェルではない**。翼内部に冷却孔を持つ**厚い 2 次元固体**なので、
   plan §4.4 の `shell2d` では表現できない → **外部連成 (Phase 1) の固体バックエンドに一般 2D 領域 (`fem2d`) が要る**。
   これは plan の構成を変える指摘なので §4.4 / §4.5 / §5.1 に反映した。
2. **入力不確かさは内部 HTC だけではない**。報告 p.21 は内部 HTC を**入口助走補正つき相関**で与え、
   **計測断面の冷却剤温度は入口・出口実測からの推定**。さらに表 VII の**温度比不確かさは ±2 %** で別項目。
   → 帯は項目ごとに積み、**計算前に登録**して合うまで広げない (plan §4.9-2, §6 V5)。
3. 翼列なので**周期境界**が要る (node の周期は既知の修正済み不具合あり — [[node-periodic-volume-source-doubling]] 等)。
4. 超音速出口 (Mark II 5411) は衝撃 × 境界層 × 熱伝達が絡み乱流モデル依存が大きいので、
   **C3X (亜音速出口) → Mark II 4411 (亜音速出口) → Mark II 5411 (超音速出口)** の順に上げる。
   4411 と 5411 は入口条件がほぼ同じなので、**出口マッハだけを変えた対**として使える (= 衝撃の効果を単独で見られる)。

## 4. 検証の分解 (この調査の主結論)

CHT の誤差は **流体側の $q_w$ 予測誤差** と **連成 (界面 + 固体) の誤差** の和である。公知データの都合が
両者で違うので、**分けて当てる**:

- **流体側 (高速・我々の regime)**: 壁温を**実測値で与えて** ($\to$ `wallProfile`) $q_w$ を当てる。
  データは親 plan のサーベイ ([hypersonic-gap-cavity-heating-survey](hypersonic-gap-cavity-heating-survey.md)) と case/48。
- **連成側**: **C3X / Mark II** で $T_w$ を当てる (固体条件が公開されている)。
- 両方が通って初めて、極超音速すきま (case/49, case/51) の CHT 予測に誤差幅を付けて渡せる。
