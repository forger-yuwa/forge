(codex plan M2 / result M2 / result-2 M1・M2)。**2026-09-22 改訂**: 初版は熱伝導だけを測り、しかも「壁面熱流束が 2 次」を

## 何を測ったか

ソルバ本体は製造解のソース項を入れられないので、内部面の式は
[`solver_density_cuda/tools/node_visc_face.py`](../../solver_density_cuda/tools/node_visc_face.py) の `visc_face()` を使う。
`viscousFlux_d.cu` の既定経路 (over-relaxed 法線項 + 面平均勾配の補正 + 転置項 + 発散項、粘性仕事 $\tau\cdot U_f$、熱伝導) を写したもので、
**実機の場に当てるとカーネルが積んだ値を再現する**: `case/53.c3x_vane_cht/run_0121_resid_split/lvl2` (旧バイナリ = 旧式の `fx`) の
480 壁節点で、熱伝導の差 rms **0.28 W/m²** (152 kW/m² 中)、粘性仕事の差 **0.00 W/m²** (3.1 kW/m² 中)。重みを射影や 0.5 に替えると
仕事項は 2.0 kW/m² ずれる = 照合は重みの違いを見分けている。

解いた問題 ([`mms_face_weight.py`](../../solver_density_cuda/tools/mms_face_weight.py)):

- 定常の熱 $-\nabla\cdot(k(T)\nabla T)=s_T$ と運動量 $-\nabla\cdot\tau(u)=s_u$ (2 成分、$\mu(T)$ 可変)。ソースは各双対面の厳密流束の Gauss 求積。
  補正項・転置項・発散項に入る節点勾配は解析値 (重みの効果だけを切り出す)。
- **格子**: 半径 0.2 m の円環の 15°–30° の扇形 (旧式の回転非不変が最大になる 22.5° が中心)。最粗で第一層 2 µm・壁沿い 0.69 mm (AR 350)、
  壁法線方向は等比 (成長率 **1.1 / 1.2**)、**壁沿い間隔に滑らかな変調 ±30 % と節点ごとの交番 ±0.3 %**。
  半径は「弦のたるみ / 第一層の半分」が最粗で 0.3 (実機 C3X は 0.1–1) になるように選んだ。初版の半径 0.05 m では
  たるみ (4.9 µm) が第一層 (2 µm) を超え、双対面が解析解の壁の内側に入って粘性仕事の厳密値の符号が反転していた。
- **細分化**: 両方向 2 倍、第一層 1/2、成長率は平方根。4 水準 (最細 609 × 520)。
- **製造解**: 温度・接線速度とも $1-e^{-s/\delta}$ ($\delta$ = 50 µm) に周方向の変調、法線速度も持たせた。

## 結果

生の表は [`2026-09-22-mms-node-face-weight.out.txt`](2026-09-22-mms-node-face-weight.out.txt)。成長率 1.1 と 1.2 で同じ傾向なので 1.1 を示す。
$p$ は隣り合う 2 水準の誤差比の $\log_2$ (水準 0→1 / 1→2 / 2→3)。

| 量 | `half` (0.5、現行) | `proj` (正しい射影) | `code` (旧式) |
| --- | --- | --- | --- |
| 壁の面での重みの範囲 (最粗 → 最細) | 0.500 | 0.58–0.77 → 0.51–0.53 | 0.37–0.83 → **0.34–0.69 (0.5 に寄らない)** |
| 温度の誤差 $p$ | 2.02 / 2.01 / **2.00** | 2.01 / 2.01 / 2.00 (誤差は half の 1.27 倍) | 1.81 / 1.82 / 1.92 (1.58 倍) |
| 速度の誤差 $p$ | 2.02 / 2.01 / **2.00** | 2.02 / 2.01 / 2.00 (1.25 倍) | 1.83 / 1.84 / 1.93 (1.51 倍) |
| 壁 CV に入る**熱伝導**の誤差 $p$ (最細の相対誤差) | 1.72 / 1.48 / 1.13 (1.8e−6) | 1.71 / 1.54 / 1.26 (2.0e−6) | 0.24 / −0.19 / −0.02 (**6.5e−5 で収束しない**) |
| 壁 CV に入る**粘性仕事**の誤差 $p$ (最粗 → 最細の相対誤差) | 1.33 / 1.07 / 1.05 (31 % → **2.9 %**) | 1.27 / 1.05 / 1.04 (16 % → **1.6 %**) | 0.22 / 0.10 / 0.11 (**33 % → 25 %、収束しない**) |
| 2 点差分の壁面熱流束・壁せん断の、**解析的な壁面値**に対する誤差 $p$ | 0.75 / 0.96 / 0.96 | 0.66 / 0.92 / 0.94 | 0.75 / 0.95 / 0.96 |
| 同じ 2 点差分を厳密温度に当てた値に対する誤差 $p$ (離散どうし) | 2.01 / 2.01 / 2.00 | 2.00 / 2.00 / 2.00 | 1.69 / 1.57 / 1.65 |

読み取れること:

1. **旧式は不整合**。壁 CV に入る粘性仕事の誤差が格子を細かくしても 25–33 % から動かない。重みが 0.5 に寄らない
   (節点ごとの交番による面重心の接線ずれは $h$ に比例して第一層と同じ率でしか縮まず、旧式はそれを重みに漏らす) ためで、
   実機の `q_eff` のうねり (粘性仕事の 14–30 % の変調) と同じ大きさ。節点値の次数も 1.8–1.9 に落ちる。
2. **`fx=0.5` の節点値 (温度・速度) は 2 次** ($p$ = 2.00、成長率 1.1 / 1.2 とも)。plan の要求 $p\ge1.8$ を満たす。
3. **壁 CV に入る流束は `fx=0.5` でも 1 次**。粘性仕事は最粗で 31 % の誤差がある。原因は幾何で、双対面の面積重心は
   弦のたるみの分だけ辺の中点より壁側にあり、そこでの速度は辺中点の値 $U_1/2$ より小さい。誤差は
   (たるみ / 第一層の半分) に比例し、これは $h$ に比例して消える。**射影の重みはこの沈みを拾うので、この項に限れば誤差が半分**
   (16 %)。ただし節点値の誤差は 1.25 倍になり、実機のようにたるみが第一層と同程度の格子では重みが 0.03–1.00 に振れるので採らない。
4. **`q_eff` への影響の見積り**。粘性仕事は `q_eff` の 2.8 % (C3X、第一層 2 µm) なので、その 30 % の過大評価は `q_eff` を
   **+0.8 % 程度**押し上げる (たるみ / 第一層の半分 = 0.3 の場合。C3X の前縁のように 1 に近い所ではもっと大きい)。
   第一層を 1 µm にすると仕事項自体が半分になる (実測 2.81 → 1.42 %)。
5. 2 点差分の壁面熱流束・壁せん断 (`iface_q_compact`・SU2 の `Heat_Flux` と同じ作り) は、**重みに関係なく 1 次** ($p\approx0.95$)。
   差分式そのものの打切り誤差 ($h/2\delta$) が支配する。

## 限界

- SST の $k$/$\omega$ 拡散、化学種拡散は測っていない (同じ `fx` と同形の法線項)。
- 実カーネルそのものを呼んではいない。担保は上の「実機の場での照合」で、`fx` 以外の式が同じであることを示す。
- 節点勾配に解析値を使っている。ソルバの LSQ 勾配の誤差は入っていない。対流・リミッタ・float32 も入っていない (倍精度)。
