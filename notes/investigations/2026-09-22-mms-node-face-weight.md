# node 拡散演算子の収束次数と面補間重み `fx` — 製造解による測定 (2026-09-22)

plan [`discretization-node-face-weight-midpoint.md`](../../plans/active/discretization-node-face-weight-midpoint.md) §5.1 #7
(codex plan M2 / result M2「辺中点の値補間が 2 次であることと、伸長格子上の解が 2 次であることは別。格子系列で測ること」)。

## 何を測ったか

ソルバ本体は製造解のソース項を入れられないので、`viscousFlux_d.cu` の**内部面の熱伝導の式**

$$F = k_f\Big[\frac{T_B-T_A}{|d|}\,\delta + g_f\cdot(S-\delta\,\hat d)\Big],\quad \delta=\frac{|d||S|^2}{d\cdot S},\quad
k_f = f k_A+(1-f)k_B,\quad g_f = f g_A+(1-f)g_B$$

を同じ形で Python に写し ([`solver_density_cuda/tools/mms_face_weight.py`](../../solver_density_cuda/tools/mms_face_weight.py))、
median-dual の双対メッシュ上で定常問題 $-\nabla\cdot(k(T)\nabla T)=s$ を解いた。

- **格子**: 円環 (内径 0.05 m = 曲面壁、壁の向きは全方位)。最粗で第一層 2 µm・壁沿い 225 節点 (AR ≈ 700)、壁法線方向は等比
  (成長率 **1.1 / 1.2**)。壁沿い間隔に**滑らかな変調 ±30 % と節点ごとの交番 ±0.3 %** を入れた (面重心の接線ずれを作る。
  これが無いと旧式の回転非不変は現れない)。
- **細分化**: 両方向 2 倍、第一層 1/2、**成長率は平方根** (層の物理的な厚さ分布を保つ)。4 水準 (最細 1800 × 520)。
- **製造解**: $T=T_w+\Delta T\,(1-e^{-(r-r_{in})/\delta_T})(1+0.2\cos3\theta)$、$\delta_T$ = 50 µm (壁の温度境界層)、
  $k=0.04\,(T/T_w)^{0.75}$。ソースは各双対面の厳密流束の Gauss 求積から作る (ソースの求積誤差を入れない)。
  勾配 $g$ は解析値 (重みの効果だけを切り出すため)。
- **比べた重み**: `half` = 0.5 (現行)、`code` = 旧実装の式 $\|n\odot\Delta\|$、`proj` = 正しい射影 $|n\cdot\Delta|$。

## 結果

観測次数 $p$ (隣り合う 2 水準の誤差比の $\log_2$)。生の表は [`2026-09-22-mms-node-face-weight.out.txt`](2026-09-22-mms-node-face-weight.out.txt)、
図は `fig/mms_face_weight.png` (追跡外)。

| 成長率 | 重み | $T$ の L2 誤差の $p$ (水準 0→1 / 1→2 / 2→3) | 壁面勾配流束の相対誤差の $p$ | 最細水準の壁面流束誤差 |
| --- | --- | --- | --- | --- |
| 1.1 | **half** | 2.04 / 2.01 / **2.00** | 2.02 / 2.01 / **2.00** | 8.39e−4 |
| 1.1 | proj | 1.95 / 1.90 / 1.95 | 1.94 / 1.80 / **1.69** | 1.28e−3 |
| 1.1 | code | 1.99 / 1.93 / 1.96 | 1.98 / 1.89 / **1.86** | 1.05e−3 |
| 1.2 | **half** | 2.05 / 2.01 / **2.00** | 2.02 / 2.01 / **2.00** | 8.39e−4 |
| 1.2 | proj | 1.96 / 1.92 / 1.97 | 1.95 / 1.80 / **1.68** | 1.28e−3 |
| 1.2 | code | 1.98 / 1.93 / 1.97 | 1.98 / 1.89 / **1.85** | 1.05e−3 |

- **`fx=0.5` は温度 (L2・L∞) も壁面熱流束も $p=2.00$**。成長率 1.1 と 1.2 で同じ。plan の要求 $p\ge1.8$ を満たす。
- **幾何重みは壁面熱流束の次数を落とす** (射影で 1.69、旧式で 1.86)。滑らかな変調と弦のたるみによるずれは $h^2$ で縮むので第一層厚 ($\propto h$) との比は消えるが、**節点ごとの交番 (相対振幅一定 = 実機の格子生成器の性質) による接線ずれは $h$ に比例して第一層厚と同じ率でしか縮まず、$f-0.5$ が細分化しても残る**。そのため
  $k_f$ を辺中点以外で評価する 1 次の成分が残る。最細水準の誤差は 0.5 比で +25 % (旧式) / +53 % (射影)。
- 「射影に直せば済む」ではないことの裏付けでもある (射影のほうが旧式より悪い)。

## 限界 (ここから言えないこと)

- 写したのは**熱伝導の内部面の式だけ**。運動量の粘性応力・粘性仕事 $\tau\cdot U_f$・SST の拡散は測っていない
  (同じ `fx` と同じ形の over-relaxed 法線項を使うので同じ性質が期待されるが、測定はしていない)。
- Python の写しであってソルバ本体の出力ではない。写しの忠実度は、同じ式の粘性仕事項を実機の場で再構成して
  カーネルの値と 0.0 W/m² で一致させた [`case/53.c3x_vane_cht/tools/wallcv_flux_terms.py`](../../case/53.c3x_vane_cht/tools/wallcv_flux_terms.py) が根拠。
- 線形に近い定常拡散問題。対流との連成・リミッタ・float32 の丸めは入っていない (倍精度)。
