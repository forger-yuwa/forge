## 2. q_FP (すきま加熱の分母) はどこから来たか

- **層流**: TP-1187 自身の小型校正パネル (Fig 1、0.05 cm 304SS、熱電対 35 点) で**実測**。Table I の 3 run のみ。
  理論 (Eckert 系) は実測より約 10 % 高い (Fig 10(a))。
- **乱流**: **TP-1187 では測っていない**。「flat-plate heating rates in a turbulent boundary layer were obtained from the
  experimental data of reference 5 at the location of the thin-wall tile centers」(p.8)。ref.5 = TN D-7275 の大型校正パネル
  (108 × 152 cm、Hastelloy X 0.318 cm、熱電対 59 点)。Fig 10(b) の実線は「interpolated experiment」。
- **状況証拠**: run 8 (Tt 1867 K) と run 14 (Tt 1901 K) の q_FP が**同じ 63.44 kW/m²**、α 7.2–7.6° の 6 run が同じ 62.99、
  α 7.5° の高 Pt 2 run が同じ 127.79。D-7275 Fig 22(b) の**平均加熱率の carpet plot** (Tt = 1900 K、Pt と α の 2 変数) で
  α≈0°・Pt≈17 MPa は約 65、α 7.5°・Pt 6.8 MPa は約 60、α 7.5°・Pt 17 MPa は約 125 kW/m² と読め、表の値と整合する。
  **乱流 q_FP は「パネル平均の carpet plot を Pt と α で内挿した値」である可能性が高い** (Tt の違いは反映されていない)。
  パネル上の乱流加熱は流れ方向に約 15 % 下がる (D-7275 p.13) ので、平均値と位置 II の局所値は同じではない。
  → 「位置 II で q_FP を再現する」という今の Gate B の立て方自体が、分母の素性と合っていない。

## 3. 実験自身が理論とどれだけ違うか

- D-7275: 乱流の中心線スタントン数は**Eckert 参照温度法より一貫して 10–30 % 低い**。「Tw/Tt ≈ 0.2 の冷壁では予想どおり」
  (ref.13 = Cary, TN D-5863)。Fig 19 (p.55)。
- forge の 2D 平板は Eckert 参照温度法と 1–2 % で一致し、実測 q_FP より +19 / +22 % 高い (case/56 README Gate B)。
  **forge は理論側に乗っており、実験は理論の 10–30 % 下にある**、という構図。forge 固有の誤差とは言えないが、
  forge (SST) が冷壁の実験を再現できていないとも言える。どちらかを決めるには局所の実測分布と比べる必要がある。

- **D-7275 が根拠に挙げた ref.13 = Cary, NASA TN D-5863 (1970)** を入手して読んだ (`papers/gap_heating/`、NTRS 19700022486)。
  Langley 20-inch M6 の鋭い前縁平板を内部冷却し、**同じ風洞・同じ模型で Tw/Tt を 0.19–0.70 に振った**乱流熱伝達。結論:
  (i) 熱伝達係数は冷却でほとんど変わらない、(ii) **低い Tw/Tt では Van Driest 法と参照温度 (T') 法が熱伝達を大きく過大評価**、
  (iii) Spalding–Chi 法が水準と傾向を最もよく予測 (ただし仮想原点を遷移末端の加熱ピークに置き、修正 Kármán のレイノルズ類推を使った場合)。
  → 「冷壁では実験が Eckert より低い」は D-7275 だけの癖ではなく、当時の Langley の別データでも見えていた。
  forge (低 Re SST) は冷却平板で理論側に乗る: case/48 (M4.19、Tw/Taw 0.26) で C_f / Van Driest II = 0.97–0.99 (2St/C_f 1.16)、
  case/56 の 2D 平板 (M7) で q_w が Eckert 参照温度法と 1–2 %。したがって **forge も D-7275・Cary の実測に対して同じ向きに過大になると予想される**。
  これが SST の冷壁での限界なのか、当時の測定・自由流還元に共通の系統誤差なのかは、この 2 本だけでは決められない。
  Cary は Tw/Tt を同一条件で振っているので、forge で**冷却に対する傾向**を比べれば両者を分けられる可能性がある。

## 4. 境界層の状態 (乱流 run 8/14 は本当に完全乱流か)

- D-7275 (フェンス付き・0.24 cm トリップ): **α = 0° では Re∞ 2.0 と 3.3 × 10⁶/m で遷移的**、4.9 × 10⁶/m で乱流 (p.12、Fig 19(a))。
  「低い Re ではより大きなトリップが要る」(p.13)。Table IV に α・Re ごとの必要トリップ径。
- TP-1187 run 8/14 は **α 0.2°・Re∞ 4.26 / 4.33 × 10⁶/m** で、D-7275 の 3.3 (遷移) と 4.9 (乱流) の**間**。
  TP-1187 p.8 は「ref.5 は 6.8 ≤ Pt,c ≤ 17.3 MPa、0° ≤ α ≤ 15° で全面一様乱流を示した」と書くが、D-7275 本文の記述とは食い違う。
- さらに Fig 19(a) の Re 4.9 の α = 0° のデータは、パネル前方で遷移の行き過ぎ (overshoot) のような山を持ち、下流で下がっている。
  位置 II がこの山の裾にかかっているかは、局所 Re を計算して確かめる必要がある (未確認)。
- p.9 の「位置 II は遷移的」は**層流を狙った鈍い前縁の条件**の話 (位置 II の層流データが無い理由) であって、乱流 run の話ではない。

- D-7275 Table II では同じ運転範囲で M∞ = 6.0–7.0 (多くは 6.6–6.9)。**case/56 の Gate A が固定した M = 7 は、この施設の実際の M とずれている可能性が高い**。
- ただし q∞ と Tt を固定して M を 7 → 6.64 に変えても U∞ は −0.6 %、ρU は同じなので、**冷壁 q_FP への効きは小さい** (Re∞ と δ* には効く)。
  +20 % の説明にはならない。

## 6. すきま部で読み落としていたこと

- **回帰式は外れ値を捨てて作っている**: 乱流は 51 観測のうち 27 だけを残した (p.13)。式 (3)/(4) を参照値として使うときはこの点を割り引く。
- 縦すきまに沿った**周期的な加熱パターン** (Langley/Ames の未発表結果、長さ 15–84 cm) があり、衝突加熱の L 依存のばらつきはこれかもしれない、と原報自身が書く (p.11)。
- 乱流 90° の衝突域の等値線は 3 次元で、影響範囲は少なくとも 3 すきま幅 (p.10)。

## 7. CFD で再現を試みる順番 (提案。plan への反映は上位への諮問後)

1. **D-7275 の大型校正パネル (乱流)**: 試験 26 (α 0°、Pt 18 MPa) と試験 25/27/28 (α 0/5/10°)。
   中心線のスタントン数分布 (Fig 17/19) と局所条件 (Table III) がある。**分母そのものの出所を直接再現する**。
   鋭い前縁 + 12.7 cm のトリップをどう扱うか (遷移位置の指定) を決める必要がある。
2. **TP-1187 の小型校正パネル (層流)**: Table I の 3 run、Fig 10(a)。乱流モデルを含まないので、自由流の再構成と
   鈍い前縁 (エントロピー層で近壁 M が半分近くに下がる、D-7275 p.14) の扱いを先に確かめられる。
3. 1 と 2 が合ってから、すきま (位置 II、90°) に戻る。

## 9. 試験形状と解析形状の監査 (2026-09-29、ユーザ依頼)

ページ: https://claude.ai/artifact/QyjKuSUGzbZjm7w8afhsQ5 (非公開)。TP-1187 Fig 2・4・5・6 と本文から読んだこと:

- **2 つの配列を同時に取り付けている** (Fig 6): 前縁から 117 cm (位置 I) に 60°/75° 配列、188 cm (位置 II) に 90° 配列が一直線。どちらも 46 × 48 × 6.35 cm。**1 回の run で両方を測る** (Table II に位置 I・II の θ・δ*・q_FP が並ぶ)。run 8 と 14 は位置 II が 90°、位置 I が 60° と 75°。
- 配列は流れ方向 15.24 cm の列が 3 つの煉瓦積み。計測タイル 2 枚は最下流の列で、2 列目の縦すきまの正面を塞ぐ。**一方は 2 列目だけの縦すきま (L = 15.24)、もう一方は 1・2 列目の縦すきまが一直線 (L = 30.48、途中で 1・2 列目の間の横すきまと十字に交差し、上流端は配列の前端)** — Fig 6 の拡大と Fig 2 の下側の「L」矢印から (読み取り ±1 cm)。
- 全タイルの全縁に半径 0.25 cm。配列は保持具の凹みに収まり、下流端に filler bar (Fig 2 側面図)。タイルは長穴付きの板で位置調整してすきま幅を作る。
- 「斜めに切った形状」= 60°/75° の薄板タイル (Fig 4、台形断面で両端が 60° と 75°)。斜めなのは計測タイルの前面だけで、位置 I の配列。今の 3D 解析は位置 II の 90° だけ。

解析との照合: **L15 側の配置は試験と一致** (上流端が横すきまに開く・下流縦すきまが半ピッチ)。違うのは (1) 縦すきまの口の丸み (解析は鋭い角 — 取り込み過小の向き)、(2) **L30 側の形** (解析は 30.48 cm の一続きの溝、上流端を横すきまへ開く — 試験と違う)、(3) 配列が有限で保持具の凹みに収まる (解析は半ピッチの無限繰り返し、L15 の隣は実際には L30 の縦すきま)、(4) 近づく境界層 (位置 I の配列と上流列を越える)、(5) すきま幅の実寸、(6) 下流縦すきまの打ち切り、(7) 壁温・投入過渡、(8) 境界層の状態・M。配列外周のすきまの開閉は不明。


### 9.1 配列外周の境目と板の下 — 同じ著者・同じ装置の報告からの傍証 (2026-09-30)

- **TP-1187 本体**: 「全タイルを長穴付きの 0.32 cm ステンレス板に取り付けた」(p.5 相当) まで。**シールの記述は無い**。外周の境目の幅・開閉も書いていない。
- **後続 (同じ Avery、同じ 8-ft HTT、同じ保持具、同じ作り方の金属タイル配列)**:
  - TM-84654 (Avery・Kerr・Wieting 1983、NTRS 19830014276)
  - TP-2307 (Avery 1985、NTRS 19850026038)
  - 両方に「All the tiles were bolted to a 0.13-in-thick stainless-steel plate **and sealed to prevent flow under the tiles**. Slotted bolt holes permitted adjustments …」とある。
  - → 同じ研究室の同じ作り方では、**板の下へ回る流れは意図して塞いでいた**。TP-1187 でも同様だった可能性が高い。ただし傍証であり、TP-1187 の記述ではない。
- **先行の TM X-3225** (Weinstein・Avery・Chapman 1975、M 6.6、同じ保持具):
  - 「共通の支持板に取り付け、長穴で幅を調整」とだけあり、シールの記述は無い。
  - 配列の端 (carrier) の近くでは千鳥配置が流れを堰き止めて加熱が下がる、という記述がある (p.11)。配列の端の効果は当時から認識されていた。
- **まだ分からないこと**: 外周の境目の**上面側** (タイル上面と同じ高さでの幅・開閉) は、どの報告にも書いていない。境目が上面で開いていても、板の下が塞がれていれば、すきまの網を「通り抜ける」経路は境目の中だけに限られる (境目が L30 の前端・横すきまの両端とつながる)。
- **TP-1187 を CFD などで逆解析・再現した文献**: 2026-09-30 に再検索 (NTRS・一般 Web) したが見つからなかった。§5 の survey (2026-09-26) の結論は変わらない。被引用索引 (Scopus/WoS) は未確認。
