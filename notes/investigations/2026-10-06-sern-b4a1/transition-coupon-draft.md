## 0. 要点(F に最初に見てほしいこと)

1. **3:1 テンプレート型(Schneiders 型)は、現行ゲート「実測の隣接間隔比 ≤ 1.2(全方向)」を原理的に通りません**(plan:892、plan:867)。
   - 2D の 3:1 テンプレート 1 個について、内部 2 節点の位置と層の厚さを走査しました。JM の `adjacent_spacing_check`(JM:981)と同じ定義で評価しています。
   - 結果は「最小 skew = 0.50」「skew < 0.6 の範囲での隣接比の最小値 = **1.76**」です。
   - もう一つ問題があります。等比 g で並んだ細い列を 3 本ずつまとめると、粗い側の公比は g³ になります(1.2 → 1.73)。そのため、まとめる前に分布を均す層が必ず要ります。
2. **一方、U ターン型(入れ子の C 型キャップ。「collapse」型を適合にしたもの)は、全ブロックを 4 辺の transfinite で組めます。** 現行ビルダー(JM:397 の BLK、JM:633・653)にそのまま載り、扇形が滑らかなら ≤ 1.2 を設計できる見込みです(**推測**、2D の試作で先に確認)。
   - これを **B の第一案**とし、3:1 テンプレートは「遷移シートに限ってゲートを改訂する」と F が決めた場合の代替にすることを提案します。
3. **試験片の節点数(断面 1 枚あたり、N を除いた外部)の予測**
   - A:53.5 k、4 station で 214 k。
   - B:22〜26 k(**推測**)。
   - 比 B/A = **0.41〜0.49**。「半分以下」の閾値に対して余裕は小さいです。
   - 予測の下限は約 0.35 です。理由は、固定する近傍域 9.9 k と、行 a の遠方が少なくとも 25 列 × 291 行要ることです。
4. **全体へ広げると、断面遷移だけでは 500 万に届きません。**
   - 細格子 (scale 1) の見込みは、A が約 3100 万、B が約 1700 万、x 方向の遷移も加えた B+X が約 1400 万です。
   - 壁を解像する近傍域を全 station に持つだけで約 1200 万、N だけでも約 650 万になります。
   - 規模を決めているのは「近傍域 × station 数」です。g5 で載せる(上限は本体のホスト RAM で約 500 万、plan:848 B4b-1)には、ユーザの判断が要ります。選択肢は §4 の R5 です。

## 1. 遷移パターンの候補比較

背景:現模型は「格子の全 x 位置を station にし、x 方向 1 セル幅の transfinite volume を積み重ねる」作りです(JM:16-18、JM:640-653)。つまり、断面 (y–z) の 2D 四角形メッシュを x 方向に積んだ全ヘキサです。

このため、**断面内の適合な四角形遷移は、x に積めばそのまま適合な全ヘキサになります**。3D の Schneiders テンプレートが要るのは、x 方向の遷移と断面内の遷移が交わる角だけです。

**U ターン 1 段で減る量(幾何の制約)**
- 中心の弦 n_c 本が、キャップ外周(幅 ≈ 2R)で隣の列の幅 × 1.2 以内に収まる必要があります。このため n_c ≈ 2R / w_外 は残ります。

- 折り返した 2k 本の列は、キャップの環の層(厚さ = 元の列幅)になります。

## 2. §6.6 試験片の具体設計

### 2.1 共通条件(A / B で同じ)

**位置と station**
- 区間 C(L_cowl ≤ x < L_ramp)。生産の全長 station 列(B4-4 の `SECX` 延長と同じ規則)のうち、**x/H = 3.0 に最も近い連続 4 station** を使います。HX_FAR は 0.08 H なので、およそ 3.00 / 3.08 / 3.16 / 3.24 です。
- 端面の x 細分の影響を受けず、全長の大部分を代表する位置です。
- 既存の `COUPON_X` / `COUPON_N`(JM:609-617)を全長延長と組み合わせて使います。

**外部境界**
- 下側:L1 の水平面 y_bot = −12.320694 H(plan:809 (3))。
- 側方:z_far = 2.50 H(絶対値、plan:790)。

**N は含めません(外部だけの試験片)**
- N との界面(e5 = N_SIDE|SW、e8 = N_BOT|CW1)は境界 `cut_nozzle` として、A / B で同じ節点にします。
- N を含めると A は 286 k になり、30 万にほぼ届きます。

**上側 y = y_r の扱い**
- SW の上面:`vehicle` 壁(帯)。
- z > z_o の部分:`cut_top`(壁ではない。生産では行 v との内部面)。
- 両端の x 面:`ext_in` / `outlet`。z = 0 は `symmetry`。

**分割数**:全長の値(scale 1、secxB_s1.0)を使います。
- NY 105、NZ 50、NSW 19、NTC 19、NL 30。
- NFY = **291**:HFAR 0.1 H、1D の則は §4.15 Minor の修正版(等比 1 本・実際の間隔列で上限判定)。
- NFZ = **34**:z_far 2.5 H。自分の計算で、±2 の幅があります。

**固定する節点(近壁側の界面)**:近傍域 = 行 b・c・de × 列 0・1・2 の全節点です。
- ブロックでは U1b、U2b、CW1、CW2、SW、Sb_b、Sb_c、Sb_de。
- 外縁 y0 = y_o − DR と z1 = z_o + DR も含めます。
- 行 a の y 線(291 本)と列 3 の z 線(34 本)は、B でもキャップの外では A と同じにします。

**遠方の最大間隔**:HFAR 0.1 H で固定します。0.5 H にすると A が AR 約 2800 で失格になり(plan:807)、比較の基準になりません。

## 3. 全体へ広げたときの節点数の見込み

**式**:N_total = Σ_station n_sec。n_sec は区間 C(x < L_ramp)の断面で代表させます。
- **A**:(Σ行 + 1)(Σ列 + 1) − 固体 V1・V2 の内部 − N 矩形の内部 + N_N。
  - 行は a・b・c・de・v・tb・tc、列は 0〜3。
  - N_N = NZ·NY + 2·NZ·NR + NY·NR。
- **B**:近傍域(行 b〜tb × 列 0〜2 + N)+ 列 3(y 弦 40 × NFZ)+ 行 a・tc(30 列 × NFY・NT)+ 遷移の上乗せ 10 %。
- **B+X**:B のうち遠方部分だけを、少ない station 数(80 / 100 / 120)に置いたもの。

**仮定**
- 分割数は secxB の値(scale 0.5 / 0.71 / 1 の NL・NR・NY・NZ・NSW・NTC)。
- NFY 294 / 292 / 291、NFZ 34(自分の計算)。
- NV ≈ 96 × NY / 105、NT 35(下書きの推測値をそのまま使用)。
- station 数 = secx の 206 / 253 / 296 + 上流 15 + ベースより下流 50(**推測**)= 271 / 318 / 361。

| scale | A | B(断面遷移) | B+X | 近傍域だけ | N だけ |
|---|---|---|---|---|---|
| 0.5(粗) | 1940 万 | 1030 万 | 780 万 | 670 万 | 370 万 |
| 0.71(中) | 2490 万 | 1330 万 | 1040 万 | 910 万 | 480 万 |
| 1(細) | 3130 万 | 1710 万 | 1390 万 | 1230 万 | 650 万 |

- 誤差はどれも ±30 % 程度です(**推測**)。
- A の値は、下書きの 2000〜2500 万より大きくなります。DG の指摘どおり NFY 291・NFZ 34 で数え直したためです。
- 遠方の 1D 則を「上限付き(1.15 で 0.1 H まで伸ばし、その後一様)」に変えると NFY は 291 → **132** になります。それでも B は 1 割強しか減りません(細格子 1510 万)。

**結論**
- 断面遷移と x 方向の遷移はどちらも有効です。しかし規模を決めているのは「壁を解像する近傍域 × 全 station」です(N の内部と端面の x 細分の伝播、DG の Major 1)。
- 500 万に入れる道は次の 3 つで、どれも上位・ユーザの判断です。
  - (i) N と近傍域の中で x 方向を局所化する(端面の細分を N のコアへ伝えない)。
  - (ii) 大容量 RAM のホストを使う。
  - (iii) 解像要件を緩める(h1、e5 の両端 h1 など)。

## 4. リスクと未決事項(F の判断が要る点)

- **R1 ゲートとの衝突**:3:1 テンプレートは隣接比 1.76 以上・skew 0.5 以上が避けられません。次のどちらかを試験前に決める必要があります。
  - B を U ターン型に限り、現行ゲートを据え置く(推奨)。
