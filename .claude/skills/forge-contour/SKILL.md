# /forge-contour — 場のコンタ図を描く

実体は **`solver_density_cuda/tools/plot_field_contours.py`**。自前で matplotlib を組まず、まずこれを使う。
足りない量があればツール側に足す (図ごとに別スクリプトを生やさない)。

```bash
python3 solver_density_cuda/tools/plot_field_contours.py <run>/res_N.h5 --out fig.png \
    [--pitch-cm 11.773] [--ylim -1 24] [--title "C3X run 108 — run_0107…"] [--mut-clip 50]
```

## 規約 (ユーザ指示 2026-09-21)

1. **カラーマップは全量 `turbo` に統一する** (ParaView の Turbo と同じ。matplotlib ≥ 3.3 の `cmap="turbo"`)。
   **量ごとに色を変えない。** 以前マッハ数 viridis / 圧力 plasma / μt magma / 温度 inferno と
   「雰囲気で」変えて、「どういう考えで変えているのか」と指摘された。色の違いが量の違いなのか
   値の違いなのかを読者に推測させない。ParaView で描く場合も Turbo プリセットを選ぶ。
2. **標準 4 量**: マッハ数 / 静圧 [kPa] / $\mu_t/\mu$ / 静温 [K]。この順で横に並べる。
   層流・非粘性 run で `vis_turb` が無ければ 3 量になる (ツールが自動で落とす)。
3. **周期翼列は `--pitch-cm` で 3 ピッチ並べる**。1 通路だけだと翼列として読めず、周期境界の
   斜めの切り口が形状の一部に見える。`--ylim` で全面が覆われている帯に切り詰める。
4. **$\mu_t/\mu$ は `--mut-clip` (既定 50) で頭打ち**にし、タイトルに頭打ち値と最大値を出す
   (ツールが自動で書く)。後流は境界層の 10 倍以上あるので、線形の全域目盛では境界層が黒く潰れ、
   対数目盛では自由流 (入口値 ~10) で全面が一色になる。どちらも実際に試して駄目だった。
5. **他の量は 0.2–99.8 パーセンタイルで目盛を切る** (1 節点の外れ値で全体が潰れるのを防ぐ)。
   切ったことで隠れる極値 (最大マッハ数など) は**キャプションに数値で書く** — ツールの標準出力に出る。
6. **凡例・カラーバーを図の上に重ねない**。カラーバーは各パネルの下、凡例は軸の外。
   これは線グラフでも同じ (形状重ね合わせ図で凡例がデータに被って指摘された)。

## 落とし穴

- **`MESH/CONNE` は可変長レコード** `[自分を含む語数, 節点…]` (3 角 = 4 語、4 角 = 5 語)。
  先頭 48 語が全部 `[4,i,j,k]` なので固定長 4 に見えるが、境界層の 4 角セルに入った途端に
  ずれる (`reshape(-1,4)` は例外も出さず壊れた三角形を返す)。ツールは歩いて読む。
- **未収束・非定常の場を「定常場」として 1 枚だけ見せない**。剥離して振動している run
  (例: 層流対照の遷移後) はスナップショットごとに別の絵になる。キャプションに
  「どの step の瞬時場か」と `check_quasisteady` の VERDICT を書く ([`forge-report`](../forge-report/SKILL.md))。
- **`/tmp` の作業領域は再起動で消える** (2026-09-21 に報告一式を失いかけた)。再利用する作図
  スクリプトは scratchpad でなくリポジトリ (`solver_density_cuda/tools/` か case の `tools/`) に置く。

## 報告への入れ方

各翼・各ケースの章の**冒頭**に「The field」として置き、表面分布の比較より前に見せる
(読者が流れ場の全体像を持ってから線グラフを読めるように)。図番号・run パス・step を
キャプションに入れるのは [`forge-report`](../forge-report/SKILL.md) の規約どおり。
