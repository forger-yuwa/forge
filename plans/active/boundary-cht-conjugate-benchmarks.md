## 1. 目的

forge の共役熱伝達 (`fem2d`) を、**固体の熱抵抗と固体内の軸方向 (流れ方向) 伝導が結果を左右する**条件で、
forge と独立な参照解と比べて検証する。2 つのケースを置く。

- **A. 厚肉管の共役 Graetz (軸対称)**: 管壁の外面の一部だけを一様熱流束で加熱する。熱は壁の中を軸方向にも伝わり、
  加熱区間より上流の壁とガスまで予熱する (Faghri & Sparrow 1980、Barozzi & Pagliarini 1985 の型)。
- **C. 共役平板 (平面)**: 一様流の中の有限厚さの平板。板の下面を一定温度に保ち、上面は層流境界層と熱をやり取りする (Luikov 1974 の型)。

完了時: 両ケースで界面温度・界面熱流束 (と局所 Nu) の分布が、登録した許容差内で独立参照解と合うことを run と VERDICT つきで言える状態。

## 3. 前提

- 固体の外側の境界条件は Robin (h, T_c) のみ (`solidFem2d`)。**一様熱流束 q_o は Robin で代用**する: h = 1e-4 W/m²K・T_c = T_in + q_o/h (≈1e7 K) とすると q = h(T_c − T_s) で、T_s が 20 K 変わっても熱流束のずれは 2e-6。
  Robin を置かない辺は断熱。
- 前身の知見: 強制形の等温・共役壁は細かいセルで `cfl_pseudo` 5 だと起動時に崩れる (2 で安定)。有限 M の散逸は ΔT=0 の対照 run を差し引いて扱うが、差し引きは流れの変化まで消すことを保証しない。
- FP64 ビルド・`FORGE_CUDA_BLOCKSIZE=128`・node。

## 4. 設計方針

### 4.1 独立参照解 (`tools` でなく case 側、`conjugate_ref.py`)

流速場を**解析的に与え** (A: Poiseuille、C: Blasius 相似解)、流体と固体の温度を一つの有限差分系で解く:
流体 ρc_p **u**·∇T = ∇·(k_f∇T)、固体 ∇·(k_s∇T) = 0、界面は温度と熱流束の連続 (調和平均の界面伝導)、軸方向伝導は両方に含める。
物性一定・散逸なし。格子を 2 水準以上で収束させ、その差を参照解の不確かさとする。
自己検査: (i) 固体を消すと前身の `graetz_ref.py` (ellip) と一致、(ii) 全体の熱収支 (入った熱 = 出た熱)、(iii) k_s→大で等温壁の解に近づく。

### 4.2 A: 厚肉管 (case/64)

- 流体は前身と同じ (R = 1 mm、M 0.05、Re 1000、Pr 0.72、Pe 720、放物入口)。**壁は全長にわたって共役** (上流・加熱区間・下流)。
- 固体殻 R ≤ r ≤ r_o、**r_o = 2 mm**、k_s/k_f = **10 と 100 の 2 水準** (軸方向伝導の効き方を変える)。外面は加熱区間 0 ≤ x ≤ L_h だけ一様熱流束 q_o、それ以外は断熱。管の両端面の固体は断熱。
- 上流の長さは、参照解で予熱が入口側で q_o の 1e-3 以下まで減衰する長さを先に求めて決める。
- q_o は壁の平均温度上昇が約 10 K になる値。
- 評価量: 内壁の温度 T_i(x) (上流の予熱を含む全長)、界面熱流束 q_i(x) (固体からガスへ)、局所 Nu = q_i D/(k_f (T_i − T_b))、上流に回り込んだ熱の割合 Q_up/Q_total。

### 4.3 C: 共役平板 (case/65)

- 一様流 U_∞ (M 0.1 程度)、層流、板長 L で Re_L ~ 1e4。板の厚さ b、下面を Robin (h 大) で T_h に保つ。板の両端面は断熱。
  前縁の上流に slip 区間、上境界は遠方 (slip または自由流)。
- Luikov 数 Br = (k_f/k_s)(b/L) Pr^{1/3} Re_L^{1/2} が O(1) になるよう k_s を選び、**Br 0.3 と 3 の 2 水準**。
- 参照解の流速は Blasius。forge の流れは前縁付近と有限 Re で Blasius から外れるので、評価窓を x/L ∈ [0.2, 0.9] に置き、前提検査で速度分布の Blasius との差を見る。
- 評価量: 界面温度 T_i(x)、界面熱流束 q_i(x)、局所 Nu_x。

### 4.4 共通の評価

- 前身の評価器の作法を流用: 期待節点集合で REFUSED、`iface_ok`、Simpson (A)、全節点の準定常、u_it、負例試験。
- 有限 M の散逸は同格子の対照 run (A: q_o = 0、C: T_h = T_∞) を差し引いた量で比べる (差し引きの限界は前身と同じく明記)。

## 6. 検証 (事前登録の骨子 — 数値は諮問後に確定)

- **前提**: 収束 PASS、準定常 (全節点)、G-if・G-cons PASS、メッシュ品質 PASS、参照解の自己検査 PASS。
- **A 主判定**: 内壁温度の上昇 (T_i − T_in) の分布が参照解と、最大差 ≤ 1 % of 加熱区間の平均上昇。界面熱流束 q_i が ≤ 2 % of q_o (加熱区間と上流の予熱域で別々に)。Q_up/Q_total の差 ≤ 0.5 % (絶対)。
- **C 主判定**: 窓 x/L ∈ [0.2, 0.9] で、界面温度 (T_h − T_i)/(T_h − T_∞) の差 ≤ 1 % (絶対)、q_i の差 ≤ 3 %。
- **格子**: 格子間差が細分化で減る (前身と同じ形)。
- **固体が効いていることの確認**: 同じ条件で固体を等温にした場合 (参照解で計算) との差が、許容差より十分大きい (固体の効果が判定で見えていること)。
