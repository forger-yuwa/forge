## 1. 目的

要求カードの流れでは M_knot を雛形の係数 0.45 × M_design で決めている (`intake/recipes/axismach_final_v1.yaml`、根拠は M6 の最短ロバスト点 2.7 = 0.45 × 6 で、
他のマッハ数への外挿は未検証)。M6 では長さ (L_c) ごとに M_K を振り、制約を満たす範囲で**最大壁角が最小**になる M_K を選んでいた (L_c 45 で 2.6・50 で 2.7)。
この選び方を**標準のルール**にし、カードの既定にする (ユーザ 2026-10-13「m6 のやり方と同じように」、目的は「最大壁角の最小化 (M6 と同じ)」をユーザが選択)。M6 の目的・制約に、境目からの距離と同点の規則を足したもの (M6 の実装は制約内の単純な min(θ_max))。完了時:

1. 長さ (from_length で L_c が決まる) を固定して M_knot を振り、制約を満たし設計が成り立たなくなる境目から距離を取った範囲で、最大壁角 θ_max が最小の M_knot を選ぶ。
2. 要求カードの既定が「自動」になり、選んだ値と掃引の表が YAML と card_log に残る。明示の `overrides: {geometry.M_knot: x}` は今と同じに効く。
3. インテークと skill で、M_knot は既定で自動であること・固定値や掃引も選べることを伝える。

## 4. 設計方針

### 4.1 ルール (目的と制約)

- **目的: 最大壁角 θ_max (`wall_qa` の `theta_max_deg`) を最小にする** (M6 と同じ)。
- **制約** (M6 の候補の条件と最短ロバストの探索の制約を合わせたもの): 設計チェーンが通る (壁 QA・設計壁の検査)、網の内部の向きの反転 0・特性線の交差 0 (標本)・重なり 0
  (`characteristic_topology_diagnostics`、seam の除外は `compare_axislaw_D.py` と同じ)、網の最小 sin 角 ≥ 0.02、壁での余裕 min(μ_w − θ_w) ≥ 1°、
  **軸則の `mpp_quality_ok` (M″ の符号反転 ≤ 1)**、**prepare の入口と同じ MOC のゲート (`require_moc_gate` と同じ判定; 2026-10-14 諮問 mknot-result-v6 で追加)**。
  制約は全部を数えて判定する (例外が出なかっただけでは成立としない)。各点の値と理由を記録。
- **境目からの距離 (新規)**: 境目は「格子の上の不成立の点」でなく、**成立と不成立が隣り合う格子の区間を二分法で幅 ≤ 0.001 まで詰めた区間**で定義し、
  N と 2N の両方の解像度で求めて、**成立の範囲を狭める側の成立側の端** (保守的な境目) から距離を測る (codex 諮問 2026-10-13 mknot-min-theta の Major)。
  選ぶ点はそこから ΔM_safe = 0.05 以上 (制約つきの最小)。境目 + 0.05 の点は候補に足す (評価して成立を確かめる) が、必ずそれを選ぶわけではない (§4.2 の順序)。
  0.05 は設計の要求 (測った安全保証ではない)。理由: 最小の点が成り立たなくなる境目 (M5 では 1.97〜1.98 の間) の近くにあり、解像度や r_t のわずかな違いで不成立側に落ちうる。
  境目は壁 QA の閾値 (`wall_axismach.py:320` の |κ₀R − 1| > 0.15 など) で、物理の限界そのものではない。
- 成立する点が無ければ例外 (表を示す; 黙って 0.45 × M に戻さない)。

### 4.2 探索

- 格子の原点を共通にする: M_K = M_A + 0.1 + 0.1·k (k = 0, 1, …、M_design − 0.1 まで) の粗い格子で全点を評価。
- **成立点の上の θ_max の局所極小を全部** (端を含む) 拾い、それぞれの前後 ±0.1 を 0.01 刻み (同じ原点からの 0.01 の格子) で詰めて、評価した候補の中の最小を選ぶ
  (保証する範囲は「評価した候補の中の最小」)。局所極小が 2 つ以上なら警告して記録。
- **選ぶ順序 (2026-10-14 確定、諮問 mknot-result-v6 の Major)**: (1) §4.1 の全部の制約が成立し、保守的な境目から ΔM_safe 以上の候補に絞る (境目 + ΔM_safe の点を評価して足す) →
  (2) その中の θ_max の最小 → (3) 同点の規則。距離で除外される点の θ_max が選択を左右しないようにする (先に全体で同点の集合を作ると、除外される点の値で選択が変わる反例がある)。
- 同点の規則: (1) で絞った候補の最小との差が 1e-3° 以内の集合から、**境目から最も遠い (成立の範囲の中央に近い) 点**を選ぶ (境目の近くを避ける)。
  1e-3° は「目的関数について設定した許容差」であり、その中の点を物理的に同じ設計と主張するものではない。結果を見て許容差を変えない。
- **解像度のゲート** (codex 諮問 2026-10-13 mknot-auto の Major): 最終の組 (§4.3) で、選んだ点の前後 ±0.1 の詰めを `geometry.n_axis_inv` を 2 倍にして再評価し、
  選んだ値の変化 ≤ 0.01、両方の解像度で制約と境目からの距離が成立、最小が詰めの範囲の端に無いことを確かめる。満たさなければ「選択は未確定」として例外。
  **境目は N と 2N で求めた区間を全部残し (対にしてまとめない)、全部の境目の成立側の端からの距離で、N と 2N の選択をそれぞれ選び直してから比べる** (2N の境目が保守側へ動いたときに
  N の境目のままで判定しない; 諮問 mknot-result-v6 の Major。同じ向き・近い境目を対にしてまとめる案は、N と 2N の不成立の区間が違う側にあると距離を過大に見積もる反例があるので不採用;
  諮問 mknot-gate-output、2026-10-14)。片方の解像度にしか無い境目も残す。入力の点と選び直した 2 点の全部を両方の解像度で制約の検査にかけ、距離は出力の候補 (選び直した点) について判定する。
- 選んだ値は評価した点の値 (格子の原点 M_A + 0.1 からの端数) のまま YAML に書く。丸めた未評価の点を出力しない (表示だけ丸める; 同諮問の Minor、却下側)。
- **出力する値はゲートで選び直した N の値 `chosen_N`** (移動量によらず; 2026-10-14 諮問 mknot-gate-output)。`select_mknot` の選択をそのまま書くと、全部の境目から ΔM_safe 未満の値が出うる。
  境目 + ΔM_safe の点は全部の境目 (範囲の中) について評価して候補に足す (上側の境目は引く)。

### 4.3 r_t の固定点との関係と最終の組 (物理スロート径のカード)

- 最初の r_t (径/2) で M_K を選び、r_t の固定点の間は固定する。固定点の中で `n_axis_inv` の倍化・`L_total_tol` の緩和・`x_end_margin` の変更が起きたら、
  それまでの M_K の評価は無効にして、その設定で選び直す (codex plan レビュー M4)。
- 収束した **最終の (r_t, M_K, 実効の geometry) の組**で、詰め (±0.1、0.01 刻み) と §4.2 の解像度のゲートと全部の制約・寸法の残差を確かめる。
  **ゲートの `chosen_N` と、r_t の固定点の計算に実際に使った M_K との差** (ゲートの入力との差 `moved_N` ではない; 選び直しが重なると累積する) が 0.01 を超えたら、
  `chosen_N` で r_t の固定点をやり直す (最大 2 回; 収まらなければ例外)。差が 0.01 以下でも、出力する組 (`chosen_N` と最後の r_t) で寸法の残差・全部の制約を確かめ直す
  (`geometry.M_knot` だけを差し替えて古い寸法の検証・記録を流用しない)。出力するのは最後に確かめた組。

### 4.4 カード・YAML・記録

- カードの既定は自動 (`M_knot` を書かない、または `overrides: {geometry.M_knot: auto}`)。数値の `overrides: {geometry.M_knot: x}` は今と同じに効く (掃引しない)。
- YAML の `geometry.M_knot` は選んだ数値 (prepare 以降は今と同じに読む)。`_card.M_knot_rule` に規則の名前 (`min_theta_max_v1`)・掃引の表 (M_K・成立・理由・θ_max・余裕・
  最小 sin 角・M″ の符号反転・x_K)・選んだ値・境目からの距離・解像度のゲートの結果・r_t の固定点の前後の選び直しを残す。card_log と YAML のコメントにも出す。
  雛形の `M_knot_factor` は使わなくなる (記録だけ残す)。
