## 1. 目的

case/16 (平面 2D ノズル、node、SST、陰解法) の定常残差は、リミッタ既定 (`limiterScaled 1`) では
`limiterScaled 0` より密度残差で約 20 倍高い床で止まる。凝縮の有無とは無関係で、床の残差は
**入口の最初の 2 列の節点に集中している** (#4l)。なぜそこでリミッタ係数が揺れ続けるのかを特定し、
直すべき欠陥 (境界の扱い・角の扱い等) か、リミッタの性質として受け入れるものかを決める。

完了時の状態: 床の原因が A/B で切り分けられ、対処 (修正 plan を起こす / 受け入れて `methods/limiter.md` に書く) が決まっている。

## 2. スコープ

- **やる**: 揺れの位置・変数・時間特性の測定、原因仮説の A/B (config・診断出力のみ、既存の場から短い run)。
- **やる**: 結果に応じた次の判断 (修正 plan の起票か、受け入れの記載)。
- **やらない**: リミッタ・境界条件の数値カーネルの修正 (原因が決まったら別 plan。AGENTS エスカレーション条件 6)。
- **やらない**: ψ 凍結の導入 (limiter-config-simplify §4.3 で「入れない」と決着済み)。
- **やらない**: case/16 以外への一般化 (他ケースで同じ型か確かめるのは原因が分かってから)。

## 3. 関連 docs と前提

### 3.1 これまでの実測 (2026-10-03)

run はすべて AWS、ビルド 8ce8da3a、共通 IC = `run_0520_twophase_off_16k` res_16000、48000 step
(condensation plan #4l)。L1 = リミッタ既定、L0 = `limiterScaled 0`、wet = 凝縮あり、dry = `condensation: 0`。

- 床 (末尾 10 % の rms_ro 中央値): wet_L1 9.4e-8 / wet_L0 4.7e-9 / dry_L1 8.9e-8 / dry_L0 4.6e-9。
  比 L1/L0 は ro・roUx・roOmega・roY で 15〜20、roUy 5、roe 2、roK 1 (wet・dry とも同じ)。dry_L0 は check_convergence ALL PASS。
- L1 の abs(res_ro) 上位 1 % の節点が Σres² の 99.5〜99.7 % を占める (L0 は 20 %)。
  その 57〜66 % で limiter_P<0.99 (全域 11〜22 %)、8〜9 % で最後の 2 枚 (2400 step 間隔) の間に limiter_P が 0.05 以上動く。
- 位置 (dry_L1 最終場): **x = −60 mm (入口境界の列) が Σres² の 37.5 %、x = −59.37 mm (2 列目) が 33.9 %**、3 列目 0.2 %。
  L0 では同じ列が 0.4 % / 1.0 % / 1.1 %。上位 20 節点は両列の壁から 0.2〜0.4 mm (M 0.11) に加え、
  x = −32 mm の壁節点 (M 0)、出口 x = 95 mm の中心線近傍 (M 1.8)。
- 入口境界の 120 節点のうち 3 節点 (abs(y) 12.32/12.40/12.54 mm、いずれも壁の隣) で `limiter_Ux` = 0 (L0 では 0 節点)。
  2 列目の上位節点は ρ・P・Ux・Uy の ψ がいずれも 0.6〜0.8。
- **否定した仮説**: 「ε̂ が float32 の丸め以下で、雑音でリミッタが入る」。上位 1 % の節点で
  abs(∇q)·h/q_ref の中央値は P 9.5e-5・ρ 1.9e-4・Ux 1.6e-3 に対し、ε̂ = (K h/L_ref)^1.5 の中央値は 2.9e-7、
  q の 1 ulp/q_ref は 1.6e-7 以下 (後処理 `notes/investigations/2026-10-03-twophase-onoff/eps_probe.py`)。
- 注意: 出力の `limiter_T` は全節点 0 (この設定では使われない置き場の値)。揺れの指標に使わない。

## 4. 設計方針 (調査の進め方)

測定 → 仮説ごとの A/B の順。A/B は **dry_L1 の最終場 (`run_0524` res_48000) を共通 IC** にし、変えるのは 1 要素だけ。
凝縮を外した dry で行う (#4l で床は凝縮と無関係と判定済み。dry の方が変数が少ない)。

### 4.1 I1: 揺れの時間特性 (測定)

`run_0524` res_48000 から L1 のまま 200 step、出力を 5 step ごと (`output.level 2`) にした run を 1 本。
入口 2 列と x = −32 mm 壁・出口中心線の上位節点について、各変数の ψ と res_ro の時系列を取り、

- どの変数の ψ が揺れているか (ρ/P/Ux/Uy)、
- 揺れが step ごとの反転 (2 step 周期) か、長周期か、不規則か、
- ψ が止まった step で res_ro が下がるか (ψ の揺れが残差の源か、残差の揺れが ψ を動かしているのか)

を出す。

### 4.2 仮説と判別 A/B

| 仮説 | 内容 | A/B (1 要素だけ変える) |
| --- | --- | --- |
| H1 入口境界の扱い | 入口境界節点 (半 CV) の ψ が、入口 BC の値 (Pt/Tt 固定・速度外挿) と再構成の相互作用で振動する | 入口列の節点だけ ψ を 1 次 (ψ=0) / 2 次 (ψ=1) に固定する診断オプションがあれば使う。無ければ L0 と L1 の差が入口列に限られるかを I1 の時系列で見るだけにし、修正候補として別 plan へ (カーネル変更は条件 6) |
| H2 入口∩壁角 | 角の節点 (`nodeInletCornerWall 1`) と壁の隣の入口節点で速度が段差を持ち (入口一様・壁 0)、Ux の ψ が 0 に張り付く・外れるを繰り返す | 揺れが壁の隣の数節点から始まり 2 列目へ伝わるかを I1 で見る。`nodeInletCornerWall` は変換時の設定なので A/B しない (メッシュが変わる) |
| H3 venkatK の大きさ | K = 0.05 は平滑域でも ψ<1 を許す。境界層の滑らかな曲率で ψ が 1 付近を出入りする | `venkatK` 0.05 → 0.2 (同じ L1 経路)。床と入口列の Σres² 占有を比べる |
| H4 時間積分との結合 | ψ の揺れは陰解法の内反復 (nStepInner 5) の中で凍結されないので、外反復ごとに作用素が変わる | `nStepInner` 5 → 1 (同じ cfl)。床の高さと入口列の占有を比べる |

A/B はいずれも 24000 step、出力 2400。

### 4.3 判定 (事前登録)

- 「仮説 Hn が床の主因」: その A/B で、**入口 2 列の Σres² 占有が 10 % 未満に落ち、かつ rms_ro の床が L1 基準 (8.9e-8) の 1/5 以下**になる。
  ほかの A/B が同時に満たしたら、どちらか一方とは言わない (両方を記録)。
- 「Hn は主因でない」: 入口 2 列の占有が 50 % 以上のまま、または床の変化が 2 倍以内。
- その間は「部分的」として I1 の時系列で補う。
- 報告量 (#4i の 7 量) が L1 と変わらないことも併記する (床が下がっても解が変わっていれば別問題)。

### 4.4 結果に応じた次の判断

- 主因が境界・角の扱い (H1/H2) → 修正の plan を起こす (カーネル変更なので上位の判断を経る)。
- 主因が K (H3) → limiter-config-simplify の既定 K を見直すか、入口だけの問題として受け入れるかを決める。
- 主因が時間積分 (H4) → ψ を内反復中で凍結する案は「ψ 凍結を入れない」の決定に触れるので、limiter-config-simplify 側で再検討する。
- どれでもない → 測定を足して仮説を作り直す (後から合格条件を変えない)。
