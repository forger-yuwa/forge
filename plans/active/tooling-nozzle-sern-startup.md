## 4. 設計方針

### 4.16 CFL と implicit_relax の方針 (2026-09-19 実測、⑤ SERN 平面)

**ルール: SERN では `implicit_relax` を使わない。CFL を上げる方で速くする。**

根拠 (`run_0123`–`0132`, 2D frozen_tp m6_on, doe_001 dv)。

| 構成 | C_T,with_shear | 基準との差 | 判定 |
| --- | --- | --- | --- |
| cfl 0.5 (現行) | 0.91537812 | — | PASS |
| cfl 2.0 | 0.91537817 | +5e-08 | PASS |
| cfl 6.0 のみ (relax 1) | 0.91537807 | −5e-08 | PASS |
| **`implicit_relax` 0.7 のみ (cfl 0.5)** | 0.91491559 | **−4.6e-04 (0.05 %)** | PASS だが**解が動く** |
| cfl 6.0 + relax 0.7 | 0.91491578 | −4.6e-04 | 同上 (ずれは relax の分と一致) |

**CFL は解を動かさず、`implicit_relax` が動かす。** 収束していれば緩和係数は定常解に影響しないはずなので、
0.05 % のずれは (a) 12000 step でも収束しきっていない、(b) 実装が定常解に触れている、のどちらか。
どちらにせよ生産では使わない。

**relax = 1 のままの CFL 上限 (梯子 2000 step に短縮した荒い場から)**: `run_0128`–`0132`

| cfl | 0.5 | 2.0 | **6.0** | 12.0 | 24.0 |
| --- | --- | --- | --- | --- | --- |
| 判定 | PASS | PASS | **PASS** | DIVERGED (残差 rising) | DIVERGED (NaN) |
| C_T,with_shear | 0.916192566 | 0.916192808 | 0.916192378 | — | — |

**軸対称ノズル (case/44) の「relax 無し cfl 6 は発散」は SERN に適用しない。** あちらの上限は
**軸列 (r→0) の温度床の洗浄**が律速で ([[implicit-cfl-ceiling-eos-floor]] の 2026-09-16 追記)、
SERN は平面で軸が無い。新ゲート `floor_gate` の実測でも cfl 0.5 / 2.0 とも
**床への張り付きが P/T/ρ/roOmega/k すべて 0 ノード**。床律速の上限そのものが存在しない。
なお §4.11 の「`implicitRelax` は SERN に無効」も、当時は**幅外の幻の固体で圧力床を叩いていた**
(§4.15.1 C2) ので軸対称と同じ床律速を人工的に作っていた。幾何を直した今は CFL が素直に上がる。

**頭打ち (本段を何 step で切れるか)**: 出力 100 step 刻みで実測。

| cfl | 0.1 % 以内 | 0.01 % 以内 | 0.001 % 以内 |
| --- | --- | --- | --- |
| 0.5 | 300 | 1800 | 2600 |
| 2.0 | 100 | 600 | 900 |
| **6.0** | 100 | 300 | **500** |

→ **cfl 6 + 本段 500 step** で現行 (cfl 0.5 × 12000) と同じ答え。本段だけなら 24 倍だが、
梯子 (12000 step) が支配的になるので 1 評価あたりは **1.9 倍**。次に効くのは梯子側の CFL
(現状 soft/mid とも 0.1)。**未確認**: 早期停止は力係数の頭打ちで切るので、
剥離やせん断層など力に出にくい遅い現象が発達しきっているかは別途確認が要る (AGENTS.md「場の発達」)。


#### 4.16.1 収束の判定基準 (2026-09-19 ユーザ決定)

**CFL を上げるのは収束を速めるためであって、最終的に収束していることが条件。** 判定は次の 5 つ
(`metrics/sern_gates.py`, `evaluate_gates`)。

| # | 条件 | 実装 |
| --- | --- | --- |
| 1 | 保存場に NaN/Inf が無く正値 | `field_health` |
| 2 | **全残差列がプラトーに達している** (上昇列なし **かつ「まだ低下中」の列もなし**) | `require_residual_plateau`(既定 True) → `fail_class: NOT_PLATEAU` |
| 3 | 残差列の桁が揃う (1 列だけ中央値の 1e6 倍以上でない) | `residual_scale_gate` |
| 4 | 床・下限への張り付きが 0 ノード (`pMin`/`tMin`/`roMin`/`roOmega` 1e-20/`k`≤0) | `floor_gate` |
| 5 | 代表値 `C_T_with_shear` ほか力係数が STEADY | `steadiness_gate` |

**残差の 3 桁低下 (`require_residual_pass`) は課さない。** この case は残差が 1–2.5 桁でプラトーする性質で、
どの構成も届かない。代わりに**過渡が終わっていること**をプラトー要求で担保する。
「まだ低下中」を不可にするのが要点で、そこを許すと過渡の途中の値を定常値として採ってしまう。

**梯子・本段の実測 (2D frozen_tp, MOC IC 外挿, 本段 cfl 5, `run_0169`–`0177`)**

| 梯子 (各段) | 設計 A | 設計 B (θ_r0 15°, L_cowl 3.0) | 設計 C (θ_r0 21°, L_cowl 1.0) |
| --- | --- | --- | --- |
| 1000 | PASS 0.913488 | **FAIL** (`rms_roY1` 上昇) | PASS 0.920893 |
| **1500** | **PASS 0.914270** | **PASS 0.943850** | **PASS 0.922221** |
| 2000 | PASS 0.914418 | PASS 0.943940 | PASS 0.922013 |

1500 と 2000 の差は 0.010–0.023 % で、**設計間差 (A→B +0.030, A→C +0.008) の 1 桁下**。順位は保たれる。
→ **梯子 1500 × 3 段が 3 設計とも通る最短**。

**段ごとの CFL (現状)**

| 段 | 乱流 | 精度 | CFL | キー |
| --- | --- | --- | --- | --- |
| 1 暖機 | none | 1 次 | 0.1 | `warm_lam_cfl` (**`warm_lam_ramp` で段階昇圧可、2026-09-19 実装**) |
| 2 soft | SST | 1 次 | 0.1 | `soft_cfl` |
| 3 mid | SST | **2 次** | 0.1 | **`soft_cfl` (2 段目と共有・独立に振れない)** |
| 4 本段 | SST | 2 次 | **5.0** | `cfl_main` (上限 6、12 で発散) |

**未確認**: soft と mid は同じキーを共有しているので段ごとの上限は不明。mid は 2 次なので soft より厳しいはずで、
soft だけならもっと上げられる可能性がある。ramp を soft/mid にも入れるのが次の手。


#### 4.16.2 CFL ramp と確定した起動レシピ (2026-09-19 実測)

**ソルバに CFL ramp は無い**ので、runner が forge を複数回起動して段階昇圧する
(風洞チェーン `runner_axismach.run_staged_ns(stages="ramp")` と同方式)。
`opt.warm_lam_ramp` (暖機) と `opt.soft_ramp` (soft/mid、キー共有なので両段に効く) を実装。

**暖機は ramp が効く。** 固定では 0.5 で step 30 発散だが、`[0.1, 0.3, 1.0]` なら **cfl 1.0 に到達**し
3 設計とも PASS。C_T は 3 設計とも **+0.08 %** の共通モードで動き、順位は保たれる。

**soft/mid は ramp でも設計 B が救えない。**

| 設計 | soft/mid 0.1 固定 | 1.0 固定 | ramp 0.1→0.3→1.0 |
| --- | --- | --- | --- |
| A | PASS 0.915168 | PASS 0.915406 | PASS 0.915480 |
| **B** (θ_r0 15°, L_cowl 3.0) | PASS 0.944722 | **FAIL** (`rms_roY1` 上昇) | **FAIL** (同左) |
| C (θ_r0 21°, L_cowl 1.0) | PASS 0.922840 | PASS 0.922894 | PASS 0.922982 |

設計 B は固定でも ramp でも同じ `rms_roY1` (外気側 = 排気∩外気のせん断層) の上昇で落ちる。
**CFL の上げ方ではなく形状固有**。カウルが長くせん断層が長く伸びる形状で、暖機 (層流) では ramp が効くのに
soft/mid (SST) で効かないのは、界面の**乱流輸送**が絡んでいることを示唆する。未解明。

## 6.2 codex plan レビュー (2026-09-19) の採用結果

判定 **NO-GO** (C0/M6/m1)。記録
[`notes/reviews/2026-09-19-tooling-nozzle-sern-startup-plan.md`](../../notes/reviews/2026-09-19-tooling-nozzle-sern-startup-plan.md)。
**全件採用。「生産レシピ確定・4.8 倍」は撤回する。**

| # | 指摘 | 採否 |
| --- | --- | --- |
| M1 | **プラトーは収束の十分条件でなく、実装も「全列プラトー」を検査していない**。`check_convergence.py:108` は `col_ok = drop >= min_drop and trend != 'rising'` で**3 桁低下した列に状態文字列を付けない**ため、3 桁落ちてなお下降中の列が `require_residual_plateau` を素通りする (仕様と実装の不一致、**自分で再現確認済**)。残差の大きさも問うていないので float32 の更新消失やクランプで止まった状態と区別できない | **採用** → R-a |
| M2 | **「1500×3 + 本段 500」は一度も回していない**。ramp の成功例 `run_0178`–`0180` は**4 段とも 2000 step** (`problem_ramp_B.yaml` で確認済)。別実験の数字を組み合わせただけ。さらに `run_0179_ramp_B` の 500 step 時点で **`vis_turb` が局所 `DRIFTING` (末尾窓 18.3 %)・ノード平均 `TRANSIENT-UNSETTLED`** = 力係数は STEADY でも乱流粘性が未発達。`24000/5000` は step 数比で実時間比ではない | **採用** → R-b |
| M3 | **残差スケールゲートは次元の違う量を中央値で比較**しており数値的根拠がない (`residualMonitor_d.cu:124` に方程式間の正規化なし)。極端な異常検知には使えるが収束条件にはできない | **採用** → R-c (補助警報に降格) |
| M4 | **MOC 初期値が NASA-9 に対する等エントロピー展開になっていない**。`runner_sern.py:359` 以降で一定 γ の式から T/P/q を作り、`roe` だけ NASA-9 に置換。実測で**全エンタルピー +1.20 %・エントロピー +30.7 J/(kg·K)** ずれる。対案は `h_sens(T) + ½M²γ(T)RT = h0_in` と `p = p_in exp[(s°(T)−s°(T_in))/R]` を NASA-9 で解く形 | **採用** → R-d |
| M5 | **設計 B の `rms_roY1` を「形状固有・せん断層の乱流輸送」と断じた根拠が不足**。全域 RMS なので発生場所を特定できていない。段の `res_*` を restart 後に消すので段別診断も残らない。未検討の候補: `speciesImplicitCoupling` 未指定 (=0) で流れの block-DPLUR と別の点陰的更新、`speciesImplicitRelax`=1、`speciesTransport_d.cu:152` の非負化・再正規化 | **採用** → R-e |
| M6 | **床ゲートの検査漏れと誤検出**。`roY*` を見ない、実 config の `tMin`/`roMin` を読まない、読取り例外で `ok=True` を返す。**`k<=0` の一律禁止は低 Re の node 壁で正当に k=0 をピンする仕様と衝突** (`procedures/solver-settings.md:250`) — run_0122 の「k≤0 が 28 ノード」も壁ピンを拾っていた可能性 | **採用** → R-f |
| m1 | 対象範囲が「平面 node・frozen_tp・m6_on の 3 形状」なのに「SERN では」と一般化している。case README の run 索引に `run_0123`–`0186` が未登録 | **採用** → R-g |

## 5.1 残作業 (2026-09-19 改訂・codex 推奨順)

| # | 項目 |
| --- | --- |
| **R-a** | **プラトーと収束を分離しゲートを直す**。`require_residual_plateau` の実装バグ (3 桁低下列の素通り) を修正し、プラトーは診断情報に降格。受理は方程式別の無次元残差上限 + 保存収支 + 場・目的量の定常性で行う |
| **R-b** | **提案レシピを直接検証する**。1500×3 + 本段 500 を A/B/C でそのまま回し、長時間参照と比較。比較量は力係数だけでなく**剥離位置・せん断層厚さ・組成断面・`vis_turb`・保存収支**。許容差を先に数値で決め、複数の連続窓で満たすまで延長する |
| **R-c** | 残差スケールゲートを補助警報に降格し、局所異常は最大値・分位値・位置で検出する |
| **R-d** | **MOC 初期値を NASA-9 整合にする** (上式)。クランプ領域の割合・位置・入口との整合・壁法線速度を記録し、別初期値から同じ最終状態に到達することを確認 |
| **R-e** | **設計 B を同一保存場から切り分ける**。soft と mid を独立に変更し、段別履歴を保存して局所種残差・対流/拡散寄与・再正規化の修正量・float32 ULP 比を測る。その後に化学種結合方式を一因子比較 |
| **R-f** | 床ゲートを config 駆動にし、`roY*` の非負性と `ΣρY=ρ` を検査。**正当な壁ピンを除いた領域で床を評価**。欠損・読取り不能は判定不能として不合格 |
| **R-g** | plan の対象を「平面 node・frozen_tp・m6_on」に限定して明記。case README の run 索引を同期 |

**CFL 上限探索は一旦止める** (codex 推奨)。受理基準と初期値を直してから起動レシピを再検証する。
