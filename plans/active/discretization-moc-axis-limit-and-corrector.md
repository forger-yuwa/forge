## 1. 目的

逆 MOC の単位過程には、軸の 1 段目に 2 つの誤差がある (monotone plan の試験 (b))。

- 軸上の端点では sinθ/r が 0/0 なので、相手の点の値を借りて代用している。借りる値が組み合わせる相手によって変わる。
- 予測修正の反復回数が 2 回固定 (`n_corr=2`) で、軸の近くでは収束しない (振動の比 ≈ −1/2)。

これを次の 2 点で直し、MOC の始点付近の角度差 (スロート直後の r″ の山の主因の一部) を減らす。

- 軸上の端点のソース項に、軸上の M 分布から求めた解析極限 θ_r を使う。
- 予測修正を収束まで回す。

ユーザ決定 (2026-10-07)。「試験用に直した手順 (予測修正を 20 回まで回す)、総点数 2400 をメインに」→ 軸上のソース項は 0 ではなく θ_r にする案で合意。θ_r は semi-perfect で求める。

## 3. 関連 docs と前提

- **θ_r の導出**: 軸の近くでは θ ≈ θ_r · r で、sinθ/r → θ_r。等エントロピー流では dν = √(M² − 1) · d ln u (Prandtl–Meyer の定義)、連続の式は d ln(ρu) = (1 − M²) d ln u。軸の近くの質量保存 2ρu θ_r = −d(ρu)/dx から、θ_r = ½ √(M² − 1) · dν/dx = ½ √(M² − 1) · (dν/dM) · dM/dx。
  - 比熱一定なら dν/dM = √(M² − 1)/(M(1 + (γ − 1)M²/2)) で、θ_r = ½ (M² − 1)/(M(1 + (γ − 1)M²/2)) · M′ に戻る。
  - semi-perfect では、MOC 本体と同じ気体モデルの ν(M) 表を使う (`moc_kernel.dnu_dM` は表の 3 次スプライン微分を返す)。γ の温度依存は ν(M) の中に入る。
  - methods の「今後の課題」にある ∂θ/∂r|r=0 = −½ d ln F/dx と同じ量。
- **事前試算** (monotone plan §9 2026-10-07、`case/45.isobutane_m6_d155/throat_moc_fix_probe*.py`、CFD 0 step):
  - 生産の n_start 41 で、第 1 点 (x = 0.025) の角度差は、生産の手順・dx0 0.03 で 0.022°。
  - 試験用の手順 (K2c: 修正子 20 回 + 軸上と軸近傍 (r < 0.05 r_other) のソース項 0) では 0.018°。修正子だけを収束させた版 (conv) は n_start 321・dx0 0.015 で 0.019° (生産 0.022°)。
  - **注意 (諮問 2026-10-07)**: これらは 0 源項の K2c と conv の観測で、解析極限 (analytic) の効果・壁の変化・残る山の大きさについての観測ではない。初稿の「効き目の大半は修正子」「軸外は生産と同じ」は撤回 (K2c は軸近傍の軸外点も 0 にしていた)。
  - 軸上のソース項 0 は物理的には誤り (正しくは θ_r ≈ 0.10 rad/r_t、x_A で)。試験では、組み合わせで値が変わる不整合を消すために使っただけ。
  - 所要時間 (design_chain 1 回): 生産 2.3 s、試験用 (修正子 20 回固定) 8.6 s。
- **A11 の記述との関係**: methods は「`AXIS_LIMIT_FRAC` による代用は生産経路で 1 度も発火しない」と書いている。一方、軸上の端点 (r ≤ 1e-9) は常に代用の分岐に入る。前者は軸外の点のしきい値の話と読める。本 plan で methods の記述を正確にする。

## 4. 設計方針

### 4.0 先行する判別 A/B (諮問 2026-10-07、`notes/reviews/2026-10-07-moc-axis-limit-diagnose.md`)

実装の最初の成果物として、放射源流 (厳密解のある軸対称流、θ_r = 1/x) で次の A/B を行い、結果で §4・§6 を確定する。
- A = `legacy + converge`、B = `analytic + converge`。違いは軸上の端点のソース項だけ (修正子は両方とも収束)。
- `design/tests/run_inverse_tests.py:268–283` の放射源流で、n_axis 140 / 280 / 560 / 1120 と n_start 25 / 49 / 97 / 193 を最後まで充填する。CFD 0 step。
- 両方で修正上限 50、更新量 ≤ 1e-12、未収束の対 0 を必須にする。
- 測る量: 第 1 段の θ・ν の厳密解からの誤差、再出発の差、同じ位置での壁の誤差と収束次数。
- 判定 (事前登録):
  - B の第 1 段の θ の誤差が各解像度で A の 1/10 以下、壁の誤差も A 以下、最細区間の壁の収束次数 ≥ 1.7 なら、軸端のソース項が第 1 段の誤差の主因という仮説を支持して実装を進める。
  - 第 1 段だけ改善し壁の条件を満たさなければ、「軸処理の修正で全体の精度も上がる」という前提を棄却し、ユーザに報告して判断を仰ぐ。
  - 第 1 段も改善しなければ、適用箇所・微分・単位の実装を点検する。

### 4.1 軸上の極限 θ_r

- 軸上の端点 (`r_p ≤ 1e-9`) の sinθ/r を、相手の値ではなく、その点の θ_r にする。
- θ_r = ½ √(M² − 1) · ν_M(M) · M′(x)。M と M′ は軸上の M 分布 (target law) から取る。初期線の軸端は、アンカーの M_A・M′_A を使う。
- **既知の軸端点の θ_r は、予測段・修正段を通じて固定する** (相手の値や、反復中の θ/r から更新しない)。
- **target (軸節点) と throat (初期線の軸端) の接続を検査する**: 軸端の x・M・ν と軸方向の微分が、両者で一致すること。一般経路では x_A ≠ x0 があり得る (`runner_axismach.py:299–313`) ので、初期線の軸端を常に x_A と扱わない。
- M′ は軸則の解析微分を使う。無い場合の代わりとして、軸節点の ν を 3 次スプラインで微分するときは、θ_r = ½ √(M² − 1) · dν/dx として ν_M を掛けない。どちらを使ったかを記録する。
- semi-perfect: `dnu_dM` は ν 表の 3 次スプライン微分で、本体の ν と逆関数は線形補間 (`gas/semiperfect.py:306`) なので、同じ表でも補間関数は違う。case/45 のアンカーで両者の勾配の差は 0.0156 % (諮問の独立計算、θ_r = 0.104146 rad/r_t)。表の解像度依存を記録し、反復の許容差 1e-12 とは別の熱力学近似誤差として扱う。
- 軸外の点 (r_p > 1e-9) は従来どおり点自身で評価する。`AXIS_LIMIT_FRAC` の分岐 (軸近傍の軸外点の相手代用) は変えないが、**発火の数と位置を記録する**。真の軸端点の処理を先に行う。

### 4.2 予測修正の収束

- 修正子の反復を、θ と ν の変化の最大が許容値 (1e-12 rad) を下回るまで回す。上限は 50 回。
- **上限で収束しない対が 1 つでも残れば、検証・生産のゲートでは不合格**とする (診断の保存は続ける)。停止判定は有効な対だけで行う (`fill_levels` は欠損を NaN で持つ、`moc_inverse.py:145–151`)。
- 最終状態で、幾何と適合式を再評価した残差も記録する。
- 使った反復回数の分布 (最大・平均) を `design_chain` の診断に出す。

### 4.3 既定値と切り替え

- 問題 YAML の `geometry.moc_axis_limit` (`legacy` | `analytic`、既定 `legacy`) と `geometry.moc_corrector` (`fixed2` | `converge`、既定 `fixed2`)。
- 既定はビット同一。case/45 の生産に入れるかは §6 の結果を見てユーザが決める。
- 他の case の既定を切り替えるかは、本 plan の範囲外 (別途判断)。
