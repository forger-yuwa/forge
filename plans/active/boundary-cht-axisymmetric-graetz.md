## 1. 目的

親 plan の軸対称 `fem2d` 連成は**静止ガスの純伝導**でしか検証していない (case/61・62、軸を含まない)。
本 plan は **流れがあり、軸を含む**軸対称の CHT を、解析解のある **Graetz 問題** (十分発達した管内層流、壁温一様) で検証する。
完了時: 「**登録した node・FP64 条件で**、流れのある軸対称 CHT の**対照差し引き後の局所 Nu** が古典 Graetz 解と
登録許容差内で一致する (範囲は §6 の窓)」を run と VERDICT つきで言える状態。**言えないこと** (codex plan レビュー m6):
加熱・対照に共通の加算誤差は差し引きで消えるので、**絶対熱流束の精度は保証しない**。G2−G1 は UWT 近似 (有限壁抵抗) を含む差である。

- 親 plan で検証済み: 固体 r 重み作用素 (V-ax1)、界面の熱量受け渡し (V-ax2 円筒殻の対数抵抗、V-ax2b 半径が変わる界面)、
  再開契約 (V-ax4)。**未検証: 流れがあるときの界面熱流束 (`flux: q_eff` の対流を含む壁 CV 収支)、軸を含む流体。**

## 4. 設計方針

### 4.1 問題と無次元数

- 管半径 $R$ = 1 mm ($D$ = 2 mm)。空気相当の定数物性 (`viscMethod: 0`・`thermCondMethod: 0`)、$c_p$ 1004.5、$\gamma$ 1.4。
- 入口 $T_{in}$ = 300 K、$p$ ≈ 101325 Pa ($\rho$ = 1.1768)、**$M$ = 0.05** ($U_m$ = 17.36 m/s)、**$Re_D$ = 1000**、**$Pr$ = 0.72**
  → $\mu$ = 4.086e-5、$k_f = \mu c_p/Pr$ = 5.700e-2、**$Pe$ = 720**。物性は $Re, Pr$ を決めるための自由パラメータ (実在空気ではない)。
- 区間: 上流断熱 10 mm ($x^+$ 0.0069) / **加熱 (共役) 172.8 mm ($x^+$ 0.12)** / 下流断熱 10 mm。$x^+ = x/(D\,Pe)$。
- 入口は `inlet_uniformVelocity` + `inletProfile` で**十分発達した放物速度** $u = 2U_m(1-r^2/R^2)$ を与える
  (亜音速ではエントロピー固定・内側からのリーマン不変量で $\rho, p$ が決まる: `boundaryCond_d.cu` `inlet_uniformVelocity_d`)。
  出口 `outlet_statPress`。軸 `axis`。壁は断熱 no-slip (`wall`) + 加熱区間だけ共役壁。
- 概算の圧力降下 $32\mu U_m L/D^2$ ≈ 1.1 kPa (1.1 %)。質量流束 $\rho U$ は保存するので $Re$・$Pe$ は区間を通じて一定。

### 4.2 基準解 (forge と独立)

`case/63.graetz_cht/graetz_ref.py`。
- **march**: 軸方向伝導なし ($Pe\to\infty$) の古典 Graetz を $x^+$ 方向にマーチング。**独立の固有値級数**
  (一般化固有値問題を直接解く) と $10^{-5}$ で一致、$Nu_\infty$ = 3.656793 と 1.2e-5 で一致 (`--selftest` PASS、2026-09-27)。
  代表値: $x^+$ 1e-3 / 3e-3 / 1e-2 / 3e-2 / 0.1 → Nu 10.130 / 7.043 / 4.916 / 3.894 / 3.658。
- **ellip**: 軸方向伝導あり (有限 $Pe$、上下流の断熱区間 $x^+$ 0.01 ずつ)。**収束値** (2026-09-27、$Pe$ 720、nr 120・nx 1600。
  nx 800 との差 ≤ 0.006 %、nr 60 との差 ≤ 0.04 %): $x^+$ 1e-3 / 3e-3 / 1e-2 / 3e-2 / 0.1 → 10.0960 / 7.0345 / 4.9141 / 3.8936 / 3.6576。
  march との差 (= 軸方向伝導の効果) は **−0.34 / −0.12 / −0.04 / −0.015 / −0.012 %**。
  (初版の ellip は等比 1.03 固定の格子で n を増やしても細分化にならず、nx 1200 で値が壊れた。対数刻みに直した)
  **有限 $Pe$ の A/B** (2026-09-27、codex diagnose の判別試験): 同じ ellip 格子 (nr 120・nx 2400・上下流 $x^+$ 0.01) で
  $Pe$ = 720 と $10^{12}$ (軸方向伝導の係数 $1/Pe^2$ だけが違う) を解き、窓内 $\max|Nu_A/Nu_B-1|$ = **0.113 %**
  ($x^+$ 1e-3 / 3e-3 / 1e-2 / 3e-2 / 0.1 で −0.327 / −0.114 / −0.029 / −0.004 / +0.000 %)。
  → 「$Pe$ 効果 ≤ 0.05 %」は撤回。**登録の基準は march (古典 Graetz)** のまま、この差を**モデル差として誤差予算に計上**する (§4.6)。
  ellip ($Pe$ 720) との差も参考に併記する。
- **独立性の限定** (codex m1): march と固有値級数は同じ半径方向の離散化 (`radial_ops`) を使うので、両者の一致は時間積分・級数和の検査であって
  空間離散化の独立検査ではない。空間離散化は**文献の固有値**で確かめた: $\lambda_{0,1,2}$ = 2.70436436 / 6.67903082 / 10.67337709 (nr 4000)
  と Shah & London の 2.70436442 / 6.67903144 / 10.67337956 の差は −2e-8 / −9e-8 / −2e-7。

### 4.3 基準解から外れる forge 側の要因と、その消し方

| 要因 | 大きさの見積もり | 処置 |
| --- | --- | --- |
| 粘性散逸・膨張冷却 (有限 $M$) | $Br$ 相当 $8Pr M^2(\gamma-1)(T/\Delta T_b)/Nu$ は $\Delta T_b$ = 2 K で ~25 % (素の値)。理想気体では混合平均の収支で相殺するが半径分布は残る | **対照 run ($T_c = T_{in}$、$\Delta T$ = 0)** を同じ格子で回し、$q$ と $T_w - T_b$ から差し引く。**検証対象は「差し引き後の Nu」であり、「散逸を消した」とは主張しない** (codex M2: 温度ごとに圧縮性流れを解き直すので差し引きは同一作用素の保証にならない。温度振幅に依らない有限 $M$ の誤差は 5/10 K の差では除外できない) |
| 密度の温度依存 ($\Delta T/T$) | $\Delta T$ = 10 K で 3 % の密度変化。Nu への効果は 1 次 | $\Delta T$ = 5 K と 10 K の差は**適用範囲の判定**に使う (§6 V-g5)。**主判定は全格子で差し引き後の $Nu_{10}$ に固定**し、差が登録値を超えても外挿で救済せず判定を保留する (codex M3) |
| 壁温の非一様 (固体の有限抵抗) | 固体 $k_s$ = 100 W/mK・厚さ 0.5 mm で $q t/k_s$ ≈ 0.01 K ($x^+$ 3e-3) | 上流の壁温履歴が温度分布に残るので、局所 $T_w$ で割るだけでは UWT にならない (codex M5)。**G2 − G1 の差は「連成の誤差」でなく「UWT への近似誤差 (有限壁抵抗の物理差) を含む差」と定義**する。非一様量を報告 |
| 混合平均・質量流束の数値積分 | 台形則は放物速度 × r の $\dot m$ を $(h/R)^2$ (N_r=16 で 0.39 %) 誤り、$x^+$ を通じて入口近くの Nu を動かす | **Simpson 則** (半径方向は一様格子・偶数区間。3 次式まで厳密なので $\dot m$ は誤差なし)。評価器が一様・偶数区間でなければ停止 |

### 4.4 固体 (共役)

- 加熱区間だけに固体殻 $r \in [R, R+t]$、$t$ = 0.5 mm、$k_s$ = 100 W/mK (UWT に近づけるため高伝導)、外面 Robin $h$ = 1e8・$T_c$、
  固体の $x$ 両端は断熱。界面節点 = 流体の共役壁の節点 (乾式 1 step の壁ダンプ座標、case/61 と同じ作法)。半径方向 8 層一様。
- $k_s/k_f$ ≈ 1750。連成の安定 (D_f・interval) は親 plan の既定 (`Df_scale` 5、`interval` 50) から始める。**不安定なら設定変更の前に諮る**。
  codex の概算 (円筒殻の局所抵抗): $g_s \approx 2.47\times10^5$ W/(m² K)、$N_r$ = 32 の $D_f \approx 9.12\times10^3$ で、
  高い $k_s/k_f$ だけを理由に不安定とみる根拠はない (安定性は未確認)。固体は半径方向 8 層一様、軸方向は流体の壁節点と 1 対 1
  (流体の格子細分に合わせて固体も軸方向に細分される。半径方向の層数は格子感度の 3 水準で固定 8)。
- 対照として**非連成の等温壁** ($T_w = T_c$ を直接指定、`interfaceDiag: 1` で同じ `iface_q_eff` を出す) も回す。
  共役と等温壁の差は「連成の誤差」ではなく**UWT への近似誤差 (有限壁抵抗の物理差) を含む差** (V-g4 と同じ定義。codex m6)、
  等温壁と Graetz の差は「流れと壁 CV 収支の誤差」を見る。

### 4.5 評価 (`case/63.graetz_cht/eval_graetz.py`)

- 構造格子なので壁節点ごとに同じ $x$ の節点列を取り (節点 ID と `MESH/COORD` で対応させる)、
  $T_b = \int \rho u_x T\, r\,dr / \int \rho u_x r\,dr$ (台形則)。
- $q_w$ = `iface_q_eff` (固体向き正。加熱では負)、$T_w$ = 界面温度 (`iface_Tw_bc`)。**`iface_ok` = 1 の節点だけ使う**
  (第一内点の取得に失敗した節点は `iface_Tw_bc` が初期値のまま: `conjugateWall.cpp`:273–283。codex M7)。
- 対照差し引き: $Nu = -\,(q - q_0) D / \big(k_f [(T_w - T_b) - (T_{w,0} - T_{b,0})]\big)$ (添字 0 は $\Delta T$ = 0 の対照 run)。
- **$x^+$ の原点は加熱開始点** ($x$ = 0。入口原点なら 10 mm で $x^+$ 0.0069 ずれ、窓下端より大きい。codex M7)。
  $x^+ = x_{\rm wall}/(D\,Pe_{\rm meas})$、$Pe$ は各 run の実測 $\dot m$ から再計算する (設定値でなく)。
- **壁流束は節点の双対面上の平均として比較する** (codex M7): `iface_q_eff` は壁 CV の熱量を半割面の面積で割った値なので、
  基準解側も同じ区間 $[x_{i-1/2}, x_{i+1/2}]$ で $q$ を平均してから $Nu$ に直す (入口特異点の近くで点値と区間平均が違う)。
- **期待節点集合** (codex plan レビュー M3): 窓内の壁節点はメッシュ ($r=R$、$0\le x\le L_{heat}$) から決め、壁ダンプに欠損・重複・
  `iface_ok`=0 があれば **REFUSED** (終了コード 2)。NaN 検査だけでは欠損を拾えない (`conjugateWall.cpp`:273 は診断値の設定を飛ばす)。
- **入口の実現分布を確認する** (codex M6): 加熱開始断面 ($x$ = 0) の $T(r)$ の非一様 (エントロピー固定なので $p$ の半径分布が温度に出る。
  入口圧が指定より 1.1 % 高ければ等エントロピーで約 0.94 K) と、入口の $u(r)$ と放物線の差 (`inletProfile` は面重心で補間:
  `methods/boundary.md`:543)。入口の $\rho$・Ps は Poiseuille の入口圧と 300 K に整合させる (`make_run.py`)。
- **軸近傍** (codex m1): G1・対照 run で軸近傍の $u_r$・圧力・速度分布と断面積分を確認する (追加の軸専用 run は置かない)。

## 5. 実装ステップ

1. `graetz_ref.py` (済、自己検査 PASS)。ellip を格子収束させて $Pe$ 効果の数値を確定。
2. `gen_mesh.py`: 軸方向に加熱開始点へ集中した構造四角格子 (半径 $N_r$ 16/32/64 一様)、`check_mesh_quality.py`。
3. `gen_solid.py`: 固体殻 (case/61 の帯トポロジ)。`make_run.py`: IC に Poiseuille + 線形圧力 + 300 K をパッチ、入口 CSV。
4. `eval_graetz.py` + 負例 (符号反転・対照なし・$x^+$ 取り違え を検出すること)。
5. §6 の run を AWS で回す。
