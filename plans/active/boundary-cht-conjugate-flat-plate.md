## 1. 目的

発注元 plan の C (共役平板: C1 厚さ方向の抵抗、C2 板の軸方向伝導) は、主判定 (界面温度・熱流束の独立参照解との比較) が 6 本すべて PASS したが、
**前提ゲートの流体収束と G-if が 6 本とも NOT CONVERGED** で、登録どおり**判定不能**として保留した。
本 plan はその原因を切り分け、登録条件を満たす形で C を再判定する。**完了条件は発注元 plan の §6 (C) のまま**変えない。

**結論 (2026-10-01、限定結果。事前登録の設定での総合 PASS ではない)**:
- **適用範囲**: C (共役平板、case/65) を、**C 専用の事後改訂設定**のもとで評価した。
  - 事後改訂の中身: `space.limiter: 0` (無制限 2 次再構成)、`cfl_pseudo` 0.5、旧 run の step 600000 からの同一格子 restart 150000 step、G-if ④ の `tol_solid` を登録式の値に。
  - 比べた相手は、FP64・node・forge の流れ場を凍結した独立参照解。
- **前提ゲート**: 流体収束・準定常・G-if (登録式の `tol_solid`)・G-cons は 6 本とも PASS。収束は 150000 step で全列が下降中のまま PASS で、床には達していない。
- **主判定**:
  - C1 n16/n32/n64 と C2 n32/n64 は参照 3 水準で PASS (C1 n64: θ 5.3e-4・q 0.085 %、C2 n64: θ 6.9e-5・q 0.31 %)。
  - **C2 n16 は FAIL**: 参照 3 水準では判定不能 (q: 差 2.23 % + U 1.03 %)、参照 4 水準では差 2.35 % + U 0.98 % > 3 % (§4.6.1)。forge の粗格子誤差の寄与を示唆するが、参照側の寄与は排除していない。
- **参照解との差**は細分化で減る (C1 の q 0.72 → 0.23 → 0.085 %、C2 の q 2.23 → 0.73 → 0.31 %。max ノルムで比 2.4〜3.1)。forge 同士の共通節点の差も減る (C1 の q 0.53 → 0.11 %、C2 の q 1.60 → 0.36 %、`GRID_DIFF_C.txt`)。
- **C2 の固体の軸方向伝導の効果**は登録量 (評価窓内の軸方向伝導あり/なしの θ_i 差、参照) で、n32 0.0130・n64 0.0135。許容 0.01 の 1.30〜1.35 倍、U_ax の 49〜106 倍 (§4.6.2 M1)。forge の θ_i は「なし」参照から 0.0128 (n32)・0.0135 (n64) 離れ、「あり」参照とは主判定の許容内で一致する。登録時の 0.018 は Blasius・源項なしの見積もりで、forge 流れ場では 0.013。Q_ax/Q_tot (≈ 0.06) は参考。
- **上境界を 1.5 倍に延ばした感度** (別掲、U に含めない): θ・q とも 1e-11 以下で、熱境界層は上境界に届いていない (§4.6.2 M2)。
- **したがって C は n32・n64 の限定結果で閉じる** (§4.6.1 の分岐、diagnostician 承認済み)。
- **生産用のリミッタ経路** (`limiter: 2`) での C は、前提ゲート不合格のまま判定不能 (`run_0005〜0010`、保持)。その停滞の原因は未確定で、言えるのは後縁直後での残差の局在とリミッタ係数の変動が同じ場所にあること、limiter 0 で解消すること、まで。

#### 4.1.2 観測仕様 (事前登録)

- **節点集合** (`mesh.h5` の `MESH/COORD` と `BCONDS/*/iCells` から作り、期待数と照合。欠落・重複・非有限は REFUSED。`CELLS/centCoords` は y=0 に節点が無いので使わない):
  - 板の界面: 前縁帯 x/L∈[0,0.02] と後縁帯 [0.98,1]、各 10 点。熱流束は全界面の系列も保持する。
  - slip: 上流 x/L∈[−0.1,0)、下流 (1,1.1]、各 21 点。
  - 上記の直上の内部 1 列 (同数、高さ 2.5e-6 m)。
- **量と尺度**:
  - P は q∞ = ½ρ∞U∞² = 709.275 Pa、T は T_h − T∞ = 10 K、`Uy` (+y 方向の速度成分。漏れ流束とは呼ばない) は U∞。
  - 界面熱流束は、元 run の step 600000 の評価窓 x/L∈[0.2,0.9] の台形積分平均の絶対値で割る。
- **残差**: `rms_ro/rms_roUy/rms_roe` の 20000 step 区間の算術平均。横ばい = 3 区間平均の max/min ≤ 1.1。
- **振幅**: 量ごと・節点群ごとに、区間内の規格化系列の標準偏差の節点最大値。異なる量を一つの最大値にまとめない。
  - 「減衰」= B の最終区間の振幅が A の最終区間の 1/10 以下、かつ B の区間振幅が 3 区間で厳密減少。
  - A・B とも振幅が測定床 (予備確認で測る毎 step 系列の丸め変動) に達している系列は、比では評価しない。
- **A の再現**: A の区間平均残差が元 run の最後の 60000 step の区間平均の 1/2〜2 倍。かつ、界面残差 (`conjugate_history.csv` と同じ定義) の最大位置を、元 run と同じ定義・同じ長さの区間で比べて同じ帯にあること。満たさなければ B1 は判定不能。
- **補助診断**: 区間ごとの CSV を `check_quasisteady.py --series-csv --series-cols … --tail 1 --abs-scale 1 --drift 0.002 --osc 0.002` にかけて併記する。温度では 0.02 K 相当なので、0.003 K の変動を STEADY とする可能性がある。B/A 振幅比の判別は置き換えない。

### 4.3 B2′: 擬似時間刻み (`cfl_pseudo`) の A/B (2026-10-01 codex diagnose [`fluid-stall-next`](../../notes/reviews/2026-10-01-conjugate-plate-fluid-stall-next-diagnose.md))

- **問い**: 有限の擬似時間刻みと更新作用素の組み合わせが、減衰しない反復振動を維持しているか。上流 slip の P の周期 7.24 step (パワーの 92 %) は物理時間の周期ではない。
- **起点**: B1 と同じ (`run_0007` の step 600000・固定壁温。`conjugate.warmup` 900000)。バイナリ・他の設定は共通。
  - **対照 A** `run_0015_cfl_c1_n64_cfl2`: `cfl_pseudo` 2 のまま、12000 step (4000 × 3 区間)。
  - **試験 B** `run_0016_cfl_c1_n64_cfl05`: `cfl_pseudo` 0.5 だけ変える、48000 step (16000 × 3 区間)。CFL × step を揃える。局所刻みなので、観測節点の累積 `dt_local` でも時間幅を確かめて併記する。
- **観測**: B1 の毎 step 系列 (P・T・Uy・界面 q/Tw) に加え、同じ節点で `Ux`・`ro`・`dt_local`・リミッタ値 (`limiter_ro/Ux/Uy/P/T`) を採る (`extraFields`)。接線速度 `Ux` の空間の交互成分 (隣接節点の符号交替) も見る。
- **判別** (区間は A 4000 step・B 16000 step の各 3 区間):
  - 前提: A が `run_0012` と同じ停滞を再現する (残差の区間平均が `run_0012` の 1/2〜2 倍、横ばい)。満たさなければ判定不能。
  - B の最後の 2 区間で、能動な残差の全列 (`rms_ro/rms_roUx/rms_roUy/rms_roe`) と主要な変動 (前縁帯の界面 q・下流 slip の P・上流 slip の P) が A の最終区間の 1/10 以下、かつ減衰傾向 → **有限刻み依存を支持**。「空間的な欠陥だけで同程度の振動が不可避」を棄却する (H1・H3 の潜在的な欠陥までは除外しない)。
  - B でも A の 1/2 以上が残り、3 区間の平均・振幅の max/min ≤ 1.1 → **「CFL 2 → 0.5 の縮小で主要な停滞を解消できる」を棄却**。H3 (slip) の確定とはしない。
  - 中間・発散・対照の再現失敗は判定不能。短い診断から収束を宣言しない。収束は別途 `check_convergence.py`、準定常も併記する。
- **やらない**: `implicitRelax` と CFL の同時変更。slip → no-slip で原因を確定すること。1 次化 (`convMethod: 0`) で改善しただけで H1 を採ること。`limiter: 0` は 1 次ではなく無制限再構成 (`limiter_d.cu:450`) なので「1 次」として使わない。
- **C の完了条件は 6 本全合格を維持**。停滞が解けなければ「前提ゲート不合格、C は判定不能・未完了」とし、事後の窓除外・時間平均化・閾値緩和で完了させない。

### 4.4 B3: リミッタの有無 (`space.limiter` 2 / 0) の A/B と残差の空間分布 (2026-10-01 codex diagnose [`after-cfl`](../../notes/reviews/2026-10-01-conjugate-plate-after-cfl-diagnose.md))

- **B2′ の書いてよい範囲**:
  - 壁温を固定した当該の観測区間で、前縁帯の界面 q と上流 slip の P の変動は、`cfl_pseudo` 0.5 で大幅に減衰した。
  - G-if ① が解けるかは未検証。G-if は平均的な不釣り合いも含み、時間変動が小さくても残り得る。
  - 「後縁に残差が局在し、刻みに依らない」は未検証。圧力の変動の最大位置は残差の発生位置を保証しないし、CFL 2 点では刻み非依存とも言えない。
  - `limiter_T` は `reconT` 既定 0 では計算されず 0 のままなので、証拠にしない。
- **問い**: リミッタを含む再構成作用素が、CFL 0.5 に残った停滞の維持に関与しているか。
- **起点**: `run_0016` の最終 FP64 場 (`res_48000.h5`) と固定壁温 (`wall_profile_5.csv` 同一、`conjugate.warmup` 900000)、`cfl_pseudo` 0.5。
  - A `run_0017_lim_c1_n64_lim2` は `space.limiter: 2`。
  - B `run_0018_lim_c1_n64_lim0` は `space.limiter: 0`。**無制限の 2 次再構成**で、係数の凍結でも 1 次化でもない (`limiter_d.cu:450`)。
  - 各 12000 step (4000 × 3 区間)。診断用で、収束を保証する長さではない。
- **観測**: B2′ の毎 step 系列に加え、全域の `res_ro/res_roUx/res_roUy/res_roe` (`extraFields`) から次を採る。
  - 3 領域 (前縁帯: x/L∈[−0.1,0.02]、後縁帯: [0.98,1.1]、いずれも y ≤ 0.05 L。その他) ごとの残差二乗和を毎 step 記録し、時間積算の割合を出す。
  - 全域 RMS `sqrt(Σres²/nNodes)` を `residual_history.csv` と照合する。
  - `limiter_ro/Ux/Uy/P` の節点ごとの時間標準偏差の分布。
- **判定** (事前登録):
  - 前提: A が `run_0016` の最終区間の残差 (能動全列) と下流 slip の P の振幅を、各 ±10 % 以内で再現すること。
  - B の最後の 2 区間で、能動全残差と下流 slip の P の振幅が A の最終区間の 1/10 以下に減衰 → **リミッタを含む再構成への依存を支持** (時間変動だけの因果の証明ではない)。
  - B でも全指標が A の 1/2 以上に残り、3 区間の max/min ≤ 1.1 → **「リミッタ単独が原因」を棄却** (境界の欠陥の確定にはしない)。
