## 1. 目的

発注元 plan の C (共役平板: C1 厚さ方向の抵抗、C2 板の軸方向伝導) は、主判定 (界面温度・熱流束の独立参照解との比較) が 6 本すべて PASS したが、
**前提ゲートの流体収束と G-if が 6 本とも NOT CONVERGED** で、登録どおり**判定不能**として保留した。
本 plan はその原因を切り分け、登録条件を満たす形で C を再判定する。**完了条件は発注元 plan の §6 (C) のまま**変えない。

## 3. 引き継ぐ事実 (発注元 plan §5.1 #6・#6b)

- 主判定 PASS (C1 n64: θ 差 6.1e-4、q 0.10 %。C2 n64: θ 1.3e-4、q 0.38 %)。準定常 (評価窓内の全節点) PASS、G-cons PASS。
- **前提ゲート FAIL**: 流体収束 NOT CONVERGED (stalled、rms_roe 1.4 桁で横ばい)。G-if NOT CONVERGED: 界面残差は板の端に集中 —
  n32 は後縁 x/L 1.0 (5.8 W/m²)、**n64 は前縁の直後 x/L 0.004〜0.015 (C1 678 W/m²・C2 607 W/m²)**、評価窓内は 0.14〜0.15 W/m² (許容 1.0 内)。
  細格子ほど悪化。後縁のすぐ下流の slip 境界に最大の時間変動 (P 3 Pa、T 3e-3 K)、前縁上流の slip 節点に法線速度 0.72 m/s。
- 原因は**未確定** (node slip の既知欠陥、前縁の熱流束の特異性と連成反復、抽出のどれか)。
- **追加の事実 (2026-10-01、手元の記録から)**: ④ res_solid は 2^-32 の整数倍の離散値しか取らない。codex の Python 再現では、厳密平衡 (一様 310 K・界面荷重 0) でも非界面残差が n16 C1 3.725e-9 W/m・n64 C1 9.313e-10 W/m となり、Robin h 1e8 の大きな相殺項の丸めが ④ に支配的に寄与する。ただし n64 C1 の後半の更新の 96.7 % は ④ の閾値内で、問題は 80 回連続判定の頑健性。n64 C1 の res_abs は 5000 step 以降 14〜742 W/m² (末尾 400 更新の平均 183) で減衰せず振れ続ける。n32 は末尾で dTw ≤ 7.0e-5 K と壁温がほぼ動かないのに、流体は同型に停滞している。
- **slip 欠陥との一致は未確認**: 既知の欠陥の症状は市松状の**接線**速度だが、今回の観測は前縁上流の slip 節点の**法線**速度。節点の `Uy` だけで壁面の漏れとは言えない (座標・法線・境界流束で確かめる)。

## 4. 切り分けの設計 (2026-10-01 codex diagnose [`2026-10-01-conjugate-plate-cause-design-diagnose.md`](../../notes/reviews/2026-10-01-conjugate-plate-cause-design-diagnose.md) を採用)

### 4.1 B1: 壁温の更新の有無だけを変える A/B (最優先)

- **問い**: 壁温の更新 (連成のフィードバック) が無くても、流体は同じように停滞するか。
- **開始点**: `run_0007_c1_n64` の同一時刻の流体場 `res_600000.h5`・固体の状態 `conjugate_state_5.h5`・壁温分布を、同一の FP64 バイナリで再開する。流体場は `restart_field.py --keep-src-dtype` で複製する (手元の `mesh.h5` の保存量は float32 なので、通常のコピーでは FP64 の場を丸めてしまう)。
- **A (連成継続) `run_0011_ab_c1_n64_coupled`** / **B (壁温固定) `run_0012_ab_c1_n64_fixed_tw`**:
  - 両側とも同じ壁温分布を読み込む。`conjugate: 1` を外すだけだと一様 `Ts 300` に戻り別の実験になるので、外さない。
  - B は `conjugate.warmup` を再開後の累積終了 step より大きくし、更新の手前で戻す。**変えるのはこの 1 キーだけ**。
  - `Df_scale`・slip・CFL・閾値は変えない。
- **長さ**: 各 60000 step。20000 step ずつ 3 区間で評価する。出力間隔は両側共通で細かくし、全残差・界面全節点の熱流束・前縁と後縁付近の `P/T/U_n` の時系列を採る。
- **判別 (事前登録。収束の合格条件ではなく診断用の比)**:
  - 前提: A が元の停滞を再現すること (`rms_ro`・`rms_roUy`・`rms_roe` が 1 桁以上下がらずに横ばい)。
  - B の末尾 2 区間で `rms_ro/rms_roUy/rms_roe` の 3 列がすべて A の **1/10 以下**になり、局所変動も減衰した場合 → 「流体側だけで同程度の停滞を維持する」を棄却 (連成が停滞を維持している)。
  - B でも 3 列が A の **1/2 以上**に残り、最後の 3 区間の代表値が 10 % 以内で横ばいの場合 → 「動的な連成だけが停滞を維持する」を棄却 (流体側の要因)。この場合も slip が原因とは断定しない。
  - 中間の結果・減衰途中なら、両側を 120000 step まで延長する。それでも分かれなければ判定不能。
  - 両側を `check_convergence.py` (単一区間。元の run は未収束なので `--from-floor` は使わない) と `check_quasisteady.py` で判定して併記する。

### 4.2 後回し・却下

- **B2 `Df_scale 20`**: 初手にはしない。壁温の振幅が小さくなっても、流体の揺れを減衰させただけかもしれないため。B1 の結果を見てから決める。
- **B3 slip を no-slip にする・領域を短くする**: 却下。登録した問題 (前縁に流入する境界層) が変わり、改善しても slip 実装の欠陥を特定できない。
- **④ の閾値を `h·T_h·Δx` で相対化する**: 却下。この尺度は大きな相殺項で、検証したい伝熱荷重そのものではない。まず残差評価の丸めと保存温度の量子化を分け、温度差で組んだ残差を高精度の評価と照合する。基準を改訂する場合は、旧 FAIL と新判定を併記し、事後改訂として扱う。
