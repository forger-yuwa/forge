## 1. 目的

発注元 plan の C (共役平板: C1 厚さ方向の抵抗、C2 板の軸方向伝導) は、主判定 (界面温度・熱流束の独立参照解との比較) が 6 本すべて PASS したが、
**前提ゲートの流体収束と G-if が 6 本とも NOT CONVERGED** で、登録どおり**判定不能**として保留した。
本 plan はその原因を切り分け、登録条件を満たす形で C を再判定する。**完了条件は発注元 plan の §6 (C) のまま**変えない。

## 2. スコープ

- **やる**: 前提ゲート FAIL の原因切り分け (境界実装・連成反復・抽出のどれか)、対処、再判定
- **やらない**: C の窓外を事後にゲートから外して完了扱いにすること、slip を真因と決めて修正に入ること (切り分けの前に)

### 4.1 B1: 壁温の更新の有無だけを変える A/B (最優先)

- **問い**: 壁温の更新 (連成のフィードバック) が無くても、流体は同じように停滞するか。
- **開始点**: `run_0007_c1_n64` の同一時刻の流体場 `res_600000.h5`・固体の状態 `conjugate_state_5.h5`・壁温分布を、同一の FP64 バイナリで再開する。流体場は `restart_field.py --keep-src-dtype` で複製する (手元の `mesh.h5` の保存量は float32 なので、通常のコピーでは FP64 の場を丸めてしまう)。
- **A (連成継続) `run_0011_ab_c1_n64_coupled`** / **B (壁温固定) `run_0012_ab_c1_n64_fixed_tw`**:
  - 両側とも同じ壁温分布を読み込む。`conjugate: 1` を外すだけだと一様 `Ts 300` に戻り別の実験になるので、外さない。
  - B は `conjugate.warmup` を再開後の累積終了 step より大きくし、更新の手前で戻す。**変えるのはこの 1 キーだけ**。
  - `Df_scale`・slip・CFL・閾値は変えない。
- **長さ**: 本段は各 60000 step (20000 step × 3 区間)、中間の結果なら 120000 step まで延長。
- **B の実現**: `conjugate.warmup` を A 5000 (元のまま) / B 900000 (延長後も更新しない) にする。**変えるのはこの 1 キーだけ**。

#### 4.1.1 予備確認 (200 step、本段の前提。2026-10-01 codex diagnose [`planreview-disposition`](../../notes/reviews/2026-10-01-conjugate-plate-planreview-disposition-diagnose.md))

- 同一起点から A/B を 200 step、**毎 step 出力**で回す。
- 受入条件:
  - 初期壁温の A/B 差 ≤ 1e-9 K。
  - B の壁温が固定されている。
  - A は累積の更新 step・更新回数・壁温の変化で連成の継続を確かめる。更新番号の継続は条件にしない (`flux_avg: 1` では `nUpdate` が復元されない、`conjugateWall.cpp:655`)。
  - 出力名の step は残差の step より 1 大きく、出力は連成の更新前 (`main.cpp:1808`)。
- **採取間隔の検定**: 本段の出力間隔の候補は 11 step (連成の 50 位相を全部巡回、60000 step で 5454 組)。予備確認の毎 step 系列と、11 step に間引いた系列で、判別対象の標準偏差が 10 % 以内で一致すること。満たさなければ本段へ進まない。短い予備確認では長周期の採取精度までは保証しない。

#### 4.1.1b 予備確認の結果と採取方法の改訂 (2026-10-01、事後改訂)

- **改訂** (codex diagnose [`sampling-redesign`](../../notes/reviews/2026-10-01-conjugate-plate-sampling-redesign-diagnose.md)): 間引きをやめ、**全判別量を毎 step・FP64 で保存**する。
  - forge は毎 step の通常出力 (流体 `res_N.h5`・壁 `res_plate_5_N.h5`) を書き、並走する `ab_extract.py` が登録節点 (流体 124 点の P/T/Uy、全界面 161 点の q/Tw) を FP64 のまま `ab_series.npz` に抜き出して、処理済みの h5 を消す。2000 step ごとの全場は残す。

  - 間引きが無くなるので、採取間隔の検定は本段の前提から外す。
  - 200 step で見えた「前縁帯の界面熱流束の変動が A 0.1245・B 0.1206 とほぼ同じ」は、原因の除外に使わない。本段の 3 区間の減衰判定に使う。

#### 4.1.2 観測仕様 (事前登録)

- **節点集合** (`mesh.h5` の `MESH/COORD` と `BCONDS/*/iCells` から作り、期待数と照合。欠落・重複・非有限は REFUSED。`CELLS/centCoords` は y=0 に節点が無いので使わない):
  - 板の界面: 前縁帯 x/L∈[0,0.02] と後縁帯 [0.98,1]、各 10 点。熱流束は全界面の系列も保持する。
  - slip: 上流 x/L∈[−0.1,0)、下流 (1,1.1]、各 21 点。
  - 上記の直上の内部 1 列 (同数、高さ 2.5e-6 m)。
- **量と尺度**:
  - P は q∞ = ½ρ∞U∞² = 709.275 Pa、T は T_h − T∞ = 10 K、`Uy` (+y 方向の速度成分。漏れ流束とは呼ばない) は U∞。
  - 界面熱流束は、元 run の step 600000 の評価窓 x/L∈[0.2,0.9] の台形積分平均の絶対値で割る。
- **残差**: `rms_ro/rms_roUy/rms_roe` の 20000 step 区間の算術平均。横ばい = 3 区間平均の max/min ≤ 1.1。
- **振幅**: 量ごと・節点群ごとに、区間内の規格化系列の標準偏差の節点最大値。異なる量を一つの最大値にまとめない。
  - 「減衰」= B の最終区間の振幅が A の最終区間の 1/10 以下、かつ B の区間振幅が 3 区間で厳密減少。
  - A・B とも振幅が測定床 (予備確認で測る毎 step 系列の丸め変動) に達している系列は、比では評価しない。
- **A の再現**: A の区間平均残差が元 run の最後の 60000 step の区間平均の 1/2〜2 倍。かつ、界面残差 (`conjugate_history.csv` と同じ定義) の最大位置を、元 run と同じ定義・同じ長さの区間で比べて同じ帯にあること。満たさなければ B1 は判定不能。
- **補助診断**: 区間ごとの CSV を `check_quasisteady.py --series-csv --series-cols … --tail 1 --abs-scale 1 --drift 0.002 --osc 0.002` にかけて併記する。温度では 0.02 K 相当なので、0.003 K の変動を STEADY とする可能性がある。B/A 振幅比の判別は置き換えない。

### 4.3 B2′: 擬似時間刻み (`cfl_pseudo`) の A/B (2026-10-01 codex diagnose [`fluid-stall-next`](../../notes/reviews/2026-10-01-conjugate-plate-fluid-stall-next-diagnose.md))

- **問い**: 有限の擬似時間刻みと更新作用素の組み合わせが、減衰しない反復振動を維持しているか。上流 slip の P の周期 7.24 step (パワーの 92 %) は物理時間の周期ではない。
- **起点**: B1 と同じ (`run_0007` の step 600000・固定壁温。`conjugate.warmup` 900000)。バイナリ・他の設定は共通。
  - **対照 A** `run_0015_cfl_c1_n64_cfl2`: `cfl_pseudo` 2 のまま、12000 step (4000 × 3 区間)。
  - **試験 B** `run_0016_cfl_c1_n64_cfl05`: `cfl_pseudo` 0.5 だけ変える、48000 step (16000 × 3 区間)。CFL × step を揃える。局所刻みなので、観測節点の累積 `dt_local` でも時間幅を確かめて併記する。
- **観測**: B1 の毎 step 系列 (P・T・Uy・界面 q/Tw) に加え、同じ節点で `Ux`・`ro`・`dt_local`・リミッタ値 (`limiter_ro/Ux/Uy/P/T`) を採る (`extraFields`)。接線速度 `Ux` の空間の交互成分 (隣接節点の符号交替) も見る。
- **判別** (区間は A 4000 step・B 16000 step の各 3 区間):
  - 前提: A が `run_0012` と同じ停滞を再現する (残差の区間平均が `run_0012` の 1/2〜2 倍、横ばい)。満たさなければ判定不能。
  - B の最後の 2 区間で、能動な残差の全列 (`rms_ro/rms_roUx/rms_roUy/rms_roe`) と主要な変動 (前縁帯の界面 q・下流 slip の P・上流 slip の P) が A の最終区間の 1/10 以下、かつ減衰傾向 → **有限刻み依存を支持**。「空間的な欠陥だけで同程度の振動が不可避」を棄却する (H1・H3 の潜在的な欠陥までは除外しない)。
  - B でも A の 1/2 以上が残り、3 区間の平均・振幅の max/min ≤ 1.1 → **「CFL 2 → 0.5 の縮小で主要な停滞を解消できる」を棄却**。H3 (slip) の確定とはしない。
  - 中間・発散・対照の再現失敗は判定不能。短い診断から収束を宣言しない。収束は別途 `check_convergence.py`、準定常も併記する。
- **やらない**: `implicitRelax` と CFL の同時変更。slip → no-slip で原因を確定すること。1 次化 (`convMethod: 0`) で改善しただけで H1 を採ること。`limiter: 0` は 1 次ではなく無制限再構成 (`limiter_d.cu:450`) なので「1 次」として使わない。
- **C の完了条件は 6 本全合格を維持**。停滞が解けなければ「前提ゲート不合格、C は判定不能・未完了」とし、事後の窓除外・時間平均化・閾値緩和で完了させない。

### 4.2 後回し・却下

- **B2 `Df_scale 20`**: 初手にはしない。壁温の振幅が小さくなっても、流体の揺れを減衰させただけかもしれないため。B1 の結果を見てから決める。
- **B3 slip を no-slip にする・領域を短くする**: 却下。登録した問題 (前縁に流入する境界層) が変わり、改善しても slip 実装の欠陥を特定できない。
- **④ の閾値を `h·T_h·Δx` で相対化する**: 却下。この尺度は大きな相殺項で、検証したい伝熱荷重そのものではない。まず残差評価の丸めと保存温度の量子化を分け、温度差で組んだ残差を高精度の評価と照合する。基準を改訂する場合は、旧 FAIL と新判定を併記し、事後改訂として扱う。
