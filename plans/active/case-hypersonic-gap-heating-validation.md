## 1. 目的

**平板 (smooth wall) の熱伝達に対して、極超音速流にさらされたすきま / 深いキャビティ内部の熱伝達が
どうなるか**を、(a) 既往の試験・相関で押さえ、(b) その公開データで forge を検証する。
完了時に得られる状態:

- **文献側** (完了): 層流・乱流それぞれの一次データと相関が、幾何・条件・正規化基準・不確かさつきで
  [survey](../../notes/investigations/hypersonic-gap-cavity-heating-survey.md) にまとまっている。
- **層流検証 (T1)**: [W70] NASA TN D-5908 (2D 深キャビティ 4 幅, $M$≈6.9, 冷壁, 層流) の
  $p_c/p_m$・局所分布・開口面積平均比を、**文献と同じ定義・同じ分母**で再現できたか否かが数値で出る。
- **乱流検証 (T2)**: [TH76] NASA TN D-8233 (**単独横すきま $W$=2.29 mm × $D$=45.7 mm → $D/W$=20.0**,
  $M$=10.3, 乱流, **外面/すきま壁 温度比 1.0–1.6**) を再現できたか否かが数値で出る。
  case/49 ($D/W$=20.0, 乱流, 温度比 ≈2.4) と**幾何比・壁温配位が同型**の唯一の公開データ。
- **case/49 への受け渡し**: T2 が成立した範囲でのみ、モデル誤差を数値で渡す。成立しない量は
  **「未定量」と明記して渡す** (codex C1 採用)。

### 3.2 [W70] の幾何 — **図面座標で固定する** (codex M2 採用、本計画で独立検証)

旧稿は「圧力孔 3.5 in = キャビティ位置」と誤っていた。Fig 1(a) を 220 dpi で描画して確認した結果:

- **前縁から後壁 (z 軸) まで 6.24 in = 158.5 mm**。模型圧力孔 3.5 in は**上流の面圧計測点**で、キャビティ位置ではない。
- 前縁は**公称 $r$=0.03 in = 0.76 mm** (図面値)。試験終了時の最大鈍化 1.5 mm は本文。
- $L$ (前縁→分離点 = 前壁) $=6.24\,\mathrm{in}-w$、キャビティ中点 $=6.24\,\mathrm{in}-w/2$。
- 深さ $d$=0.8 in=20.3 mm、スパン $\ell$=3 in (2D 確認用に 1 in)。キャビティ圧力孔は**床から 0.05 in**。
  最上部熱電対は Table I の $x$=0.01 in=**0.254 mm** ($x/d$=0.0125)。

**独立検証** (本計画で実施): 報告の $N^*_{Re,L}$=1.4–1.8e5 は、$L$≈157 mm + Eckert 基準温度
($T^*/T_\infty\approx3.1$, $\rho^*\mu^*$ 補正 ≈0.14) で $Re^*_L\approx1.3$e5 となり整合する。
$L$=88.9 mm なら 0.7e5 で合わない。→ **6.24 in を採用**。

### 4.2 条件の再構成 — 「再現確認」と「照合」を分ける (codex M3 採用)

旧稿の「3 点同時一致」は、$M$・$Re_\infty$ を**入力として合わせているだけ**で独立な検証点ではなかった。分離する:

1. **ゲート A (再現確認)**: 組成 $Y$ と輸送則を固定したうえで、
   $h(T_\infty,Y)+\tfrac12 M^2\gamma(T_\infty,Y)R(Y)T_\infty = h(T_t,Y)$、
   $\rho_\infty = Re'_\infty\,\mu(T_\infty,Y)/U_\infty$ を解いて $(p_\infty,T_\infty,\rho_\infty,U_\infty)$ を一意に決める。
   これは**入力の再現**であって検証ではない、と明記する。
2. **ゲート B (照合)**: 上で決めた状態から Pohlhausen + Eckert で $q_{fp}$ を再計算し、Table IV 値と照合。
   **これは「基準式と物性の整合確認」**であって実験検証ではない (文献の $q_{fp}$ も解析値)。
3. **診断**: 再構成した全圧と実測 $p_t$ の差を残す。**組成誤差を未特定の全圧損失に吸収させない**。
4. **試験気体**: [W70] が物性に用いた文献 (ref. 18) を特定し、**燃焼生成物の組成・輸送則・低温域の扱い**を先に固定する。
   空気 TP は**代替モデルの感度**として扱う (一次ではない)。CEA を使う場合は燃空比・反応物温度・凍結条件を明記する。

### 4.2b T2 の成立ゲート — 試験の流入場を再構成できるか (codex 2 巡目 M1 採用)

[TH76] は**トンネル側壁の厚い乱流 BL** に面一で置いた模型であり、掃引角を 0° にしても流入場が 2 次元になるわけではない
([TH75] pp.8–11 が横方向の BL 分布変化・壁圧と自由流静圧の差・トンネル圧縮領域を明記)。したがって:

1. **T2 は「中央断面の 2 次元近似」と定義する** (試験の忠実再現ではない)。
2. 入口条件は $\delta^*,\theta$ の 2 つでは決まらない。[TH75] Fig 11–13 の分布と [TH76] Fig 4 の積分厚さから、
   **入口〜開口直前の $U,T,p,k,\omega$、加熱区間長、実効 $\delta^*,\theta$** を固定する。
   `inlet_uniformVelocity` + `inletProfile` は**亜音速部を特性関係/圧力外挿で作る**ので
   ([`boundaryCond_d.cu`:814](../../solver_density_cuda/cuda_forge/boundaryCond_d.cu))、CSV の全量が固定されるとは限らない。
   **場に入った値を verify で確認する**。
3. **投入条件 (T2-G0) — 定量で書く**: すきま無しの再構成で次を満たすこと。**満たすまで T2 本体に進まない**。
   - **参照の熱条件を合わせる**: $h_{fp}$ 相関は**等温 ($T_{surf}/T_{gap}$=1.0) の基準模型**に由来するので、
     G0 の比較は**等温条件の smooth 計算**で行う (加熱履歴つき smooth に $h/h_{fp}\approx1$ を課さない)。
   - 比較断面・比較位置・尺度・許容を `acceptance.json` に**事前登録**する
     (圧力: 壁圧の相対差 / 熱伝達: $h/h_{fp}$ / BL: $\delta^*,\theta$ と分布形の $L^2$ 差)。
   - **未測定量 ($k,\omega$) は「実測再現量」と区別**し、仮定値と感度範囲を明記する。
   満たせない場合、T2 は「探索」に降格し、case/49 への受け渡しは行わない。
4. $\delta^*$ ±20 % の感度は**厚さの不確かさ**であって、熱的履歴・乱流分布の不確かさの代替ではない。
   加熱区間長と壁温履歴は別の感度として扱う。

#### 4.2c ゲート A / B の実測 (2026-09-19, case/50)

[`case/50.deep_cavity_wieting_m7/tools/conditions.py`](../../case/50.deep_cavity_wieting_m7/tools/conditions.py) を実行した結果:

#### 4.4c 幅依存性は「比」でなく「絶対量」で見る (2026-09-20)

#### 4.7-4 T1 の残差プラトーの正体 — 有界な振動であって停滞ではない (2026-09-20)

G9 (残差 PASS) が達成可能かを決めるために、`run_0016_T1_wd0063_fine_settle` (150k step、
`unsteady: 0` の定常局所 dt、層流、block-DPLUR、`implicitRelax: 0.7`) の残差履歴を調べた。

- **丸め誤差の床ではない**。`rms_ro/\langle\rho\rangle` は float32 eps の **90 倍** (他の 3 幅では 390–490 倍)。
  あと 2 桁の余地がある。
- **全保存量が完全に同期して動く**。区間平均の比が `rms_ro` 1.513 / `rms_roUx` 1.513 /
  `rms_roUy` 1.511 / `rms_roe` 1.516 と 3 桁一致する。**残差ベクトルの向きが固定されていて
  振幅だけが動いている** = 単一の大域モード。
- **トレンドが無い**。$d\log_{10}(rms_{\rho})/d(10^5\,\mathrm{step})$ は全区間 **−0.070 ± 0.003**、
  後半 −0.030 ± 0.008、**末尾 25 % は +0.100 ± 0.023** (上昇)。全区間の傾きで外挿しても
  あと 1 桁下げるのに **140 万 step** かかる。
- 振幅は `rms_ro` = 3.2e−8 … 1.6e−6 の **1.5 桁**を数万 step 周期で往復する。

→ **「停滞 (stalled)」ではなく「有界な振動」**。`check_convergence.py` の
「needs scheme change, not more steps」という表示は、この case では正しい。
候補は定常局所 dt がキャビティの音響モードを減衰できないこと
(memory `steady-localdt-acoustic-transient-instability` と同型) だが、**未検証の候補**である。

**G9 への含意**: 現在の定式化では残差 PASS は step 数では達成できない。報告量 $Q_c$ は
`STEADY` (drift 0.4–1.6 %/tail) なので**報告量としては使える**が、**G9 を満たしたとは書かない**。
基準の組み替えか定式化の変更かは §5.1 #46 で決める。

#### 4.7-5 SU2 クロスチェックは「反復数」でなく「擬似時間」で揃える (2026-09-20)

`run_0007_xcheck_su2` を 200k 反復まで回し、100k と 200k の場を重ねたところ深部の
$\lvert U\rvert$ がほとんど動いていなかった (904→914 / 591→586 / 431→401 / 344→301 m/s)。
一度は「SU2 は**換気された**定常状態に落ち着き、forge の静穏な状態と違う」と読んだが、
**これは誤り**である。`AVG_CFL` を出力させると **0.30 に張り付いていた** (`CFL_ADAPT_PARAM` の
`CFL_min` そのもの)。

**CFL 適応が原理的に下限へ落ちる**: SU2 は残差が増えた反復で `CFL *= factor_down`、
減った反復で `CFL *= factor_up` する。既定の `(0.5, 1.2)` は積が **0.60 < 1** なので、
**残差が振動している限り CFL は必ず下限へ落ちる**。§4.7-4 のとおりこの case の残差は
有界振動なので、条件がそろっている。係数を `(0.95, 1.05)` (積 0.9975) にしても
1000 反復で 0.29 倍になり、2.0 から下限 1.0 まで落ちた (`run_0010_xcheck_su2_cfl` 初回)。

**擬似時間で見た進み方** (同一メッシュ 65194 節点、他プロセスなしで実測):

| | ms/反復 | 実効 CFL | CFL/秒 |
| --- | --- | --- | --- |
| forge (RTX 3060) | **4.36** | 1.5 | 344 |
| SU2 (i5-12400F × 6 スレッド) | **59.4** | 0.30 | 5.1 |

1 反復あたり 13.6 倍、**擬似時間の進み方で 68 倍**。累積では
forge 800k×1.5 = 1.20e6 CFL-step に対し SU2 200k×0.30 = 6.0e4 CFL-step = **forge の 1/20**。
→ **「10 万反復動かないから定常」は、この CFL では根拠にならない**。SU2 は単にまだ
排出しきっていないだけの可能性が高い。

**含意**: 外部ソルバとのクロスチェックで「片方だけ違う状態にいる」と言う前に、
**両者が同程度の擬似時間を進んでいるか**を確かめる。反復数・壁時計・残差レベルは
いずれもその代理にならない。SU2 側は `CFL_ADAPT= NO` + 固定 CFL で進める
(`case/56/_cflprobe_{5,10,20}` で安定上限を確認中、本番は `run_0010_xcheck_su2_cfl`)。
なお 12 スレッドは 113.7 ms/反復で 6 スレッドより遅い (i5-12400F は 6 物理コア)。

##### 4.7-6a 減衰は対数的で、tail 窓の drift 判定をすり抜ける

帯 5–10 の $\bar u$ は $\log(\text{step})$ に対して直線 (32.4 mm/s → 17.4 mm/s、

> **撤回 (2026-09-23)**: 本セッションは $v=v_\infty+Ae^{-s/\tau}$ を 6 点に事後フィットして
> 「漸近値 2.395 W/m² ($\tau$=3.23e5)」と報告した。**§4.7-3 が禁じている手であり、実測で破れた**:
> 通算 1.35M step の実測 1.9650 に対しフィット予測 2.4127 (**+23 %**)、しかも差は開き続けている。
> **漸近値を引用しないこと。**

**→ 深部を報告するゲートは、$q_w$ の tail drift ではなく「深部帯の $U_y$ 平均 (= dilatation) が
十分小さいこと」に置くべき** (目安: $\lvert\bar u\rvert < 10^{-4}$ m/s ≈ SU2 の 3–5 帯レベル)。

##### 4.7-6c 「step を増やせば済む」ではない — 不均衡はべき乗則で残る (2026-09-23)

「あと何 step 回せばよいか」を、**保存則そのもの**で測った。水平断面を通る正味の質量流束
$\dot m(z)=\int\rho U_y\,dx$ は、**定常解ならどの深さでもゼロ**でなければならない。

| z/W | forge (通算 1.6M) | SU2 (160k 反復) |
| --- | --- | --- |
| 5 | −4.06e-7 | −1.78e-9 |
| 8 | −5.84e-7 | **−6.30e-12** |
| 15 | −4.54e-7 | **−8.59e-12** |
| 25 | −2.26e-7 | 3.96e-12 |
| 32 | −7.41e-8 | **−1.05e-14** |

**SU2 は 1e-12〜1e-14 で保存を満たす** (= 定常解)。forge は深さによらず 4–6e-7 が残る。

$z/W$=15 の $\lvert\dot m\rvert$ を 50k–1.6M step の 32 枚で追うと、**step のべき乗則**になる:

$$\lvert\dot m\rvert \propto \text{step}^{-0.2046}\quad(\text{log-log 相関 } -0.9989)$$

すなわち **step を 2 倍にしても 13.2 % しか減らない**。SU2 の水準 8.6e-12 に達するには
$2^{97.4}=2.1\times10^{29}$ step = **1e19 年**。

→ **「step を増やせば収束する」は成り立たない。** `check_convergence` の
`needs scheme change, not more steps` は文字どおり正しい。

> **撤回**: 本セッションは先に $q_w$ を $\ln(\text{step})$ に線形フィットして
> 「1.3e8 step (59 時間) で SU2 水準に届く」と見積もった。**べき乗則を有限区間で対数線形に
> 見誤ったもの**で、正の量が有限 step でゼロを横切るという不合理な外挿だった。採らない。

**まだ分かっていないこと**: 擬似時間律速 (CFL 側) なのか、離散方程式が深部で非ゼロの質量ソースを
持つのかは**未決**。判別には面流束の和 `res_ro` が要るが、**`res_ro` は `output_cellValNames` に
登録されていない**ので level 2 でも `extraFields` でも出ない (出るのは `res_roK`/`res_roOmega` のみ)。
LSQ 再構成勾配から組んだ $\rho\nabla\cdot u+u\cdot\nabla\rho$ を代理にすると、実測の密度変化の
**574 倍**を予測するので**代理にならない** (節点で $\nabla\cdot u\neq0$ でも面流束の和は 0 になりうる)。
→ §5.1 #56。

##### 4.7-6d `res_ro` の実測 — **当初の結論は撤回** (2026-09-23)

**`res_ro` は `FORGE_OUT_RESIDUALS=1` で出せる** (`main.cpp:2113`。`output_cellValNames` には
最初から入っているが GPU から戻していないため level 2 だけでは出ない)。ソース変更も再ビルドも不要。
書かれる値は「最終サブ反復・最終 sweep 時点」の `res_*` = block-DPLUR の固定 RHS = 面流束の和。

> **撤回**: 当初「$\langle res\_ro\rangle$ の step 倍加あたり減衰比 0.855 が質量流束 $\lvert\dot m\rvert$ の
> 0.853 と一致する → 残差と場が一緒に縮んでいる → 離散方程式は整合しており構造的な質量ソースではない」と
> 書いた。**これは誤り**。深さ $z$ より下の CV の `res_ro` を足し上げると望遠鏡和でその断面の流束になる:
>
> | z/W | $\Sigma res\_ro$ (下) | $\int\rho U_y dx$ | 比 |
> | --- | --- | --- | --- |
> | 8 | 6.1057e-07 | −5.8347e-07 | −1.046 |
> | 15 | 4.5460e-07 | −4.5356e-07 | **−1.002** |
> | 25 | 2.2673e-07 | −2.2504e-07 | −1.008 |
>
> **両者は定義上同じ量**であり、「2 つが同じ率で減った」は独立な一致でなく恒等式だった。
> したがって構造的ソースの否定にはならない。**構造的ソース仮説は依然として未否定**
> (S があるなら残差は S で頭打ちになるが、べき乗則なので頭打ちの手前にいるだけかもしれない)。

**言えること**: 深部 ($z/W>10$, 16607 節点) の $\langle res\_ro\rangle$ は 3.42e-11、
rms 6.71e-11、mean/rms = 0.510。ゼロ平均ノイズの $1/\sqrt N$ = 0.0078 に対し **65 倍系統的**。
すなわち**正味の質量流入が系統的に存在する**。これは $\dot m$ の測定と同じ事実の別表現。

**否定できた構造的ソース候補**: 双対面の閉性は `check_dual_closure.py` で
`|\Sigma S|/\Sigma|S|` が median 0・**max 3.31e-08**・`VERDICT: PASS` (65194 CV, 閾値超え 0)。
→ **幾何的な閉性の欠陥ではない** (SERN で問題になった型は該当しない)。

**残差の空間分布** (深部、単位体積あたり): z/W 4-10 / 10-20 / 20-30 / 30-35 で
7.12 / 7.13 / 6.61 / 7.18 e-3 kg/m³/s = **深さによらず一様**。壁からの距離でも中央まで一様に分布。
→ 境界処理に局在した源ではなく、**分布した源**の形。ただし過渡の一様充填も同じ形になるので、
これだけでは両者を分けられない。

#### 4.4a 正規化は文献ごとに 3 形式ある — 同じ作り方で作る (2026-09-19 追加)

| 形式 | 文献 | 分母 | 駆動温度差 |
| --- | --- | --- | --- |
| **(i) 冷壁 $q$ 比** | [A78] TP-1187、[WAC75] TM X-3225 | **較正パネル / タイル中央で実測した冷壁熱流束** $q_{FP}$ [kW/m²] (TP-1187 の symbol list は `q = cold-wall heating rate`)。薄肉過渡法なので「冷壁」は**データ取得時点で壁が室温付近**という状態を指す | **割らない** ($q$ どうしの比) |
| **(ii) 冷壁 $q$ ÷ 解析 $q$** | [W70] TN D-5908 | 同じ冷壁条件の**計算値** (Pohlhausen + **Eckert 基準温度** $T^*$、物性評価にのみ $T^*$ を使う) | 割らない |
| **(iii) $h$ 比** | [TH76] TN D-8233 | $h_{fp}=C\,(Re'_\infty)^{0.69}$ (平板の実験相関)。分子も $h=q/(T_{aw}-T_w)$ | **明示的に割る** ($r$=0.89) |

- **(i) は $h$ 比ではない**。すきま内は $T_{aw}$ が外部と違うのに駆動温度差を割っていないので、
  深部では $q$ 比が $h$ 比より小さく出る方向にずれる。**文献の比を $h$ 比と読み替えない**。
- **理論 (Burggraf, W70 Appendix B) も「$q_{fp}$ の何倍か」でしか定義されていない**:
  $q_s/q_{fp}=0.6\,Q(X)$ で、$Q(X)$ は形状だけの分布 (一般化 Riemann ゼータ)、絶対値は
  Chapman の $0.60\,q_{fp}$ ($Pr$=1) で与える。**$Pr=1$ の仮定の下では壁温は比から落ちる**が、
  実際の $Pr\approx0.7$ では $(h_t-h_w)/(h_{aw}-h_w)$ の分だけ残る (本条件で +12 %)。
  → **壁が熱いほど効きが増し、断熱壁では $q_{fp}=0$ で比が定義できない**。
  **case/49 (平板断熱) に (i)(ii) 形式の $q$ 比を使ってはいけない** — (iii) の $h$ 比にする
  (2026-09-19 決定。実装 `case/50/tools/burggraf.py`)。
- **CFD 側は文献ごとに同じ作り方で作る**: (i)(ii) は等温壁の $q$ をそのまま比に、(iii) は $h$ に直してから比にする。
  どの形式で作ったかを出力ファイルの属性と表の列名に書く (`ratio_kind: q_cold | q_over_theory | h`)。

- **分母 $h_{fp}$ は試験の平板相関** ($N_{St}Re^{x}_{w,\theta}$=const を $h_{fp}=C\,(Re'_\infty)^{0.69}$ に還元、Appendix)。
  **係数 $C$ は Appendix 図から digitize して固定**する。指数 0.69 は効きが大きく、
  $Re'_\infty$ を 1.5→7.8e6/m にすると分母は **3.12 倍**になる → **G13 ($Re$ 依存の向き) はこの正規化に依存する**ので、
  分母の digitize 誤差を G13 の判定に伝播させる。
- **CFD も同じ演算で $h/h_{fp}$ を作る** (forge の smooth run で分母を作り直さない)。

##### 4.2b-1 T2-G0a — 報告の $\theta$ は圧縮性運動量厚さではない (2026-09-20)

$C_f$ を入力にせず (Gate B で相関と VD-II が 1.8 倍違うため)、実測 $\delta^*,\theta$ から
$(\delta, u_\tau)$ を解こうとしたところ **2 条件が両立しなかった**。報告の形状係数は
$H=\delta^*/\theta$ = **8.89** だが、$M$ 10.3 の圧縮性 (質量流束) 定義では $T_w$ 300→995 K・
速度冪 $1/7$→$1/20$ の全域で $H$ = **24.0–40.4** にしかならない ($T_w/T_\infty$=5.7 で BL 内密度が
$\rho_e$ の 0.12–0.18 倍に落ちるため)。圧縮性定義で 8.9 を出すには $M_{eq}\approx6.7$ が要る。

**原典 Fig 4 を再読して digitize を確認した — 読み取りは正しかった**。右パネルは
$w$=0.229 cm を図中に明記して $\delta^*/w$=56, $\theta/w$=6.3 を直接プロットしている。
定義の組合せを総当たりすると **$\delta^*_{圧縮性}/\theta_{運動学}$ だけ**が 8.9 に届き
(6.49 @ $1/7$ → 7.48 @ $1/10$、冪を上げるほど接近)、$\delta^*$ を錨にした再構成は報告 $\theta$ を
運動学定義で **1.31–1.41 倍**まで再現する (圧縮性と読んだときの 2.5–2.8 倍とは別物)。

→ **報告の $\theta$ は圧縮性運動量厚さではないと判断**し、$\delta^*$ を錨に再構成する。
結果は $\delta$ = **19.4–23.0 cm** (試験部 78.74 cm 角にコア 33–39 cm が残り成立。報告 $\theta$ を
圧縮性と読んで固定すると $\delta$=49–65 cm で対向壁 BL が重なり一様コアが消えるため不可能)、
圧縮性 $\theta$ = 0.42–0.51 cm、$Re_\theta$ = 7.5e3–3.3e4、$H_{圧縮性}$ = 25.0–25.1 (4 系列一致)、
$\delta/W$ = 85–100。台帳は `case/51/bl_derived.json`、`conditions.json` の報告値は
`theta_cm_reported` に保持 (棄却ではない)。

**原典 ref.6 を入手して決着させた (同日)**。ref.6 は **TN D-7939** (NTRS 19750020309) であり、
ref.3 の TM X-71945 とは別物 (両方取得済み)。判明したこと:

- **(a) 定義は圧縮性だった** (式 5, 6)。上の運動学説は**否定された**。
- **(b) $\rho$ と $u$ は独立に測られていない** — **11 本ピトー・レーク**のピトー圧からの還元で、
  密度分布の仮定は報告に書かれていない。
- **(c) この基準流れは 2 次元平衡平板ではない**。本文が、角干渉 (側壁・床・天井 BL) による
  **3 次元性**でプロファイル形状が横方向に大きく変わること、データが
  ノズル/試験部の交差部が作る**圧縮領域**で取られたことを明記している。
- **(d) 分母の原式は $Re'$ ではなく $\delta^*$ の式**: $N_{St}R_{w,\theta}^{0.07}=A\delta^*+B$
  ($A$=−2.77e−4 cm⁻¹, $B$=4.66e−3)。TN D-8233 Appendix はこれを $h_{fp}=C\,Re'^{0.69}$ に還元したもの。
- **(e) 著者自身が適用範囲を限定**: "The correlation has **no application to any flow other than
  this tunnel-wall boundary layer**"。
- **(f) digitize は原図 6 倍描画で確認済み** (縦軸 $h_{fp}$ [W/(m²K)]、4 点 1.45/2.5/3.7/4.65)。
  $C$=7.95e-5・冪 0.69 は正しい。

**原式 (7) でも閉じない (同日)**。$N_{St}$ の定義も判明した ($=h/(\rho_w U_e c_p)$、壁密度基準)。
式 (7) を自由流条件で評価すると Appendix 相関との比が $Re'$ とともに **1.94 → 1.23 → 0.89** と
系統的に動き、実効冪も **1.16** (Appendix 0.69 / VD-II 0.78) と合わない。単一オフセットでは埋まらず、
$\rho_w$ に実測の局所壁静圧、$U_e$ に局所エッジ速度といった digitize されていない量が要る。
→ **分母は 3 つの独立経路が最大 2 倍・冪も 0.69/0.78/1.16 とばらつき、第一原理から再構成できない。**

**T2 の成立可否への含意**: $H$=8.9 が 2D 平衡profileで出ないことと、$h_{fp}$ が VD-II の 1/1.8 しか
ないことは、**同一の原因**で説明がつく — 基準流れが角干渉で 3 次元化した圧縮領域のトンネル壁 BL
であって平板ではない。したがって

1. **2D 平板 CFD で $h_{fp}$ の絶対値は再現できない**。§4.2b の T2-G0 のうち「smooth の熱伝達が
   整合すること」は**原理的に通らない**。
2. 使えるとすれば**比 $h/h_{fp}$ のみ**で、「比が局所エッジ条件と $\delta^*/W$ で決まり
   3 次元性と圧力勾配が分子分母で相殺する」という**未検証の仮定**に乗る。
   これは T2-G0 が試すはずだった仮定そのもの。
3. → §4.2b の「満たせない場合 T2 は探索に降格し、case/49 への受け渡しは行わない」に
   **該当する公算が大きい**。降格するなら乱流一次検証を差し替える (§5.1 #21)。
4. **$\theta$ は T2 の拘束条件として使わない** ((b)(c) のどちらに帰着するか報告から分離できない)。
   $\delta^*$ は TM X-71945 本文の独立記述 ($Re$=1e6/ft で $\delta^*\approx$4.75 in = 12.07 cm、
   Fig 4 の同条件 11.5 cm と 5 % 一致) で裏が取れているので錨にする。


### 4.5 計算領域とメッシュ

- **T1 (`case/50`)**: 前縁から解く (流入 BL は結果であって入力ではない)。$x$: 前縁 $-$ 少し上流 〜 後壁下流、
  後壁を $x$=158.5 mm に置く。前縁は**公称 $r$=0.76 mm** を一次とし、鋭 (0) と試験後鈍化 (1.5 mm) を感度。
- **T2 (`case/51`)**: トンネル壁 BL を前縁から作らず、**入口に乱流 BL プロファイル**を与える (§4.2b の手順で固定)。
- **壁温接合部のモデル化** (codex 2 巡目 M3 採用): 試験模型は「加熱真鍮板 → **断熱材 + 水冷通路** → 薄肉すきま →
  非加熱後板」であり、**異温度の 2 つの等温面を直接突き合わせた形ではない**。
  - `nodeWallDirichlet_d.cu` は壁ノード温度を `Ts` に代入し、**bcond ごとに順に実行する**ため、
    異なる `Ts` の壁が**角ノードを共有すると後勝ちで上書き**される。
    → **共有ノードに矛盾する `Ts` を与えない**形状分割にする (接合部を別 physID の遷移区間にする)。
  - 理想的な温度ジャンプ角では $|\partial T/\partial n|\sim|\Delta T|/(\alpha r)$ の特異性が出て、
    **角まで積分した個別壁の熱量は対数的な格子依存を持つ**。→ **遷移長を定義して固定**し、その上で格子細分する。
    寸法が図面から決まらない部分は**入力不確かさとして感度に含める**。
  - 比較量は**角近傍を除いた区間熱量**と実測座標の局所値にする (角の最大値を合否に使わない)。
- **メッシュ規則 (codex m10 採用)**: 「上端 $3w$ に深さ節点の半分」は $w$=7.77/10.64 mm で $3w>d$ となり破綻する。
  **開口近傍の細分化高さは $\min(3w,\,0.3d)$ で頭打ち**にし、最大成長率 1.15、底隅の最小解像、
  幅方向 ≥40 点 を幅別ルールとして `mesh_rules.json` に書く。
- 品質は `check_mesh_quality.py` (AR 緩和を使うなら run README に明記)。
- **壁解像の呼出契約を固定する** (codex 4 巡目 M1。既定では誤合格する):
  `check_wall_resolution.py` は既定で**目標超過を 2 % まで許し** (`--over-frac` 既定 2.0)、
  **「面積割合」を点数割合で計算**し、未評価点も許す (本計画で確認。case/48 run_0011 は
  最大 $y_1^+$=3.9 でも既定 PASS、`--target 1 --over-frac 0` で FAIL)。
  → 本計画では **`--target 1 --over-frac 0`、全対象壁の壁ダンプを確認、全評価点が有限**を契約とし、
  **未評価点があれば不合格**にする。報告する面積割合は**実際の境界面積で重み付け**して別途出す。
  ツール側の修正 (点数→面積、未評価点の扱い) は判定ツール plan へ依存登録する。

### 4.10 不確かさと合否帯 (codex M7 採用 — ±25 % の根拠なし問題)

**「実験不確かさとの整合」と「工学的許容」を分ける**。

- **実験不確かさ帯 (伝播)**: 局所比 $R$ に対し $\Delta R \simeq \sigma_q/q_{fp} + \varepsilon_{dig}R$。
  [W70] は $\sigma_q$=0.68 kW/m²、$q_{fp}$=30.4 kW/m²、$\varepsilon_{dig}$=3 % →
  $R$=0.6 で ±6.7 %、$R$=1.5 で ±4.5 %、**$R$=0.02 では ±112 %** (深部は相対評価不能)。
  分母を共有することによる相関、前壁理論補完の不確かさも伝播に含める。
- **[W70] の ±0.68 kW/m² は「報告された精度限界」であって標準偏差ではない** (codex 2 巡目 M5)。
  よって上式は**保守的な区間**であり、「統計的不確かさ伝播」とは呼ばない。標準偏差として扱える量
  (digitize の読み取り分散など) のみ二乗和で合成し、精度限界は区間として加算する — **どちらで扱ったかを量ごとに明記**する。
- **積分量**は測定点間の相関と前壁理論補完の不確かさを含める。**T2 はさらに $T_w$・$T_{aw}$・$h_{fp}$ 相関
  (係数 $C$ の digitize と指数 0.69) の不確かさを含める**。
- **判定表は CFD を見る前に確定する** (事前登録): 点別・積分量別に「量 / 単位 / 基準値 / 許容 / 根拠」を
  `acceptance.json` に書き、run 後に動かさない。
- **工学帯の作り方**: 「既往データ間のばらつき」をそのまま帯にすると、排除したはずの**条件違いの混用が戻る**。
  したがって工学帯は **(i) 同一条件・同一定義で繰り返された試験のばらつき**、または
  **(ii) case/49 の用途から逆算した要求精度** のどちらかに限り、**根拠を量ごとに書く**。
  どちらも作れない量は**合否にせず誤差報告に留める**。
- **除外**: [TH76] の**黒塗り記号 (精度に疑義のある低加熱データ) は精度検証から除外**する。
- **深部 ($R<0.05$)**: 検出限界 ($R\approx0.02$) を含む**絶対量**で報告し、「一致」という語を使わない。
