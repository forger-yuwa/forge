## 1. 目的

デュアルベル (ベース + 壁角を外へ折った変曲点 + 延長部) を、**高度で書いた仕様**から設計する。低い設計高度 $h_1$ で海面モード
(変曲点で剥離) の性能、高い設計高度 $h_2$ で高空モード (延長部まで付着) の性能を最大にし、**使えなくてよい高度帯**
$[h_a,h_b]$ の外では各モードが保たれることを制約にする。モードが保たれるかは**公知の試験データにもとづく経験式で判定**し
(適用範囲の外は「保証未判定」と返す)、forge の CFD は念のための検証に使う。完了時には、問題定義 YAML (高度・重み・高度帯・運転履歴の前提)
から、形状・各高度の性能・モード保証の判定と余裕・CFD 検証の結果が一通り出る状態を得る。

## 2. スコープ

- **やる**
  - 問題定義: 推進剤・燃焼室条件 (③の基準ケースと共通の TP)、$h_1$、$h_2$、$[h_a,h_b]$、重み、運転履歴の前提 (§4.1)、標準大気 (US 1976)
  - モード判定の契約: 方向別・事象別の閾値、出典つきの係数と幅、適用範囲 (§4.2)
  - 形状: ベース (③の道具で設計し、衝撃波のない MOC 場を作れるものに限る)、変曲点 (壁角の折れ)、延長部 (**初版は全長の CP 型**、壁圧を指定した MOC)
  - MOO: 目的 = 各高度の推力係数 $C_F=F/(p_cA_t)$ ($h_1$・$h_2$、重み付きまたは 2 目的) と全長、制約 = モード保証 (§4.3)。$\eta$ は損失の診断量 (出口面積比が形状ごとに変わるので、同面積比の理想推力で割る $\eta$ を目的にすると推力の順位が逆転しうる — plan レビュー M7)
  - CFD 検証: 有望形状の $h_1$・$h_2$ での評価と、NPR を上げる・下げる継続計算 (外部領域は兄弟 plan)
  - 検証: DLR P6.2 の軸対称デュアルベルを寸法から作り直す (幾何の整合と MOC の数値検証)、経験式の較正データと独立の検証データを分ける
- **やらない**
  - **切り詰めた延長と PP 型 (正の壁圧勾配) のモード保証** — 対応する試験相関が受理されるまで保証の対象外 (形状は作れても「保証未判定」)
  - 内部衝撃波を含むベース (この MOC 経路では未対応として返す)
  - 遷移の非定常・横荷重 (URANS)、sneak transition の時間挙動
  - 飛行中の外部流の効果 (TAU の CFD で延長部の剥離域の圧力が外気の 75 % まで下がるという報告 [SGWK12] があるが試験ではない — §8)
  - 冷却壁 (当面断熱)、3D、膜冷却
  - CFD に合わせて判定係数を較正すること (親 §3-15)

## 3. 関連 docs と前提

- **試験データ (調査ノート §2.3)**。各点に「方向 (上げ/下げ)・事象 (開始/完了)・作動ガスと温度・形状・試験か CFD か」を付けて使う:
  - DLR P6.2 軸対称デュアルベル [NGS07 ✔][NGS10 △]: $R^*$=10 mm、$\varepsilon_b$=11.3、$\varepsilon_e$=27.1、$L_b/R^*$=6.2、$L_e/R^*$=8.3、変曲角 $\alpha$=9°、ベース TIC (設計 Mach は記載なし)、延長は等圧 (MOC)。N2 冷気、$p_a$=1 bar、供給圧を上下。**事象は別々**: NPR 30 で変曲部剥離、48 で剥離域の勾配が減り、51 で全流れ (上げ側)。ヒステリシス約 20 %。延長部の剥離域圧力は $p_a$ の 92 %。座標表は非公開。
  - Génin & Stark 2011 の平面デュアルベル [GS11a ✔]: 冷気では延長部の壁圧勾配がわずかに負になり (3D 効果) **本来の遷移が起きなかった**。600 K の温風では H2O が凝縮して遷移 NPR が下がった。輪郭 1 は製作不良。→ 遷移の閾値の較正には使わない (sneak transition の比較には使える)。
  - [SGWK12 ✔、主セッションが本文で確認 2026-10-11]: 遷移予測式 (式 1) は冷気の 3 モデルの試験と「very good accordance」(図 3、数値は本文に無い)。**延長の基準長は「延長の終端で壁角が 0 に向かうところまで」**で、CP 延長を切り詰めると遷移 NPR は線形に上がり、式は**全長のときだけ**使える。$L'=L_e/L_{tot}$。ヒステリシス $=(\mathrm{NPR}_{tr}-\mathrm{NPR}_{retr})/\mathrm{NPR}_{tr}$ は切り詰めで線形に減り、±10 % の圧力変動に対してモードを保つには 20 % 以上、それには $L'\ge0.5$。Vulcain 2 型の設計例では、**遷移高度を buffeting の帯 (7〜10 km) の外**に置く制約を使っている (表 2: $h>10$ km または $<7$ km)。外部流の 75 % は TAU の CFD。
  - Verma ら [VSH13 △]: レイノルズ数が下がると遷移 NPR が上がる。Schneider & Génin 2016 [抄録 △]: RANS が遷移 NPR を 1 % で予測 (別モデル)。
- **経験式 (調査ノート §3)**: Stark の剥離式 $p_{sep}/p_a=1/M_{sep}$ と、それを等圧延長に当てはめた遷移式 $\mathrm{NPR}_{tr}=\frac{1}{M_e}\left(1+\frac{\gamma-1}{2}M_e^2\right)^{\gamma/(\gamma-1)}$ [SGWK12 式 (1) ✔]。**延長を全長で使う場合だけ成り立ち、切り詰めると遷移 NPR は線形に上がる** (調査ノート §3)。経験式どうしのばらつきは大きい。NASA の Crocco–Probstein への 20 % 余裕は別の相関の話で、本計画の幅に転用しない。
- **形状の部品**: ベースは兄弟 plan の (D) 直接モード (先に使える) または (M) Rao (S1 を通ってから)。延長部の壁圧指定の MOC は新規。
- **評価器**: 兄弟 plan の共通評価器と、別セッションの外部領域・剥離評価。

## 4. 設計方針

### 4.1 仕様 (問題定義 YAML)

| 項目 | 内容 |
| --- | --- |
| 燃焼・寸法 | ③の基準ケースと同じ燃焼条件 (LOX/LH2・10 MPa・O/F 6、凍結 TP、断熱)。③と共通に固定する寸法はスロート半径・スロート曲率・収縮部だけで、**面積比は固定しない** ($\varepsilon_b$ は設計変数、$\varepsilon_e$ は全長 CP から従属) |
| 作動点 | `operating_points: [{name, altitude または p_a, weight}]`。少なくとも $h_1$ と $h_2$ |
| 使えなくてよい高度帯 | `transition_band: {h_a, h_b}` |
| 運転履歴の前提 | `history: ascent_monotonic` (点火は海面モード、NPR は単調に増える) または `history: arbitrary` (スロットル・下降で NPR が戻りうる) |
| 燃焼室圧の範囲 | 低高度側の最大・最小、高高度側の最小 (スロットルが無ければ公称値 1 点)。§4.3 の制約が使う |

$p_a(h)$ は US 標準大気 1976、NPR $=p_c/p_a(h)$。

### 4.2 モード判定の契約

- **閾値は方向別・事象別に持つ**: $N_{up,start}$ (上げ側で剥離点が変曲点を離れ始める NPR。sneak transition の開始を含む)、$N_{up,end}$ (上げ側で全付着に達する NPR)、$N_{dn,start}$ (下げ側で付着から剥離へ戻り始める NPR)、$N_{dn,end}$ (下げ側で変曲点の剥離に戻りきる NPR)。
- **係数と幅**: 各閾値を、Stark の式に方向・事象ごとの係数を掛けた形で表し、係数の幅を**適格な試験データだけ**から作る (上の §3 のメタ情報で、CFD・凝縮・製作不良・遷移しなかった試験を除く)。適格なデータが無い閾値は「幅未定」とし、その閾値に依存する保証は「保証未判定」にする。
- **適用範囲**: 全長の CP 延長 (全長の定義は [SGWK12] の $L'$ に合わせて §8-1 で決める)、冷気から燃焼ガス・実寸への外挿は宣言した外挿幅の範囲。範囲の外は「保証未判定」。
- **TP への写像**: $p_c/p_{ext}$ を凍結 TP の等エントロピーで求め $\mathrm{NPR}_{tr}=(p_c/p_{ext})/M_e$ とする式は**熱力学的な拡張の候補**として扱う。CPG 極限での一致は実装の回帰試験にすぎず、経験則を TP に使ってよい根拠にはならない。外挿幅が決まるまで、TP の基準ケースでの判定は「較正済み・未検証」と表示する。
- **状態を 2 つに分ける** (plan レビュー M1): `validation_status` (係数の証拠の状態: 較正済み・未検証 / 独立検証で受理 / 不受理) と `guarantee_verdict` (この形状・この仕様でのモード保証: GUARANTEED / VIOLATED / UNKNOWN)。必要な閾値の欠測・外挿幅の未定・検証の未受理・全長終端の未確認 (§4.4) は必ず `UNKNOWN`。**MOO の可行解は GUARANTEED だけ**。全候補が UNKNOWN でも INFEASIBLE とは呼ばない (「判定の証拠が無い」と返す)。TP の基準ケースでの保証つき MOO は、証拠のゲート (§5.1) を通ってから。
- 実装は `metrics/separation_criteria.py` (仮)。係数・幅・各データ点のメタ情報・出典を持ち、CFD の結果では書き換えない。

### 4.3 モード保証の制約

- **ベース**: 対象の運転域 (低高度側の外気圧の最大と、低高度側の燃焼室圧の最小) で、ベースの**全壁面**の局所剥離余裕 $m=\min_x\left(p_w/p_{sep}^{upper}\right)-1$ が正であること ($p_{sep}^{upper}$ は剥離圧の幅の上側)。$h_1$ の 1 点だけで確かめない。
- **$h\le h_a$ で海面モード**:
  - `ascent_monotonic`: $\mathrm{NPR}(h_a)<N_{up,start}^{lo}$ (sneak transition の開始も含めた下限)。
  - `arbitrary`: 履歴に依らない保証が要るので $\mathrm{NPR}(h_a)<N_{dn,end}^{lo}$ (海面モード以外が残りうる最も低い NPR より下)。
- **$h\ge h_b$ で高空モード**: `ascent_monotonic` では $\mathrm{NPR}(h_b)\ge N_{up,end}^{hi}$ (公称燃焼室圧)。`arbitrary` では、高高度域でとりうる**最小の NPR** (高高度側の最小燃焼室圧と $h_b$ の外気圧) 自体が $N_{up,end}^{hi}$ 以上であること (下げ側の閾値 $N_{dn,start}$ だけで足りるのは、先に全付着に達したことを保証できる履歴に限る — plan レビュー M2 の反例: $N_{up,end}=60$・$N_{dn,start}=45$・公称 80・最小 50 で剥離状態から上昇すると全付着に達しない)。
- **事前の成立判定**: 係数が形状に依らず固定で、閾値の包絡が $[c_{lo}N_0,\ c_{hi}N_0]$ と書ける場合に限り、$\mathrm{NPR}(h_b)/\mathrm{NPR}(h_a)\le c_{hi}/c_{lo}$ なら**不成立** (INFEASIBLE)。超えても**成立は未確定** (形状ごとの判定に回す)。係数が長さ・Re・運転条件で変わる場合は「事前判定不能」と返す。

### 4.4 形状

- **ベース**: 兄弟 plan の手順 (先に (D)、(M) は S1 を通ってから) で $h_1$ を設計点にする。延長部の始点の流れを作るため、**初期線から衝撃波のない超音速場を MOC で構成できるベースだけを受理する**。前進 MOC で特性線の交差・衝撃波・亜音速域を検出した候補は「この MOC 経路では未対応」として返す (非一様であること自体は排除の理由にしない)。**不受理の理由を明示的に検出する** (plan レビュー M6): 既存 `geometry/moc_kernel.py` は亜音速の入力を音速にクリップし (`pm_nu`、29 行付近)、前進処理で失敗した点を `continue` で捨て (382 行付近)、スカラー版には軸上の解析極限が入っていない (151 行付近の注記)。**スカラー版 `KernelMOC` は使わず、①風洞の生産で検証済みの配列版の経路に乗せる** (2026-10-11 ユーザ指示「風洞のスクリプトを参考に」): `interior_vec` を `axis_limit="analytic"`・`corrector="converge"` で使い (plan accepted/discretization-moc-axis-limit-and-corrector)、対ごとの分類 `stats["status"]` (収束 / 欠損 / 特性線が平行 / 非有限 / 上限到達 / 軸より下 — `moc_kernel.py:446-455`) をそのまま不受理の理由に写す。これに亜音速入力の検査 (クリップ前) と同族特性線の交差・網の反転の検査を足す。壁を与える前進 (ベース) と壁圧を与える前進 (延長) のマーチは、風洞の逆 MOC (`geometry/moc_inverse.py`) の構造と充填の作法を手本に新しいモジュールで書く。`moc_kernel.py`・`moc_inverse.py` の既定の挙動は変えないので**風洞には影響しない**。
- **変曲点**: 壁角を外へ $\alpha$ だけ折る。**C2 の例外** (親 §3-11)。丸めは選択肢として持つが既定は尖り (丸めると固定が弱まる [GS11a])。**最終の物理壁まで折れを保つ** (plan レビュー M5): ベースと延長を区分表現にし、変曲点では位置だけを共有して左右の勾配を別々に拘束する (既存の物理壁処理 `wall_axismach.py:354` 付近は法線オフセット後に全体を 1 本の滑らかな spline にするので使わない)。メッシャ (`meshing/mesh2d.py`) に変曲点を必須の節点として渡す。δ\* 補正・当てはめ・変換のあとに、折れ角・延長の終端・寸法・CP 設計からの逸脱を再検査し、モード保証はこの最終形状に対して判定する。
- **延長部 (初版)**: ベース出口の流れから、変曲点の中心膨張扇を経て、壁圧一定 $p_w=p_{ext}$ の壁を MOC で前進して作る (CP 型)。長さは §8-1 の「全長」の定義 (壁角が 0 に向かうところまで) に従って従属に決める。$p_{ext}$ が決まれば $\alpha$ は膨張扇から従属に決まる。MOC 壁点は兄弟 plan で拡張する当てはめで B-spline にする (始点は変曲点の $r,r'$、壁内で C2)。δ\* は一発補正。切り詰めと PP 型は形状として作れるようにしておくが、保証の対象外。
- **設計変数** (初版): ベースの (D) 変数のうち $L_b$ と $\theta_{e,b}$ (他は固定。$\varepsilon_b$ はここから決まる)、$p_{ext}$ (§4.3 を満たす範囲)。3 個前後。延長長と $\varepsilon_e$ は全長 CP から従属。

### 4.5 評価と CFD 検証

- **MOO のループ内**: 推力は CFD で測り、目的は各高度の $C_F=F/(p_cA_t)$ ($h_1$ は外部領域つきで変曲点の剥離を含めて、$h_2$ は付着流)。モード保証は §4.2・§4.3 の経験式の判定で行う (ループ内で遷移の継続計算はしない)。保証が「未判定」の候補は MOO の可行解に入れない。
- **CFD での想定モードの確認**: ループ内の $h_1$・$h_2$ の CFD で、実際の剥離位置から評価したモードが想定と違う候補は、係数を変えずに**保留**にする。
- **CFD 検証 (有望形状のみ)**: NPR を上げる系列と下げる系列を前の NPR の収束解から継続計算し、方向別の閾値を求めて経験式の幅と比べて記録する。食い違っても係数は直さず、上位に諮る。定常性のゲートは兄弟 plan と同じ (定常計算の `OSCILLATING` は判定不能)。

## 6. 検証

**判定基準は run の前にここで固定する。** codex diagnose (2026-10-11) の指摘を反映した案で、plan 段レビューを受けて確定する。

- **V1 (モード判定の単体)**: 実装した各式が原典の式・数値例を再現する。TP 版の遷移式が CPG の極限で Stark の式と一致する (回帰)。**状態遷移の試験** (codex diagnose の合成例、試験の再現値ではない): 上げ側閾値 50・下げ側閾値 40・低高度端の NPR 45・高高度端の NPR 60 で、A = 剥離から開始、B = 付着から開始して NPR 45 で状態を更新すると A は剥離・B は付着のまま。`history: arbitrary` の仕様では、この組を「海面モードを保証できる」と受理しないこと。`ascent_monotonic` では A の履歴だけが許されるので受理してよい。スロットルの反例 ($N_{up,end}$ 60・$N_{dn,start}$ 45・公称 80・最小 50、`arbitrary`) を受理しないこと。適用範囲外 (切り詰め・PP・外挿幅未定・終端未確認) の入力で `guarantee_verdict=UNKNOWN` を返し、UNKNOWN が可行解に入らないこと。
- **V2 (延長部 MOC の数値検証と P6.2 の幾何の整合)**: 数値検証 = CP 型で壁圧の一定性 ≤ 0.1 %、質量流量の保存 1e-4、MOC 格子を細かくして壁形状の変化が収束すること、平面版が平面の単純波の関係と一致、**軸対称の放射源流の厳密解の再現** (軸対称の適合式の検証。風洞の試験 `design/tests/moc_axis_limit_radial.py`・`run_inverse_tests.py:268-283` の放射源流をそのまま使う)、**負例** (衝撃波を必要とする壁・亜音速の入力で、不受理の理由が正しく返る)、変曲点の折れ角が δ\* 補正・当てはめ・メッシュ変換の後も保たれる (必須節点)。幾何の整合 = 作り直した P6.2 で、$\alpha$ 9°・$L_e/R^*$ 8.3 の CP 延長の出口面積比が公表値 27.1 と相対 2 % 以内 (幾何の整合の確認に限る。ベースの逆算の一意性や延長部の壁面 Mach の正しさの証明には使わない)。
- **V3 (係数の較正)**: §5.1 #2 で較正用に分けた適格な試験点から、方向別の係数と幅を決める (合否ではない)。
- **V4 (係数の独立検証)**: 幅を確定したあと、較正に使っていない適格な試験点が、測定不確かさ込みで予測区間に入るかを見る。入らなければその保証モデルを不受理とする (事前登録)。独立の試験点が無ければ「較正済み・未検証」と表示する。
- **V5 (CFD 検証)**: P6.2 の作り直し形状で、冷気 N2・$p_a$ 1 bar の NPR 掃引 (上げ・下げ)。各閾値は「最後に旧状態だった NPR と最初に新状態だった NPR の区間」で返し、剥離位置の判定 (変曲点からの距離の許容差)・NPR の刻み・格子・領域の不確かさを登録する。各端点の run には同じ実効設定区間の `check_convergence.py` の **PASS** と、剥離位置・推力の `check_quasisteady.py` の **STEADY** を必須とし、各方向の初期状態 (上げは剥離から、下げは付着から) を確かめる。CFD の方向別閾値と試験・経験式の幅の並びを記録する。合否の基準は外部領域の検証 (兄弟 plan) の結果を見てから、run の前に書く (未登録)。
- **V6 (TP 基準ケースの固定形状)**: §5.1 #6。$h_1$ と $h_2$ の両方でゲート (PASS・STEADY・CV 残差) を満たし、$h_1$ で剥離が変曲点に固定されていること。基準は run の前に登録する (未登録)。
