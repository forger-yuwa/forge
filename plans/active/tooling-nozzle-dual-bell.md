## 1. 目的

デュアルベル (ベース + 壁角を外へ折った変曲点 + 延長部) を、**高度で書いた仕様**から設計する。低い設計高度 $h_1$ で海面モード
(変曲点で剥離) の性能、高い設計高度 $h_2$ で高空モード (延長部まで付着) の性能を最大にし、その間の**使えなくてよい高度帯**
$[h_a,h_b]$ の外では、各モードが保たれることを制約にする。モードが保たれるかは**公知の試験データにもとづく経験式で判定**し、
forge の CFD は念のための検証に使う。完了時には、問題定義 YAML (高度・重み・高度帯) から、形状・各高度の性能・モード保証の余裕・
CFD 検証の結果が一通り出る状態を得る。

## 2. スコープ

- **やる**
  - 問題定義: 推進剤・燃焼室条件 (③の基準ケースと共通の TP)、$h_1$、$h_2$、$[h_a,h_b]$、重み、標準大気 (US 1976) による $p_a(h)$
  - 経験式の部品: 公知の剥離・遷移の式とデータから、判定係数とその幅 (ばらつき) を作る (§4.2)
  - 形状: ベース (③の道具で $h_1$ に合わせる)、変曲点 (壁角の折れ)、延長部 (壁圧を指定した MOC。CP 型・PP 型)
  - MOO: 目的 = $\eta(h_1)$・$\eta(h_2)$ (重み付き、または 2 目的) と全長、制約 = モード保証 (§4.3)
  - CFD 検証: 有望形状の $h_1$・$h_2$ での評価と、NPR を上げる・下げる継続計算で遷移の位置を確かめる (外部領域は兄弟 plan)
  - 検証: DLR P6.2 の軸対称デュアルベルを寸法から作り直し、経験式の遷移 NPR と CFD を試験と比べる
- **やらない**
  - 遷移の非定常・横荷重 (URANS)、sneak transition の時間挙動
  - 飛行中の外部流の効果 (延長部の剥離域の圧力が地上試験の 92 % から 75 % に下がる報告がある [SGWK12]) — 記録して余裕に含めるかを §8 で決める
  - 冷却壁 (当面断熱)、3D、膜冷却
  - CFD に合わせて判定係数を較正すること (親 §3-15)

## 3. 関連 docs と前提

- **試験データ (調査ノート §2.3)**:
  - DLR P6.2 軸対称デュアルベル [NGS07 ✔][NGS10 △]: $R^*$=10 mm、$\varepsilon_b$=11.3、$\varepsilon_e$=27.1、$L_b/R^*$=6.2、$L_e/R^*$=8.3、変曲角 $\alpha$=9°、ベース TIC (設計 Mach は記載なし。$\varepsilon_b$ と $L_b$ から逆算)、延長は等圧 (MOC)。N2、$p_a$=1 bar。NPR 30 で変曲部剥離、48 で剥離域の勾配が減り、51 で全流れ。延長部の剥離域圧力は $p_a$ の 92 %。座標表は公開されていない。
  - Génin & Stark 2011 の平面デュアルベル [GS11a ✔]: $\varepsilon_b$=3.95、$\varepsilon_e$=7.97、$\alpha$=15°、変曲部 5 形状 (尖り・丸め)、sneak transition の ΔNPR。
  - Verma ら: レイノルズ数が下がると変曲域が広がり遷移 NPR が上がる (寸法効果)。
  - Schneider & Génin 2016 (抄録 △): 軸対称 RANS (SA・RSM) が遷移 NPR を 1 %・ヒステリシスを約 10 % で予測。
- **経験式 (調査ノート §3)**: Stark の剥離式 $p_{sep}/p_a=1/M_{sep}$ と、それを等圧延長に当てはめた**デュアルベルの遷移式** $\mathrm{NPR}_{tr}=\frac{1}{M_e}\left(1+\frac{\gamma-1}{2}M_e^2\right)^{\gamma/(\gamma-1)}$ ($M_e$ = 等圧延長の壁面 Mach 数、延長を全長で使う場合。切り詰めると遷移 NPR は線形に上がる) [SGWK12 ✔]。Schmucker・Summerfield・Morrisette & Goldberg ほか。経験式どうしのばらつきは大きい (調査ノート §3 末尾)。
- **形状の部品**: ベースは兄弟 plan の (D) 直接モード (先に使える) または (M) Rao (S1 を通ってから)。延長部の壁圧指定の MOC は新規。ベース出口の流れは、ベースの壁に沿った前進 MOC (壁が既知の直接問題) で作る。どちらのモードのベースでも同じ方法で得られる。
- **評価器**: 兄弟 plan の共通評価器 (TP・断熱・低 Re・閉じた CV の推力・ゲート) と、別セッションの外部領域・剥離評価。

## 4. 設計方針

### 4.1 仕様 (問題定義 YAML)

| 項目 | 内容 |
| --- | --- |
| 燃焼 | ③の基準ケースと同じ (LOX/LH2・10 MPa・O/F 6、凍結 TP、断熱) |
| 寸法 | スロート半径・スロート曲率・収縮部 (③と共通の spec) |
| 作動点 | `operating_points: [{name, altitude または p_a, weight}]`。少なくとも $h_1$ (海面モードの設計点) と $h_2$ (高空モードの設計点) |
| 使えなくてよい高度帯 | `transition_band: {h_a, h_b}`。帯の外のモードを保証し、帯の中の性能は問わない |
| 任意 | スロットルの範囲 (高空モードでの燃焼室圧の最低値。下げ側の遷移 [付着 → 剥離] を避ける制約に使う) |

$p_a(h)$ は US 標準大気 1976、NPR $=p_c/p_a(h)$。

### 4.2 判定の係数 (試験データを正とする)

- 判定は「延長部の壁面 Mach 数 (CP 型なら一様) から決まる遷移 NPR」で行う。基準は Stark の遷移式。TP では $p_c/p_{ext}$ を凍結 TP の等エントロピー関係で求め、$\mathrm{NPR}_{tr}=(p_c/p_{ext})/M_e$ とする (剥離式 $p_{sep}/p_a=1/M_{sep}$ をそのまま使う)。
- **係数の幅**: 遷移式の予測と試験 (P6.2 の 48〜51、平面モデル) の差、他の経験式との差、ヒステリシス (上げと下げの差) から、遷移 NPR の上下限 $[\mathrm{NPR}_{tr}^{lo},\ \mathrm{NPR}_{tr}^{hi}]$ を作る係数の幅を決める。冷気サブスケールから燃焼ガス・実寸への外挿の分は、別の余裕係数として宣言する (§8-2)。
- 係数と幅は `metrics/separation_criteria.py` (仮) に、出典つきで持つ。CFD の結果では書き換えない。

### 4.3 モード保証の制約

- **ベースが $h_1$ で剥がれない**: ベースの壁圧の最小 (ベース出口) が、$h_1$ での剥離圧の上限 (経験式の幅の上側) を上回る。
- **$h\le h_a$ で海面モード**: 遷移が帯の手前で起きない — $\mathrm{NPR}(h_a)<\mathrm{NPR}_{tr}^{lo}$。
- **$h\ge h_b$ で高空モード**: 遷移が帯の中で終わる — $\mathrm{NPR}_{tr}^{hi}\le\mathrm{NPR}(h_b)$。スロットルの範囲を指定したときは、その最低燃焼室圧でも下げ側の遷移が起きないこと。
- **帯が狭すぎるとき**: $\mathrm{NPR}(h_b)/\mathrm{NPR}(h_a)$ が係数の幅より狭ければ、どの形でも成立しないので、問題定義の段階で INFEASIBLE として返す (形状を作る前に検査する)。

### 4.4 形状

- **ベース**: 兄弟 plan の手順 (先に (D)、(M) は S1 を通ってから) で、$h_1$ を設計点にする。面積比 $\varepsilon_b$ は §4.3 の「ベースが剥がれない」の範囲で設計変数にする。
- **変曲点**: 壁角を外へ $\alpha$ だけ折る。**C2 の例外** (親 §3-11) で、剥離を固定するための意図的な折れ。丸めは選択肢として持つが既定は尖り (丸めると固定が弱まる [GS11a])。
- **延長部**: ベース出口の流れ (ベースの壁に沿った前進 MOC で作る) から、変曲点の中心膨張扇を経て、指定した壁圧 $p_w(x)$ を満たす壁を MOC で前進して作る。CP 型は $p_w=p_{ext}$ 一定、PP 型は $p_w$ が下流へ増える (勾配を設計変数に)。$p_{ext}$ が決まれば $\alpha$ は膨張扇から従属に決まる。MOC 壁点は兄弟 plan で拡張する当てはめで B-spline にする (始点は変曲点の $r,r'$、壁内で C2)。δ\* は一発補正。
- **設計変数** (初版): ベースの (D) 変数のうち $L_b$ と $\theta_{e,b}$ (他は固定)、$p_{ext}$ (§4.3 の範囲で)、延長長 $L_e$、PP の勾配 (CP なら 0)。5 個前後。

### 4.5 評価と CFD 検証

- **MOO のループ内**: 推力は CFD で測る ($h_1$ は外部領域つきで変曲点の剥離を含めて、$h_2$ は付着流)。モード保証は §4.3 の経験式の制約で判定する (ループ内で遷移の継続計算はしない)。
- **CFD 検証 (有望形状のみ)**: NPR を上げる系列と下げる系列を、前の NPR の収束解から継続計算し、剥離位置の跳びから CFD の遷移 NPR (上げ・下げ) を求め、経験式の幅と比べて記録する。食い違っても係数は直さず、食い違いを上位に諮る。
- 定常性のゲートは兄弟 plan と同じ (定常計算の `OSCILLATING` は判定不能)。

## 6. 検証

**判定基準は run の前にここで固定する。以下は諮問前の案。**

- **V1 (経験式)**: 実装した各式が原典の式・数値例を再現する。TP 版の遷移式が CPG の極限で Stark の式と一致する。
- **V2 (延長部 MOC と P6.2 の作り直し)**: 作り直した P6.2 で、指定した $\alpha$ 9°・$L_e/R^*$ 8.3 の CP 延長の出口面積比が公表値 27.1 と相対 2 % 以内 (ベース TIC の逆算の誤差を含む許容。超えたら作り直しの仮定を見直す)。
- **V3 (経験式と試験)**: P6.2 の作り直し形状で、Stark の遷移式の遷移 NPR が試験 (全流れ 51、勾配の変化 48) と比べてどこにあるかを記録し、§4.2 の幅の決定に使う (この比較が幅の根拠そのものなので、合否ではなく幅の入力)。
- **V4 (CFD 検証)**: P6.2 の作り直し形状で、冷気 N2・$p_a$ 1 bar の NPR 掃引 (上げ・下げ)。CFD の遷移 NPR が試験の 48〜51 と、経験式の幅とどう並ぶかを記録する。合否の基準は外部領域の検証 (兄弟 plan) の結果を見てから、run の前に書く (未登録)。
