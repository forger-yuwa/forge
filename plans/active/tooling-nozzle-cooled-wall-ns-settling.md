## 1. 目的

case/70 (空気 M5、T_w 350 K / T_aw ≈ 1150 K) で、NS 後の δ_E でカードから作り直した設計の出口コア M が 5.000 ± 0.05 % に入るかを、定常の解で判定できるようにする。
前身の plan で次が未達のまま残った (前身 §6.1・§9):

1. 冷却壁の NS に非常に遅いモードがある: 残差が床に着いた後も、出口コア M が 10k step ごとに −1〜−2.5e-4 (cfl 1)・−5e-4 (cfl 5)、流量が +0.02 % で動き続ける
   (`case/70.m5_air_wt_demo/run_0014b〜d`、`run_0010b`)。補正の元にした NS の場もこのモードについて未整定だった。
2. 入力 δ_E の準定常 (前身 §6 V3e) と Euler 参照の厳密な受入れ (前身 §5.1 #5) を満たさなかった (Euler は残差が床で横ばい)。
3. 抽出の帯選択 (edge の縁 y* の推定) が場のわずかな違いで別の枝に切り替わり、x 2〜12 の δ_E を 5e-4 r_t 動かす (前身 §5.1 #5b)。

## 4. 設計方針

### 4.1 NS を定常にする (main のソルバの範囲で)

- M6 の B0 は main に無いキー (`lineDtDirectionalCap`・`implicitThermalJacobian`) に依るので、case/70 では使わない (M6 のブランチが main に入ったら再検討)。
- **擬似 CFL を上げる** (block-DPLUR、`implicitRelax` は使わない — 解を動かすことがある [[sern-cfl-no-implicit-relax]]): 同じ開始の場 (run_0014c の最終 = 通算 240k) から
  cfl 5・10・20 の腕で回し、遅いモードの量 (Q・出口コア M・流量・δ_m) が止まる速さと、止まった値が腕の間で一致するか (定常解は擬似時間の進め方に依らないはず) を見る。
- **整定の判定 (case/70 用、`case/70.m5_air_wt_demo/settle_judge.py`)**: 窓 = 5k ごとの 5 枚 (20k step)。量ごとに、窓の中の変化 |q_last − q_first| と
  推定の残りの変化 (末尾の増分が同じ符号で減衰しているとき、増分の比 ρ < 1 から Δ_last·ρ/(1−ρ); ρ ≥ 1・符号の反転・推定できないときは「推定不能」) を出す。
  許容: 出口コア M は変化・残りとも ≤ 2.5e-4 (絶対)、Q は変化 ≤ 0.1 %・残り ≤ 0.2 %、流量は変化 ≤ 1e-4・残り ≤ 2e-4 (相対)、δ_m は変化 ≤ 1e-4・残り ≤ 2e-4 r_t。
  全部満たし推定不能が無い最初の窓を「整定」とする。**目標範囲 (4.9975〜5.0025) は整定の条件に入れない** — 整定した後の設計の合否だけに使い、
  合否の値は「最後の値 + 推定の残りの変化」(codex 諮問 2026-10-13 settling-plan の Major: 目標を外れて整定した解を未整定として回し続けない)。
  M6 の `m9_watch.py` は case/45 の量を読むので流用しない。

### 4.2 帯位置の選び方

- c を上げるだけでは出口の δ_E が c で動く (§3.1) ので、c は 1.25 のまま。
- **帯位置を窓で一度だけ決める**: 判定の窓 (整定した後の 5 枚) の梯子を平均して縁 y* と帯位置 y_b(x) を一度だけ選び、窓の各枚はその y_b(x) で抽出して δ_E を点ごとに平均する。
  帯位置の切り替わりを窓の中で起こさない (前身 §5.1 #5b の固定の腕で差 2.4e-5)。設計の作り直しの入力はこの平均。

### 4.2b 帯選択の頑健化の方法 (2026-10-13 起案、諮問の前)

- **切り替わりの原因** (`ladder_probe.py`・`_ladder_probe/`、run_0010 の 50k・55k × run_0012): 縁 y* は梯子の R(y) = δ_r(1.25 y)/δ_r(y) − 1 が最初に |R| < ε (0.003) を満たす段
  (`deltastar.py:358`)。スロート付近 (x ≈ 0.7) では梯子が平らにならず (δ_r が帯位置で 1.6e-3 → 5e-4 と大きく変わる)、**一番内側の段で R が偶然 ±0.003 の中に入るかどうか**で、
  50k は y* = その段 (R +0.0018)、55k は y* = NaN (R −0.0037) になった。次の段は R −0.14。y* の有無が食い違う断面 67・20 % 以上変わる断面 38 (全 1800) が、直管・縮流部・スロート付近の
  δ_r が小さい区間に集まる。
- **方法案: 縁の判定に持続を要求する** — 交点から K 段続けて |R| < ε のとき、その最初の段を y* にする (無ければ NaN; NaN は今と同じく帯位置の平滑化で隣から埋まる)。
  偶然の 1 段だけの交点を拾わない。測定 (`band_persist_ab.py`・`_band_persist_ab/`、測定用の差し替え):

| K | case/70 50k→55k の δ_E の差 (使用域) | y* の有無の食い違い | case/45 run_0038 × 0037 の K=1 からの δ_E の差 (x ≥ 0) |
| --- | --- | --- | --- |
| 1 (今) | 5.4e-4 r_t | 67 | — |
| 4 | **6.3e-5** | 14 | 最大 4.3e-4 r_t (x 95.1 = 出口の端、0.063 %)、y* の NaN の割合 0.01 → 0.09 |
| 8 | 1.4e-4 | 28 | 同上 |

  **K = 4 を採る** (諮問 2026-10-13 band-persistence)。既定値にする (新しい標準は既定に; 旧の K = 1 は引数で再現できる)。case/45 の出口の端の 0.063 % の差は M6 の生産の壁に入るので、M6 のセッションに伝える。
  条件 (諮問の Major): NaN の断面を帯位置の平滑化で埋める効果と、縁を安定に見つけた効果を分けるため、**NaN の区間の埋め方だけを変える A/B** を S2b に足す。

### 4.3 ユーザ決定 (2026-10-13): 帯選択を先に、遅いモードは M6 待ち

ユーザ「2 だけ先に、1 は M6 待ち」(選択肢: 2 だけ先に / 1 と 2 の両方 / 一旦止める)。
- **帯選択の頑健化 (§5.1 #3) を先に進める** — M6 の生産も使う抽出の共通部分。plan 段のレビュー M3 の窓をまたぐ再現性を判定に入れる。
- **遅いモード (§5.1 #1b・#2) と M5 デモの再開 (#4) は保留** — M6 のブランチの B0 (`lineDtDirectionalCap`・`implicitThermalJacobian`) と停止規則が main に入ったら、
  それを使って再開する (plan 段のレビュー M1・M2・M4 の対応もそのときに)。

## 6. 検証

- **S0 (判定の台本の再生試験、forge 0 step)**: 合成の 5 枚 (M_A,i = 5.000 + 1e-5·2^(−i)、i = 0…4; M_B = M_A − 0.003; 他の量は同じで整定する系列) を `settle_judge.py` に通す。
  合格: A・B とも「整定」、設計の合否だけ A = 合格・B = 不合格。加えて、増分が減衰しない系列 (ρ = 1) は「推定不能」で整定しないこと。
- **S1 (CFL の腕)**: run_0014c の最終の場から cfl 5・10・20 を各 60k step (発散したら記録して打ち切る)。判定: (a) 各腕で §4.1 の整定に届く step、
  (b) 整定した腕どうしの値の差が 出口コア M ≤ 2.5e-4・Q ≤ 0.2 %・流量 ≤ 1e-4・δ_m ≤ 1e-4 r_t。(a) と (b) を満たす最も速い腕を以降の段取りにする。
  どの腕も整定しなければ判別未了 (諮問)。
- **S2 (帯位置の窓での固定)**: 整定した場の 5 枚で、窓で一度だけ選んだ帯位置の抽出と、毎回選ぶ抽出を比べる。判定: 窓の中の δ_E の max−min (使用域) が 固定 ≤ 1e-4 r_t、
  固定と毎回選ぶ抽出の平均の差は記録 (切り替わりが起きなければ一致するはず)。
- **S2b (持続の判定の検証、事前登録の案)**: (a) 窓をまたぐ再現性 — run_0010b (通算 60k〜120k) の非重複の窓 W1 = 70k・75k・80k・85k・90k、W2 = 100k・105k・110k・115k・120k で、
  各窓で帯位置を独立に選んだ抽出 (K = 4) の窓の平均の δ_E の差と、W2 の帯位置に固定した共通帯の抽出の差 (= 場の変化) を出し、**帯の再選択による差** (前者 − 後者) の最大 ≤ 1e-4 r_t (使用域)。
  K = 1 でも同じ量を出して比べる。(b) 非劣化 — case/45 の 4 対 (run_0038×0037・0036×0035・0034×0033・0022×0001) で K = 4 と K = 1 の δ_E の差を記録し、
  出口の端を除く x ∈ [0, x_e − 3] で ≤ 1e-4 r_t、出口の端 (hold の区間) は記録 (M6 に伝える)。(c) 単体: 1 段だけの偶然の交点は拾わず、K 段の平らな部分は今と同じ y*。
  (d) **NaN の区間の埋め方の A/B** (諮問 band-persistence): K = 4・ε・c・中央値・hold・後段は固定、変えるのは y* の連続した NaN の区間の埋め方だけ — A = 今の P-spline、B = その区間を両隣の有効点の A の `kappa_s` を結ぶ直線に置き換えてから同じ hold (有効点の値は変えない)。W1・W2 の各枚と case/45 の 4 対で、使用域の max|δ_E,B − δ_E,A| ≤ 1e-4 r_t (位置と NaN の区間の長さを記録)。超えれば生産への適用を止める。使用域・hold の基準位置で両側の支持点が無ければ確認不能 (合格にしない)。
- **S3 (M5 デモの再開)**: 前の設計 (run_0010 系) を S1 の段取りで整定 → S2 の δ_E でカードから作り直し → 新しい設計を整定 → 出口コア M を前身 §6 V5 で判定。
