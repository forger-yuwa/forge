## 1. 目的

case/70 (空気 M5、T_w 350 K / T_aw ≈ 1150 K) で、NS 後の δ_E でカードから作り直した設計の出口コア M が 5.000 ± 0.05 % に入るかを、定常の解で判定できるようにする。
前身の plan で次が未達のまま残った (前身 §6.1・§9):

1. 冷却壁の NS に非常に遅いモードがある: 残差が床に着いた後も、出口コア M が 10k step ごとに −1〜−2.5e-4 (cfl 1)・−5e-4 (cfl 5)、流量が +0.02 % で動き続ける
   (`case/70.m5_air_wt_demo/run_0014b〜d`、`run_0010b`)。補正の元にした NS の場もこのモードについて未整定だった。
2. 入力 δ_E の準定常 (前身 §6 V3e) と Euler 参照の厳密な受入れ (前身 §5.1 #5) を満たさなかった (Euler は残差が床で横ばい)。
3. 抽出の帯選択 (edge の縁 y* の推定) が場のわずかな違いで別の枝に切り替わり、x 2〜12 の δ_E を 5e-4 r_t 動かす (前身 §5.1 #5b)。

## 4. 設計方針

### 4.1 NS を定常にする (main のソルバの範囲で)

- M6 の B0 は main に無いキー (`lineDtDirectionalCap`・`implicitThermalJacobian`) に依るので、case/70 では使わない (M6 のブランチが main に入ったら再検討)。
- **擬似 CFL を上げる** (block-DPLUR、`implicitRelax` は使わない — 解を動かすことがある [[sern-cfl-no-implicit-relax]]): 同じ開始の場 (run_0014c の最終 = 通算 240k) から
  cfl 5・10・20 の腕で回し、遅いモードの量 (Q・出口コア M・流量・δ_m) が止まる速さと、止まった値が腕の間で一致するか (定常解は擬似時間の進め方に依らないはず) を見る。
- **整定の判定 (case/70 用、`case/70.m5_air_wt_demo/settle_judge.py`)**: 窓 = 5k ごとの 5 枚 (20k step)。量ごとに、窓の中の変化 |q_last − q_first| と
  推定の残りの変化 (末尾の増分が同じ符号で減衰しているとき、増分の比 ρ < 1 から Δ_last·ρ/(1−ρ); ρ ≥ 1・符号の反転・推定できないときは「推定不能」) を出す。
  許容: 出口コア M は変化・残りとも ≤ 2.5e-4 (絶対)、Q は変化 ≤ 0.1 %・残り ≤ 0.2 %、流量は変化 ≤ 1e-4・残り ≤ 2e-4 (相対)、δ_m は変化 ≤ 1e-4・残り ≤ 2e-4 r_t。
  全部満たし推定不能が無い最初の窓を「整定」とする。**目標範囲 (4.9975〜5.0025) は整定の条件に入れない** — 整定した後の設計の合否だけに使い、
  合否の値は「最後の値 + 推定の残りの変化」(codex 諮問 2026-10-13 settling-plan の Major: 目標を外れて整定した解を未整定として回し続けない)。
  M6 の `m9_watch.py` は case/45 の量を読むので流用しない。

### 4.2 帯位置の選び方

- c を上げるだけでは出口の δ_E が c で動く (§3.1) ので、c は 1.25 のまま。
- **帯位置を窓で一度だけ決める**: 判定の窓 (整定した後の 5 枚) の梯子を平均して縁 y* と帯位置 y_b(x) を一度だけ選び、窓の各枚はその y_b(x) で抽出して δ_E を点ごとに平均する。
  帯位置の切り替わりを窓の中で起こさない (前身 §5.1 #5b の固定の腕で差 2.4e-5)。設計の作り直しの入力はこの平均。

### 4.2b 帯選択の頑健化の方法 (2026-10-13 起案、諮問の前)

- **切り替わりの原因** (`ladder_probe.py`・`_ladder_probe/`、run_0010 の 50k・55k × run_0012): 縁 y* は梯子の R(y) = δ_r(1.25 y)/δ_r(y) − 1 が最初に |R| < ε (0.003) を満たす段
  (`deltastar.py:358`)。スロート付近 (x ≈ 0.7) では梯子が平らにならず (δ_r が帯位置で 1.6e-3 → 5e-4 と大きく変わる)、**一番内側の段で R が偶然 ±0.003 の中に入るかどうか**で、
  50k は y* = その段 (R +0.0018)、55k は y* = NaN (R −0.0037) になった。次の段は R −0.14。y* の有無が食い違う断面 67・20 % 以上変わる断面 38 (全 1800) が、直管・縮流部・スロート付近の
  δ_r が小さい区間に集まる。
- **方法案: 縁の判定に持続を要求する** — 交点から K 段続けて |R| < ε のとき、その最初の段を y* にする (無ければ NaN; NaN は今と同じく帯位置の平滑化で隣から埋まる)。
  偶然の 1 段だけの交点を拾わない。測定 (`band_persist_ab.py`・`_band_persist_ab/`、測定用の差し替え):

| K | case/70 50k→55k の δ_E の差 (使用域) | y* の有無の食い違い | case/45 run_0038 × 0037 の K=1 からの δ_E の差 (x ≥ 0) |
| --- | --- | --- | --- |
| 1 (今) | 5.4e-4 r_t | 67 | — |
| 4 | **6.3e-5** | 14 | 最大 4.3e-4 r_t (x 95.1 = 出口の端、0.063 %)、y* の NaN の割合 0.01 → 0.09 |
| 8 | 1.4e-4 | 28 | 同上 |

  **K = 4 を採る** (諮問 2026-10-13 band-persistence)。既定値にする (新しい標準は既定に; 旧の K = 1 は引数で再現できる)。case/45 の出口の端の 0.063 % の差は M6 の生産の壁に入るので、M6 のセッションに伝える。
  条件 (諮問の Major): NaN の断面を帯位置の平滑化で埋める効果と、縁を安定に見つけた効果を分けるため、**NaN の区間の埋め方だけを変える A/B** を S2b に足す。

### 4.4 ユーザ決定 (2026-10-13): 帯選択は実用として 5 枚の窓の平均で区切る

ユーザ「実用として 5 枚平均で区切る」(選択肢: 5 枚平均で区切る / 別の方法を試す / 止める)。
- **設計の入力の δ_E の標準**: 整定した場の 5 枚の窓 (5k ごと) で、各枚は帯を独立に選び (K = 1、既定)、δ_E を点ごとに平均する。hard・held の検査は各枚で行う (不合格を平均で消さない)。
- **既知の限界**: 梯子が平らにならない区間 (冷却壁のスロート付近・直管・縮流部) では 1 枚ごとに帯位置が切り替わり、局所で δ_E が 5e-4 r_t 動く。5 枚のうち 1 枚が切り替わると平均は 1.03e-4 r_t 動く
  (事前の基準 1e-4 をわずかに超える; `_band_switch_ab/`)。窓をまたぐ再選択の差は 6.1e-5 (run_0010b の 1 組)。
- 平らにならない区間の扱い (帯位置を平らな断面から補間する等) は、遅いモードと一緒に M6 の B0 の main 入りの後に再開する (§5.1 #3b)。

### 4.6 停止規則 (ユーザ決定 2026-10-14、§4.1 の整定の判定を置き換える)

ユーザ「質量の変化も入口ー出口で、平均値が 0.05% 以下 振幅は 0.5% 以下、とかにしませんか。Θ_r は … 0.5% にしよう。振幅は。平均値は 0.05% 以下にしようか。…移植に進んでくれていいよ」。
M6 の `m9_watch.py` (case/45 専用、forge-integ-1005 の feature/nozzle-wall-fit-and-pipeline) の考え方を設計チェーンに移す。M6 の判定 (窓の両端の差 ≤ 0.05 %/2 万 step) は
傾向と振動を混ぜるので、**平均の変化と振幅を分けて**判定する。

- **判定量**: (1) 質量の収支 r = (ṁ_in − ṁ_out)/ṁ_in (入口・出口の列の折れ線を通る流束、M6 の `cold_xcheck.reduce_fields` と同じ式)、
  (2) 境界層の運動量厚さ θ_r を 3 断面 (設計壁の出口 x_E に対する比 0.4・0.7・0.95; M6 の x = 40・70・94 は x_E 95.3 に対して 0.42・0.73・0.99) で
  (`reduce_fields` と同じ式: 一定 x の断面で帯の外縁 y_b の (ρ_e, u_e) を縁にした面積で等価な厚さ)。y_b は本段の間は固定する (帯の選び直しの段差を判定量に入れない)。
  **y_b = 本段の最初の出力を固定 Euler 参照 (`prepare_info.euler_ref`) で抽出した帯の位置** (`band_select="edge"` の y_b、すでに縁 y* の 1.25 倍なのでさらに掛けない;
  諮問 stop-rule (a))。`euler_ref` の無い run では停止規則を使えない (黙って別の縁にしない) — 本段は `ns_steps` の長さで回し、その旨を記録する。後期にも縁を覆うかは未確認 (記録して見る)。
- **窓**: 直近 2 万 step (出力の間隔に依らず step で)。窓に出力が 9 点以上 (M6 と同じ) を要求。
- **合格の条件** (全部): r は窓の平均の絶対値 ≤ 0.05 %・振幅 (窓の (最大 − 最小)/2) ≤ 0.5 %。θ_r は各断面で、
  **平均の変化を 2 万 step あたりに換算した Dθ = |後半の平均 − 前半の平均| / |窓の平均| × 20000 / (後半の平均の step − 前半の平均の step) ≤ 0.05 %**
  (諮問 stop-rule の Major: 換算しないと前後半の代表の時刻が約 1 万 step しか離れず M6 の「2 万 step で 0.05 %」より約 2 倍緩い。2 万 step に 0.08 % 単調に動く系列を止めてしまう反例)、
  振幅 ((最大 − 最小)/2 / 窓の平均) ≤ 0.5 %。満たした最初の出力で止める (連続は要らない; 諮問 (b)。ただし本段の履歴が実際に 2 万 step を覆い 9 点以上)。
  REACHED は「指定の量の停止の条件を満たした」の意味に限り、収束・設計の量の定常の VERDICT とは別に扱う。
- **状態**: REACHED (止めた) / CENSORED (上限まで正常に回って届かない = 未到達) / DIVERGED (非有限) / EXEC_ERROR (forge が上限より前に異常終了) / DATA_ERROR。
  M6 の見張りの欠陥 (チェーン経由で終了コードを後から書くので上限まで回った run を EXEC_ERROR と誤る) を避けるため、**`run_staged_ns` の本段の中で forge の子プロセスを持ったまま
  見張る** (終了コードはその場で分かる)。REACHED・DIVERGED では SIGTERM → 待って SIGKILL、止めた後に書かれた出力は消す。
- **上限**: 停止規則を使うときの本段の上限は M6 と同じ **20 万 step** (諮問 (c): M6 の到達 9.75 万・12 万 step は 60,000 を超える)。上限に届いたら CENSORED (合格ではない)。
  停止規則を使わないときの本段の長さは `evaluate.ns_steps` (既定 60,000)。
- **記録する量 (判定には使わない; 諮問 (d))**: 出口コア M・流量・δ_E は平均 ± 振幅で記録する (設計の合否は別、§4.1 の「整定と設計の合否を分ける」を保つ)。
- 閾値は M6 の実績を移しただけで、風洞の形状での妥当性は未確認 (§6 S-stop で既存の case/70 の run に当てて見る)。
- **既定と r (ユーザ決定 2026-10-14「1:a 2:今のまま」)**: 停止規則は既定で使い、上限 20 万 step。r は入口の列で測る (直管の質量の過渡を判定に含める)。
