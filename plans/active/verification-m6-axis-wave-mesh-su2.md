## 1. 目的

case/45 最終形 (`run_0038_ns_final_rt77p02`) の試験部で、軸 M が x≈70 r_t に局所的な山を持つ。親 plan はこれを
「x≈15–25 の積分法壁と抽出壁の δ 差 (~1 %) への軸の集束応答 (物理)」と推定したが、A/B で確かめていない。
ユーザ指摘 (2026-10-04): **軸中心の数値的な振動解** (軸近傍の解像不足・軸処理) の可能性がある。
これを (A) 軸近傍の半径方向細分と (B) 同一メッシュの SU2 比較で切り分ける。

## 2. スコープ

- **やる**: 軸側だけ細分したメッシュ 2 水準で run_0038 と同じ壁・設定を回し、山の高さの格子依存を見る (A)。
  run_0038 と同じメッシュ・壁を CPG に揃えて forge と SU2 の両方で回し、軸近傍の x 方向の局所構造を比べる (B)。
  `Mesh2DParams` に軸側の最大間隔の上限 (`axis_gap_frac`) を足す (既定 None で従来とビット同一)。
- **やらない**: 山を消す設計変更 (law 側帰還・δ 平滑化の変更) — 本 plan の結論を見て別 plan。SU2 側の軸細分。

## 4. 設計方針

### 4.1 腕 A: 軸側の半径方向細分 (TP, run_0038 と同じ壁・設定)

- `meshing/mesh2d.py::_radial_fracs` に `axis_gap_frac` (間隔 / r_w の上限) を追加。壁側は既存と**同じ第 1 セル・同じ比 q**
  (base の nj=97 から求めた q) で等比に伸ばし、間隔が上限に達したら軸まで一様にする (最後の一様区間は和が 1 になるよう等分)。
  nj は導出値になる。壁側の格子は base と同一なので、壁・境界層の解像は変わらない。
  **変わる範囲は「軸近傍」ではなくコア全体** (2026-10-04 レビュー m1): 一様化するのは A1 で η≲0.691 (nj 110)、A2 で η≲0.835 (nj 141)。
  したがって本腕が測るのは**軸境界の扱い単独ではなく、コア内の半径方向の離散化 (波の伝播の解像を含む) への感度**である。
- 水準: **A0′** = 上限なし (軸側 0.075 r_w、run_0038 と同一メッシュ) / **A1** = 0.025 r_w / **A2** = 0.0125 r_w。ni・x 分布・壁は同一。
  **比較の基準は旧 run_0038 ではなく、同じバイナリで回す A0′** (2026-10-04 諮問・レビュー M3: run_0038 の config は `limiterScaled` 未指定で、
  2026-09-20 に既定が 1 に変わった。旧バイナリとの差は格子効果と交絡する)。主比較は **A0′ vs A2**、A1 は単調性の補助。
- 壁: run_0038 と同じ δ_r (`run_0025_ns_ib_pass2_q/delta_r_next.csv`, ω=1.0)、同じ problem (`problem_d155_ns_rt77p02.yaml`)、r_t 77.02 mm。
  **壁の再抽出はしない** (δ 反復を回すと壁が変わり格子効果と交絡する)。
- 初期場: run_0038 最終場から `interp_field.py` で cross-mesh restart。設定は生産 warm レシピ (stages none / cfl 5 / implicitRelax 0.7 / 12000 step)。
- **A0′**: run_0038 の最終場を `restart_field.py` で同一メッシュ継続 12000 step。A1/A2 は同じ場から `interp_field.py`。
- 全腕で同じバイナリ (AWS `~/forge-axiswave` = commit `bc1c84d1` の native Release build)・同じ実効設定。`RUN_PROVENANCE.txt` で確認する。
- 出力は 1000 step ごと (山の時系列を取るため)。
- Euler 参照 run_0037 は副指標 b の分母にだけ使う。**b は max−median の非線形指標なので参照の誤差は腕間差で相殺しない** (レビュー M5)。
  主指標は NS どうしの直接差 (§4.3)。

### 4.2 腕 B: 同一メッシュの forge vs SU2 (CPG に揃える) — **第一手から外す (2026-10-04 諮問・レビュー M6)**

腕 A の後に回す。外した理由: (1) CPG ではガスと SST 補正 (dilatation/KL) が変わり、波の発生・伝播条件が別物になるので、
x∈[60,80] に山が無くても TP の仮説を棄却できない (腕 A と独立な検証にならない)。(2) 準備手順の欠陥: `prepare_ns` は
`cfd_gas: cpg` で設計チェーンごと CPG で**壁を作り直す**、旧 `sst.cfg` は出口圧 1389 Pa (run_0038 は 2237 Pa)、
入口乱流の対応が未確認。回すときは run_0038 のメッシュを直接複製・変換し (設計チェーンを通さない)、EOS・輸送係数・入口乱流・
出口圧の対照表を固定し、TP→CPG の初期場は CPG EOS でエネルギーを組み直す。結論は「CPG 条件でソルバ間差あり／検出できず」に限る。
SU2 の軸ノードが 2 % 級に低い件は**原因未同定のソルバ間差として保持**し、forge 側の正しさの証拠には使わない。

以下は外す前の案 (参考):

- SU2 は圧縮性で一定 γ しか扱えないので **両方 CPG γ=1.27354, R=292.13** (2026-10-04 ユーザ決定)。
  メッシュ・壁は run_0038 と同一 (`nozzle.msh` → `nozzle.su2`)。CPG では A/A* が合わないので流れは M6 にならないが、
  比べるのは同一形状・同一ガスでの**ソルバ間差の x 方向の局所構造**。
- forge は SU2 に合わせた素 SST (`dilatationCorrection: 0`, `katoLaunder: 0`; run_0013 と同じ)。SU2 は run_0012 の `sst.cfg`
  (ROE+MUSCL+Venkat、SST、Sutherland、断熱壁、axis = MARKER_SYM) を流用。初期場は forge CPG の収束場を SU2 restart CSV に書いて与える
  (`restart_flow.csv` の列: x, y, Density, Momentum_x/y, Energy, TKE, Omega)。
- SU2 はローカル CPU (12 コア、2026-10-04 ユーザ決定)。forge は AWS。

### 4.3 指標

- **M は `hypot(Ux,Uy)/sonic` で出す** (`VALUE/sonic`。無ければ停止)。初稿の予備値は TP にも一定 γ を使っていた誤り (レビュー M4)。
  修正後の run_0038 の b(0) は **0.2325 %pt** (4000/8000/12000 step で 0.2310/0.2317/0.2325)。
- **主指標 (直接差)**: D(x, η) = 100·(M_A2/M_A0′ − 1)、共通の (x, η) で補間。局所部 D̃ = D − median_{x∈[45,90]} D。
  max_{x∈[60,80]} |D̃| を η ∈ {0, 0.05, 0.10} で出す。
- 副指標: ΔM(x, η) = M_run(x, η) / M_E(x, η) − 1。各 station で η=r/r_w の行内線形補間、x 方向線形補間。M_E は run_0037。
- 山の高さ `b(η)` = max_{x∈[60,80]} ΔM − median_{x∈[45,90]} ΔM (%pt)。η ∈ {0, 0.05, 0.10, 0.20}。x≈30–40 の山も同じ定義
  (窓 [25,45]) で併記する。
- 腕 B: D_j(x) = M_forge/M_SU2 − 1 (節点一致、行 j)、x∈[30,94] で 2 次トレンドを除いた残差の最大値と位置。
  加えて forge CPG・SU2 CPG それぞれの軸 M に x≈60–80 の局所構造があるか (同じ 2 次トレンド除去)。

### 4.4 帯の選び方の修正と確認 A/B (2026-10-04 追加、ユーザ指示「帯の修正で壁を作り直して確認」)

- **修正案 (`band_select: "plateau"`)**: 断面ごとに帯の位置を y_b,k = max(1.5 δ_in, 0.02 r_w)·1.25^k (k = 0..9) と外へ並べ、各 k で帯を固定して δ_r,k を測る。
  **連続する 2 段の相対変化がともに plateau_tol (0.3 %) 未満になった最初の k** を採り、δ_r = δ_r,k+1 (3 点の中央)、感度欄に δ_r,k と δ_r,k+2 を入れる。
  見つからなければ hard 不合格 (`no_plateau`、前回値保持)。今の `adaptive` は「帯の中の比の傾き・残留欠損」で止めるが、
  本案は「**答え (δ_r) が帯の位置に依存しなくなったか**」で止める。既定は `adaptive` のまま (既存の結果は不変)。
- オフライン試験 (2026-10-04、run_0042 の場、帯固定の梯子): プラトー選択の隣接断面の跳びは最大 0.42 % (adaptive は 9.4 %、x≈38 で 1.8 %)。
  x ≥ 15 では 2.34〜3.66 δ_in、スロート側は 4.6〜7.2 δ_in で止まる。プラトー無し 16 断面 (x < 1)。
- **新バイナリの基準のずれ**: run_0042 (新バイナリ・最終壁) から測ると、δ_r / δ_in は 1.04〜1.06 (run_0038 旧バイナリでは 0.993〜1.002)。
  9/20 の limiterScaled 既定変更で境界層が厚く出ていると見られる (未確定)。そのため帯の効果だけを見る A/B にする:
  - **B0** `run_0045_ns_band_adaptive`: run_0042 の場から**今の抽出器 (adaptive)** で δ_r を作り (ω 1.0、P-spline λ 1 + 単調性ガード) 壁を作る。
  - **B1** `run_0046_ns_band_plateau`: 同じ場から **plateau** で作る。それ以外 (problem `problem_d155_ns_rt77p02.yaml`、r_t 77.02 mm、IC = run_0042 を interp_field、
    stages none / cfl 5 / implicitRelax 0.7 / 12000 step / 出力 1000 毎、AWS `~/forge-axiswave` = `bc1c84d1`) は同一。
  - 出口半径は δ が厚くなる分ずれる (仕様 0.775 m からのずれは記録のみ、r_t 補正は本 A/B の範囲外)。

## 6. 検証

**事前登録 (2026-10-04、run 投入前。codex 諮問・plan レビューを受けて改訂)**。

- **結論の範囲**: 本 plan が出すのは「**半径方向離散化への感度あり / 検出できず**」だけ。「物理」とは書かない
  (細分で不変でも x 方向誤差・共通の軸処理誤差・反復誤差が残る。細分で山が増えても物理の証明にはならない)。
- **前提**: 3 腕とも同一バイナリ・同一実効設定、NaN 0。品質は A0′ と同じ SOFT-PASS を許す (壁側格子は全腕同一で、最大 AR 1208 の位置も同じ)。
- **収束の扱い**: run_0038 は `check_convergence` が NOT CONVERGED (プラトー) で、`--from-floor` の参照に使えない。各腕の VERDICT を記録し、
  PASS でなければ結論に「残差プラトー下の探索的診断」と明記する。加えて**山の時系列**: b(0) と D̃ の末尾 5 スナップショット
  (1000 step 間隔) の変動幅 ≤ 0.005 %pt を要求する。満たさなければ 6000 step 延長を 1 回、なお満たさなければ判定保留。
- **判定 (A0′ vs A2)**:
  - **感度あり (粗格子が山を増幅)**: b(0) が A0′→A2 で **0.10 %pt 以上減る**、かつ max_{x∈[60,80]} |D̃(η=0)| ≥ 0.10 %。
  - **感度を検出できず**: |b(0; A2) − b(0; A0′)| ≤ **0.02 %pt**、かつ η ∈ {0, 0.05, 0.10} で max_{x∈[60,80]} |D̃| ≤ 0.03 %、山の位置のずれ ≤ 2 r_t。
  - それ以外 (中間値・増大・位置の移動・未定常) → **判定保留**とし諮問 (AGENTS エスカレーション条件 3)。閾値は広げない。
  - A1 は単調性の補助として併記する (判定には使わない)。
- 腕 B は §4.2 のとおり後回し。旧案の判定基準 (下) は使わない。
