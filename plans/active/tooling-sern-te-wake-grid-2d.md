## 1. 目的

2D メッシャ (`mesh_sern.py:256`) も 3D と同じく後縁の下流の中間線を θ_b で引くので、格子線が後縁で折れる。3D で採用した局所化 (`te_wake_mode: local`) と同じ方式を 2D に入れ、2D で独立に検証する (3D の成功で 2D を受理しない)。

## 2. スコープ

- **やる**: 2D メッシャへのオプション (既定 0 でビット一致)、2D runner の受け渡し、2D 用の格子検査 (品質・双対閉性・実際の辺の角度・層厚) と形状から作る監視領域、初期場の作り方、2D の判別 A/B。
- **やらない**: 3D の受入れ (起点 plan で完了)、$w$ 処置。

## 3. 関連 docs と前提

起点 plan §4 の「2D」の項 (codex plan レビュー 2026-10-08 M4): 既存の道具は 3D 専用 (`te_wake_grid_check._read_h5` はヘキサ接続を要求、`te_monitor.py` は側端を z = 0.1 m に固定)。2D に無い側端の領域は対象外、必要な領域が空なら判定不能。

## 4. 設計方針

起点 plan の 3D の局所化 (変形前の格子に $\delta(x)\varphi(d)$、0.02/0.30 H 固定、5 次の滑らかな関数) を 2D の断面にそのまま適用する。詳細は着手時に書き、codex plan レビューを受ける。

## 5. 実装ステップ

1. `mesh_sern.py` にオプション、2D runner の受け渡し、既定 0 のビット一致の試験。
2. 2D 用の格子検査と監視領域の生成。
3. 2D の判別 A/B (A = 0 で症状の再現、B = 局所化で起点 plan §6 #1〜#3 の合格)。
