## 1. 目的

今の物理壁は、区間ごとに別の式の和になっている。

- 入口直管の定数。
- 収縮部の 5 次 Hermite H(x)。
- 拡大部の 5 次 B-spline S(x) (係数 259 個)。
- 境界層の排除厚 δ_r(x)。δ_r は 2 段で作っている。
  - 第 1 段: ξ = √(x + 16.5) の 5 次 P-spline、係数 71 個。
  - 第 2 段: その 1500 点の値を通す 5 次補間スプライン (約 1500 区間)。

ユーザ決定 (2026-10-07):「設計側の平滑化そのものを x の B-spline に替える」「できれば共通化させたい」「(i) で、全域 1 本にして進めて」。

物理壁を、入口から出口まで 1 本の x の 5 次 B-spline (ノット列と係数) で表す。式を簡潔にし、CAD にそのまま渡せる形にする。

## 2. スコープ

- **やる**:
  - δ_r の平滑化を、x の 5 次 B-spline (不等間隔ノット、∫(δ_r‴)² dx の罰則) に替える。
  - 物理壁を全域 1 本の 5 次 B-spline に組み立てる。式がそのまま 5 次多項式になる所は厳密に、ならない所 (ランプ区間) は許容誤差つきの当てはめで。
  - メッシュ生成・報告・NS の準備がこの 1 本を使う。ノット・係数を書き出す (CAD 用)。
  - 生産に入れるかどうかの判断。物理壁が µm 級で変わるので、NS・凝縮の再評価が要る。MOC の軸処理の plan も生産に入れる場合は、再評価をまとめて 1 回にする。
- **やらない**:
  - 設計壁 (Euler が使う非粘性の壁) の変更。こちらは MOC の plan が扱う。
  - δ_r の物理モデル (CONTUR の積分法・k_f) の変更。
  - STEP/IGES などの CAD 形式への書き出し。ノット・係数の CSV/JSON までにとどめる。

## 3. 関連 docs と前提

- **今の δ_r の平滑化** (`design/forge_design/metrics/deltastar.py::smooth_delta_quintic`): 横軸 ξ = √(x − x₀ + 4) で等間隔のノット (x₀ = −12.5)、係数 71 個 (中央でノット間隔 ≈ 2 r_t)、係数の 3 階差分の罰則 λ = 1。当てはめの残差は相対 rms 1.9 %、最大 3.5e-4 r_t (run_0147)。
- **第 2 段の補間** (`runner_axismach.delta_r_from_table`): 1500 点 (0.0719 r_t 間隔) を通す 5 次補間スプライン。第 1 段との差は、値で 6e-11 r_t、2 階微分で 3e-7 (2026-10-07 の試算)。
- **物理壁の今の式** (r_t 単位):
  - [−12.5, −12) は 6.485。
  - [−12, −11) は H。[−11, −6) は H + s·δ_r。[−6, 0) は H + δ_r。ランプは s = 10ξ³ − 15ξ⁴ + 6ξ⁵、ξ = (x + 11)/5。
  - [0, x_e] は S + δ_r。
  - 継ぎ目 (−12・−11・−6・0) で 2 階微分まで連続。
- ランプ区間の H + s·δ_r は、区間ごとに 10 次の多項式になるので、5 次 B-spline では厳密に書けない。

## 4. 設計方針

### 4.1 δ_r の平滑化 (x 空間)

- 5 次 B-spline in x。内部ノットは、今の ξ の等間隔ノットを x に戻した位置に置く。変換には固定値ではなく、今のコードの実際の `x0`・`x_stretch` を使う (`metrics/deltastar.py:654`)。今と同じ係数の数で、スロート側で密になる。
- 罰則は λ ∫(δ_r‴)² dx。区間ごとの Gauss 求積で厳密に評価する。不等間隔ノットでは、係数の差分の罰則は意味がずれるため。
- **λ の決め方** (2026-10-07 諮問で改訂): 有効自由度 (EDF) が今と等しい λ は、残差 2.66 % (今 1.90 %) で不合格になる (諮問の独立試算)。EDF は診断値として記録するだけにする。
  - 「残差の相対 rms ≤ 今 × 1.1 (2.09 %)」と、§6 W1 の局所形状の条件をすべて満たす λ のうち、最大のもの (最も滑らか) を選ぶ。λ は対数で走査し、走査の範囲と刻みを記録する。
  - 条件を満たす λ が無ければ、ノット数を変えずに諮問する。
  - 先に判別 A/B を記録する: 同じ x の基底・入力・重みで、λ = 0 と EDF が等しい λ を比べる (諮問の試算では 0.68 % と 2.66 %)。
- 断熱壁の「δ_r ≥ 0」の切り落とし (`positive`) は、新しい経路では**発火したら不合格**にする (発火すると滑らかさが壊れるため。今の生産では最小 0.0011 r_t で発火していない)。
- 新しい平滑化は、δ_r を使うすべての入口に同じものを通す: 積分法初期化 (`prepare_ns`)、`delta_r_csv` の経路、δ* ループの抽出 (`deltastar_loop.py:88`・`:93`)、C2 の較正器 (`c2pin_solve.py`)。係数とノットをそのまま渡し、CSV 入力の意味 (平滑化前か後か) と旧データからの移行方法を明記する。

### 4.2 全域 1 本の B-spline の組み立て

- 区間ごとの式 (§3) から、1 本の 5 次 B-spline を組み立てる。
  - 直管 (定数)、[−12, −11) の H、[−6, 0) の H + δ_r、[0, x_e] の S + δ_r は、5 次の区分多項式なので、ノットの和集合の上で厳密に書く (変換誤差は丸め程度)。
  - 継ぎ目では、元の連続性に合わせてノットを重ねる (2 階微分まで連続の継ぎ目は重複度 3)。
  - ランプ [−11, −6) は H + s·δ_r が 10 次なので、区間を細かいノットで分けて最小二乗で当てはめる。値・1〜2 階微分を両端で合わせる拘束つき。
    - 合格条件: 半径の誤差 ≤ 0.1 µm (1.3e-6 r_t) に加え、ランプ全域で 1 階・2 階微分の誤差の上限を設ける (半径誤差の振幅 ε・幅 h の振動は r″ に ε/h² で出るため)。上限は Δr′ ≤ 1e-6、Δr″ ≤ 1e-4。区間多項式の極値で検査する。
    - 今のランプのゲート (`max|r″ − r″_design| ≤ 0.005`、`max r′ < 0`、`wall_axismach.py:399`) も維持する。
    - 満たすまでノットを細かくする (ランプ内部の追加ノットは単純ノット)。
  - ノットの重複度: 通常の内部ノットは単純、2 階微分まで連続の継ぎ目は重複度 3、全域の両端は重複度 6。同じ位置のノットは重複度を足さず、要る最大の重複度を取る。
- 結果は `PhysicalNozzleWall` と同じ呼び出し (`r(x, deriv)`・`x_in`・`x_e`) で使えるクラスにし、メッシュ生成・報告・NS 準備はそれを使う。
- ノット列・係数・次数を run の `prepare_info.json` と、別ファイル (CSV/JSON、m 単位と r_t 単位) に書き出す。
- **CAD 向けの仕様** (諮問 ⑦): 書き出すのはスカラー関数 r(x) の係数 (x が助変数)。平面曲線として渡す場合は x(u) の係数も要る。次数・ノットの重複度・定義域・単位・軸方向を仕様に書く。物理単位に直すと n 階微分は r_t^(1−n) 倍になることも検査する。

## 6. 検証

### 6.0 事前登録 (初稿 2026-10-07、諮問の前)

- **W0 既定のビット同一**: キー無しで、今の物理壁 (run_0147 の `wall_physical.csv`・メッシュの座標) と完全一致。design/tests の既存テストが FAIL 0。
- **W1 δ_r の新しい平滑化** (単調壁の生産問題、CFD 0 step):
  - 記録: 今の δ_r との差 (値・1〜3 階微分の最大と位置)、当てはめの残差 (相対 rms・最大)、EDF、選んだ λ と走査の範囲、物理壁の変化 (最大と位置、出口)。
  - 合格:
    - 残差の相対 rms ≤ 今 × 1.1 (2.09 %)。`positive` の発火なし。
    - 新旧の物理壁の関数を、同じ座標・同じフィルタで直接評価した r″ の高周波 (0.5 r_t 移動平均からの残差) が、ランプ・スロート近傍 (x ∈ [−1, 2])・下流 (x > 2) のそれぞれで今以下。報告の `r2_highfreq_max_x_gt2` は CSV の再補間で x > 2 だけを見るので、参考値にとどめる。
    - 単調壁の形状ゲート S6 (物理壁の r″ の最大増加 ≤ 0.002) が PASS。
  - **C2 較正**: 較正器 (`c2pin_solve.py`) にも新しい平滑化を通す。CFD 0 step では、今の k_f・r_t での新しい較正式の残差と、出口半径を記録する (諮問の試算で出口 +4.3 µm)。出口半径の変化だけを根拠に「較正し直さなくてよい」とは決めない。生産評価 (W4) で、出口半径 0.775 m ± 0.1 mm と δ_E/δ_C = 1 ± 0.5 % を別々に判定し、定常化したうえで外れたら、新しい平滑化で C2 の r_t・k_f を解き直す。未定常なら較正せず保留。
- **W2 全域 1 本の表現**: 区間ごとの式との差。厳密に書く区間は ≤ 1e-10 r_t。ランプ区間は §4.2 の条件 (半径 ≤ 1.3e-6 r_t、Δr′ ≤ 1e-6、Δr″ ≤ 1e-4、今のランプのゲート)。継ぎ目の 1〜2 階微分の跳び ≤ 1e-8、それ以外の区間内は 4 階微分まで連続。ノット数と係数の数を記録する。
- **W3 生産の入口の再現**: `prep_c2pin.py`・`deltastar_loop --init-integral` に加え、`delta_r_csv` の経路と、δ* ループの抽出・C2 の較正器が同じ平滑化を使い、同じ 1 本の B-spline と同じメッシュを作ることを確かめる。
- **W4 NS・凝縮の再評価** (生産に入れる場合): monotone plan の §6 N・K と同じ手順・ゲート。MOC の plan も入れる場合は、**MOC 単独の検証と本 plan の形状検証 (W1〜W3・W5) を先に終え、最終形状と較正値を固定してから** N → K を回す。2 つの変更をまとめた受入試験なので、個別の影響は判別できない。失敗しても、交絡したまま原因を断定しない。
- **W5 下流の道具**: メッシュ品質 (AR ≤ 5000・skew ≤ 0.9) が PASS。報告 (nozzle_report) が新しい壁の関数そのものを評価していること (CSV の再補間でないこと) を確かめる。書き出したノット・係数を**独立の評価器** (scipy の `BSpline` を使わない de Boor の自前実装など) で読み、値・接線・曲率・継ぎ目が元と ≤ 1e-12 r_t (曲率は相対 1e-9) で一致すること、物理単位への変換で n 階微分が r_t^(1−n) 倍になることを確かめる。
