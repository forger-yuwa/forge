## 1. 目的

旧テンソル積メッシャ (g3) の SERN で、厚さ 0 のカウル後縁の近くの内部節点が非物理に冷え、m10_on で温度床 50 K に到達して評価が不成立になっている (R7b 4-2)。
機序は node + SLAU の 2 次再構成の速度の外挿 (後流側の面で全エンタルピーを運び出す) と診断済み。端の近傍に限った局所の扱いで床到達を無くし、旧メッシャのまま m10_on の評価を成立させ、設計ループ (R7b) を再開できる状態にする。

## 2. スコープ

- **やる**: 自由端の近傍集合 $S_2$ の定義と作成、$S_2$ の速度の再構成をセル値にする opt-in の処置 (node + SLAU)、判別 A/B、恒久対策としての受入れ (m10_on の評価成立・他作動点の感度・設計差の取り直し・他ケースの回帰)。
- **やらない**: 床値の変更・床ゲートの除外・`bndFirstOrder`・勾配配列のゼロ化・節点 ID を固定した生産処置・全ケースのリミッタ変更・流れの閾値検出器やスキーム変更 (第一手として却下、§4)。有限厚の全ヘキサとの差を温度誤差の上限と呼ぶこと。

## 3. 関連 docs と前提

- 診断の事実 (codex diagnose 2026-10-08 [記録](../../notes/reviews/2026-10-08-sern-te-reconstruction-fix-diagnose.md) と、そのブリーフ `notes/reviews/briefs/2026-10-08-sern-te-reconstruction-fix.md`):
  m6_on で後流側の 1 面の速度の外挿 (セル 10 → 1333 m/s) が低温を維持し、その 1 面をセル値にすると低温が消える (力の感度は許容の 1/100 以下)。m10_on では同じ 1 面の介入で冷点が隣の第 1 層 (517199) へ移り、
  その冷却は EOS 前の更新 (対流を含む残差) で説明できる (`notes/investigations/2026-10-05-sern-r7a/R5H_M10_LEDGER100.txt`、EOS の上書きは call 50 で −1.746e-2 J/kg に対し更新 −1.499e3 J/kg)。
- 現行のリミッタは近傍の成分別 min/max を参照する (`limiter_d.cu:323`)。診断介入は `FORGE_DIAG_FACE_VEL_CELL` (`convectiveFlux_slau_d.inc.cuh:279`、1 面・片側の速度だけ)。
- SLAU は残差を `atomicAdd` で組み立てる (`convectiveFlux_slau_d.inc.cuh:661`) — 長時間の run 全体のビット不変は保証できない。

## 4. 設計方針

**判断: 2026-10-08 codex (diagnose) — 全件採用。第一手は幾何で限定した速度の再構成の抑制 (診断案)。流れの閾値検出器・成分別上下限制約・流束の変更は第一手として却下** (今回必要なのは「範囲逸脱」の実証で、大きい速度の外挿だけではその証拠にならない。成分別に有界でも別々に再構成した ρ・U・P からのエネルギー流束の妥当性は保証されない)。

- **端集合 E**: 指定した板の上下の壁面タグ (SERN では `cowl_in` と `cowl_out`) が**同じ節点 ID の辺を共有する自由端**の節点。後縁の線と露出した側端を含む。座標一致だけで別 ID の節点を結合しない (旧メッシャの共有処理は `mesh_sern3d.py:271`)。
- **$S_2$**: 内部面の接続グラフで E から距離 2 以下の節点 (グラフの 2 リング。壁法線の「2 層」とは区別)。記録上 517199 は壁点から 1 接続、517160 は 2 接続なので両方を含む診断用の最小候補。
- **作用**: $S_2$ の節点に接する全内部面で、**その節点側だけ** Ux・Uy・Uz の再構成をセル値に戻す (相手も $S_2$ なら両側)。勾配配列・粘性・壁 BC・密度/圧力/組成の再構成は変えない。速度二乗・面エンタルピー・質量流束を計算する前に適用し、1 つの面流束を両節点へ逆符号で加算 (保存)。
- **適用範囲**: node + SLAU の**明示 opt-in** (設定キー、例 `space.zeroThicknessEdgeVelocity: {tags: [cowl_in, cowl_out], rings: 2}`)。空の集合なら旧経路 (面値・面流束はビット不変)。
- **記録**: E・$S_2$ の節点数・面数、実座標での広がり、対象体積を起動ログと出力に。異方格子なのでリング数だけでは物理的な広さを表せない。
- **段階**: (1) 判別 A/B (§6.1) で「$S_2$・速度限定の処置で 517199 と 517160 の両方を救えるか」を判別 → (2) 合格なら恒久対策としての受入れ (§6.2)。短い診断だけでは R7b を再開しない。

## 6. 検証

### 6.1 判別 A/B (事前登録 2026-10-08、codex diagnose)

**変えるのは $S_2$ の速度再構成抑制の OFF/ON の 1 点。主判定は共通状態の 1 更新、続く 100 call は冷点移動の早期監視**。
1. 起点 `run_1055_r7b_m10_A_c` (保存済み) から旧単面介入 (`FORGE_DIAG_FACE_VEL_CELL`、面 1535833・節点 517160) で再生し、517199 が床に達する前の冷却状態 (既存集計の **call 10 相当**) を退避する。再生した状態で冷却が確認できなければ判定不能。
2. 同じ退避状態から 2 枝: **A** = 旧単面介入のみ、**B** = それに $S_2$ の速度抑制を追加 (旧単面介入は両枝に共通、差は追加した範囲だけ)。バイナリ・実効設定・種 DB・リミッタ基準値・時間積分設定をそろえる。
3. 517160・517199 と $S_2$、その外側 1 リングについて、面別流束、対流・粘性・その他の残差、実保存量増分、EOS・境界補正を別々に記録。内部エネルギー射影 $\Pi = R_{\rho E} - \mathbf u\cdot R_{\rho\mathbf u} + (|\mathbf u|^2/2 - e_{int}) R_\rho$ を有限幅の実更新と混同しない。
4. **結果 A**: 対照で負の Π と負の実内部エネルギー更新を持つ 517199 が、B では両方とも非負になり、517160 も冷却側へ戻らない → 局所速度処置の設計を進める (§6.2 へ)。
   **結果 B**: 閉合・介入が正常でも満たさない → $S_2$・速度限定処置の十分性を棄却 (速度再構成一般の関与までは否定しない)。**冷点が外周へ移る場合も不合格で、結果を見てリングを継ぎ足さない**。
   閉合誤差が介入差の 1 % または丸め誤差上限を超えれば判定不能。100 call の昇温・床消失では定常性や正しい温度を認定しない。

### 6.2 恒久対策の受入れ (事前登録 2026-10-08、§6.1 が結果 A のとき)

- **m10_on の評価成立**: `run_1055` の最終場から処置ありで 20000 step (未定常なら既存規則どおり +20000 を 1 回)。末尾 10000 step の全保存場で温度床到達 0、同区間の毎更新で**新規の床違反・床による保存量補填なし** (EOS 前の床違反と保存量補正量も監視)、全域とマスク外周で冷点移動なし、他の物理ゲート。
  全残差の `check_convergence` と 4 力量の `check_quasisteady` の VERDICT を区間付きで残す (プラトー受理の方針は維持、収束とは呼ばない)。
- **窓と感度**: 力量の前後 10000 step 平均差は C_T・C_T_with_shear・C_L ≤ 5e-5、C_M ≤ 5e-4。m6_on・m4_off の処置前後で $D_q = |\text{平均差}| + \max(a_A, d_A, 10^{-6}) + \max(a_B, d_B, 10^{-6})$ (a = 半振幅、d = 前後窓平均差) にも同じ閾値。
  これは小さい感度の認定基準で、超過は修正の誤りと断定せず**旧評価の持ち越しを止める**。
- **設計差**: 成立する対照で $\delta = (q_{1.0} - q_{0.8})_{処置あり} - (q_{1.0} - q_{0.8})_{処置なし}$ を 4 評価の変動幅込みで判定。床を含む m10_on の旧結果には適用しない。修正後の 3 作動点で g3/g4・領域感度を取り直し、加重目的とその不確かさで判断 (0.002 は各作動点の必須改善量ではない)。
- **温度場**: 床の有無に加え、固定した物理位置・領域で T・P・U・組成・h0 の断面と熱・エネルギー収支、局所格子細分と処置範囲 (リング数) への感度。鋭い端の 1 点の T を合わせることは基準にしない。
  有限厚の全ヘキサ接続模型は補助資料 (内壁位置・外部領域が違い、側方上部を `vehicle` 壁で閉じている) — 「正しい温度」の定量的認定は保留。
- **他ケース**: `case/66` の node 構成で回帰。対象の端が無いケースは空マスクで、共通状態の面値・面流束 (決定的) をビット比較、組立残差と時間発展は**変更前だけで校正・凍結した許容幅**で比較 (`procedures/verification/README.md`)。2D SERN・case/49 など端を持つ格子は、マスクが実際に発火するかを先に確認し、発火するケースを空マスク回帰で代用しない。
- **R7b の再開条件**: m10_on の評価成立と必要な回帰を満たしてから、修正後の設計比較へ。
