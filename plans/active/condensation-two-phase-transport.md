## 1. 目的

凝縮 ON の NS run で、液相を水蒸気として扱っている輸送の近似を正す。現状 (2026-09-27 コード読み取り):

- kinetic 輸送 (`viscMethod: 2`) の組成は `roY` (H2O は蒸気 + 液の総水分) から作り、液相分率 `g` を参照しない (`cuda_forge/gasProperties_d.cu:71-85`)。
  液の質量も水蒸気の分子として μ・λ・拡散係数の混合に入る。
- 化学種拡散は総水分 `Y_w` の勾配を気相の拡散係数 (分子 + 乱流 `μt/(ρSc_t)`) で Fick 拡散させ、蒸気のエンタルピー h_v を運ぶ。
  **液 `rog` (凝縮モーメント) は拡散しない** (受動拡散 `passiveDiffusion_d_wrapper` はトレーサからしか呼ばれない, `tracerTransport_d.cu:176`;
  2026-09-27 訂正: 当初「液は別経路で受動拡散」と書いたのは誤り)。したがって拡散で動くのは実質「蒸気」で (g は不変)、エネルギー勘定は蒸気として整合しているが、
  駆動勾配が `∇Y_w` (蒸気でなく総水分) である。差 (蒸気) の非負性は拡散では保証されず、毎ステップの実現可能性クランプ `0 ≤ rog ≤ roY_w`
  (`condensationRealizability_d.cuh:92-113`, 液を削る = 強制蒸発, 総水分・エネルギーは保存) に頼っている。

完了時には、μ・λ・拡散係数は気相組成で評価され、拡散は「蒸気の勾配で分子拡散・液は分子拡散なし (任意で微小な液 Sc)・乱流は同じ Sc_t」になり、
蒸気の非負性が拡散作用素の構造で保たれる (クランプは保険として残し、働いた量を監視する)。

## 2. スコープ

- **やる**:
  - (A) 輸送物性 (μ・λ・化学種拡散係数) を**気相組成** (蒸気 `Y_w − g`、`1 − g` で正規化) で評価する。液滴の懸濁効果 (粘性増加・有効熱伝導) は無視 (2026-09-27 ユーザ決定)。
  - (B) 拡散: 総水分の分子拡散流束を蒸気の勾配 `−ρD∇(Y_w − g)` に、液 `rog` の分子拡散は既定で 0 (安定化用に**微小な液シュミット数を任意指定**できる選択肢を残す; ユーザ要望)、
    乱流拡散は総水分・液とも同じ `Sc_t`。輸送変数 (`roY_w`, `rog`, モーメント) は分け直さない。
  - (C) 監視: 実現可能性クランプの液の補正量 (累積, 総液量比) を凝縮 run で常にログと判定ツールに出す。
- **やらない**: 液滴の懸濁効果のモデル化、二温度 (液滴温度) の輸送への反映、液滴の慣性・スリップ。

- ~~エネルギー項の現状 (旧記述: 乱流で運ばれる液が h_v を運び受け手の温度が高く出る)~~ → **2026-09-27 訂正**: 液は拡散しないので、拡散で動くのは蒸気で h_v は整合。欠けているのは**液と蒸気が逆向きに乱流混合することで運ばれる潜熱流束** `L·ρD_t∇g` (目標モデルでは質量は打ち消し、エンタルピーは L ぶん残る)。以下の見積もりはその量の旧解釈による値:見積もり (次元解析のみ): 誤差 `L·J_g` と乱流熱流束の比 ≈ (L/cp)(Δg/ΔT)(Pr_t/Sc_t) ≈ 2500 K × (0.01/50 K) ≈ 0.5、g が 1 % 動くごとに温度誤差 ~L·Δg/cp ≈ 25 K の規模。境界層に液が入る NS + 凝縮 run で効き得る。

- **流束の実測 (2026-09-27, `case/16.nozzle_wys/analyze_liquid_diffusion_error.py`, 最終スナップショット)**: `run_0483` (旧経路) / `run_0482` (S3) の g>1e-4 のノードで、
  「液の勾配による余計な蒸気分子流束 / 本来の蒸気分子流束」= 1 (全点) = 入口組成一様で Y_w がほぼ一様なので**現行の水の拡散流束はほぼ 0**。

## 4. 設計方針 (codex plan 段 NO-GO を反映して改訂 2026-09-27; 上位諮問 §5.1 #1 待ち)

### 4.1 (A) 気相組成の輸送物性

- **2026-09-27 改訂 (輸送物性の作り直し後)**: μ・λ は種ごとの輸送物性 (`viscMethod: 2` + `physProp.transport`; plan `thermophysics-solver-owned-species-db` §4.3c、`feature/species-transport`) になり、セル・壁とも `transport_mix_Y` / 表引き `transport_mix_Y_tab` (`cuda_forge/transportMix_d.cuh`・`transportTables_d.cuh`) が輸送種の Y から組成を作る。旧 Wilke 経路は撤去済み。
- 凝縮 carrier (TP) のとき、この入口に渡す組成を気相組成にする: `Y_s^gas = Y_s/(1−g)` (s ≠ 凝縮種), `Y_w^gas = (Y_w − g)/(1−g)` (液を除き再正規化)。その後は通常どおり輸送種 X → lump 展開 → CEA 形混合。
  変更は組成を作る関数 (表引き `gas_transport_cell_rY`・直接評価 `gas_transport_cell_Y`・壁・probe・拡散係数の組成) を 1 つの気相組成関数に通すことに限り、`transport_mix_Y` の式は変えない (§5.1 #3)。
- 化学種拡散係数 (混合平均、`thermo_Dmix_species_f`) も同じ気相組成で評価する。CPG carrier (空気) と `viscMethod 0/1` は組成を見ないので変更なし。

### 4.2 (B) 拡散作用素 — 気相内の分子拡散 + 全相共通の乱流混合 (2026-09-27 改訂, codex plan 段 C1/M2/M4/M5 反映)

記号: 気相密度 `ρ_g = ρ(1−g)`、気相内の質量分率 `z_k = Y_k/(1−g)` (k ≠ 水)、`z_v = (Y_w − g)/(1−g)`。輸送変数は現行のまま
(`roY_k`, `roY_w` = 総水分, `rog` と `Q0/Q1/Q2`)。

- **分子拡散 (気相のみ)**: `j_k⁰ = −ρ_g D_k ∇z_k` (k は水蒸気を含む全気相種、D_k は §4.1 の気相組成で評価した混合平均)、
  補正は**気相内で** `j_k = j_k⁰ − z_k Σ_j j_j⁰` (`Σ_気相 j_k = 0`)。駆動変数は混合物基準の Y ではなく気相基準の z
  (旧案の `−ρD_k∇Y_k` は D_k が種ごとに違うと、気相一様・g 非一様で偽の分離流束 `ρ z_k (D_k − Σ z_j D_j)∇g` を作る: codex C1)。
  液の分子拡散は 0。**有限 `Sc_l` は本 plan では実装しない** (§5.1 #8 に分離。g だけ拡散すると Q3 が動き実現可能性 `Q2² ≤ Q1Q3` を壊す、
  小さい Sc_l は強い拡散である: codex M5)。
- **乱流混合 (全相共通)**: 全輸送量 (気相種の Y_k、総水分 Y_w、液 g、Q0/Q1/Q2 を質量当たりにしたもの) に同じ `−(μt/Sc_t)∇(·)`。Σ∇Y = 0 なので補正不要。
- **組み立て**: 総水分の流束 `J_w = j_v + J_t(Y_w)`、液 `J_l = J_t(g)`、蒸気 `J_v^tot = J_w − J_l = j_v + J_t(Y_w − g)`。
  エネルギー流束 `Σ_{k≠水} h_k J_k + h_v J_w − L(T) J_l` (h_l = h_v − L; 既存 EOS `e = e_gas + g(R_wT − L)` と同じ基準。
  L 項と EOS の −L r_g が相殺して温度に効くのは −R_wT r_g、§3)。**液と Q の乱流流束を入れずにエネルギーだけ直すことは禁止**。
- **面流束を 1 回だけ作り共有する** (codex M4): 新カーネル `twoPhaseDiffusion` が面ごとに上の流束を作り、化学種残差・`rog`/Q 残差・エネルギー残差・
  dual-time FCT の低次作用素と面流束履歴 (`passiveFct_d.cuh` の `qDiff` を液・Q・総水分へ拡張) に同じ値を足す。
  呼び出し位置は**全残差の初期化 (`passiveAdvection_d_wrapper` の液残差ゼロ初期化) の後、境界ピン・周期集約の前**。凝縮 TP では既存の化学種拡散
  (`speciesTransport_d.cu:259` 付近) の水・気相種の分子拡散をこれで置き換え、二重に足さない。
- **更新の契約 (codex M2 + diagnose 2026-09-27)**: 保存を求めるのは**離散方程式**である。定常 (局所 dt の擬似時間) では収束した固定点が、
  dual-time では各物理時間ステップで解き切った状態が、**全輸送量で共通の輸送行列 (移流 + 本節の拡散の非対角を含む) を持つ保存形の後退 Euler / BDF 方程式**を満たすこと。
  点対角 (蒸気: 分子 + 乱流、液・Q: 乱流) はその反復の前処理にすぎず、1 擬似反復ごとの保存は求めない (局所 dt の擬似時間は forge の全保存量で 1 反復ごとには保存しない)。
  ただし前処理を種ごとに変えると中間状態の比 (液/総水分) がずれるので、蒸気 `ρv = ρY_w − ρg` と液 `ρg` を変数に増分を作り `Δ(ρY_w) = Δρv + Δρg` で戻す。
  拡散の離散形は現行と同じ二点差分 (`speciesTransport_d.cu:263`; 非直交補正は現行も無い)。
  化学種の再正規化で `ρY_w` に掛けた係数を `ρg` と Q にも掛ける (現行は液更新の前に水だけ再正規化される, `main.cpp:2094` 付近)。
  実現可能性クランプは保険として残し §4.3 で監視する。**再正規化・クランプで吸収した後に保存を判定しない** (§6)。
- **対象外 (明示)**: CPG carrier (空気凝縮, `speciesEnabled` を通らない単成分) は本 plan では現行のまま (液は拡散しない)。起動ログに
  「CPG carrier: 二相拡散は未対応」と出す。cell 離散化は経路のコード確認のみで実行検証しない (「cell 未検証」と記録)。

### 4.3 (C) 監視 (codex M6 反映)

- 理由別に計上する: 蒸気上限違反 (`g > Y_w`)、負値 floor、増分制限 (`condensationTransport_d.cu:388` 付近)、モーメント射影、液滴消滅 (物理)、化学種再正規化の係数偏差。
- 各々について区間値 (ログ間隔ごと) と累積、制限前の最小蒸気分率と違反ノード数を出す。総液量比は液量が 0 のとき絶対量で出す。累積は restart で 0 から (ログに明記)。
- 判定: 液滴消滅以外の数値補正の区間値が総液量比 1e-6 を超えたら WARN (閾値は #2 の基準取得で見直す)。
