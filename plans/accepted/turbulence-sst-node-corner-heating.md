## 1. 目的

case/16 の 3D 半幅 node SST (run_0220/0222/0226/0227) で、側壁∩輪郭壁の**角線に沿って壁温が入口全温 Tt を +5〜+11 K
(バッファ無しでは +41 K→NaN) 超えて上がる**現象を止める。判定基準は「角部の T が上がり続けず、Tt を超えない」(実験との
壁圧の一致度は本 plan の対象外)。

6ν/(β₁y²)、k 13、μt/μ 6e-4、T−Tt −2 K。2D node SST (run_0213) も同じく解析値と一致。3D **層流** (run_0221) は角でも T−Tt −7 K。

角線近傍の第一内点列 (y₁=0.61 µm, z_i ≤ 21 µm) は ω ≈ 5〜7e8 で、平坦壁の第一内点 (5.7e9) の **1/10**、解析値の 1/30。
その隣接壁ノードの ω ピンは 1.8e11 (側壁側は 2.8e10) で正常、wall_dist も 0.61 µm で正常。**ピンでも壁距離でもなく、
角近傍のノードで ω 輸送の解が壁近傍の漸近解から 10〜100 倍下に外れている**。その結果 k が粘性底層まで減衰せず
(wd 2.5 µm で k 1.9e3、平坦壁は 13)、μt/μ が角の第一〜数点で O(1〜50) になる。

角の高温プラグ (T−Tt ≈ +9 K、幅 ~200 µm、|U| 0〜70 m/s) は k ≈ 4e3 ≈ cp·ΔT に対応する大きさ。

### 2.1 追加観測: 角線ノードの双対 CV 構造は原因ではない (別セッション, 2026-09-07, ローカル RTX 3060)

「角線ノードは双対 CV が内部セルと接しないためおかしくなる」仮説を run_0220 の場と判別実験で検証した
(図と数値は Artifact「角線ノード仮説の検証」、run 一覧は case/16 README)。

- **構造は事実**: 2.08M 六面体の角線ノード 694 個 (輪郭 347 × 上下) はエッジ隣接が全て壁ノードで、内部ノードとの双対面を持たない。
  壁関数の代表点探索 `wf_irep` (エッジ隣接のみ) はこの構造で候補なし → u_τ=0 に退避する (wallTreatmentSST=1 を 3D で使うときの罠)。
  ω ピンの y_eff は 2-ring で拾えている (角線 ω = 隣接 ω)。
- **値は連続**: run_0220 res_12000 の角線 T−Tt / P / ω は隣接壁ノード (側壁側 Δy 0.6 µm・輪郭側 Δz 2 µm) と 0.01 K / 0.01 % 以内で一致し、
  角線に局所スパイクは無い。角線ノードは u=0・ω ピン・残差射影後に壁ノード間伝導と圧力しか残らない受動ノードで、値を生む側ではない。
- **高温域は境界層合流域**: T>Tt は 506k ノード (24 %)、うち角線は 376。側壁上で輪郭壁から ≤1.5 mm、輪郭壁上で側壁から ≤1〜3 mm。
  T0 超過は throat 直後 (x≈2〜5) の側壁 BL から始まり x とともに増大、出口角で +19.8 K (2D run_0213 の T0 超過は +2.0 K が上限)。
- **同一トポロジの粗メッシュは健全**: 同じ生成器で x 半分・NY 60・z 25 (z₁ 2 µm 同一, y₁ 0.6→1.8 µm) の 257k 六面体 (角線構造は同一) を
  run_0220 と同手順で回すと、node (`run_0300_corner_node3d_sst_coarse`) も cell (`run_0301_corner_cell3d_sst_coarse`) も
  **T>Tt のノード 0**、T0 最大 +2.3 K、出口角 P 頭打ち (check_quasisteady pmax/machmax STEADY; node は rms_ro 3.0 桁↓)。
  → 加熱は角線の隣接構造ではなく、近壁解像度 (y₁ 0.6 µm × z₁ 2 µm の異方角セル / AR) に依存する ω 不足 (§3 H1) 側の問題。
- **引き金は輪郭壁 y₁ 0.6 µm 側の異方角セル**: (x,y) を 2.08M と同一 (y₁ 0.6 µm) にして z だけ 25 節点にした
  `run_0302_corner_node3d_sst_finexy_z25` (1.04M, QC は AR>1000 が 0.66 % で FAIL の診断 run) で加熱が**再現**した:
  T>Tt 151k ノード (14.5 %)、出口角壁 T−Tt +2.1→+5.2→+6.7→+7.1 K (2000→8000 step, 上昇中)、角壁 P 12.2→13.5 kPa 上昇、x=60 角壁 +3.3 K
  (check_quasisteady pmax/machmax STEADY だが角壁 T/P は単調上昇; rms_roOmega plateau 1.3e-1)。角線トポロジは 3 run 同一、z は粗いままなので、
  H1 の ω 不足は角セルの (dy 0.6 : dz 2 : dx 420) 異方性 / 高 AR に依存する離散化の問題。R2 の収支 dump と R1 の検証はこの 1.04M メッシュ
  (ローカル RTX 3060 で soft/mid/8000 step 約 55 分) で回せる。
- **別件の欠陥 (wall_dist の値位置)**: node 変換の `wall_dist` は `calcWallDistance_kdtree` が `cells[ic].centCoords` (converter では双対 CV 重心) を
  query 点・壁点の両方に使うため「双対重心 → 最寄り壁ノードの双対重心」の距離になっている (2.08M・257k とも全ノード 0.1 % 以内で一致)。
  側壁第 1 層 1.57〜1.67 µm (真値 2.0, −17〜−22 %)、輪郭壁は −0.15 µm オフセット。solver 側は `nodeValueAtNode` で centCoords をノード座標に
  置換するが converter には効いていない。§2 表の wd 0.61 も同じ定義。ω ピンの y_eff (=隣接の wall_dist) も同率で小さい。修正は別 plan
  (converter で node のとき `nodes[ic].coords` を使う)。

### 2.1 追記: 出口処理後の時系列 (run_0226→0227, 通算 36000 step)

出口バッファ 20 mm (slip, `wallDistExtraPhysIDs` で壁距離に算入) + 出口静圧固定 10.3 kPa + `wall_y_eff` 修正で、角線 T−Tt は
12000 step の +9.4 (x=46) / +10.9 (x=85) から 36000 step で +0.7 / +1.8 へ単調減少 (x=16 は −1.1)。壁 p/p0 は頭打ち
(0.3199→0.3282 @x=46)。**「上がり続ける」挙動は出口角 (3 境界共有ノード) 起因で、出口処理で止まった**。残るのは §2 の
角近傍 ω 不足 (k 未減衰・μt 過大) による壁圧の +29 % 過大 (実験比) で、これが本 plan の対象。

## 3. 仮説

- **H1 (主)**: 角近傍で ω が壁漸近解を大きく下回る (原因は未特定: 2 壁を共有する双対 CV の拡散流束 / 高 AR (dx 420 : dz 2〜20 :
  dy 0.6 µm) 双対面の ω 拡散離散化 / 角の隣接構造)。ω 不足 → k 未減衰 → μt 過大 → 角の乱流熱伝導と粘性仕事で加熱。
- **H2 (副)**: エネルギー式は E = e + ½u² (k を含まない) で、粘性仕事項に (μ+μt) を使う一方 k 式は P_k−ε を別勘定にしている。
  局所平衡 P_k≈ε が成り立つ所では無害だが、角のように P_k ≫ ε (ω 不足で k が溜まる) では平均流から奪った仕事が
  熱として二重に入り得る。H1 が直れば顕在化しないが、一般の整合性問題として残る。

## 3.5 codex レビュー結果 (2026-09-08, read-only, ログ scratchpad/codex_review_corner.log)

- **P0 (真因)**: `scalarTransport_d.cu` `scalar_diffusion_first_order_d` の `safe_denom = max(|d·S|, 1e-12)` は [m³] の
  **絶対値**床。3D の µm 級双対面では |d·S| ~ 1e-15 で、k/ω の拡散コンダクタンスが角第一内点で 1/1400、角 i=3 で 1/900、
  平坦壁第一内点でも 1/4〜1/8 に削られていた (凍結場解析: 角第一内点の実装 ω 拡散 +3.17 が源項合計 −3.17 と釣り合う
  別平衡)。床が解除される wd≈200 µm と高温プラグ幅 ~200 µm が整合。**相対ガード max(|d·S|, ε|d||S|) へ変更**が第一対策。
  非直交補正が無い点 (dphidx 未使用) は直交格子では副次的。
- **P1**: R1 (全ノード ω 床) は不適切 — 壁ノードで特異 (ω 1e21 が壁ピン 1e11 を壊す)、保存形 ρω の未計上ソース、
  `ransSource` 内の局所床では ω を持ち上げられない。診断用に限定し、P0 修正後に要否を再判定。
- **P1**: H1 の下流因果 (ω 不足→k 高止まり→μt≈ρk/ω 過大→応力仕事と cp μt/Prt 熱伝導で異常輸送) は妥当。F1=F2=1。
- **P2**: 境界半割面 skip は無関係 (W–I 面は両端実ノードで内部ループを通る)。wall_y_eff は要監査だが符号が逆 (ピンを高くする側)。
- **P2**: H2 の「P_k ≫ ε」は当該スナップショットと不整合 (P_k/D_k = 0.9〜1.0)。整合性問題自体 (E に k が無く P_k−D_k の相殺項が無い)
  は実在 → R3 は別 plan (SU2 型 E=e+u²/2+k か、E_mean に −(P_k−D_k) 源)。
- **P2 (別件)**: ω 生産が αρS² (修正 SST の αP_k/νt でない、比 0.92〜1.07)、σk/σω が F1 ブレンド無し、壁 k=0 が ghost 反射のみ
  (壁ノードをピンしない)、dilatationCorrection 2 の −2ρk divU/3 に対応する等方 Reynolds 応力が運動量に無い。
- **安価な診断**: 内部面の |d·S|/1e-12 と cosθ の分布、ω 残差の項別分解、相対ガードだけ変えた同一 restart A/B、
  相似メッシュの無次元拡散残差一致テスト。

## 4.0 (旧案の記録)

### 4.1 R1: 粘性底層の ω 下限 (推奨・一次対応)

全ノードで $\omega \ge \omega_{visc}(d) = 6\nu/(\beta_1 d^2)$ を課す ($d$ = wall_dist, β₁=0.075)。Menter (1994) の壁漸近解で、
$1/d^2$ で減衰するため対数層 ($\omega \sim u_\tau/(\sqrt{\beta^*}\kappa d) \propto 1/d$) より遠方では自動的に不活性になる。
平坦壁では既に解が漸近解に乗っている (上表) ので**変化しない**。角近傍だけ ω が 10〜100 倍持ち上がり k が減衰する。
実装: `ransSource` または `dependentVariables` で roOmega を床置き (config `sstOmegaSublayerFloor: 1`, 既定 0)。
Wilcox (2006) が第一〜数セルに解析 ω を課す "rough-wall/sublayer" 処方と同種。

- 利点: 局所・保存則に触れない・平坦壁で不変・数行。
- 懸念: 床が能動な領域では ω 式の解を上書きするので、根本原因 (H1 の離散化) を隠す。
  → **床の発動ノード数と位置を診断出力**し、角近傍以外で発動したら原因追跡へ戻す。

### 4.2 R2: 角近傍の ω 拡散離散化の原因追跡 (根治)

角の第一内点で ω 収支 (拡散 in from 2 壁 / 破壊 / 対流) を dump し、平坦壁の同じ wd の点と比較する。疑う所:
node 境界半割面の k/ω 拡散 skip (plan diffusion-node-boundary-real-distance) が **2 壁共有 CV** で W↔I 双対面の
実距離を過大にしていないか (角 CV は 3 方向に高 AR)。

### 4.3 R3: エネルギー式の k 整合 (H2, 長期)

E に ρk を含める (SU2/OpenFOAM 流) か、粘性仕事の μt 分と (P_k−ε) の整合を取る。全ケースに波及するので別 plan。

### 4.4 やらないこと

- 角線ノードの k/ω 特別処理 (ピン・スムージング): 症状の上書きで、平坦壁との整合が崩れる。
- 壁関数 (wallTreatmentSST 1): node 壁関数の Cf 欠損が既知 (別問題を持ち込む)。
