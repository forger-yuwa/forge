## 1. 目的

forge の共役熱伝達 (`fem2d`) を、**固体の熱抵抗と固体内の軸方向 (流れ方向) 伝導が結果を左右する**条件で、
forge と独立な参照解と比べて検証する。2 つのケースを置く。

- **A. 厚肉管の共役 Graetz (軸対称)**: 管壁の外面の一部だけを有限の Robin 条件 (外部温度 T_c・熱伝達率 h_o) で加熱する。熱は壁の中を軸方向にも伝わり、
  加熱区間より上流の壁とガスまで予熱する (Faghri & Sparrow 1980、Barozzi & Pagliarini 1985 の型)。
- **C. 共役平板 (平面)**: 一様流の中の有限厚さの平板。板の下面を一定温度に保ち、上面は層流境界層と熱をやり取りする (Luikov 1974 の型)。

完了時: 両ケースで界面温度・界面熱流束・積分量が、登録した許容差内で独立参照解と合うことを run と VERDICT つきで言える状態。局所 Nu は分母 (T_i − T_b) が十分大きい領域での参考量で、合否に使わない (codex plan レビュー m7)。

**分割 (2026-09-30、codex diagnose [`notes/reviews/2026-09-30-conjugate-benchmarks-closure-diagnose.md`](../../notes/reviews/2026-09-30-conjugate-benchmarks-closure-diagnose.md))**:
§1 の完了条件は両ケースの成立だったが、C は前提ゲート (流体収束・G-if) が FAIL のまま原因が未確定なので、**C を後継 plan に登録条件・失敗結果・完了条件ごと移し**、この plan は **A の限定された部分結果**で閉じる。
**分割を事前登録の総合 PASS に読み替えない**。A の結論 (2026-09-30 確定、評価版 `70b155cd`): 「**FP64・node・forge の流れ場を固定した伝熱問題**として、固体の軸方向伝導と熱抵抗が効く軸対称の共役伝熱 (上流へ 15 % / 35 % の熱が壁を伝って回り込む) で、**§4.6 の事後改訂 (上流延長の感度を U から外して別記) を含む同一有限領域の比較条件**のもと、forge の界面温度・熱流束・積分量・固体の効果は N_r 32・64 (A1・A2 とも) で全項目許容内。最も粗い N_r 16 は A1・A2 とも `FAIL (一部判定不能)`。参照を 4 水準に 1 段細分しても不確かさ込みで FAIL が残る。A1 は差単独でも許容超 (加熱区間の温度 1.25 %)、A2 は差単独では許容内 (熱流束 1.875 % < 2 %) で U を足して超える — forge の粗格子誤差の寄与を示唆するが、参照側の寄与は排除していない (A2 の加熱区間の熱流束の差は r16→32→64 で 1.78 → 0.44 → 0.11 %)。代表格子の選定は事後」。以前の版 (A2 r64 の Q_up を判定不能とした等) は §5.1 #6b・#6c に履歴として残す。
float32、流れ場自体の正しさ、共役伝熱一般への拡張はしない。

## 3. 前提

- 固体の外側の境界条件は Robin (h, T_c) のみ (`solidFem2d`)。Robin を置かない辺は断熱。
  **一様熱流束を巨大な T_c の Robin で代用する案は使えない** (2026-09-29 codex diagnose): 固体温度の安全ガード (`conjugateWall.cpp`:985) が
  固体温度を「min(T_c) − 20 以上・流体全温の最大 + 20 以下」に制限し、T_c ≈ 1e7 K では許容区間が空になって全節点で停止する
  (保存場での再現: h 1e-4・T_c 1e7 で拒否 2115/2115 節点、h 100・T_c 315 K で 0/2115)。**加熱は有限の h・T_c の Robin にする**。
- 前身の知見: 強制形の等温・共役壁は細かいセルで `cfl_pseudo` 5 だと起動時に崩れる (2 で安定)。有限 M の散逸は ΔT=0 の対照 run を差し引いて扱うが、差し引きは流れの変化まで消すことを保証しない。
- FP64 ビルド・`FORGE_CUDA_BLOCKSIZE=128`・node。

## 4. 設計方針

### 4.1 独立参照解 (case 側、`conjugate_ref.py`)

**主判定の参照解 (2026-09-29 codex diagnose で変更)**: forge の保存場の **ρ・u・v・p を固定**し、流体と固体の温度を一つの節点中心有限体積系で解く
(前身の `temp_reproduce.py` の流体側を固体まで拡張したもの):
流体 ρc_p **u**·∇T = ∇·(k_f∇T) + Φ + **u**·∇p、固体 ∇·(k_s∇T) = 0、界面は温度と熱流束の連続、軸方向伝導は両方に含める。
**界面温度・界面熱流束は参照解の未知数として解く** (forge の界面温度を境界条件に与えない)。
入口・遠方・固体外面の条件は forge と同一 (加熱 Robin を含む)。
**主張は「与えられた流れに対する伝熱・連成の検証」に限る** (流れの正しさは別の前提検査)。対照 run の差し引きは使わず、**絶対温度・絶対熱流束**で比べる。
不確かさ: 参照格子を**最低 3 水準** (forge の流れ場を補間して写す) で変え、参照の離散化・写像・領域切断・反復の不確かさの合計を出す。
合否は **観測差 + 不確かさ ≤ 許容幅**、不確かさが許容幅の 1/3 を超えたら判定不能。
自己検査: (i) 固体を消し Poiseuille・源項なしにすると前身の `graetz_ref.py` (ellip) と一致、(ii) 全体の熱収支、(iii) k_s→大で等温壁の解に近づく。

**参考の参照解**: 解析的な流速 (A: Poiseuille、C: Blasius) と源項なしで同じ共役問題を解き、forge との差を参考として出す (流れの差が混ざるので合否に使わない)。

### 4.2 A: 厚肉管 (case/64)

- 流体は前身と同じ (R = 1 mm、M 0.05、Re 1000、Pr 0.72、Pe 720、放物入口)。**壁は全長にわたって共役** (上流・加熱区間・下流)。
- 固体殻 R ≤ r ≤ r_o、**r_o = 2 mm** (候補)、k_s/k_f = **10 と 100 の 2 水準** (候補)。外面は加熱区間 0 ≤ x ≤ L_h だけ **有限の Robin 加熱 (h_o, T_c)**、それ以外は断熱。管の両端面の固体は断熱。
- **登録するパラメータ** (§5.1 #3b の参照解サーベイで選ぶ): r_o/R、k_s/k_f、Pe、**L_h/R、上流長/R、下流長/R、Bi_o = h_o r_o/k_s、(T_c − T_in)/T_in**。
  上流長は、参照解で予熱が入口側で十分減衰する長さ。伝導比の 2 水準は**同じ加熱条件**で比べる (温度上昇を合わせ直さない)。
- 上流に回り込んだ熱の割合は同じ単位 (per rad) で Q_up = R ∫_{up} q_i dx、Q_total = r_o ∫_{heat} h_o (T_c − T_o) dx。
- 評価量: 内壁の温度 T_i(x) (上流の予熱を含む全長)、界面熱流束 q_i(x) (固体からガスへ)、局所 Nu = q_i D/(k_f (T_i − T_b))、上流に回り込んだ熱の割合 Q_up/Q_total。

### 4.3 C: 共役平板 (case/65)

- 一様流 U_∞ (M 0.1 程度)、層流、板長 L で Re_L ~ 1e4。板の厚さ b、下面を Robin (h 大) で T_h に保つ。板の両端面は断熱。
  前縁の上流に slip 区間、上境界は遠方 (slip または自由流)。
- Luikov 数 Br = (k_f/k_s)(b/L) Pr^{1/3} Re_L^{1/2} (厚さ方向の抵抗の効き) と、**板の軸方向伝導の効き (固体方程式の軸方向項と厚さ方向項の比 (b/L)²)** を別々に指定する。**b/L と k_s を登録** (§5.1 #3b)。
- 主判定の参照解は forge の流れ場を使う (§4.1)。Blasius の参照解は参考。評価窓 x/L ∈ [0.2, 0.9] (候補)。
- 評価量: 界面温度 T_i(x)、界面熱流束 q_i(x)、局所 Nu_x。

### 4.4 共通の評価

- 前身の評価器の作法を流用: 期待節点集合で REFUSED、`iface_ok`、全節点の準定常、u_it、負例試験。
- **対照差し引きは主判定に使わない** (前身の温度診断は判定不能に終わった。加熱で ρu と源項が変わるので差を取っても同じ線形方程式にならない)。有限 M の散逸と圧力仕事は参照解の源項に含める。
- **「固体が効いている」ことの登録指標** (等温固体との差だけでは熱抵抗と軸方向伝導を分けられない): (i) 固体の厚さ方向の温度差 ΔT_s(x)、(ii) 固体断面を通る軸方向熱量 Q_ax(x) とその空間変化が界面熱収支に占める割合。
  **各効果が測定不確かさの 5 倍以上、かつ対応する主判定の許容幅を超える**条件を選ぶ。
- 予熱の末端など T_i − T_b が不確かさに近い所では局所 Nu を主判定に使わず、温度と熱流束を使う。

### 4.6 不確かさの出し方 (plan レビュー M4、主参照に適用)

主参照 (forge の流れ場を固定) の不確かさ U は、次を**別々に**評価して各判定量に換算し、足し合わせる:
(a) 参照格子の細分化 (3 水準、補間した同じ流れ場で) の最後の差、(b) 流れ場の写像 (双線形 ↔ 3 次) の差、
(c) 散逸・圧力仕事の微分方式 (2 次 ↔ 片側を 1 段上げた方式) の差、(d) 領域の切断 (C: 上境界を 1.5 倍に、A: 上流を 1.5 倍に) の差。
**事後改訂 (2026-09-30、codex disposition [`2026-09-30-conjugate-A-result-disposition-diagnose.md`](../../notes/reviews/2026-09-30-conjugate-A-result-disposition-diagnose.md) の (ii))**:
(d) は比較の U に**入れず**、「問題定義の感度」として別掲する。forge と参照は同一の有限領域・同一 BC の問題を解いており、上流延長は入口位置・固体端面位置・源項の範囲を変える。
根拠: 合成の正常ケースで延長を U に入れると全長温度の U が 2.46 % (上限 0.33 %) になり、参照解そのものでも判定不能になる。
**旧登録条件 (延長を U に含む) での判定履歴は残す** (この改訂を旧登録の PASS に読み替えない)。延長感度の原因は A/B (`ext_source_ab.py`: 追加区間の源項だけを 0 にする) で確かめる。
入力流れ場の微分・補間に共通する誤差は (a) だけでは見えないので (b)(c) で見る。**合否は |観測差| + U ≤ 許容幅、U > 許容の 1/3 なら判定不能**。
主参照の前に次の試験を通す: 製造解 (済)、非零 v・源項の平面試験 (済、製造解に含む)、**散逸の軸上極限** (Poiseuille で Φ = μ(du/dr)² を解析値と照合、軸上 v/r → ∂v/∂r)。

### 4.7 実行・評価条件の固定 (plan レビュー M5、run の前に固定)

- **判定量と符号**: q_i = −`iface_q_eff` (流体へ向かう熱を正)、比較位置は forge の壁節点、参照解は同じ x に補間。
  A の温度は (T_i − T_in)、規格化は加熱区間の壁温上昇の長さ平均。A の q_i は加熱区間の外面から入る熱流束の長さ平均で規格化。C の温度は θ_i、q_i は窓内の q_i の長さ平均で規格化。
  誤差ノルムは窓内・全節点の最大。積分量 (Q_up・Q_tot) は台形則で端点を含める。
- **収束**: `check_convergence.py <run>` (単一区間、全列)。
- **準定常**: 全窓節点の (T_i − T_in)/(規格化尺度) と q_i/(規格化尺度)、積分量の系列を `check_quasisteady.py --series-csv --tail 0.5 --drift D --osc D` に渡す。D = 比較許容の 1/5 (A 温度 0.002、q 0.004、C θ 0.002)。**絶対温度そのままの系列には掛けない** (相対変動の分母が 300 K になり意味を失う)。
- **G-if**: `eps_abs_Wm2` = 窓内の最小 |q_i| の 0.5 %、`eps_rel` 1e-3、`dT_K` = 1e-4 × 規格化温度、`tol_solid` = 窓内の節点荷重の 1e-5、`n_consec` 80 (値は参照解から run の前に数値で書く)。**G-cons**: `check_cht_balance.py --q-floor Q_tot --tol-rel 1e-3 --tol-abs 1e-3·Q_tot`。
- **出力**: 保存間隔は連成間隔 50 の倍数にしない。**順序**: メッシュ品質 → 乾式 1 step の境界帰属 → 評価器の負例試験 → 本番 run (起動 `cfl_pseudo` 2、IC は A: Poiseuille、C: 一様流)。格子変更で restart しない (各格子を IC から)。
- **C の上境界**: slip (断熱)。参照解も上端は断熱。
